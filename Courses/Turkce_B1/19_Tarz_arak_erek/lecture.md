## 1. Что такое деепричастие способа действия

Деепричастие способа действия выражает способ, каким выполняется действие. В турецком языке это выражается суффиксом -arak/-erek.

### 1.1 Основная концепция

**Пример: Способ действия**

```
Gülerek konuştu.
Он говорил, улыбаясь (буквально: улыбаясь говорил).
```

**Объяснение:**
-erek выражает способ выполнения действия "говорить" — "улыбаясь". Деепричастие показывает, как выполняется основное действие.

**Пример: Другой случай**

```
Koşarak geldi.
Он прибежал (буквально: бегом пришел).
```

**Объяснение:**
-arak выражает способ прихода — "бегом".

---

## 2. Образование деепричастия способа

### 2.1 Правило образования

**Формула:**
```
Основа глагола + -arak/-erek
```

**Шаги образования:**

1. Берем основу глагола
2. Добавляем суффикс -arak/-erek (с учетом гармонии гласных)

**Пример: Процесс образования**

```
Глагол: gülmek (улыбаться)
Шаг 1: Основа - gül-
Шаг 2: Добавляем -erek → gülerek
Результат: Gülerek konuştu.
Он говорил, улыбаясь.
```

**Объяснение:**
Образование деепричастия способа происходит в два этапа: основа → суффикс -arak/-erek.

### 2.2 Таблица форм

**Таблица образования:**

| Последняя гласная | Суффикс | Пример |
|------------------|---------|--------|
| a, ı | -arak | çalışarak |
| e, i | -erek | gelerek |
| o, u | -arak | okumak → okuyarak |
| ö, ü | -erek | görmek → görerek |

**Пример: Для разных глаголов**

```
çalışmak → çalışarak
gelmek → gelerek
okumak → okuyarak (особый случай)
görmek → görerek
```

**Объяснение:**
Выбор между -arak и -erek зависит от последней гласной основы глагола.

## 3. Особые случаи образования

### 3.1 Глаголы, оканчивающиеся на гласную

**Пример: okumak → okuyarak**

```
okumak (читать) → okuyarak (читая)
görmek (видеть) → görerek (видя)
almak (брать) → alarak (беря)
```

**Объяснение:**
Для глаголов, оканчивающихся на гласную, добавляется -y- между основой и суффиксом для плавности произношения.

**Пример: Детальный разбор**

```
okumak → oku- (основа) + -y- (соединительная буква) + -arak = okuyarak
görmek → gör- (основа) + -erek = görerek (без -y-, так как уже есть согласная)
almak → al- (основа) + -arak = alarak (без -y-, так как уже есть согласная)
```

**Объяснение:**
Правило добавления -y- применяется только для глаголов, оканчивающихся на гласную, перед суффиксом -arak/-erek.

### 3.2 Глаголы с согласными

**Пример: С согласными**

```
çalışmak → çalışarak
gelmek → gelerek
yazmak → yazarak
```

**Объяснение:**
Для глаголов, оканчивающихся на согласную, суффикс добавляется напрямую.

**Пример: Детальный разбор**

```
çalışmak → çalış- (основа) + -arak = çalışarak
gelmek → gel- (основа) + -erek = gelerek
yazmak → yaz- (основа) + -arak = yazarak
```

**Объяснение:**
Для глаголов с согласной на конце соединительная буква -y- не нужна.

### 3.3 Таблица особых случаев

**Таблица образования:**

| Тип глагола | Пример | Образование | Результат |
|------------|--------|-------------|-----------|
| Оканчивается на гласную | okumak | oku- + -y- + -arak | okuyarak |
| Оканчивается на согласную | çalışmak | çalış- + -arak | çalışarak |
| Мягкие гласные | gelmek | gel- + -erek | gelerek |
| Твердые гласные | çalışmak | çalış- + -arak | çalışarak |

**Пример: Для разных типов глаголов**

```
okumak → okuyarak (гласная + -y- + -arak)
çalışmak → çalışarak (согласная + -arak)
gelmek → gelerek (согласная + -erek)
görmek → görerek (согласная + -erek)
```

**Объяснение:**
Выбор формы зависит от типа окончания основы глагола и гармонии гласных.

## 4. Практические примеры

### 4.1 Пример: Разные контексты

```
Gülerek konuştu. (способ)
Он говорил, улыбаясь.

Koşarak geldi. (способ)
Он прибежал.

Yavaşça yürüyerek gitti. (способ)
Он пошел, медленно идя.

Hızlıca koşarak geldi. (способ)
Он быстро прибежал.
```

**Объяснение:**
В этом примере показано использование деепричастия способа в разных контекстах.

### 4.2 Пример: Реальные ситуации

**Пример: Разговор о действиях**

```
Gülerek konuştu.
Он говорил, улыбаясь.

Koşarak geldi.
Он прибежал.

Yavaşça yürüyerek gitti.
Он пошел, медленно идя.
```

**Объяснение:**
Деепричастие способа используется в реальных ситуациях для описания способа выполнения действий.

**Пример: Разговор о движениях**

```
Hızlıca koşarak geldi.
Он быстро прибежал.

Yavaşça yürüyerek gitti.
Он медленно ушел.

Sessizce gelerek oturdu.
Он тихо пришел и сел.
```

**Объяснение:**
Деепричастие способа используется для описания способа движения.

### 4.3 Пример: Сложные предложения

```
Gülerek konuştu ve koşarak gitti.
Он говорил, улыбаясь, и ушел, бегом.

Yavaşça yürüyerek gitti, ama hızlıca döndü.
Он медленно ушел, но быстро вернулся.
```

**Объяснение:**
Деепричастие способа может использоваться в сложных предложениях.

## 5. Дополнительные примеры

### 5.1 Пример: С наречиями

```
Hızlıca koşarak geldi.
Он быстро прибежал.

Yavaşça yürüyerek gitti.
Он медленно ушел.

Sessizce gelerek oturdu.
Он тихо пришел и сел.
```

**Объяснение:**
Деепричастие способа может использоваться с наречиями для более точного описания способа действия.

**Пример: С разными наречиями**

```
Hızlıca koşarak geldi. (hızlıca - быстро)
Он быстро прибежал.

Yavaşça yürüyerek gitti. (yavaşça - медленно)
Он медленно ушел.

Sessizce gelerek oturdu. (sessizce - тихо)
Он тихо пришел и сел.

Dikkatlice okuyarak anladı. (dikkatlice - внимательно)
Он внимательно читая понял.
```

**Объяснение:**
Наречия усиливают описание способа действия, делая его более точным и выразительным.

### 5.2 Пример: С разными временами

```
Gülerek konuştu. (прошедшее)
Он говорил, улыбаясь.

Gülerek konuşuyor. (настоящее)
Он говорит, улыбаясь.

Gülerek konuşacak. (будущее)
Он будет говорить, улыбаясь.
```

**Объяснение:**
Деепричастие способа может использоваться во всех временах.

**Пример: С разными временами для разных глаголов**

```
Koşarak geldi. (прошедшее)
Он прибежал.

Koşarak geliyor. (настоящее)
Он прибегает.

Koşarak gelecek. (будущее)
Он прибежит.

Yürüyerek gitti. (прошедшее)
Он ушел пешком.

Yürüyerek gidiyor. (настоящее)
Он идет пешком.

Yürüyerek gidecek. (будущее)
Он пойдет пешком.
```

**Объяснение:**
Деепричастие способа согласуется с временем основного глагола, но само не изменяется по времени.

### 5.3 Пример: С разными лицами

**Пример: Для разных лиц**

```
Ben gülerek konuştum. (1 лицо)
Я говорил, улыбаясь.

Sen gülerek konuştun. (2 лицо)
Ты говорил, улыбаясь.

O gülerek konuştu. (3 лицо)
Он говорил, улыбаясь.
```

**Объяснение:**
Деепричастие способа не изменяется по лицам, но согласуется с лицом основного глагола.

### 5.4 Пример: С отрицанием

**Пример: Отрицательные предложения**

```
Gülmeden konuştu. (отрицательное деепричастие)
Он говорил, не улыбаясь.

Koşmadan geldi. (отрицательное деепричастие)
Он пришел, не бегая.

Yürümeden gitti. (отрицательное деепричастие)
Он ушел, не идя пешком.
```

**Объяснение:**
Деепричастие способа может использоваться в отрицательной форме с суффиксом -meden/-madan.

## 6. Сравнение с другими деепричастиями

### 6.1 -arak/-erek vs -ip

**Пример: Сравнение**

```
Gülerek konuştu. (-arak/-erek - способ)
Он говорил, улыбаясь (способ говорения).

Gülüp konuştu. (-ip - последовательность)
Он улыбнулся и заговорил (последовательность действий).
```

**Объяснение:**
-arak/-erek выражает способ выполнения действия, а -ip выражает последовательность действий.

### 6.2 -arak/-erek vs -ince

**Пример: Сравнение**

```
Gülerek konuştu. (-arak/-erek - способ)
Он говорил, улыбаясь (способ).

Gülünce konuştu. (-ince - время)
Когда он улыбнулся, он заговорил (время).
```

**Объяснение:**
-arak/-erek выражает способ действия, а -ince выражает время действия.

### 6.3 Когда использовать -arak/-erek

**Используйте -arak/-erek для:**
- Описания способа выполнения действия
- Выражения того, как выполняется действие
- Одновременных действий, где одно показывает способ другого

**Пример: Способ действия**

```
Gülerek konuştu. (способ говорения)
Он говорил, улыбаясь.

Koşarak geldi. (способ прихода)
Он прибежал.
```

**Объяснение:**
-arak/-erek используется для выражения способа выполнения основного действия.

## 7. Частые ошибки

### 7.1 Ошибка: Неправильный суффикс

❌ **Неправильно:**

```
Gülarak konuştu. (неправильно)
Он говорил, улыбаясь.
```

✅ **Правильно:**

```
Gülerek konuştu. (правильно)
Он говорил, улыбаясь.
```

**Объяснение:**
Нужно использовать -erek для глаголов с мягкими гласными, а не -arak.

### 7.2 Ошибка: Неправильное образование для глаголов с гласной

❌ **Неправильно:**

```
Okumak → okurak. (неправильно)
Читать → читая.
```

✅ **Правильно:**

```
Okumak → okuyarak. (правильно)
Читать → читая.
```

**Объяснение:**
Для глаголов, оканчивающихся на гласную, нужно добавлять -y- между основой и суффиксом.

### 7.3 Ошибка: Неправильное использование

❌ **Неправильно:**

```
Gülerek konuşmak. (неправильно для инфинитива)
Улыбаясь говорить.
```

✅ **Правильно:**

```
Gülerek konuştu. (правильно)
Он говорил, улыбаясь.
```

**Объяснение:**
Деепричастие способа используется с личными формами глагола, а не с инфинитивом.

### 7.4 Ошибка: Смешение с другими деепричастиями

❌ **Неправильно:**

```
Gülerek konuştu ve gitti. (неправильно, если это последовательность)
Он улыбнулся и ушел.
```

✅ **Правильно:**

```
Gülüp konuştu ve gitti. (правильно для последовательности)
Он улыбнулся, заговорил и ушел.

Или:

Gülerek konuştu, sonra gitti. (правильно для способа)
Он говорил, улыбаясь, потом ушел.
```

**Объяснение:**
Для последовательности действий используйте -ip, а не -arak/-erek.

## 8. Дополнительные примеры и практика

### 8.1 Пример: Полный разбор предложения

**Разберем предложение:**

```
Gülerek konuştu.
Он говорил, улыбаясь.
```

**Разбор:**
- `gül-` — улыбаться (основа глагола)
- `gülerek` — улыбаясь (деепричастие способа)
- `konuştu` — он говорил (основной глагол)

**Объяснение:**
В этом предложении деепричастие способа показывает, как выполнялось основное действие "говорить".

**Пример: Разбор сложного предложения**

```
Hızlıca koşarak geldi ve gülerek konuştu.
Он быстро прибежал и говорил, улыбаясь.
```

**Разбор:**
- `hızlıca` — быстро (наречие)
- `koş-` — бегать (основа глагола)
- `koşarak` — бегом (деепричастие способа)
- `geldi` — он пришел (основной глагол)
- `gülerek` — улыбаясь (деепричастие способа)
- `konuştu` — он говорил (основной глагол)

**Объяснение:**
В сложном предложении может быть несколько деепричастий способа для описания разных действий.

### 8.2 Пример: Практические упражнения

**Упражнение 1: Образуйте деепричастие способа**

```
çalışmak → çalışarak
gelmek → gelerek
okumak → okuyarak
görmek → görerek
yazmak → yazarak
almak → alarak
```

**Объяснение:**
Практикуйтесь в образовании деепричастия способа от различных глаголов.

**Упражнение 2: Составьте предложения**

```

Koşmak → Koşarak geldi.

**Объяснение:**
Практикуйтесь в составлении предложений с деепричастием способа.

**Упражнение 3: Выберите правильную форму**

gelmek → gelerek (мягкие гласные)

```

**Объяснение:**
Выбор формы зависит от последней гласной основы глагола и типа окончания.

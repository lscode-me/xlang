## 1. Что такое конструкция -ebilmek

Конструкция **-ebilmek/-abilmek** используется для выражения:

- **Способности**: Я могу/умею делать что-то

- **Возможности**: Возможно сделать что-то

- **Разрешения**: Мне разрешено делать что-то

### 1.1 Основное значение

Суффикс -ebil/-abil присоединяется к основе глагола и затем спрягается как обычный глагол.

**Example: Способность**

```

Türkçe konuşabiliyorum.
Я могу говорить по-турецки (умею).
```

**Объяснение:**
Конструкция показывает, что человек обладает способностью говорить по-турецки.

### 1.2 Три значения -ebilmek

**Use cases:**

1. **Способность (ability):**

   ```

   Yüzebilirim. — Я умею плавать.
   ```

2. **Возможность (possibility):**

   ```

   Yarın gelebilirim. — Я могу прийти завтра (есть возможность).
   ```

3. **Разрешение (permission):**

   ```

   Girebilir miyim? — Могу я войти? (разрешение)
   ```

## 2. Образование конструкции -ebilmek

### 2.1 Формула образования

```

Основа глагола + -ebil/-abil + временной суффикс + личное окончание
```

**Выбор -ebil или -abil:**

- **-ebil** — после гласных (окончание на гласную)

- **-abil** — после согласных (окончание на согласную)

**Example: Выбор суффикса**

```

ПОСЛЕ СОГЛАСНЫХ:
git-mek → git-abil-irim (я могу идти)
gel-mek → gel-ebil-irim (я могу приходить)
oku-mak → oku-y-abil-irim (я могу читать)

ПОСЛЕ ГЛАСНЫХ:
söyle-mek → söyle-y-ebil-irim (я могу говорить)
anla-mak → anla-y-abil-irim (я могу понимать)
```

> **💡 Pro Tip:**  
> После гласных добавляется буфер -y- между основой и -ebil/-abil!

### 2.2 Гармония гласных

После добавления -ebil/-abil следует гармония гласных:

| Основа | Суффикс | Пример |
|--------|---------|--------|
| e/i окончание | -ebil | gelebilirim |
| a/ı окончание | -abil | gidebilirim |
| o/u окончание | -abil | okuyabilirim |
| ö/ü окончание | -ebil | görebilirim |

**Example: Полная таблица**

```

gelmek (приходить, e-type):
gel + ebil → gelebil-
gelebilirim, gelebilirsin, gelebilir...

gitmek (идти, i-type):
git + ebil → gidebil-
gidebilirim, gidebilirsin, gidebilir...

bakmak (смотреть, a-type):
bak + abil → bakabil-
bakabilirim, bakabilirsin, bakabilir...

okumak (читать, u-type):
oku + (y) + abil → okuyabil-
okuyabilirim, okuyabilirsin, okuyabilir...
```

## 3. Спряжение в разных временах

### 3.1 Настоящее время (-yor)

Самая распространённая форма — настоящее время:

```

Основа + -ebil/-abil + -iyor + личное окончание
```

**Example: Спряжение "gelmek" (приходить)**

| Лицо | Форма | Перевод |
|------|-------|---------|
| ben | gelebiliyorum | я могу прийти |
| sen | gelebiliyorsun | ты можешь прийти |
| o | gelebiliyor | он/она может прийти |
| biz | gelebiliyoruz | мы можем прийти |
| siz | gelebiliyorsunuz | вы можете прийти |
| onlar | gelebiliyorlar | они могут прийти |

### 3.2 Geniş zaman (аорист)

Для выражения общей способности используется geniş zaman:

```

Основа + -ebil/-abil + -ir/-er/-ar/-r + личное окончание
```

**Example: Спряжение в geniş zaman**

| Лицо | Форма | Перевод |
|------|-------|---------|
| ben | gelebilirim | я могу приходить (вообще) |
| sen | gelebilirsin | ты можешь приходить |
| o | gelebilir | он/она может приходить |
| biz | gelebiliriz | мы можем приходить |
| siz | gelebilirsiniz | вы можете приходить |
| onlar | gelebilirler | они могут приходить |

**Объяснение:**
В geniş zaman способность выражается как постоянная характеристика.

### 3.3 Прошедшее время (-di)

Для выражения способности в прошлом:

```

Основа + -ebil/-abil + -di + личное окончание
```

**Example: Прошедшее время**

```

gelebildim — я смог прийти
gelebildin — ты смог прийти
gelebildi — он/она смог/смогла прийти
gelebildik — мы смогли прийти
gelebildiniz — вы смогли прийти
gelebildiler — они смогли прийти
```

## 4. Отрицательная форма

### 4.1 Образование отрицания

Отрицание образуется с суффиксом **-eme/-ama**:

```

Основа + -eme/-ama + -z + личное окончание
```

**Выбор -eme/-ama:**

- **-eme** после e-i-ö-ü

- **-ama** после a-ı-o-u

**Example: Отрицательные формы**

```

gelmek → gel-eme-m (я не могу прийти)
gitmek → gid-eme-m (я не могу идти)
bakmak → bak-ama-m (я не могу смотреть)
okumak → oku-y-ama-m (я не могу читать)
```

### 4.2 Полное спряжение отрицательной формы

**Example: "gelmek" (приходить) — отрицание**

| Лицо | Форма | Перевод |
|------|-------|---------|
| ben | gelemem | я не могу прийти |
| sen | gelemezsin | ты не можешь прийти |
| o | gelemez | он/она не может прийти |
| biz | gelemeyiz | мы не можем прийти |
| siz | gelemezsiniz | вы не можете прийти |
| onlar | gelemezler | они не могут прийти |

> **💡 Pro Tip:**  
> Обратите внимание: для "biz" используется "gelemeyiz" (не "gelemeziz").

### 4.3 Отрицание в настоящем времени

**Example: С -iyor**

```

gelemiyorum — я не могу прийти (сейчас)
gelemiyorsun — ты не можешь прийти
gelemiyor — он/она не может прийти
gelemiyoruz — мы не можем прийти
gelemiyorsunuz — вы не можете прийти
gelemiyorlar — они не могут прийти
```

## 5. Вопросительная форма

### 5.1 Образование вопросов

Вопросы образуются с частицами **mi/mı/mu/mü**:

```

Основа + -ebil/-abil + временной суффикс + mi/mı/mu/mü + личное окончание
```

**Example: Вопросы в настоящем времени**

```

Gelebiliyor musun? — Ты можешь прийти?
Gelebiliyor muyuz? — Мы можем прийти?
Gidebiliyor mu? — Он может идти?
Okuyabiliyor musunuz? — Вы можете читать?
```

### 5.2 Вопросы в geniş zaman

**Example: Общие вопросы о способности**

```

Türkçe konuşabilir misin?
Ты можешь говорить по-турецки? (умеешь ли?)

Yüzebilir misiniz?
Вы умеете плавать?

Arabayı kullanabilir mi?
Он умеет водить машину?
```

### 5.3 Вопросы о разрешении

**Example: Просьба разрешения**

```

Girebilir miyim?
Могу я войти?

Pencereyi açabilir miyim?
Могу я открыть окно?

Sorabilir miyim?
Могу я спросить?

Telefonu kullanabilir miyim?
Могу я воспользоваться телефоном?
```

## 6. Различие между -ebilmek и другими формами

### 6.1 -ebilmek vs. Geniş zaman

**Comparison Table:**

| -ebilmek | Geniş zaman | Значение |
|----------|-------------|----------|
| Türkçe konuşabilirim | Türkçe konuşurum | Способность vs. привычка |
| Yüzebilirim | Yüzerim | Умею плавать vs. плаваю (регулярно) |
| Gelebilirim | Gelirim | Могу прийти vs. прихожу (обычно) |

**Example: Сравнение**

```

СПОСОБНОСТЬ:
İngilizce konuşabilirim.
Я могу говорить по-английски (владею языком).

ПРИВЫЧКА:
Her gün İngilizce konuşurum.
Я говорю по-английски каждый день (привычка).
```

### 6.2 -ebilmek vs. -meli (необходимость)

**Example: Различие**

```

СПОСОБНОСТЬ (-ebilmek):
Yarın gelebilirim.
Я могу прийти завтра (есть возможность).

НЕОБХОДИМОСТЬ (-meli):
Yarın gelmeliyim.
Я должен прийти завтра (обязательство).
```

## 7. Практические примеры и ситуации

### 7.1 Example: Просьба разрешения

**Диалог в офисе:**

```

— Girebilir miyim?
— Могу я войти?

— Evet, buyurun.
— Да, пожалуйста.

— Bir soru sorabilir miyim?
— Могу я задать вопрос?

— Tabii ki, sorun.
— Конечно, спрашивайте.
```

### 7.2 Example: О способностях

**Разговор о навыках:**

```

— Hangi dilleri konuşabilirsin?
— На каких языках ты можешь говорить?

— İngilizce ve biraz Türkçe konuşabilirim.
— Могу говорить по-английски и немного по-турецки.

— Piyano çalabilir misin?
— Ты умеешь играть на пианино?

— Hayır, çalamam ama gitar çalabilirim.
— Нет, не умею, но могу играть на гитаре.
```

### 7.3 Example: О возможности

**Планирование встречи:**

```

— Yarın buluşabilir miyiz?
— Мы можем встретиться завтра?

— Üzgünüm, yarın gelemem. İş var.
— Извини, завтра не могу прийти. Есть работа.

— Peki, öbür gün ne dersin?
— Хорошо, как насчёт послезавтра?

— Evet, öbür gün gelebilirim.
— Да, послезавтра могу прийти.
```

### 7.4 Example: В магазине

**Просьба о помощи:**

```

— Bana yardım edebilir misiniz?
— Вы можете мне помочь?

— Tabii, size nasıl yardımcı olabilirim?
— Конечно, чем я могу вам помочь?

— Bu elbiseyi deneyebilir miyim?
— Могу я примерить это платье?

— Evet, tabii. Kabinler şurada.
— Да, конечно. Примерочные вон там.
```

## 8. Распространённые выражения с -ebilmek

### 8.1 Ежедневные фразы

**Example: Частые выражения**

```

Anlayabiliyorum. — Я могу понять / Я понимаю.
Görebiliyor musun? — Ты видишь? / Ты можешь видеть?
Duyabiliyor musunuz? — Вы слышите?
Yapabilirim. — Я могу это сделать.
Gelebilir misin? — Ты можешь прийти?
```

### 8.2 Вежливые просьбы

**Example: Просьбы о разрешении**

```

Pencereyi açabilir miyim? — Могу я открыть окно?
Burada oturabilir miyim? — Могу я здесь сесть?
Bir şey sorabilir miyim? — Могу я что-то спросить?
Telefonu kullanabilir miyim? — Могу я воспользоваться телефоном?
Fotoğraf çekebilir miyim? — Могу я сфотографировать?
```

### 8.3 Выражение неспособности

**Example: "Не могу..."**

```

Gelemem. — Я не могу прийти.
Yapamam. — Я не могу это сделать.
Anlamıyorum, anlayamıyorum. — Я не понимаю, не могу понять.
Göremiyorum. — Я не вижу.
Duyamıyorum. — Я не слышу.
```

## 9. Особые случаи и исключения

### 9.1 Глагол "olmak" (быть)

Глагол "olmak" имеет особую форму:

**Example: "Olabilmek"**

```

Doktor olabilirim. — Я могу стать врачом.
Mutlu olabilirsin. — Ты можешь быть счастливым.
Ne olabilir? — Что может быть?
Olabilir. — Может быть. (возможно)
```

**Объяснение:**
"Olabilir" часто используется как короткий ответ, означающий "может быть, возможно".

### 9.2 Модальное значение "может быть"

**Example: Предположение**

```

Yarın yağmur yağabilir.
Завтра может пойти дождь.

O hasta olabilir.
Он может быть болен.

Geç kalabilirler.
Они могут опоздать.
```

**Объяснение:**
В этих случаях -ebilmek выражает предположение или возможность (не способность).

## 10. Распространённые ошибки

### 10.1 Ошибка: Путаница -ebil/-abil

**❌ Неправильно:**

```

gel-abil-irim (должно быть gelebilirim)
git-abil-irim (правильно gidebilirim)
```

**✅ Правильно:**

```

gelebilirim (e-type)
gidebilirim (i-type)
```

**Объяснение:**
После e-i используется -ebil, после a-ı-o-u используется -abil.

### 10.2 Ошибка: Пропуск буфера -y-

**❌ Неправильно:**

```

oku-abil-irim (должно быть okuyabilirim)
söyle-ebil-irim (должно быть söyleyebilirim)
```

**✅ Правильно:**

```

okuyabilirim
söyleyebilirim
```

**Объяснение:**
После гласных обязательно добавляется -y- перед -ebil/-abil.

### 10.3 Ошибка: Смешение с geniş zaman

**❌ Неправильно:**

```

Türkçe konuşurum. (для выражения способности)
```

**✅ Правильно:**

```

Türkçe konuşabilirim. (я могу/умею говорить по-турецки)
```

**Объяснение:**
Для выражения способности используйте -ebilmek, а не geniş zaman.

## 🔑 Key Takeaways

1. **Формула**: основа + -ebil/-abil + время + личное окончание
2. **-ebil** после e-i-ö-ü, **-abil** после a-ı-o-u
3. Буфер **-y-** после гласных (okuyabilirim)
4. Три значения: **способность, возможность, разрешение**
5. Отрицание: **-eme/-ama-z** (gelemem, bakamam)
6. Вопросы: **mi/mı/mu/mü** (Gelebilir misin?)
7. Отличие от geniş zaman: **способность vs. привычка**
8. "Olabilir" = **может быть (возможно)**

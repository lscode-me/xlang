## 1. Образование Past Simple правильных глаголов

### 1.1 Основное правило

**Правило:**

```

Глагол + -ed = Past Simple

work → worked (работал)
play → played (играл)
watch → watched (смотрел)
```

**Объяснение:**
Правильные глаголы (Regular Verbs) образуют форму прошедшего времени добавлением окончания **-ed** к базовой форме глагола. Эта форма одинакова для всех лиц и чисел.

### 1.2 Одна форма для всех

**Примеры:**

```

I worked yesterday.         (Я работал вчера.)
You worked yesterday.       (Ты работал вчера.)
He/She/It worked yesterday. (Он/она работал(а) вчера.)
We worked yesterday.        (Мы работали вчера.)
They worked yesterday.      (Они работали вчера.)
```

**Объяснение:**
В отличие от настоящего времени, в Past Simple глагол НЕ меняется по лицам — нет окончания -s для третьего лица!

## 2. Правила орфографии при добавлении -ed

### 2.1 Стандартное добавление -ed

**Для большинства глаголов просто добавляем -ed:**

```

work → worked (работать)
play → played (играть)
look → looked (смотреть)
walk → walked (гулять)
talk → talked (разговаривать)
watch → watched (смотреть, наблюдать)
listen → listened (слушать)
visit → visited (посещать)
open → opened (открывать)
close → closed (закрывать)
```

### 2.2 Глаголы, оканчивающиеся на -e

**Добавляем только -d:**

```

live → lived (жить)
like → liked (нравиться)
love → loved (любить)
use → used (использовать)
smile → smiled (улыбаться)
dance → danced (танцевать)
arrive → arrived (прибывать)
move → moved (двигаться)
```

**Объяснение:**
Если глагол уже заканчивается на -e, добавляем только -d, чтобы не было двух букв "e" подряд.

### 2.3 Глаголы, оканчивающиеся на согласную + y

**Меняем -y на -i и добавляем -ed:**

```

study → studied (учиться, изучать)
try → tried (пытаться)
cry → cried (плакать)
carry → carried (нести)
copy → copied (копировать)
marry → married (жениться/выходить замуж)
worry → worried (волноваться)
```

**⚠️ Важно:**
Если перед -y стоит гласная, просто добавляем -ed:

```

play → played (играть)
stay → stayed (оставаться)
enjoy → enjoyed (наслаждаться)
```

### 2.4 Удвоение согласной

**Удваиваем последнюю согласную, если:**

1. Глагол односложный (один слог)
2. Оканчивается на одну гласную + одну согласную
3. Ударение падает на последний слог

**Примеры:**

```

stop → stopped (останавливаться)
plan → planned (планировать)
drop → dropped (ронять)
shop → shopped (ходить по магазинам)
```

**НО без удвоения:**

```

open → opened (два слога, ударение НЕ на последнем)
visit → visited (две согласные в конце)
play → played (две гласные перед согласной)
```

**Объяснение:**
Удвоение помогает сохранить короткий звук гласной. Это правило может быть сложным, но со временем вы запомните написание популярных глаголов.

## 3. Произношение окончания -ed

### 3.1 Три варианта произношения

**Окончание -ed произносится тремя способами:**

**[t] — после глухих согласных (p, k, f, s, sh, ch):**

```

worked [wɜːkt] — работал
looked [lʊkt] — смотрел
watched [wɒtʃt] — смотрел
washed [wɒʃt] — мыл
stopped [stɒpt] — остановился
finished [ˈfɪnɪʃt] — закончил
```

**[d] — после звонких согласных и гласных:**

```

played [pleɪd] — играл
lived [lɪvd] — жил
opened [ˈəʊpənd] — открыл
arrived [əˈraɪvd] — прибыл
cleaned [kliːnd] — убирал
stayed [steɪd] — оставался
```

**[ɪd] — после звуков [t] и [d]:**

```

wanted [ˈwɒntɪd] — хотел
needed [ˈniːdɪd] — нуждался
visited [ˈvɪzɪtɪd] — посетил
started [ˈstɑːtɪd] — начал
ended [ˈendɪd] — закончился
decided [dɪˈsaɪdɪd] — решил
```

**Объяснение:**
Произношение [ɪd] создаёт дополнительный слог. Остальные варианты не добавляют слог к слову.

## 4. Формы предложений

### 4.1 Утвердительная форма (Affirmative)

#### 4.1.1 Структура предложения

**Формула:**

```

Подлежащее + глагол-ed + остальные слова

I worked yesterday.
Я работал вчера.
```

#### 4.1.2 Примеры утвердительных предложений

**Простые действия:**

```

I worked yesterday.
Я работал вчера.

She called me.
Она позвонила мне.

We watched a movie.
Мы посмотрели фильм.

They played football.
Они играли в футбол.

He studied English.
Он изучал английский.
```

**С указанием времени:**

```

I visited my friend last week.
Я навестил друга на прошлой неделе.

She cooked dinner yesterday.
Она приготовила ужин вчера.

We walked in the park two days ago.
Мы гуляли в парке два дня назад.

They moved to London last year.
Они переехали в Лондон в прошлом году.

He finished his homework an hour ago.
Он закончил домашнюю работу час назад.
```

#### 4.1.3 Последовательность действий в прошлом

**Примеры:**

```

I woke up, brushed my teeth and had breakfast.
Я проснулся, почистил зубы и позавтракал.

She opened the door, looked around and smiled.
Она открыла дверь, оглянулась и улыбнулась.

We arrived at the station, waited for the train and travelled to Moscow.
Мы прибыли на станцию, подождали поезд и поехали в Москву.
```

---

### 4.2 Отрицательная форма (Negative)

#### 4.2.1 Структура отрицания

**Формула:**

```

Подлежащее + did not (didn't) + глагол (базовая форма)

I didn't work yesterday.
Я не работал вчера.
```

**⚠️ Важно:**
После "didn't" используется БАЗОВАЯ форма глагола (без -ed), потому что "did" уже показывает прошедшее время!

#### 4.2.2 Примеры отрицательных предложений

**С didn't:**

```

I didn't work yesterday.
Я не работал вчера.

She didn't call me.
Она не звонила мне.

We didn't watch TV.
Мы не смотрели телевизор.

They didn't play football.
Они не играли в футбол.

He didn't study English.
Он не изучал английский.
```

**С полной формой did not:**

```

I did not work yesterday.
Я не работал вчера.

She did not like the movie.
Ей не понравился фильм.

We did not visit them.
Мы не навещали их.
```

#### 4.2.3 Отрицание одинаково для всех лиц

**Примеры:**

```

I didn't work.
You didn't work.
He didn't work.
She didn't work.
We didn't work.
They didn't work.
```

---

### 4.3 Вопросительная форма (Questions)

#### 4.3.1 Структура общих вопросов

**Формула:**

```

Did + подлежащее + глагол (базовая форма) + остальные слова?

Did you work yesterday?
Ты работал вчера?
```

**⚠️ Важно:**
После "did" используется БАЗОВАЯ форма глагола (без -ed)!

#### 4.3.2 Примеры общих вопросов

**Простые вопросы:**

```

Did you work yesterday?
Ты работал вчера?

Did she call you?
Она звонила тебе?

Did they play football?
Они играли в футбол?

Did he study English?
Он изучал английский?

Did we watch that movie?
Мы смотрели тот фильм?
```

#### 4.3.3 Краткие ответы

**Утвердительные:**

```

Did you work yesterday? — Yes, I did.
Ты работал вчера? — Да.

Did she call you? — Yes, she did.
Она звонила тебе? — Да.

Did they play football? — Yes, they did.
Они играли в футбол? — Да.
```

**Отрицательные:**

```

Did you work yesterday? — No, I didn't.
Ты работал вчера? — Нет.

Did she call you? — No, she didn't.
Она звонила тебе? — Нет.

Did they play football? — No, they didn't.
Они играли в футбол? — Нет.
```

---

### 4.4 Специальные вопросы (Wh-questions)

#### 4.4.1 Структура специальных вопросов

**Формула:**

```

Вопросительное слово + did + подлежащее + глагол + остальные слова?

Where did you work?
Где ты работал?
```

#### 4.4.2 Примеры с разными вопросительными словами

**What (что):**

```

What did you do yesterday?
Что ты делал вчера?

What did she cook?
Что она приготовила?

What did they watch?
Что они смотрели?
```

**Where (где):**

```

Where did you work?
Где ты работал?

Where did she live?
Где она жила?

Where did they play?
Где они играли?
```

**When (когда):**

```

When did you arrive?
Когда ты приехал?

When did she call?
Когда она позвонила?

When did they move?
Когда они переехали?
```

**Why (почему):**

```

Why did you stop?
Почему ты остановился?

Why did she cry?
Почему она плакала?

Why did they leave?
Почему они ушли?
```

**How (как):**

```

How did you travel?
Как ты путешествовал?

How did she learn English?
Как она изучала английский?
```

## 5. Указатели времени (Time expressions)

### 5.1 Слова, указывающие на прошлое

**Популярные выражения:**

```

yesterday — вчера
last night — вчера вечером
last week — на прошлой неделе
last month — в прошлом месяце
last year — в прошлом году
two days ago — два дня назад
a week ago — неделю назад
in 2020 — в 2020 году
this morning — сегодня утром (если сейчас уже не утро)
```

### 5.2 Примеры с указателями времени

**Примеры:**

```

I worked yesterday.
Я работал вчера.

She called me last night.
Она позвонила мне вчера вечером.

We visited them last week.
Мы навестили их на прошлой неделе.

They moved here a year ago.
Они переехали сюда год назад.

He studied in London in 2019.
Он учился в Лондоне в 2019 году.
```

## 6. Типичные ошибки русскоговорящих

### ❌ Ошибка 1: Использование -ed в вопросах и отрицаниях

**Неправильно:**

```

✗ Did you worked yesterday?
✗ I didn't worked yesterday.
✗ Did she played football?
```

**Правильно:**

```

✓ Did you work yesterday?
✓ I didn't work yesterday.
✓ Did she play football?
```

**Объяснение:**
После did/didn't всегда используется БАЗОВАЯ форма глагола (без -ed), потому что "did" уже показывает прошедшее время.

### ❌ Ошибка 2: Добавление -s для третьего лица

**Неправильно:**

```

✗ He workeds yesterday.
✗ She playeds football.
```

**Правильно:**

```

✓ He worked yesterday.
✓ She played football.
```

**Объяснение:**
В Past Simple глагол одинаков для всех лиц, нет окончания -s.

### ❌ Ошибка 3: Неправильное написание -ed

**Неправильно:**

```

✗ stoped (правильно: stopped)
✗ studyed (правильно: studied)
✗ liveed (правильно: lived)
```

**Правильно:**

```

✓ stopped (удвоение согласной)
✓ studied (y → i)
✓ lived (глагол на -e, добавляем -d)
```

**Объяснение:**
Следуйте правилам орфографии: удвоение согласной, замена y на i, добавление только -d после -e.

### ❌ Ошибка 4: Использование настоящего времени со словами прошедшего

**Неправильно:**

```

✗ I work yesterday.
✗ She plays football last week.
✗ We watch a movie two days ago.
```

**Правильно:**

```

✓ I worked yesterday.
✓ She played football last week.
✓ We watched a movie two days ago.
```

**Объяснение:**
Со словами, указывающими на прошлое (yesterday, last week, ago), используйте Past Simple, а не Present Simple.

### ❌ Ошибка 5: Путаница was/were с обычными глаголами

**Неправильно:**

```

✗ I was work yesterday.
✗ She were played football.
```

**Правильно:**

```

✓ I worked yesterday.
✓ She played football.
```

**Объяснение:**
Was/were используются ТОЛЬКО для глагола to be. С обычными глаголами используйте форму с -ed.

### ❌ Ошибка 6: Отрицание с "not" вместо "didn't"

**Неправильно:**

```

✗ I not worked yesterday.
✗ She worked not.
```

**Правильно:**

```

✓ I didn't work yesterday.
✓ She didn't work.
```

**Объяснение:**
Отрицание в Past Simple образуется с помощью didn't + базовая форма глагола.

## 💡 Key Takeaways

После изучения этого модуля запомните:

- **Образование:** глагол + -ed (для правильных глаголов)

- **Одна форма для всех лиц:** I/you/he/she/it/we/they worked

- **Правила орфографии:** -e → -d, y → ied, удвоение согласной

- **Произношение -ed:** [t], [d], или [ɪd]

- **Отрицание:** didn't + базовая форма (БЕЗ -ed)

- **Вопросы:** Did + подлежащее + базовая форма?

- **Краткие ответы:** Yes, I did. / No, I didn't.

- **Указатели времени:** yesterday, last week, ago, in 2020

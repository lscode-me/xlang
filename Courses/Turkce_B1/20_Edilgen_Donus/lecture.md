## 1. Пассивный залог

### 1.1 Что такое пассивный залог

Пассивный залог выражает действие, которое выполняется над подлежащим, а не самим подлежащим. В турецком языке пассивный залог образуется с помощью суффиксов -il/-in/-ıl/-ın/-ul/-ün.

### 1.2 Форма -il / -in

**Пример: Пассивный залог**

```
Kapı açıldı.
Дверь открылась (буквально: дверь была открыта).
```

**Объяснение:**
-il используется для образования пассивного залога. В пассивном залоге действие выполняется над подлежащим, а не самим подлежащим.

**Пример: Другой случай**

```
Kitap okundu.
Книга была прочитана.
```

**Объяснение:**
-un используется для образования пассивного залога от глагола okumak (читать).

### 1.3 Образование пассивного залога

**Правило образования:**

**Формула:**

```
Основа глагола + пассивный суффикс (-il/-in/-ıl/-ın/-ul/-ün) + личное окончание
```

**Таблица пассивных суффиксов:**

| Последняя гласная | Суффикс | Пример |
|------------------|---------|--------|
| a, ı | -ıl/-il | açmak → açıldı |
| e, i | -il/-in | seçmek → seçildi |
| o, u | -ul/-un | okumak → okundu |
| ö, ü | -ül/-ün | görmek → görüldü |

**Пример: Образование**

```
açmak (открывать) → aç- + -ıl → açıldı (было открыто)
okumak (читать) → oku- + -n → okundu (было прочитано)
seçmek (выбирать) → seç- + -il → seçildi (было выбрано)
```

**Объяснение:**
Выбор пассивного суффикса зависит от последней гласной основы глагола.

### 1.4 Использование пассивного залога

**Пример: Разные времена**

```
Kapı açıldı. (прошедшее время)
Дверь была открыта.

Kapı açılıyor. (настоящее время)
Дверь открывается.

Kapı açılacak. (будущее время)
Дверь будет открыта.
```

**Объяснение:**
Пассивный залог может использоваться во всех временах.

**Пример: С разными глаголами**

```
Yemek pişirildi.
Еда была приготовлена.

Ev temizlendi.
Дом был убран.

Mektup yazıldı.
Письмо было написано.
```

**Объяснение:**
Пассивный залог используется с различными глаголами для выражения действий, выполняемых над объектами.

## 2. Возвратный залог

### 2.1 Что такое возвратный залог

Возвратный залог выражает действие, которое направлено на само подлежащее или на взаимное действие между несколькими субъектами. В турецком языке возвратный залог выражается через местоимение birbirimiz (друг друга).

### 2.2 Местоимение birbirimiz

**Пример: Возвратный залог**

```
Birbirimizi anladık.
Мы поняли друг друга (буквально: друг друга мы поняли).
```

**Объяснение:**
birbirimizi используется для выражения взаимного действия. Местоимение birbirimiz означает "друг друга" и изменяется по падежам.

**Пример: Другой случай**

```
Birbirimize yardım ettik.
Мы помогли друг другу.
```

**Объяснение:**
Возвратный залог выражается через местоимение birbirimiz (друг друга) с дательным падежом.

### 2.3 Формы местоимения birbirimiz

**Таблица форм:**

| Падеж | Форма | Пример |
|-------|-------|--------|
| Именительный | birbirimiz | Birbirimiz arkadaşız |
| Винительный | birbirimizi | Birbirimizi anladık |
| Дательный | birbirimize | Birbirimize yardım ettik |
| Исходный | birbirimizden | Birbirimizden öğrendik |

**Пример: С разными падежами**

```
Birbirimizi anladık. (винительный)
Мы поняли друг друга.

Birbirimize yardım ettik. (дательный)
Мы помогли друг другу.

Birbirimizden öğrendik. (исходный)
Мы узнали друг от друга.
```

**Объяснение:**
Местоимение birbirimiz изменяется по падежам в зависимости от грамматической функции.

### 2.4 Использование возвратного залога

**Пример: Разные времена**

```
Birbirimizi anladık. (прошедшее время)
Мы поняли друг друга.

Birbirimizi anlıyoruz. (настоящее время)
Мы понимаем друг друга.

Birbirimizi anlayacağız. (будущее время)
Мы поймем друг друга.
```

**Объяснение:**
Возвратный залог может использоваться во всех временах.

**Пример: С разными глаголами**

```
Birbirimizi seviyoruz.
Мы любим друг друга.

Birbirimize yardım ediyoruz.
Мы помогаем друг другу.

Birbirimizden öğreniyoruz.
Мы учимся друг у друга.
```

**Объяснение:**
Возвратный залог используется с различными глаголами для выражения взаимных действий.

---

## 3. Сравнение пассивного и возвратного залога

### 3.1 Различия

**Таблица сравнения:**

| Аспект | Пассивный залог | Возвратный залог |
|--------|----------------|------------------|
| Действие | Выполняется над объектом | Взаимное действие |
| Субъект | Не указан | Указан (birbirimiz) |
| Пример | Kapı açıldı | Birbirimizi anladık |

**Пример: Сравнение**

```
Kapı açıldı. (пассивный - действие над объектом)
Дверь была открыта (кем-то).

Birbirimizi anladık. (возвратный - взаимное действие)
Мы поняли друг друга (мы друг друга).
```

**Объяснение:**
Пассивный залог выражает действие над объектом без указания субъекта, а возвратный залог выражает взаимное действие между субъектами.

## 4. Практические примеры

### 4.1 Пример: Пассивный залог

```
Kapı açıldı.
Дверь открылась.

Kitap okundu.
Книга была прочитана.

Yemek pişirildi.
Еда была приготовлена.

Ev temizlendi.
Дом был убран.

Mektup yazıldı.
Письмо было написано.
```

**Объяснение:**
В этом примере показано использование пассивного залога с различными глаголами.

### 4.2 Пример: Возвратный залог

```
Birbirimizi anladık.
Мы поняли друг друга.

Birbirimize yardım ettik.
Мы помогли друг другу.

Birbirimizden öğrendik.
Мы узнали друг от друга.

Birbirimizi seviyoruz.
Мы любим друг друга.
```

**Объяснение:**
В этом примере показано использование возвратного залога с различными глаголами и падежами.

### 4.3 Пример: Реальные ситуации

**Пример: Разговор о событиях**

```
Kapı açıldı ve içeri girdik.
Дверь открылась, и мы вошли внутрь.

Kitap okundu ve beğenildi.
Книга была прочитана и понравилась.

Birbirimizi gördük ve selamlaştık.
Мы увидели друг друга и поздоровались.
```

**Объяснение:**
Залоги используются в реальных ситуациях для описания событий и действий.

## 6. Частые ошибки

### 6.1 Ошибка: Смешение залогов

❌ **Неправильно:**

```
Kapı açıldı ve birbirimizi gördük. (неправильно для пассивного)
Дверь открылась, и мы увидели друг друга.
```

✅ **Правильно:**

```
Kapı açıldı. (пассивный залог)
Дверь открылась.

Birbirimizi gördük. (возвратный залог)
Мы увидели друг друга.
```

**Объяснение:**
Пассивный и возвратный залог используются в разных контекстах.

### 6.2 Ошибка: Неправильное образование пассивного залога

❌ **Неправильно:**

```
Kapı açıldı. (неправильно, если глагол непереходный)
Дверь открылась.
```

✅ **Правильно:**

```
Kapı açıldı. (правильно - переходный глагол)
Дверь была открыта (кем-то).
```

**Объяснение:**
Пассивный залог образуется только от переходных глаголов (глаголов с прямым дополнением).

### 6.3 Ошибка: Неправильное использование birbirimiz

❌ **Неправильно:**

```
Birbirimiz anladık. (неправильно - нет падежа)
Мы поняли друг друга.
```

✅ **Правильно:**

```
Birbirimizi anladık. (правильно - винительный падеж)
Мы поняли друг друга.
```

**Объяснение:**
Местоимение birbirimiz должно использоваться с правильным падежом в зависимости от грамматической функции.

## 7. Дополнительные примеры и практика

### 7.1 Пример: Полный разбор предложения

**Разберем предложение:**

```
Kapı açıldı.
Дверь была открыта.
```

**Разбор:**
- `Kapı` — дверь (подлежащее)
- `aç-` — открывать (основа глагола)
- `açıl-` — быть открытым (пассивная форма)
- `açıldı` — была открыта (прошедшее время)

**Объяснение:**
В этом предложении пассивный залог показывает, что действие "открывать" было выполнено над дверью кем-то (субъект не указан).

### 7.2 Пример: Практические упражнения

**Упражнение 1: Образуйте пассивный залог**

```
açmak → açıldı (было открыто)
okumak → okundu (было прочитано)
yazmak → yazıldı (было написано)
pişirmek → pişirildi (было приготовлено)
```

**Объяснение:**
Практикуйтесь в образовании пассивного залога от различных глаголов.

**Упражнение 2: Используйте возвратный залог**

```
anlamak → Birbirimizi anladık.
yardım etmek → Birbirimize yardım ettik.
öğrenmek → Birbirimizden öğrendik.
```

**Объяснение:**
Практикуйтесь в использовании возвратного залога с различными глаголами и падежами.

## 💡 Key Takeaways

- **Пассивный залог**: Выражается через -il/-in, действие выполняется над подлежащим
- **Возвратный залог**: Выражается через -iş или birbirimiz, действие направлено на само подлежащее
- **Различие**: Пассивный — действие над объектом, возвратный — взаимное действие
- **Гармония гласных**: Выбор суффикса зависит от последней гласной
- **Основа понимания**: Понимание залогов необходимо для уровня B1

# Промпт для генерации вопросов RU→AV Quiz (Phrases)

Ты - эксперт по аварскому языку и создатель учебных материалов. Твоя задача - генерировать вопросы для теста на перевод **фраз и предложений** с русского на аварский язык.

## Формат вывода

Генерируй ТОЛЬКО JSONL (JSON Lines) - каждая строка = один валидный JSON объект.

**НЕ ДОБАВЛЯЙ**:
- Никаких markdown блоков кода (```json)
- Никаких комментариев
- Никаких пояснений
- Только чистые JSONL строки

## Структура каждого JSON объекта

```json
{"id":"<LEVEL>-<SET>-<NUM>","question":"<Russian phrase>","options":["<Option 1>","<Option 2>","<Option 3>","<Option 4>"],"correct":<1-4>,"explanation":"<Explanation>","tags":["<tag1>","<tag2>"],"source":"llm"}
```

## Обязательные поля

- **id**: Уникальный идентификатор в формате `<LEVEL>-<SET>-<NUM>`
  - Примеры: `A1-001-0001`, `B2-005-0023`
  - LEVEL: A1, A2, B1, B2, или C1

- **question**: Фраза или предложение на русском языке.
  - Соответствует уровню сложности.

- **options**: Массив из **ровно 4** вариантов перевода на аварский.
  - Только **ОДИН** вариант - правильный перевод.
  - Остальные 3 - правдоподобные дистракторы (ошибки в лексике, падежах или смысле).
  - Используй корректную аварскую орфографию с "I".

- **correct**: Номер правильного варианта (1, 2, 3, или 4).

- **explanation**: Объяснение на русском.
  - Краткий разбор фразы или грамматических особенностей.

## Требования по уровням

### A1-A2 (Начальный)
- Короткие фразы, приветствия, базовые вопросы ("Как дела?", "Где ты?", "Я иду домой").
- Лексика: семья, дом, простые действия.

### B1-B2 (Средний)
- Более сложные предложения, использование причастий, деепричастий, косвенной речи.
- Темы: работа, путешествия, обсуждение мнений.

### C1 (Продвинутый)
- Идиомы, сложные синтаксические конструкции, литературный язык, тонкие смысловые оттенки.

## Правила качества

1. **Естественность**: Фразы должны звучать натурально для аварского языка.
2. **Однозначность**: Правильный ответ должен быть бесспорно правильным.
3. **Корректность**: Тщательно проверяй использование классных показателей (в-, й-, б-, р-).

```json
{"id":"A1-001-0001","question":"Как тебя зовут?","options":["Дур цIар щиб?","Дир цIар щиб?","Дур эмен щиб?","Дир эбель щиб?"],"correct":1,"explanation":"Дур — твой, цIар — имя, щиб — что/какое.","tags":["phrase","greeting"],"source":"llm"}

Класс 'в' для мужчин.","tags":["phrase","daily"],"source":"llm"}
```

## Инструкция

Сгенерируй **N фраз** для уровня **LEVEL**.
Используй набор **SET**.
Начинай с номера **START_NUM**.

Только JSONL вывод!

## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Инфинитив — это базовая форма глагола с частицей to (to go, to read) |
| 2 | C | Герундий — форма глагола с -ing, используемая как существительное (reading, going) |
| 3 | A | want требует инфинитива: I want to go |
| 4 | B | enjoy требует герундия: I enjoy reading |
| 5 | C | want + to-infinitive: I want to go |
| 6 | B | enjoy + gerund: I enjoy reading |
| 7 | D | decide + to-infinitive: She decided to leave |
| 8 | B | finish + gerund: I've finished writing |
| 9 | A | avoid + gerund: He avoids talking |
| 10 | A | agree + to-infinitive: They agreed to help |
| 11 | D | remember + to-inf = не забыть сделать (действие в будущем от момента "вспоминания") |
| 12 | B | remember + gerund = помнить о совершённом действии |
| 13 | C | stop + to-inf = остановиться, чтобы сделать что-то |
| 14 | B | stop + gerund = прекратить делать что-то |
| 15 | C | forget + to-inf = забыть сделать: Don't forget to lock |
| 16 | A | forget + gerund используется с never: I'll never forget visiting |
| 17 | D | try + to-inf = пытаться, стараться (с усилием) |
| 18 | A | try + gerund = попробовать как эксперимент, возможное решение |
| 19 | A | После предлогов всегда герундий: for helping |
| 20 | C | look forward to + gerund: looking forward to seeing |
| 21 | A | be used to + gerund: I'm used to getting up |
| 22 | B | suggest + gerund: She suggested going |
| 23 | D | mind + gerund: I don't mind waiting |
| 24 | A | offer + to-infinitive: He offered to help |
| 25 | C | consider + gerund: Have you considered moving |
| 26 | C | regret + to-inf = сожалеть, что приходится сообщать |
| 27 | A | regret + gerund = сожалеть о совершённом действии |
| 28 | D | mean + to-inf = намереваться |
| 29 | B | mean + gerund = означать, предполагать |
| 30 | D | go on + to-inf = перейти к другому действию |

| 36 | C | make + bare infinitive: made her cry |
| 37 | B | afford + to-infinitive: can't afford to buy |

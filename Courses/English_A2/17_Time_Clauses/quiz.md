## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | В придаточных времени о будущем используется Present Simple: when I arrive. |
| 2 | C | После "after" в будущем времени используется Present Simple: After I finish. |
| 3 | B | После "before" в будущем времени используется Present Simple: before you leave. |
| 4 | C | После "until" в будущем времени используется Present Simple: until I come back. |
| 5 | D | После "as soon as" в будущем времени используется Present Simple: as soon as I know. |
| 6 | B | "While" используется для одновременных длительных действий. |
| 7 | A | "When" используется, когда короткое действие прерывает длительное. |
| 8 | A | "After I ate dinner" = сначала поел ужин, потом смотрел телевизор. |
| 9 | A | "Before I ate" = сначала помыл руки, потом ел. |
| 10 | C | "Until" без отрицания в английском: Wait until I come back. |
| 11 | A | В прошедшем времени используется Past Simple: When I opened. |
| 12 | A | Короткое действие "arrived" прерывает длительное "was cooking" → when. |
| 13 | D | Запятая нужна, если придаточное в начале: When I arrive, I'll call you. |
| 14 | C | "As soon as" означает "как только". |
| 15 | D | "Until" означает "до тех пор пока (не)". |
| 16 | D | В главном предложении используется будущее время: I will be ready. |
| 17 | D | Для привычки в настоящем: Present Simple в обеих частях. |
| 18 | A | "While" для одновременных действий в будущем. |

| 20 | C | "Since" используется с Present Perfect для указания начального момента. |
| 21 | B | Это косвенный вопрос (не time clause), поэтому используется "will arrive". |
| 22 | C | В прошедшем времени: after he arrived. |

| 26 | A | "While" для одновременных действий. |

| 28 | C | После "until" в будущем используется Present Simple: until you come. |

| 30 | D | Длительное действие прервано коротким: I was reading when the phone rang. |

## Scoring Guide

- 27-30 правильных ответов: Отлично! Вы полностью освоили придаточные предложения времени.
- 23-26 правильных ответов: Хорошо! Повторите правило о Present Simple в будущем времени.
- 18-22 правильных ответов: Неплохо, но нужно больше практики с временными союзами.
- Меньше 18 правильных ответов: Рекомендуется повторить лекцию и запомнить, что после when/after/before/until используется Present Simple для будущего.

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | "so that I could catch" — выражает цель (зачем я ушёл рано) |
| 2 | C | "because I was ill" — выражает причину (почему я остался дома) |
| 3 | C | "so boring that I left" — выражает результат (настолько скучно, что ушёл) |
| 4 | A | Present tense → can (I'm learning → I can communicate) |

| 6 | D | In order to + infinitive (без подлежащего и модального глагола) |

| 8 | B | "to help" = "so that I could help" — оба выражают цель |
| 9 | D | So that позволяет иметь разные подлежащие (I spoke / everyone could) |
| 10 | C | Because of + noun (the bad weather) |
| 11 | B | Because of + noun (the traffic), не clause |
| 12 | D | As используется для фоновой причины в начале предложения |
| 13 | A | Since используется для известного факта (you already know) |
| 14 | B | Because — главная причина; as/since — фоновая или известная |
| 15 | D | So + adjective (cold) + that = so cold that |
| 16 | B | Such a + adjective + singular noun (such a good teacher) |
| 17 | D | So + adjective без noun (so nice) — правильно |
| 18 | C | Such + adjective + plural noun (such nice people, без a/an) |
| 19 | C | Such + adjective + uncountable noun (such bad weather, без a/an) |
| 20 | A | So many + countable plural (people) |
| 21 | B | So little + uncountable (time) |
| 22 | D | "so that I wouldn't be late" — цель (чтобы не опоздать) |

| 26 | A | For + noun (for some milk) — цель с существительным |

| 36 | C | Such + a + noun (such a fool) — требуется артикль |

| 38 | B | Because of + gerund (arriving) — правильная форма |
| 39 | C | Such a + adjective + noun в восклицании (such a beautiful day!) |

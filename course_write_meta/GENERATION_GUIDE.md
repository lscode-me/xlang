# 🚀 Руководство по генерации лекций

Этот документ описывает полный процесс создания лекций из `course.txt` до готовых модулей в `Courses/`.

---

## 📋 Обзор процесса

```
Courses_templates/[CourseName]/course.txt
        ↓
    Анализ структуры курса
        ↓
    Создание папок в Courses/[CourseName]/
        ↓
    Для каждого модуля:
    ├── Генерация lecture.md
    └── Генерация quiz.md
        ↓
    Проверка по LECTURE_CHECKLIST.md
        ↓
    Review и публикация
```

---

## 📁 Структура входных данных

### Файл course.txt

Располагается в `Courses_templates/[CourseName]/course.txt`

**Формат:**
```
[Course Name]
[Описание курса. Целевая аудитория, уровень сложности, что изучат.]
[XX_ModuleName] [краткое описание содержимого модуля]
[XX_ModuleName] [краткое описание содержимого модуля]
...
Требования: [prerequisites для всего курса]
```

**Пример (Английский A1):**
```
English_A1
Курс по грамматике английского языка для начинающих. Для изучающих английский с нуля или с минимальными знаниями.
01_Articles артикли a, an, the — использование, правила, исключения.
02_Present_Simple настоящее простое время — образование, использование, маркеры времени.
03_Plural множественное число существительных — правила образования, исключения.
...
Требования: базовое знание алфавита, умение читать транскрипцию.
```

## 🔧 Пошаговый процесс

### Шаг 1: Анализ course.txt

1. Открыть `Courses_templates/[CourseName]/course.txt`
2. Определить:
   - Название курса
   - Целевую аудиторию
   - Количество модулей
   - Prerequisites для курса

### Шаг 2: Создание структуры папок

```bash
# Создать папку курса
mkdir -p Courses/[CourseName]

# Создать папки модулей
mkdir -p Courses/[CourseName]/01_ModuleName
mkdir -p Courses/[CourseName]/02_ModuleName
# ... для каждого модуля
```

### Шаг 3: Генерация lecture.md

Для каждого модуля:

1. Скопировать `LECTURE_TEMPLATE.md` → `lecture.md`
2. Заполнить содержимое согласно:
   - Описанию модуля из `course.txt`
   - Стандартам из `LECTURE_STANDARD.md`
   - Примеру из `LECTURE_EXAMPLE.md`

### Шаг 4: Генерация quiz.md

Для каждого модуля:

1. Скопировать `QUIZ_TEMPLATE.md` → `quiz.md`
2. Создать 20-40 вопросов, покрывающих:
   - Learning Objectives из лекции
   - Ключевые концепции
   - Практические сценарии

### Шаг 5: Проверка качества

1. Проверить каждый модуль по `LECTURE_CHECKLIST.md`
2. Убедиться, что балл ≥ 125/155
3. Исправить найденные проблемы

## 🤖 Промпт для AI-генерации

При использовании AI (Claude, GPT и др.) для генерации контента, используйте следующий промпт:

### Промпт для генерации лекции

```
Создай лекцию для модуля курса согласно стандартам CourseBuilder.

## Входные данные

**Курс:** [Название курса]
**Модуль:** [XX_ModuleName]
**Описание модуля:** [описание из course.txt]
**Prerequisites курса:** [requirements из course.txt]

## Требования к лекции

1. **Структура** (обязательные секции):
   - H1: Название модуля
   - H2: Конкретная тема
   - 📋 Prerequisites (2-4 пункта)
   - 🎯 Learning Objectives (3-5 целей с глаголами действия)
   - 5-12 основных секций с нумерацией (## 1., ## 2., ...)
   - Подсекции (### 1.1, ### 1.2, ...)
   - 💡 Key Takeaways (3-5 пунктов)
   - 🚀 Next Steps

2. **Метрики:**
   - Длина: 600-1000 строк
   - Примеров предложений/правил: 20-40 примеров
   - Время чтения: 30-45 минут

3. **Стиль:**
   - Дружелюбный, но профессиональный тон
   - От простого к сложному
   - Каждый пример с переводом и объяснением
   - Объяснять не только "как", но и "зачем" (когда использовать правило)

4. **Примеры:**
   - Реальные предложения на изучаемом языке
   - Переводы и транскрипции где необходимо
   - Примеры правильного и неправильного использования
   - Таблицы с формами и исключениями

5. **Эмодзи** (только для секций):
   📋 Prerequisites, 🎯 Objectives, 💡 Takeaways, 🚀 Next Steps, ⚠️ Warnings, ✅/❌ Good/Bad

Сгенерируй полную лекцию в формате Markdown.
```

### Промпт для генерации quiz.md

```
Создай quiz.md для модуля курса согласно стандартам CourseBuilder.

## Входные данные

**Модуль:** [XX_ModuleName]
**Learning Objectives из лекции:**
1. [Objective 1]
2. [Objective 2]
...

**Ключевые темы лекции:**
- [Тема 1]
- [Тема 2]
...

## Требования к quiz

1. **Количество:** 25-30 вопросов

2. **Распределение:**
   - 40% — понимание грамматических правил
   - 40% — практическое применение (выбор правильной формы, построение предложений)
   - 20% — исключения и частые ошибки

3. **Формат каждого вопроса:**
   - Номер и тема: ## Question N: [Тема]
   - Текст вопроса (может включать предложения на изучаемом языке)
   - 4 варианта ответа (A, B, C, D)
   - Только один правильный ответ
   - Неправильные ответы должны быть правдоподобными
   - Правильный ответ не должен выделяться длиной и детализацией
   - Неправильные ответы не должны быть узкими настолько чтобы было очевидно, что они неверные
   - Слово "только" часто выдает неправильный ответ. Не надо этим злоупотреблять.

4. **Answer Key:**
   - Таблица с номером, буквой ответа, пояснением
   - Пояснение должно объяснять ПОЧЕМУ это правильно

5. **Scoring Guide:**
   - 90-100%: Отлично
   - 70-89%: Хорошо
   - 50-69%: Удовлетворительно
   - <50%: Нужно повторить

Сгенерируй полный quiz.md.
```

## ✅ Чеклист генерации курса

### Перед началом
- [ ] Изучен `course.txt` целевого курса
- [ ] Понятна целевая аудитория
- [ ] Определены prerequisites курса
- [ ] Создана структура папок

### Для каждого модуля
- [ ] `lecture.md` создан из шаблона
- [ ] Все обязательные секции заполнены
- [ ] 3-5 Learning Objectives с глаголами действия
- [ ] 3-5 Key Takeaways
- [ ] 20-40 примеров предложений с переводами и объяснениями
- [ ] Длина 600-1000 строк
- [ ] `quiz.md` создан (20-40 вопросов)
- [ ] Вопросы покрывают Learning Objectives
- [ ] Проверка по LECTURE_CHECKLIST.md пройдена (≥125 баллов)

### Финализация курса
- [ ] Все модули прошли проверку
- [ ] Prerequisites между модулями согласованы
- [ ] Next Steps ссылаются на существующие модули
- [ ] Нет broken links
- [ ] Терминология единообразна

## 🎯 Критерии качества готового модуля

### Must Have (обязательно)
- ✅ Все обязательные секции присутствуют
- ✅ Все примеры предложений корректны и имеют переводы
- ✅ Learning Objectives измеримы (глаголы действия)
- ✅ Quiz покрывает материал лекции
- ✅ Балл по чеклисту ≥ 125/155

### Should Have (желательно)
- ✅ Прогрессия от простого к сложному
- ✅ Практические примеры из реального мира
- ✅ Объяснение "зачем", а не только "как"
- ✅ Warning блоки для частых ошибок

### Nice to Have (бонус)
- ✅ Pro Tips для продвинутых пользователей
- ✅ Сравнительные таблицы
- ✅ Визуальные схемы (если применимо)

## 📊 Примеры

### Пример: От course.txt к модулю

**Вход (course.txt):**
```
02_Present_Simple настоящее простое время — образование, использование, маркеры времени.
```

**Выход (структура lecture.md):**
```markdown
# Present Simple
## Настоящее простое время в английском языке

---

## 📋 Prerequisites
- Базовое знание английского алфавита
- Понимание структуры простого предложения
- Знание личных местоимений (I, you, he, she, it, we, they)

## 🎯 Learning Objectives
- Образовывать утвердительные, отрицательные и вопросительные предложения в Present Simple
- Правильно использовать окончания -s/-es для третьего лица единственного числа
- Применять маркеры времени (always, usually, often, etc.)
- Различать случаи использования Present Simple и других времен

## 1. Что такое Present Simple
### 1.1 Основные случаи использования
...

## 2. Образование утвердительных предложений
### 2.1 Формы глагола
...

## 3. Отрицательные и вопросительные предложения
...

## 4. Маркеры времени
...

## 5. Исключения и особые случаи
...

## 6. Практические примеры
...

## 💡 Key Takeaways
- **Present Simple** используется для регулярных действий и фактов
- В третьем лице единственного числа добавляется -s/-es
- Вспомогательный глагол do/does используется в отрицаниях и вопросах
- Маркеры времени помогают определить правильное время

## 🚀 Next Steps
- [03_Present_Continuous](../03_Present_Continuous/) — настоящее длительное время
- [04_Past_Simple](../04_Past_Simple/) — прошедшее простое время
```

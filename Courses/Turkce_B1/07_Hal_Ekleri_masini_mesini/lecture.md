## 1. Что такое форма -masını / -mesini

Форма -masını/-mesini — это притяжательная форма -ması/-mesi с винительным падежом. Она используется, когда действие с субъектом является прямым объектом другого действия.

### 1.1 Основная концепция

**Пример: Действие как объект**

```
Onun gelmesini bekliyorum.
Я жду его прихода (буквально: я жду его приход).
```

**Объяснение:**
-mesini указывает на то, что действие "приходить" принадлежит третьему лицу (onun - его), и это действие является объектом глагола "ждать" (beklemek). Винительный падеж -ni указывает на то, что это прямое дополнение.

**Пример: Другой случай**

```
Bunu yapmasını istiyorum.
Я хочу, чтобы он это сделал (буквально: я хочу его делание этого).
```

**Объяснение:**
-masını указывает на то, что действие "делать" принадлежит третьему лицу, и это действие является объектом глагола "хотеть" (istemek).

---

## 2. Образование формы -masını / -mesini

### 2.1 Правило образования

**Формула:**

```
Основа глагола + -ma/-me + притяжательный суффикс + винительный падеж
```

**Шаги образования:**

1. Берем основу глагола
2. Добавляем -ma/-me (с учетом гармонии гласных)
3. Добавляем притяжательный суффикс (-sı/-si для 3 лица)
4. Добавляем винительный падеж (-nı/-ni)

**Пример: Процесс образования**

```
Глагол: gelmek (приходить)
Шаг 1: Основа - gel-
Шаг 2: Добавляем -me → gelme
Шаг 3: Добавляем притяжательный суффикс -si → gelmesi
Шаг 4: Добавляем винительный падеж -ni → gelmesini
Результат: Onun gelmesini bekliyorum.
Я жду его прихода.
```

**Объяснение:**
Образование -masını/-mesini происходит в четыре этапа: основа → -ma/-me → притяжательный суффикс → винительный падеж.

### 2.2 Таблица форм для разных лиц

**Таблица образования:**

| Лицо | Форма | Пример |
|------|-------|--------|
| 1 лицо ед.ч. | -memi | gelmemi (мой приход) |
| 2 лицо ед.ч. | -meni | gelmeni (твой приход) |
| 3 лицо ед.ч. | -masını/-mesini | gelmesini (его приход) |
| 1 лицо мн.ч. | -memizi/-memizi | gelmemizi (наш приход) |
| 2 лицо мн.ч. | -menizi/-menizi | gelmenizi (ваш приход) |
| 3 лицо мн.ч. | -malarını/-melerini | gelmelerini (их приход) |

**Пример: Для разных лиц**

```
Benim gelmemi bekliyor. (1 лицо)
Он ждет моего прихода.

Senin gelmeni bekliyor. (2 лицо)
Он ждет твоего прихода.

Onun gelmesini bekliyor. (3 лицо)
Он ждет его прихода.
```

**Объяснение:**
Форма меняется в зависимости от лица субъекта действия. Притяжательный суффикс и винительный падеж согласуются с лицом.

---

## 3. Использование с глаголами управления

### 3.1 Глаголы, требующие -masını/-mesini

**Пример: С глаголом beklemek (ждать)**

```
Onun gelmesini bekliyorum.
Я жду его прихода.
```

**Объяснение:**
После глагола beklemek (ждать) нужно использовать -masını/-mesini, потому что действие является объектом ожидания.

**Пример: С глаголом istemek (хотеть)**

```
Bunu yapmasını istiyorum.
Я хочу, чтобы он это сделал.
```

**Объяснение:**
После глагола istemek (хотеть) нужно использовать -masını/-mesini, когда речь идет о действии другого лица.

**Пример: С глаголом istemek (просить)**

```
Ali'nin çalışmasını istiyorum.
Я хочу, чтобы Али работал (я прошу Али работать).
```

**Объяснение:**
-masını используется для выражения просьбы или желания, чтобы другой человек выполнил действие.

### 3.2 Другие глаголы

**Пример: С другими глаголами**

```
Onun gelmesini umuyorum. (umut etmek - надеяться)
Я надеюсь на его приход.

Ali'nin başarısını kutluyorum. (kutlamak - праздновать)
Я праздную успех Али.
```

**Объяснение:**
-masını/-mesini может использоваться после различных глаголов, когда действие является объектом.

---

## 4. Отличие от формы -ması

### 4.1 -ması vs -masını

**Пример: Сравнение**

```
Onun gelmesi önemli. (-ması - именительный падеж)
Его приход важен.

Onun gelmesini bekliyorum. (-masını - винительный падеж)
Я жду его прихода.
```

**Объяснение:**
-ması используется, когда действие является подлежащим предложения (именительный падеж). -masını используется, когда действие является прямым дополнением (винительный падеж).

### 4.2 Когда использовать -masını

Используйте -masını/-mesini для:
- Прямого дополнения (после глаголов управления)
- Действия другого лица как объекта
- Когда действие является объектом другого действия

**Пример: Прямое дополнение**

```
Ali'nin çalışmasını istiyorum.
Я хочу, чтобы Али работал.
```

**Объяснение:**
-masını используется, потому что действие Али (работать) является прямым дополнением глагола "хотеть".

## 5. Дополнительные примеры

### 5.1 Пример: С разными временами

**Пример: С настоящим временем**

**Объяснение:**
-masını/-mesini может использоваться с разными временами основного глагола.

Я ждал его прихода.

Bunu yapmasını istedim. (прошедшее)
Я хотел, чтобы он это сделал.
```

**Объяснение:**
-masını/-mesini может использоваться в прошедшем времени.

### 5.2 Пример: С разными лицами

**Пример: Для разных лиц**

```
Benim gelmemi bekliyor. (1 лицо)

Он ждет твоего прихода.

Onun gelmesini bekliyor. (3 лицо)

**Объяснение:**
-masını/-mesini может использоваться для разных лиц с соответствующими притяжательными суффиксами.

## 6. Практические примеры

### 6.1 Пример: Разные контексты

```
Onun gelmesini bekliyorum. (ждать)
Я жду его прихода.

Bunu yapmasını istiyorum. (хотеть)
Я хочу, чтобы он это сделал.

Ali'nin çalışmasını tercih ediyorum. (предпочитать)
Я предпочитаю, чтобы Али работал.
```

**Объяснение:**
В этом примере показано использование -masını/-mesini с разными глаголами управления.

### 6.2 Пример: Реальные ситуации

**Пример: Разговор о ожиданиях**

```
Onun gelmesini bekliyorum.
Я жду его прихода.

Ali'nin çalışmasını bekliyorum.
Я жду работы Али.

Senin hazır olmanı bekliyorum.
Я жду твоей готовности.
```

**Объяснение:**
-masını/-mesini используется в реальных ситуациях для выражения ожиданий относительно действий других.

**Пример: Разговор о желаниях**

```
Bunu yapmasını istiyorum.
Я хочу, чтобы он это сделал.

Ali'nin çalışmasını istiyorum.
Я хочу, чтобы Али работал.

Senin gelmeni istiyorum.
Я хочу, чтобы ты пришел.
```

**Объяснение:**
-masını/-mesini используется для выражения желаний относительно действий других.

### 6.3 Пример: Сложные предложения

```
Ali'nin geç kalmasını istemiyorum.
Я не хочу, чтобы Али опаздывал.

Onun gelmesini bekliyorum, ama geç kalmasını istemiyorum.
Я жду его прихода, но не хочу, чтобы он опаздывал.
```

**Объяснение:**
-masını используется в сложных предложениях для выражения различных отношений к действиям других.

## 8. Частые ошибки

### 8.1 Ошибка: Смешение -ması и -masını

❌ **Неправильно:**

```
Onun gelmesi bekliyorum. (неправильно)
Я жду его прихода.
```

✅ **Правильно:**

```
Onun gelmesini bekliyorum. (правильно)
Я жду его прихода.
```

**Объяснение:**
После глаголов управления, требующих прямого дополнения, нужно использовать винительный падеж -masını, а не именительный -ması.

### 8.2 Ошибка: Отсутствие субъекта

❌ **Неправильно:**

```
Gelmesini bekliyorum. (неправильно - нет субъекта)
Я жду прихода.
```

✅ **Правильно:**

```
Onun gelmesini bekliyorum. (правильно - есть субъект)
Я жду его прихода.
```

**Объяснение:**
При использовании -masını/-mesini нужно указывать субъект действия (onun, Ali'nin и т.д.).

### 8.3 Ошибка: Неправильный падеж

❌ **Неправильно:**

```
Onun gelmesine bekliyorum. (неправильно - дательный падеж)
Я жду его прихода.
```

✅ **Правильно:**

```
Onun gelmesini bekliyorum. (правильно - винительный падеж)
Я жду его прихода.
```

**Объяснение:**
После глагола beklemek нужно использовать винительный падеж -masını, а не дательный -masına.

### 8.4 Ошибка: Смешение с формой -ma

❌ **Неправильно:**

```
Onun gelmeyi bekliyorum. (неправильно - нет притяжательного суффикса)
Я жду его прихода.
```

✅ **Правильно:**

```
Onun gelmesini bekliyorum. (правильно - с притяжательным суффиксом)
Я жду его прихода.
```

**Объяснение:**
Для действия другого лица нужно использовать -masını/-mesini с притяжательным суффиксом, а не просто -mayı/-meyi.

## 9. Дополнительные примеры и практика

### 9.1 Пример: Полный разбор предложения

**Разберем предложение:**

```
Onun gelmesini bekliyorum.
Я жду его прихода.
```

**Разбор:**
- `Onun` — его (субъект в родительном падеже)
- `gel-` — приходить (основа глагола)
- `gelme` — приход (форма -ma)
- `gelmesi` — его приход (притяжательная форма)
- `gelmesini` — его приход (винительный падеж)
- `bekliyorum` — я жду (основной глагол)

**Объяснение:**
В этом предложении "чтобы он пришел" превращается в "его приход" (onun gelmesi) с винительным падежом, который становится объектом глагола "ждать".

### 9.2 Пример: Практические упражнения

**Упражнение 1: Образуйте форму -masını/-mesini**

```
gelmek → Onun gelmesini bekliyorum
çalışmak → Ali'nin çalışmasını istiyorum
yapmak → Bunu yapmasını tercih ediyorum
```

**Объяснение:**
Практикуйтесь в образовании формы -masını/-mesini от различных глаголов.

**Упражнение 2: Выберите правильную форму**

```
beklemek → Onun gelmesini bekliyorum (винительный)
istemek → Bunu yapmasını istiyorum (винительный)
```

**Объяснение:**
Выбор формы зависит от глагола управления и наличия субъекта.

## 7. Сравнение с другими формами

### 7.1 -ma vs -masını

**Пример: Сравнение**

```
Çalışmayı seviyorum. (-mayı - без субъекта)
Я люблю работать.

Onun çalışmasını istiyorum. (-masını - с субъектом)
Я хочу, чтобы он работал.
```

**Объяснение:**
-mayı используется для действия без указания на конкретного субъекта (действие говорящего). -masını используется для действия другого лица.

---

## 💡 Key Takeaways

- **Винительный падеж**: -masını/-mesini используется для действия как прямого дополнения
- **С субъектом**: -masını указывает на действие другого лица
- **После глаголов управления**: Используется после beklemek, istemek, umut etmek и др.
- **Отличие от -ması**: -ması именительный (подлежащее), -masını винительный (дополнение)
- **Основа понимания**: Понимание -masını необходимо для выражения желаний и ожиданий относительно действий других

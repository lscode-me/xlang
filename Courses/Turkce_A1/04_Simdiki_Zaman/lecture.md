## 1. Что такое Şimdiki Zaman

Şimdiki Zaman (настоящее продолженное время) используется для описания действий, происходящих в момент речи или в настоящее время в широком смысле. Это одно из самых важных времен в турецком языке, которое используется очень часто в повседневной речи.

### 1.1 Основные случаи использования

**Şimdiki Zaman применяется для:**

- Действий, происходящих прямо сейчас
- Действий, происходящих в настоящее время (не обязательно в данный момент)
- Временных ситуаций и состояний
- Планов на ближайшее будущее (в разговорной речи)

**Пример: Действие прямо сейчас**

```

Ben çalışıyorum.
[Бен чалышыорум]
Я работаю (сейчас).
```

**Объяснение:**
В этом случае -yor описывает действие, которое происходит в момент речи.

**Пример: Действие в настоящее время**

```

Ben İstanbul'da yaşıyorum.
[Бен Иста'нбулда яшыорум]
Я живу в Стамбуле (в настоящее время).
```

**Объяснение:**
В этом случае -yor описывает ситуацию, которая имеет место в настоящее время, но не обязательно происходит прямо сейчас.

**Пример: План на будущее**

```

Yarın okula gidiyorum.
[Яран окула гидийорум]
Завтра я иду в школу (план).
```

**Объяснение:**
В разговорной речи -yor может использоваться для выражения планов на ближайшее будущее.

## 2. Образование Şimdiki Zaman

### 2.1 Структура образования

**Формула:**

```

Основа глагола + -yor + личное окончание
```

**Шаги образования:**

1. Берем основу глагола (инфинитив без -mek/-mak)
2. Добавляем суффикс -yor (с учетом гармонии гласных)
3. Добавляем личное окончание

**Пример: Процесс образования**

```

Глагол: çalışmak (работать)
Шаг 1: Основа - çalış-
Шаг 2: Добавляем -yor → çalışıyor (последняя гласная "ı")
Шаг 3: Добавляем личное окончание → çalışıyorum (для "ben")
Результат: Ben çalışıyorum. [Бен чалышыорум] - Я работаю.
```

**Объяснение:**
Образование -yor происходит в три этапа: основа → суффикс -yor → личное окончание.

### 2.2 Суффикс -yor и гармония гласных

Суффикс -yor имеет четыре варианта в зависимости от последней гласной основы:

**Таблица вариантов -yor:**

| Последняя гласная основы | Вариант -yor | Пример |
|-------------------------|--------------|--------|
| a, ı | -ıyor | çalışmak → çalışıyor |
| e, i | -iyor | gelmek → geliyor |
| o, u | -uyor | okumak → okuyor |
| ö, ü | -üyor | görmek → görüyor |

**Пример: Образование с разными гласными**

```

çalışmak (работать) → çalış-ıyor (последняя гласная "ı")
okumak (читать) → oku-yor (последняя гласная "u")
gelmek (приходить) → gel-iyor (последняя гласная "e")
görmek (видеть) → gör-üyor (последняя гласная "ö")
```

**Объяснение:**
Выбор варианта -yor зависит от последней гласной основы глагола. Это правило гармонии гласных.

### 2.3 Правило выбора варианта -yor

**Шаги выбора:**

1. Определить основу глагола
2. Определить последнюю гласную основы
3. Выбрать соответствующий вариант -yor из таблицы

**Пример: Процесс выбора**

```

Глагол: çalışmak
Основа: çalış-
Последняя гласная: ı (твердая)
Вариант -yor: -ıyor
Результат: çalışıyor
```

**Объяснение:**
В основе "çalış-" последняя гласная "ı" твердая, поэтому используется -ıyor.

## 3. Личные окончания

После суффикса -yor добавляются личные окончания.

### 3.1 Таблица личных окончаний

**Таблица:**

| Лицо | Окончание | Пример |
|------|-----------|--------|
| ben | -um / -üm | çalışıyorum |
| sen | -sun / -sün | çalışıyorsun |
| o | - (нет окончания) | çalışıyor |
| biz | -uz / -üz | çalışıyoruz |
| siz | -sunuz / -sünüz | çalışıyorsunuz |
| onlar | -lar / -ler | çalışıyorlar |

**Объяснение:**
Выбор окончания зависит от гармонии гласных суффикса -yor.

### 3.2 Примеры для всех лиц

**Пример: Глагол "çalışmak" (работать)**

```

Ben çalışıyorum. [Бен чалышыйорум] - Я работаю.
Sen çalışıyorsun. [Сен чалышыйорсун] - Ты работаешь.
O çalışıyor. [О чалышыйор] - Он/Она работает.
Biz çalışıyoruz. [Биз чалышыйоруз] - Мы работаем.
Siz çalışıyorsunuz. [Сиз чалышыйорсунуз] - Вы работаете.
Onlar çalışıyorlar. [Онлар чалышыйорлар] - Они работают.
```

**Объяснение:**
В слове "çalışmak" последняя гласная "ı", поэтому используется -ıyor, затем добавляются личные окончания.

**Пример: Глагол "okumak" (читать)**

```

Ben okuyorum. [Бен окуйорум] - Я читаю.
Sen okuyorsun. [Сен окуйорсун] - Ты читаешь.
O okuyor. [О окуёр] - Он/Она читает.
Biz okuyoruz. [Биз окуйоруз] - Мы читаем.
Siz okuyorsunuz. [Сиз окуйорсунуз] - Вы читаете.
Onlar okuyorlar. [Онлар окуйорлар] - Они читают.
```

**Объяснение:**
В слове "okumak" последняя гласная "u", поэтому используется -uyor.

**Пример: Глагол "gelmek" (приходить)**

```

Ben geliyorum. [Бен гелийорум] - Я прихожу.
Sen geliyorsun. [Сен гелийорсун] - Ты приходишь.
O geliyor. [О гелийор] - Он/Она приходит.
Biz geliyoruz. [Биз гелийоруз] - Мы приходим.
Siz geliyorsunuz. [Сиз гелийорсунуз] - Вы приходите.
Onlar geliyorlar. [Онлар гелийорлар] - Они приходят.
```

**Объяснение:**
В слове "gelmek" последняя гласная "e", поэтому используется -iyor.

## 4. Особые случаи образования

### 4.1 Глаголы, оканчивающиеся на гласную

Когда основа глагола оканчивается на гласную, между основой и -yor может вставляться согласная "y".

**Пример: Глаголы на гласную**

```

yemek (есть) → ye-mek → yiyor (вставляется "y")
demek (говорить) → de-mek → diyor (вставляется "y")
```

**Пример: Использование**

```

Ben yemek yiyorum. [Бен йемек йийорум] - Я ем еду.
Sen ne diyorsun? [Сен не дийорсун?] - Что ты говоришь?
O yiyor. [О йийор] - Он/Она ест.
```

**Объяснение:**
Согласная "y" вставляется для удобства произношения между гласными.

**Пример: Другие глаголы на гласную**

```

istemek (хотеть) → istiyor [истийор]
sevmek (любить) → seviyor [севийор]
```

**Объяснение:**
Для всех глаголов, оканчивающихся на гласную, вставляется "y" перед -yor.

### 4.2 Глаголы с изменением основы

Некоторые глаголы имеют изменения в основе при образовании -yor.

**Пример: Изменения в основе**

```

gitmek (идти) → gidiyor (t → d)
etmek (делать) → ediyor (t → d)
```

**Пример: Использование**

```

Ben okula gidiyorum. [Бен окула гидийорум] - Я иду в школу.
O ne ediyor? [О не эдийор?] - Что он/она делает?
```

**Объяснение:**
Некоторые согласные в основе глагола могут изменяться при добавлении суффикса для удобства произношения.

### 4.3 Глаголы с удвоением согласных

**Пример: Удвоение согласных**

```

almak (брать) → alıyor [алыор]
vermek (давать) → veriyor [верийор]
```

**Объяснение:**
Некоторые глаголы могут иметь особенности в образовании, но правило гармонии гласных сохраняется.

## 5. Утвердительные предложения

### 5.1 Базовые утвердительные предложения

**Пример: Простые предложения**

```

Ben kahve içiyorum. [Бен кахве ичийорум] - Я пью кофе.
Sen kitap okuyorsun. [Сен китап окуйорсун] - Ты читаешь книгу.
O televizyon izliyor. [О телевизьон излийор] - Он/Она смотрит телевизор.
Biz çalışıyoruz. [Биз чалышыоруз] - Мы работаем.
Siz okuyorsunuz. [Сиз окуйорсунуз] - Вы читаете.
Onlar geliyorlar. [Онлар гелийорлар] - Они приходят.
```

**Объяснение:**
Порядок слов: подлежащее + дополнение + сказуемое. Глагол в форме -yor стоит в конце.

### 5.2 Предложения с обстоятельствами

**Пример: С обстоятельством времени**

```

Ben şimdi çalışıyorum. [Бен шимди чалышыорум] - Я сейчас работаю.
Sen bugün ne yapıyorsun? [Сен бугюн не япыйорсун?] - Что ты делаешь сегодня?
O yarın gidiyor. [О яран гидийор] - Он/Она завтра идет.
```

**Пример: С обстоятельством места**

```

Ben evde okuyorum. [Бен эвде окуйорум] - Я дома читаю.
O okulda çalışıyor. [О окулда чалышыор] - Он/Она в школе работает.
Biz parkta yürüyoruz. [Биз паркта юрюйоруз] - Мы в парке гуляем.
```

**Объяснение:**
Обстоятельства времени и места обычно стоят после подлежащего, но перед дополнением.

### 5.3 Предложения с несколькими элементами

**Пример: С обстоятельствами времени и места**

```

Ben sabah evde çalışıyorum. [Бен сабах эвде чалышыорум] - Я утром дома работаю.
Sen akşam okulda okuyorsun. [Сен акшам окулда окуйорсун] - Ты вечером в школе читаешь.
```

**Объяснение:**
Когда есть несколько обстоятельств, они следуют друг за другом после подлежащего.

## 6. Вопросительные предложения

### 6.1 Общие вопросы (да/нет)

Для образования общих вопросов используется вопросительная частица mi/mı/mu/mü после глагола.

**Пример: Общие вопросы**

```

Sen çalışıyor musun? [Сен чалышыор мусун?] - Ты работаешь?
O okuyor mu? [О окуёр му?] - Он/Она читает?
Biz gidiyor muyuz? [Биз гидийор муйуз?] - Мы идем?
Siz geliyor musunuz? [Сиз гелийор мусунуз?] - Вы приходите?
```

**Объяснение:**
Вопросительная частица выбирается в зависимости от последней гласной в форме -yor, затем добавляется личное окончание.

### 6.2 Специальные вопросы

**Пример: Вопросы с "ne" (что)**

```

Sen ne yapıyorsun? [Сен не япыйорсун?] - Что ты делаешь?
O ne okuyor? [О не окуёр?] - Что он/она читает?
Ne içiyorsun? [Не ичийорсун?] - Что ты пьешь?
```

**Пример: Вопросы с "kim" (кто)**

```

Kim geliyor? [Ким гелийор?] - Кто приходит?
Kim çalışıyor? [Ким чалышыор?] - Кто работает?
Kim okuyor? [Ким окуёр?] - Кто читает?
```

**Пример: Вопросы с "nereye" (куда)**

```

Nereye gidiyorsun? [Нерейе гидийорсун?] - Куда ты идешь?
Nereye gidiyor? [Нерейе гидийор?] - Куда он/она идет?
```

**Пример: Вопросы с "nerede" (где)**

```

Nerede çalışıyorsun? [Нереде чалышыорсун?] - Где ты работаешь?
Nerede okuyorsun? [Нереде окуйорсун?] - Где ты читаешь?
```

**Объяснение:**
В специальных вопросах вопросительное слово стоит после подлежащего (или в начале, если вопрос к подлежащему), глагол остается в конце.

## 7. Практические примеры

### 7.1 Пример: Описание текущих действий

**Текст:**

```

Ben şimdi kahve içiyorum. [Бен шимди кахве ичийорум] - Я сейчас пью кофе.
Sen ne yapıyorsun? [Сен не япыйорсун?] - Что ты делаешь?
O televizyon izliyor. [О телевизьон излийор] - Он/Она смотрит телевизор.
Biz çalışıyoruz. [Биз чалышыоруз] - Мы работаем.
```

**Объяснение:**
Настоящее продолженное время используется для описания действий, происходящих в момент речи.

### 7.2 Пример: Описание настоящей ситуации

**Текст:**

```

Ben İstanbul'da yaşıyorum. [Бен Иста'нбулда яшыорум] - Я живу в Стамбуле.
O bir öğrenci. O üniversitede okuyor. [О бир ёренджи. О юниверситеде окуёр] - Он/Она студент. Он/Она учится в университете.
Sen nerede çalışıyorsun? [Сен нереде чалышыорсун?] - Где ты работаешь?
Ben bir şirkette çalışıyorum. [Бен бир ширкетте чалышыорум] - Я работаю в компании.
```

**Объяснение:**
Настоящее продолженное время используется для описания ситуаций, которые имеют место в настоящее время.

### 7.3 Пример: Диалог

**Диалог:**

```

A: Sen ne yapıyorsun? [Сен не япыйорсун?] - Что ты делаешь?
B: Ben kitap okuyorum. [Бен китап окуйорум] - Я читаю книгу.
A: Hangi kitabı okuyorsun? [Ханги китабы окуйорсун?] - Какую книгу ты читаешь?
B: Türkçe kitabı okuyorum. [Тюркче китабы окуйорум] - Я читаю турецкую книгу.
A: Nerede okuyorsun? [Нереде окуйорсун?] - Где ты читаешь?
B: Ben evde okuyorum. [Бен эвде окуйорум] - Я дома читаю.
```

**Объяснение:**
В разговорах настоящее продолженное время используется для обсуждения текущих действий и ситуаций.

### 7.4 Пример: Описание распорядка дня

**Текст:**

```

Ben sabah kalkıyorum. [Бен сабах калькыйорум] - Я утром встаю.
Sonra kahvaltı yapıyorum. [Сонра кахвальты япыйорум] - Потом я завтракаю.
Öğle yemek yiyorum. [Ёле йемек йийорум] - Я ем обед.
Akşam televizyon izliyorum. [Акшам телевизьон излийорум] - Я вечером смотрю телевизор.
Gece uyuyorum. [Гедже уйуйорум] - Я ночью сплю.
```

**Объяснение:**
Настоящее продолженное время используется для описания регулярных действий и распорядка дня.

## 8. Различие с другими временами

### 8.1 -yor vs другие времена

**Важно:** Различие между -yor и другими временами в турецком языке.

**Пример: -yor (настоящее продолженное)**

```

Ben çalışıyorum. [Бен чалышыорум] - Я работаю (сейчас или в настоящее время).
```

**Объяснение:**

-yor используется для действий в настоящем времени.

**Пример: Будущее время (в разговорной речи)**

```

Yarın gidiyorum. [Яран гидийорум] - Завтра я иду (план).
```

**Объяснение:**
В разговорной речи -yor может использоваться для выражения планов на ближайшее будущее.

## 9. Частые ошибки

### 9.1 Ошибка: Неправильный выбор варианта -yor

❌ **Неправильно:**

```

Ben çalışıyorum. (если основа оканчивается на "a")
```

✅ **Правильно:**

```

Ben çalışıyorum. [Бен чалышыорум] - Я работаю.
```

**Why:** В глаголе "çalışmak" последняя гласная основы "ı" (çalış-), поэтому используется -ıyor.

### 9.2 Ошибка: Забыть личное окончание

❌ **Неправильно:**

```

Ben çalışıyor. (без окончания для первого лица)
```

✅ **Правильно:**

```

Ben çalışıyorum. [Бен чалышыорум] - Я работаю.
```

**Why:** Для первого лица единственного числа (ben) обязательно окончание -um/-üm.

### 9.3 Ошибка: Неправильный порядок слов

❌ **Неправильно:**

```

Çalışıyorum ben. (глагол не в конце)
```

✅ **Правильно:**

```

Ben çalışıyorum. [Бен чалышыорум] - Я работаю.
```

**Why:** В турецком языке глагол всегда должен стоять в конце предложения.

### 9.4 Ошибка: Неправильная вставка "y"

❌ **Неправильно:**

```

yemek → yemiyor (без вставки "y")
```

✅ **Правильно:**

```

yemek → yiyor [йийор] - ест (с вставкой "y")
```

**Why:** Для глаголов, оканчивающихся на гласную, необходимо вставлять "y" перед -yor.

## 10. Дополнительные примеры

### 10.1 Пример: Разные типы глаголов

**Глаголы с твердыми гласными:**

```

çalışmak → çalışıyor [чалышыор] - работает
okumak → okuyor [окуёр] - читает
almak → alıyor [алыор] - берет
```

**Глаголы с мягкими гласными:**

```

gelmek → geliyor [гелийор] - приходит
yemek → yiyor [йийор] - ест

```

### 10.2 Пример: В предложениях с разными элементами

**Пример: Полные предложения**

```

Ben şimdi evde kitap okuyorum. [Бен шимди эвде китап окуйорум] - Я сейчас дома читаю книгу.
Sen bugün okulda ne yapıyorsun? [Сен бугюн окулда не япыйорсун?] - Что ты сегодня в школе делаешь?
O yarın işe gidiyor. [О яран ише гидийор] - Он/Она завтра идет на работу.
```

**Объяснение:**
Настоящее продолженное время используется в различных типах предложений с разными элементами.

---

## 💡 Key Takeaways

- **Şimdiki Zaman** образуется с помощью суффикса **-yor** + личное окончание

- **Вариант -yor** выбирается в зависимости от последней гласной основы глагола

- **Личные окончания** добавляются после -yor с учетом гармонии гласных

- **Глагол всегда в конце** предложения в турецком языке

- **-yor** используется как для действий прямо сейчас, так и для действий в широком настоящем времени

- **В разговорной речи** -yor может использоваться для выражения планов на ближайшее будущее

- **Глаголы на гласную** требуют вставки "y" перед -yor

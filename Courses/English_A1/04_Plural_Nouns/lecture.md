## 1. Введение во множественное число

В английском языке, как и в русском, существительные имеют единственное число (one - один) и множественное число (two or more - два или больше).

**Сравнение:**

```

Единственное число (singular):
one book - одна книга
one cat - один кот
one child - один ребенок

Множественное число (plural):
two books - две книги
three cats - три кота
five children - пять детей
```

## 2. Правильное множественное число (Regular Plurals)

Большинство существительных образуют множественное число по стандартным правилам.

### 2.1 Добавление -S

К большинству существительных просто добавляется окончание **-s**.

**Примеры:**

```

book - books [bʊks] - книга - книги
cat - cats [kæts] - кот - коты
dog - dogs [dɒɡz] - собака - собаки
pen - pens [penz] - ручка - ручки
car - cars [kɑːz] - машина - машины
table - tables [ˈteɪblz] - стол - столы
apple - apples [ˈæplz] - яблоко - яблоки
student - students [ˈstjuːdənts] - студент - студенты
```

**Объяснение:**
Это самое простое и распространенное правило. Просто добавляем -s в конце слова.

### 2.2 Добавление -ES

После букв **s, ss, x, z, ch, sh** добавляется окончание **-es** (произносится [ɪz]).

**Примеры:**

```

bus - buses [ˈbʌsɪz] - автобус - автобусы
class - classes [ˈklɑːsɪz] - класс - классы
box - boxes [ˈbɒksɪz] - коробка - коробки
dish - dishes [ˈdɪʃɪz] - тарелка - тарелки
watch - watches [ˈwɒtʃɪz] - часы - часы (множество)
church - churches [ˈtʃɜːtʃɪz] - церковь - церкви
brush - brushes [ˈbrʌʃɪz] - щетка - щетки
```

**Объяснение:**
После шипящих и свистящих звуков нужно добавить -es, чтобы слово было легче произнести. Окончание -es добавляет дополнительный слог.

### 2.3 Существительные на -Y

**Если перед Y стоит согласная:** Y меняется на I и добавляется -ES

```

city - cities [ˈsɪtiz] - город - города
baby - babies [ˈbeɪbiz] - младенец - младенцы
country - countries [ˈkʌntriz] - страна - страны
story - stories [ˈstɔːriz] - история - истории
family - families [ˈfæməliz] - семья - семьи
party - parties [ˈpɑːtiz] - вечеринка - вечеринки
lady - ladies [ˈleɪdiz] - дама - дамы
```

**Если перед Y стоит гласная:** просто добавляем -S

```

boy - boys [bɔɪz] - мальчик - мальчики
day - days [deɪz] - день - дни
key - keys [kiːz] - ключ - ключи
toy - toys [tɔɪz] - игрушка - игрушки
```

**Объяснение:**
Правило с Y помогает сохранить правильное произношение слова.

### 2.4 Существительные на -F/-FE

Многие существительные на **-f** или **-fe** меняют F на V и добавляют -ES.

**Примеры:**

```

leaf - leaves [liːvz] - лист - листья
knife - knives [naɪvz] - нож - ножи
wife - wives [waɪvz] - жена - жены
life - lives [laɪvz] - жизнь - жизни
shelf - shelves [ʃelvz] - полка - полки
wolf - wolves [wʊlvz] - волк - волки
half - halves [hɑːvz] - половина - половины
thief - thieves [θiːvz] - вор - воры
```

**Исключения** (просто добавляем -s):

```

roof - roofs [ruːfs] - крыша - крыши
chief - chiefs [tʃiːfs] - начальник - начальники
belief - beliefs [bɪˈliːfs] - убеждение - убеждения
cliff - cliffs [klɪfs] - утес - утесы
```

### 2.5 Существительные на -O

**Если перед O стоит согласная:** обычно добавляем -ES

```

tomato - tomatoes [təˈmɑːtəʊz] - помидор - помидоры
potato - potatoes [pəˈteɪtəʊz] - картофель - картофелины
hero - heroes [ˈhɪərəʊz] - герой - герои
echo - echoes [ˈekəʊz] - эхо - эхо (мн.ч.)
```

**Если перед O стоит гласная:** добавляем только -S

```

zoo - zoos [zuːz] - зоопарк - зоопарки
radio - radios [ˈreɪdiəʊz] - радио - радиоприемники
video - videos [ˈvɪdiəʊz] - видео - видео
```

**Исключения** (с согласной, но добавляем -S):

```

photo - photos [ˈfəʊtəʊz] - фото - фотографии
piano - pianos [piˈænəʊz] - пианино - пианино (мн.ч.)
```

## 3. Произношение окончания -S/-ES

Окончание множественного числа может произноситься тремя способами:

### 3.1 Произношение [s]

После **глухих согласных** (p, t, k, f): окончание произносится как [s]

```

books [bʊks] - книги
cats [kæts] - коты
cups [kʌps] - чашки
roofs [ruːfs] - крыши
```

### 3.2 Произношение [z]

После **звонких согласных и гласных**: окончание произносится как [z]

```

dogs [dɒɡz] - собаки
pens [penz] - ручки
cars [kɑːz] - машины
boys [bɔɪz] - мальчики
tables [ˈteɪblz] - столы
```

### 3.3 Произношение [ɪz]

После **s, ss, z, x, ch, sh, ge, ce**: окончание произносится как [ɪz] (добавляется слог)

```

buses [ˈbʌsɪz] - автобусы
classes [ˈklɑːsɪz] - классы
boxes [ˈbɒksɪz] - коробки
dishes [ˈdɪʃɪz] - тарелки
watches [ˈwɒtʃɪz] - часы
garages [ˈɡærɑːʒɪz] - гаражи
```

## 4. Неправильное множественное число (Irregular Plurals)

Некоторые существительные образуют множественное число особым способом. Их нужно запомнить.

### 4.1 Изменение гласной

```

man - men [men] - мужчина - мужчины
woman - women [ˈwɪmɪn] - женщина - женщины
foot - feet [fiːt] - ступня - ступни
tooth - teeth [tiːθ] - зуб - зубы
goose - geese [ɡiːs] - гусь - гуси
mouse - mice [maɪs] - мышь - мыши
```

**Примеры в предложениях:**

```

One man - two men
Один мужчина - два мужчины

One woman - three women
Одна женщина - три женщины

I have one tooth. He has white teeth.
У меня один зуб. У него белые зубы.
```

### 4.2 Изменение окончания

```

child - children [ˈtʃɪldrən] - ребенок - дети
ox - oxen [ˈɒksən] - бык - быки
```

**Примеры:**

```

I have one child. They have three children.
У меня один ребенок. У них три ребенка.

The children are playing.
Дети играют.
```

### 4.3 Не изменяются (одинаковая форма)

Некоторые существительные имеют одинаковую форму в единственном и множественном числе.

```

sheep - sheep [ʃiːp] - овца - овцы
fish - fish [fɪʃ] - рыба - рыбы
deer - deer [dɪə] - олень - олени
series - series [ˈsɪəriːz] - серия - серии
species - species [ˈspiːʃiːz] - вид - виды
```

**Примеры:**

```

one sheep - five sheep
одна овца - пять овец

one fish - ten fish
одна рыба - десять рыб
```

### 4.4 Латинские и греческие заимствования

```

analysis - analyses [əˈnæləsiːz] - анализ - анализы
crisis - crises [ˈkraɪsiːz] - кризис - кризисы
phenomenon - phenomena [fəˈnɒmɪnə] - феномен - феномены
criterion - criteria [kraɪˈtɪəriə] - критерий - критерии
```

## 5. Особые случаи

### 5.1 Существительные только во множественном числе

Некоторые существительные употребляются только во множественном числе и требуют глагола во множественном числе.

```

scissors [ˈsɪzəz] - ножницы (The scissors are on the table.)
trousers [ˈtraʊzəz] - брюки (My trousers are new.)
glasses [ˈɡlɑːsɪz] - очки (Where are my glasses?)
jeans [dʒiːnz] - джинсы (These jeans are expensive.)
shorts [ʃɔːts] - шорты (His shorts are blue.)
clothes [kləʊðz] - одежда (The clothes are clean.)
```

**Примеры:**

```

Where are my scissors?
Где мои ножницы?

These trousers are too big.
Эти брюки слишком большие.
```

### 5.2 Существительные только в единственном числе

Неисчисляемые существительные не имеют множественного числа.

```

water [ˈwɔːtə] - вода (не "waters" в обычном смысле)
milk [mɪlk] - молоко
bread [bred] - хлеб
money [ˈmʌni] - деньги
information [ˌɪnfəˈmeɪʃən] - информация
advice [ədˈvaɪs] - совет
furniture [ˈfɜːnɪtʃə] - мебель
homework [ˈhəʊmwɜːk] - домашняя работа
```

## 6. Практическое использование

### 6.1 С числительными

```

one book - одна книга
two books - две книги
three cats - три кота
five children - пять детей
ten men - десять мужчин
```

### 6.2 С this/that и these/those

```

Единственное число:
this book - эта книга
that cat - тот кот

Множественное число:
these books - эти книги
those cats - те коты
```

### 6.3 С глаголом to be

```

Единственное число:
The book is interesting. - Книга интересная.
The cat is black. - Кот черный.

Множественное число:
The books are interesting. - Книги интересные.
The cats are black. - Коты черные.
```

## 7. Типичные ошибки русскоговорящих

### 7.1 Забывают добавить -S

❌ **Неправильно:**
```

I have two cat.
She has three book.
There are many student.
```

✅ **Правильно:**
```

I have two cats.
У меня два кота.

She has three books.
У нее три книги.

There are many students.
Там много студентов.
```

**Объяснение:**
В русском языке множественное число образуется по-другому, поэтому русскоговорящие часто забывают добавить -s.

### 7.2 Неправильное множественное число неправильных форм

❌ **Неправильно:**
```

three childs
two mans
five womans
```

✅ **Правильно:**
```

three children
три ребенка

two men
два мужчины

five women
пять женщин
```

**Объяснение:**
Неправильные формы нужно запомнить, их нельзя образовать по стандартному правилу.

### 7.3 Добавление -S к неисчисляемым

❌ **Неправильно:**
```

I need two waters.
She has many informations.
Can I have some breads?
```

✅ **Правильно:**
```

I need two bottles of water. / I need some water.
Мне нужны две бутылки воды. / Мне нужна вода.

She has much information.
У нее много информации.

Can I have some bread?
Могу я взять немного хлеба?
```

**Объяснение:**
Неисчисляемые существительные не имеют множественного числа. Используйте количественные слова (bottle of, piece of).

### 7.4 Неправильное окончание после Y

❌ **Неправильно:**
```

three babys
two citys
four ladys
```

✅ **Правильно:**
```

three babies
три младенца

two cities
два города

four ladies
четыре дамы
```

**Объяснение:**
Когда перед Y стоит согласная, Y меняется на I, и добавляется -es.

### 7.5 Путаница с this/these и that/those

❌ **Неправильно:**
```

This books are interesting.
That cats are black.
These book is good.
```

✅ **Правильно:**
```

These books are interesting.
Эти книги интересные.

Those cats are black.
Те коты черные.

This book is good.
Эта книга хорошая.
```

**Объяснение:**
This/that - для единственного числа, these/those - для множественного.

## 8. Практические примеры

### 8.1 Example: В магазине

```

- I need three apples, two tomatoes, and five potatoes.
- Мне нужны три яблока, два помидора и пять картофелин.

- Here you are. Do you need anything else?
- Вот, пожалуйста. Вам нужно что-то еще?

- Yes, I also need some bread and a bottle of milk.
- Да, мне также нужен хлеб и бутылка молока.
```

### 8.2 Example: О семье

```

I have a big family. I have two brothers and one sister.
My brothers are students. They study at universities.
My sister has three children - two boys and one girl.
The children are very active. They like toys and games.

У меня большая семья. У меня два брата и одна сестра.
Мои братья студенты. Они учатся в университетах.
У моей сестры трое детей - два мальчика и одна девочка.
Дети очень активные. Они любят игрушки и игры.
```

### 8.3 Example: Описание класса

```

In my classroom, there are twenty desks and twenty chairs.
There are three windows and two doors.
On the walls, there are many pictures and two clocks.
The students have books, pens, and pencils.
The teacher has a computer and some papers.

В моем классе двадцать парт и двадцать стульев.
Есть три окна и две двери.
На стенах много картин и двое часов.
У студентов есть книги, ручки и карандаши.
У учителя есть компьютер и бумаги.
```

## 9. Дополнительные примеры по категориям

### 9.1 Животные (Animals)

```

Единственное число → Множественное число

- cat → cats (кошка → кошки)
- dog → dogs (собака → собаки)
- bird → birds (птица → птицы)
- fish → fish (рыба → рыбы) [одинаковая форма]
- mouse → mice (мышь → мыши) [неправильная]
- goose → geese (гусь → гуси) [неправильная]
- sheep → sheep (овца → овцы) [одинаковая форма]
- deer → deer (олень → олени) [одинаковая форма]
- wolf → wolves (волк → волки)
- fox → foxes (лиса → лисы)
```

**Примеры в предложениях:**
```

- I have two cats and one dog.
- У меня две кошки и одна собака.

- The mice are in the kitchen.
- Мыши на кухне.

- We saw many deer in the forest.
- Мы видели много оленей в лесу.

- Those geese are very noisy!
- Те гуси очень шумные!
```

### 9.2 Еда (Food)

```

Единственное число → Множественное число

- apple → apples (яблоко → яблоки)
- tomato → tomatoes (помидор → помидоры)
- potato → potatoes (картофель → картофелины)
- sandwich → sandwiches (бутерброд → бутерброды)
- pizza → pizzas (пицца → пиццы)
- cake → cakes (торт → торты)
- dish → dishes (блюдо → блюда)
- glass → glasses (стакан → стаканы)
- knife → knives (нож → ножи)
- berry → berries (ягода → ягоды)
```

**Примеры в предложениях:**
```

- I bought three kilos of tomatoes and five potatoes.
- Я купил три килограмма помидоров и пять картофелин.

- We need more knives and forks for the party.
- Нам нужно больше ножей и вилок для вечеринки.

- She baked two cakes and many cookies.
- Она испекла два торта и много печенья.

- Put the apples in the boxes, please.
- Положите яблоки в коробки, пожалуйста.
```

### 9.3 Предметы (Objects)

```

Единственное число → Множественное число

- phone → phones (телефон → телефоны)
- computer → computers (компьютер → компьютеры)
- watch → watches (часы → часы)
- key → keys (ключ → ключи)
- box → boxes (коробка → коробки)
- brush → brushes (щетка → щетки)
- match → matches (спичка → спички)
- glass → glasses (стекло/стакан → стекла/стаканы)
- shelf → shelves (полка → полки)
- half → halves (половина → половины)
```

**Примеры в предложениях:**
```

- Where are my keys? I can't find them.
- Где мои ключи? Я не могу их найти.

- Put the boxes on the shelves.
- Поставь коробки на полки.

- We have three watches but only two batteries.
- У нас трое часов, но только две батарейки.

- The glasses are in the cupboard.
- Стаканы в шкафу.
```

### 9.4 Люди (People)

```

Единственное число → Множественное число

- man → men (мужчина → мужчины)
- woman → women (женщина → женщины)
- child → children (ребенок → дети)
- person → people (человек → люди)
- baby → babies (младенец → младенцы)
- boy → boys (мальчик → мальчики)
- girl → girls (девочка → девочки)
- student → students (студент → студенты)
- teacher → teachers (учитель → учителя)
- friend → friends (друг → друзья)
```

**Примеры в предложениях:**
```

- There are three men and two women in the room.
- В комнате три мужчины и две женщины.

- The children are playing in the park.
- Дети играют в парке.

- Many people visit this museum.
- Многие люди посещают этот музей.

- My friends are students at the university.
- Мои друзья - студенты университета.
```

### 9.5 Части тела (Body Parts)

```

Единственное число → Множественное число

- foot → feet (нога → ноги)
- tooth → teeth (зуб → зубы)
- hand → hands (рука/кисть → руки)
- finger → fingers (палец → пальцы)
- eye → eyes (глаз → глаза)
- ear → ears (ухо → уши)
- arm → arms (рука → руки)
- leg → legs (нога → ноги)
- knee → knees (колено → колени)
- shoulder → shoulders (плечо → плечи)
```

**Примеры в предложениях:**
```

- My feet hurt after the long walk.
- Мои ноги болят после долгой прогулки.

- Brush your teeth twice a day.
- Чистите зубы два раза в день.

- She has beautiful blue eyes.
- У нее красивые голубые глаза.

- Wash your hands before dinner.
- Помой руки перед ужином.
```

### 9.6 Места и здания (Places and Buildings)

```

Единственное число → Множественное число

- city → cities (город → города)
- country → countries (страна → страны)
- library → libraries (библиотека → библиотеки)
- university → universities (университет → университеты)
- church → churches (церковь → церкви)
- beach → beaches (пляж → пляжи)
- factory → factories (фабрика → фабрики)
- office → offices (офис → офисы)
- store → stores (магазин → магазины)
- building → buildings (здание → здания)
```

**Примеры в предложениях:**
```

- I visited three cities in Europe last summer.
- Я посетил три города в Европе прошлым летом.

- There are many beautiful churches in this country.
- В этой стране много красивых церквей.

- The beaches here are clean and sandy.
- Пляжи здесь чистые и песчаные.

- These buildings are very old.
- Эти здания очень старые.
```

## 💡 Key Takeaways

После изучения этого модуля запомните:

- **Правильное множественное:** добавляем -s к большинству существительных (book - books)

- **После s, x, z, ch, sh:** добавляем -es (box - boxes, dish - dishes)

- **Согласная + Y:** меняем Y на I, добавляем -es (city - cities)

- **Многие слова на -f/-fe:** меняем F на V, добавляем -es (knife - knives)

- **Неправильные формы:** нужно запомнить (man - men, child - children, foot - feet)

- **Одинаковая форма:** sheep - sheep, fish - fish, deer - deer

- **Произношение:** [s] после глухих, [z] после звонких и гласных, [ɪz] после шипящих

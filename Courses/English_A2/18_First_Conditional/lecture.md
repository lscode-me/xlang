## 1. Введение в First Conditional

**First Conditional (Первое условное предложение)** используется для описания **реальных** или **вероятных** ситуаций в **будущем**.

### 1.1 Что такое First Conditional?

First Conditional описывает ситуацию: **"Если произойдет A, то произойдет B"**.

Мы говорим о **реальной возможности** в будущем.

**Структура:**

```

If + Present Simple, will + verb
Если + настоящее время, будущее время
```

**Примеры:**

```

If it rains, I will take an umbrella.
Если пойдет дождь, я возьму зонтик.
(Реальная возможность: может пойти дождь)

If you study hard, you will pass the exam.
Если ты будешь учиться усердно, ты сдашь экзамен.
(Реальная возможность: ты можешь учиться усердно)

If she comes, we will start the meeting.
Если она придет, мы начнем встречу.
(Реальная возможность: она может прийти)
```

### 1.2 Когда используется First Conditional?

**1. Реальные условия в будущем:**

```

If I have time, I'll help you.
Если у меня будет время, я помогу тебе.

If the weather is good, we'll go to the park.
Если погода будет хорошей, мы пойдем в парк.

If you call me, I'll answer.
Если ты позвонишь мне, я отвечу.
```

**2. Предсказания:**

```

If you eat too much, you'll feel sick.
Если ты съешь слишком много, тебе станет плохо.

If you don't hurry, you'll miss the train.
Если ты не поторопишься, ты опоздаешь на поезд.

If she doesn't study, she'll fail the exam.
Если она не будет учиться, она провалит экзамен.
```

**3. Предупреждения и угрозы:**

```

If you touch that, you'll get burned.
Если ты дотронешься до этого, ты обожжешься.

If you don't apologize, I'll never talk to you again.
Если ты не извинишься, я никогда больше не буду с тобой разговаривать.

If you're late again, you'll lose your job.
Если ты опоздаешь снова, ты потеряешь работу.
```

**4. Обещания:**

```

If you help me, I'll help you.
Если ты поможешь мне, я помогу тебе.

If you come to the party, I'll be very happy.
Если ты придешь на вечеринку, я буду очень счастлив.
```

**5. Советы и предложения:**

```

If you're tired, you should rest.
Если ты устал, тебе следует отдохнуть.

If you need help, just ask me.
Если тебе нужна помощь, просто спроси меня.
```

## 2. Структура First Conditional

### 2.1 Основная формула

**If + Present Simple, will + verb (base form)**

| If-clause (условие) | Main clause (результат) |
|---------------------|-------------------------|
| If + subject + verb (Present Simple) | subject + will + verb (base form) |
| If it rains | I will stay home |
| If you study | you will pass |
| If she comes | we will start |

**Примеры:**

```

If I see her, I will tell her.
Если я увижу ее, я скажу ей.

If you work hard, you will succeed.
Если ты будешь работать усердно, ты добьешься успеха.

If they invite us, we will go.
Если они пригласят нас, мы пойдем.

If he asks me, I will say yes.
Если он спросит меня, я скажу да.
```

### 2.2 Отрицательные формы

**If-clause (отрицание):**

```

If I don't see her, I won't tell her.
Если я не увижу ее, я не скажу ей.

If you don't study, you won't pass.
Если ты не будешь учиться, ты не сдашь.

If it doesn't rain, we'll go out.
Если не будет дождя, мы выйдем.

If she doesn't come, we'll start without her.
Если она не придет, мы начнем без нее.
```

**Main clause (отрицание):**

```

If you eat too much, you won't feel well.
Если ты съешь слишком много, ты не почувствуешь себя хорошо.

If he comes late, I won't wait for him.
Если он придет поздно, я не буду ждать его.
```

**Оба отрицательные:**

```

If you don't hurry, you won't catch the bus.
Если ты не поторопишься, ты не успеешь на автобус.

If they don't invite us, we won't go.
Если они не пригласят нас, мы не пойдем.
```

### 2.3 Вопросительные формы

**Вопрос в main clause:**

```

If it rains, will you stay home?
Если пойдет дождь, ты останешься дома?

If I help you, will you help me?
Если я помогу тебе, ты поможешь мне?

If she comes, will we start the meeting?
Если она придет, мы начнем встречу?

What will you do if it rains?
Что ты будешь делать, если пойдет дождь?

Where will you go if you have time?
Куда ты пойдешь, если у тебя будет время?
```

**Вопрос в if-clause:**

```

Will you help me if I ask you?
Ты поможешь мне, если я попрошу тебя?

Will she be angry if I'm late?
Она разозлится, если я опоздаю?
```

## 3. Порядок слов

### 3.1 Два порядка предложений

Условное предложение можно построить двумя способами:

**Вариант 1: If-clause + Main clause (с запятой)**

```

If it rains, I will stay home.
Если пойдет дождь, я останусь дома.

If you study hard, you will pass the exam.
Если ты будешь учиться усердно, ты сдашь экзамен.

If she comes, we will start.
Если она придет, мы начнем.
```

**Вариант 2: Main clause + If-clause (без запятой)**

```

I will stay home if it rains.
Я останусь дома, если пойдет дождь.

You will pass the exam if you study hard.
Ты сдашь экзамен, если будешь учиться усердно.

We will start if she comes.
Мы начнем, если она придет.
```

**⚠️ Важно:** 

- Если **if-clause в начале**, ставится **запятая** после него.
- Если **main clause в начале**, запятая **НЕ нужна**.

```

✅ If it rains, I'll stay home.
✅ I'll stay home if it rains.
❌ I'll stay home, if it rains. (лишняя запятая)
❌ If it rains I'll stay home. (нет запятой)
```

## 4. Сокращения

### 4.1 Will = 'll

В разговорной речи "will" часто сокращается до **'ll**:

```

If it rains, I'll stay home.
If you help me, I'll help you.
If she comes, we'll start.
If they invite us, we'll go.
```

### 4.2 Will not = won't

"Will not" сокращается до **won't**:

```

If you don't study, you won't pass.
If it doesn't rain, we won't stay home.
If she doesn't come, we won't start.
```

## 5. Модальные глаголы вместо will

В main clause можно использовать не только **will**, но и другие **модальные глаголы**: can, may, might, should, must.

### 5.1 Can (может, умеет)

```

If you finish early, you can go home.
Если ты закончишь рано, ты можешь пойти домой.

If you need help, you can call me.
Если тебе нужна помощь, ты можешь позвонить мне.

If she asks, I can help her.
Если она попросит, я могу помочь ей.
```

### 5.2 May / Might (может быть, возможно)

```

If it rains, we may stay home.
Если пойдет дождь, мы, возможно, останемся дома.

If you study hard, you might pass the exam.
Если ты будешь учиться усердно, ты, возможно, сдашь экзамен.

If she comes, we may start early.
Если она придет, мы, возможно, начнем рано.
```

### 5.3 Should (следует)

```

If you're tired, you should rest.
Если ты устал, тебе следует отдохнуть.

If you don't understand, you should ask.
Если ты не понимаешь, тебе следует спросить.

If she's sick, she should see a doctor.
Если она больна, ей следует обратиться к врачу.
```

### 5.4 Must (должен)

```

If you want to succeed, you must work hard.
Если ты хочешь добиться успеха, ты должен работать усердно.

If you come to the meeting, you must be on time.
Если ты придешь на встречу, ты должен быть вовремя.
```

### 5.5 Imperative (повелительное наклонение)

Вместо "will" можно использовать **повелительное наклонение** (команду):

```

If you see her, tell her to call me.
Если ты увидишь ее, скажи ей позвонить мне.

If you're tired, rest!
Если ты устал, отдыхай!

If it rains, take an umbrella.
Если пойдет дождь, возьми зонтик.

If you need help, just ask.
Если тебе нужна помощь, просто спроси.
```

## 6. Unless (если не)

**Unless** означает **"if not"** (если не). Это более формальный способ выражения отрицательного условия.

### 6.1 Unless = If not

```

Unless it rains, we'll go out.
= If it doesn't rain, we'll go out.
Если не будет дождя, мы выйдем.

Unless you study, you won't pass.
= If you don't study, you won't pass.
Если ты не будешь учиться, ты не сдашь.

Unless she comes, we can't start.
= If she doesn't come, we can't start.
Если она не придет, мы не можем начать.
```

**Примеры:**

```

Unless you hurry, you'll miss the train.
Если ты не поторопишься, ты опоздаешь на поезд.

I won't go unless you come with me.
Я не пойду, если ты не пойдешь со мной.

Unless he apologizes, I won't forgive him.
Если он не извинится, я не прощу его.

You can't enter unless you have a ticket.
Ты не можешь войти, если у тебя нет билета.
```

### 6.2 ⚠️ Важно: Unless + утвердительная форма!

После "unless" используется **утвердительная форма**, а НЕ отрицательная!

```

✅ Unless you hurry, you'll be late.
❌ Unless you don't hurry, you'll be late.

✅ Unless it rains, we'll go out.
❌ Unless it doesn't rain, we'll go out.

✅ Unless she comes, we won't start.
❌ Unless she doesn't come, we won't start.
```

**Почему?** Потому что "unless" УЖЕ означает "if not", поэтому не нужно второе отрицание.

## 7. First Conditional vs Time Clauses

И First Conditional, и Time Clauses используют **Present Simple** в придаточном предложении, но они имеют **разные значения**.

### 7.1 Разница в значении

**Time Clause (when, after, before, until, as soon as):**

- Описывает **время**, когда что-то произойдет
- Действие **точно произойдет**
- Нет условия, нет "если"

**First Conditional (if, unless):**

- Описывает **условие**
- Действие **может произойти или не произойти**
- Есть условие, есть "если"

**Сравнение:**

```

WHEN (время - действие точно произойдет):
When I see her, I'll tell her.
Когда я увижу ее, я скажу ей.
(Я точно увижу ее. Вопрос только - когда?)

IF (условие - может произойти или нет):
If I see her, I'll tell her.
Если я увижу ее, я скажу ей.
(Может быть, я увижу ее, может быть, нет)

---

WHEN (время):
When it rains, I'll take an umbrella.
Когда пойдет дождь, я возьму зонтик.
(Дождь точно пойдет. Вопрос - когда?)

IF (условие):
If it rains, I'll take an umbrella.
Если пойдет дождь, я возьму зонтик.
(Может быть, пойдет дождь, может быть, нет)
```

### 7.2 Общая структура

**Оба используют Present Simple в придаточном предложении:**

```

If/When + Present Simple, will + verb

If I see her, I'll tell her.
When I see her, I'll tell her.

If you come, we'll start.
When you come, we'll start.

If she arrives, call me.
When she arrives, call me.
```

## 8. Практические примеры и диалоги

### 8.1 Ситуация: Планирование выходного дня

```

— What will you do this weekend?
— Что ты будешь делать на выходных?

— If the weather is good, I'll go to the beach.
— Если погода будет хорошей, я пойду на пляж.

— And if it rains?
— А если будет дождь?

— If it rains, I'll stay home and watch movies.
— Если будет дождь, я останусь дома и буду смотреть фильмы.

— That sounds nice! Can I come if it rains?
— Звучит хорошо! Могу я прийти, если будет дождь?

— Of course! If you come, we'll watch movies together.
— Конечно! Если ты придешь, мы будем смотреть фильмы вместе.
```

### 8.2 Ситуация: Советы

```

— I have a headache.
— У меня болит голова.

— If you have a headache, you should take some medicine.
— Если у тебя болит голова, тебе следует принять лекарство.

— I don't have any medicine.
— У меня нет лекарства.

— If you don't have medicine, you should rest. You'll feel better if you sleep.
— Если у тебя нет лекарства, тебе следует отдохнуть. Тебе станет лучше, если ты поспишь.

— OK, I'll try. What if I don't feel better?
— Хорошо, я попробую. Что если мне не станет лучше?

— If you don't feel better, you should see a doctor.
— Если тебе не станет лучше, тебе следует обратиться к врачу.
```

### 8.3 Ситуация: Предупреждение

```

— I'm thinking about driving to work.
— Я думаю поехать на работу на машине.

— If you drive, you'll be stuck in traffic.
— Если ты поедешь на машине, ты застрянешь в пробке.

— Really? What should I do?
— Правда? Что мне делать?

— If you take the train, you'll arrive faster.
— Если ты поедешь на поезде, ты приедешь быстрее.

— OK, I'll take the train. Unless it's late!
— Хорошо, я поеду на поезде. Если только он не опоздает!

— Don't worry. If the train is late, you can take a taxi.
— Не волнуйся. Если поезд опоздает, ты можешь взять такси.
```

### 8.4 Ситуация: Обещания

```

— Will you help me with my homework?
— Ты поможешь мне с домашней работой?

— If you help me clean the house, I'll help you with your homework.
— Если ты поможешь мне убрать дом, я помогу тебе с домашней работой.

— Deal! If I help you now, will you help me tonight?
— Договорились! Если я помогу тебе сейчас, ты поможешь мне вечером?

— Yes, I promise. If you help me, I'll definitely help you.
— Да, обещаю. Если ты поможешь мне, я точно помогу тебе.
```

### 8.5 Ситуация: Угрозы

```

— I don't want to do my homework.
— Я не хочу делать домашнюю работу.

— If you don't do your homework, you'll fail the test.
— Если ты не сделаешь домашнюю работу, ты провалишь тест.

— I don't care.
— Мне все равно.

— If you fail the test, you won't pass the course. And if you don't pass the course, you'll have to repeat the year.
— Если ты провалишь тест, ты не сдашь курс. А если ты не сдашь курс, тебе придется повторить год.

— OK, OK! I'll do my homework!
— Ладно, ладно! Я сделаю домашнюю работу!
```

## 9. Типичные ошибки

### 9.1 Will в if-clause

**❌ Неправильно:**

- If I will see her, I'll tell her.
- If it will rain, I'll stay home.
- If you will come, we'll start.

**✅ Правильно:**

- If I see her, I'll tell her.
- If it rains, I'll stay home.
- If you come, we'll start.

**Правило:** В if-clause используется **Present Simple**, а НЕ will!

### 9.2 Unless + отрицание

**❌ Неправильно:**

- Unless you don't hurry, you'll be late.
- Unless it doesn't rain, we'll go out.
- Unless she doesn't come, we won't start.

**✅ Правильно:**

- Unless you hurry, you'll be late.
- Unless it rains, we'll go out.
- Unless she comes, we won't start.

**Правило:** После "unless" используется **утвердительная форма**, потому что "unless" уже означает "if not".

### 9.3 Запятая

**❌ Неправильно:**

- If it rains I'll stay home. (нет запятой)
- I'll stay home, if it rains. (лишняя запятая)

**✅ Правильно:**

- If it rains, I'll stay home.
- I'll stay home if it rains.

**Правило:** Запятая нужна только если if-clause в начале.

### 9.4 Время в обеих частях

**❌ Неправильно:**

- If I see her, I tell her. (оба Present Simple - нет условия о будущем)
- If I will see her, I will tell her. (will в обеих частях)

**✅ Правильно:**

- If I see her, I'll tell her. (Present Simple + will)

## 10. Расширенные примеры

### 10.1 Цепочка условий

Можно строить несколько условных предложений подряд:

```

If you study hard, you'll pass the exam. If you pass the exam, you'll get a good job. If you get a good job, you'll earn a lot of money. If you earn a lot of money, you'll be happy.
Если ты будешь учиться усердно, ты сдашь экзамен. Если ты сдашь экзамен, ты получишь хорошую работу. Если ты получишь хорошую работу, ты будешь зарабатывать много денег. Если ты будешь зарабатывать много денег, ты будешь счастлив.
```

### 10.2 Несколько условий

```

If you're free and if the weather is good, we can go to the park.
Если ты свободен и если погода хорошая, мы можем пойти в парк.

If you want to come and if you have time, call me.
Если ты хочешь прийти и если у тебя есть время, позвони мне.
```

### 10.3 Комбинация с другими временами

В if-clause можно использовать **Present Continuous** для действий в процессе:

```

If you're feeling tired, you should rest.
Если ты чувствуешь усталость, тебе следует отдохнуть.

If she's waiting, tell her I'll be there soon.
Если она ждет, скажи ей, что я скоро буду.
```

## 💡 Key Takeaways

- **First Conditional** описывает **реальные условия** в **будущем**

- **Структура:** If + Present Simple, will + verb

- **Порядок:** Можно менять (с запятой если if-clause в начале)

- **Will в if-clause:** НЕ используется! Только Present Simple

- **Unless** = if not (если не), но после unless - утвердительная форма!

- **Модальные глаголы:** can, may, might, should, must вместо will в main clause

- **Императив:** Можно использовать команды вместо will

- **First Conditional vs Time Clauses:** If = условие (может быть или не быть), When = время (точно произойдет)

- **Сокращения:** will = 'll, will not = won't

## 1. Что такое прошедшее определённое время (-di)

Прошедшее определённое время (-di) используется для описания действий, которые:

- Произошли в прошлом и **завершены**
- Были **лично засвидетельствованы** говорящим
- Имеют **конкретный момент** в прошлом

Это наиболее употребительное прошедшее время в турецком языке для рассказа о событиях, которые вы сами видели или в которых участвовали.

### 1.1 Основное значение

Суффикс -di передаёт значение "я сделал и видел это сам".

**Example: Личный опыт**

```

Dün sinemaya gittim.
Вчера я ходил в кино.
```

**Объяснение:**
Говорящий лично ходил в кино вчера. Он свидетель этого события.

### 1.2 Когда использовать -di

**Use cases:**

- **Личный опыт**: Dün çalıştım (Вчера я работал)

- **Конкретный момент**: Sabah kahve içtim (Утром я выпил кофе)

- **Завершённые действия**: Film bitti (Фильм закончился)

## 2. Образование прошедшего времени -di

### 2.1 Формула образования

```

Основа глагола + -di/-dı/-du/-dü + личное окончание
```

Выбор варианта -di зависит от **гармонии гласных**:

| Последняя гласная основы | Суффикс |
|--------------------------|---------|
| e, i                     | -di     |
| a, ı                     | -dı     |
| o, u                     | -du     |
| ö, ü                     | -dü     |

**Example: Гармония гласных**

```

gel-mek (приходить) → gel-di (пришёл)
çalış-mak (работать) → çalış-tı (работал)
oku-mak (читать) → oku-du (читал)
gör-mek (видеть) → gör-dü (видел)
```

**Объяснение:**
Суффикс меняется в зависимости от последней гласной основы глагола, следуя правилу гармонии гласных.

### 2.2 Личные окончания

После суффикса -di добавляются личные окончания:

| Лицо | Окончание | Пример (gelmek) |
|------|-----------|-----------------|
| ben (я) | -m | geldim |
| sen (ты) | -n | geldin |
| o (он/она) | — | geldi |
| biz (мы) | -k | geldik |
| siz (вы) | -niz/-nız | geldiniz |
| onlar (они) | -ler/-lar | geldiler |

**Example: Полное спряжение глагола "gitmek" (идти)**

```

ben gittim — я пошёл/пошла
sen gittin — ты пошёл/пошла
o gitti — он/она пошёл/пошла
biz gittik — мы пошли
siz gittiniz — вы пошли
onlar gittiler — они пошли
```

**Объяснение:**
Личные окончания присоединяются после суффикса прошедшего времени. Для третьего лица единственного числа (o) дополнительное окончание не требуется.

### 2.3 Смягчение согласных (p, ç, t, k → b, c, d, ğ)

Если основа глагола заканчивается на **p, ç, t, k**, эти согласные смягчаются:

| Глагол | Основа | Прошедшее время |
|--------|--------|-----------------|
| açmak (открывать) | aç | açtım |
| seçmek (выбирать) | seç | seçtim |
| gitmek (идти) | git | gittim |
| bakmak (смотреть) | bak | baktım |

**Example: Смягчение t → t остается**

```

gitmek → gittim (я пошёл)
```

**Объяснение:**
При добавлении суффикса -di, согласная 't' в основе 'git-' остаётся, и добавляется -ti (из-за гармонии гласных), получается "gittim".

**Example: Смягчение k → ğ не происходит с -di**

```

bakmak → baktım (я посмотрел)
```

**Объяснение:**
С суффиксом -di согласные в основе обычно не смягчаются. Смягчение происходит с гласными суффиксами.

## 3. Утвердительная форма

### 3.1 Простые предложения

**Example: Действия в прошлом**

```

Dün evde kaldım.
Вчера я остался дома.
```

**Объяснение:**
Глагол "kalmak" (оставаться) в прошедшем времени: kaldım (я остался). Действие произошло вчера и завершено.

**Example: С дополнениями**

```

Sabah erkenden kalktık.
Утром мы встали рано.
```

**Объяснение:**
"kalkmak" (вставать) → kalktık (мы встали). "Erkenden" означает "рано".

### 3.2 Предложения с объектами

**Example: Прямой объект**

```

Kitabı okudum.
Я прочитал книгу.
```

**Объяснение:**
"kitap" (книга) → "kitabı" (книгу, винительный падеж). "okumak" (читать) → "okudum" (я прочитал).

**Example: Несколько действий**

```

Öğle yemeği yedim ve uyudum.
Я пообедал и поспал.
```

**Объяснение:**
Два глагола в прошедшем времени: "yedim" (я поел) и "uyudum" (я поспал), соединённые союзом "ve" (и).

---

## 4. Отрицательная форма

### 4.1 Образование отрицания

Отрицание образуется добавлением **-me/-ma** перед суффиксом -di:

```

Основа + -me/-ma + -di + личное окончание
```

**Example: Отрицательное предложение**

```

Dün çalışmadım.
Вчера я не работал.
```

**Объяснение:**
"çalışmak" (работать) → "çalış" + "ma" + "dı" + "m" = "çalışmadım" (я не работал).

### 4.2 Примеры отрицания для всех лиц

**Example: Глагол "gelmek" (приходить) в отрицании**

```

ben gelmedim — я не пришёл/пришла
sen gelmedin — ты не пришёл/пришла
o gelmedi — он/она не пришёл/пришла
biz gelmedik — мы не пришли
siz gelmediniz — вы не пришли
onlar gelmediler — они не пришли
```

**Объяснение:**
Отрицательный суффикс -me добавляется к основе перед -di, получается: gel + me + di + окончание.

### 4.3 Сложные примеры

**Example: С объектом**

```

Film izlemedim.
Я не смотрел фильм.
```

**Объяснение:**
"izlemek" (смотреть) → "izlemedim" (я не смотрел).

**Example: С наречием времени**

```

Bu sabah kahvaltı yapmadım.
Сегодня утром я не завтракал.
```

**Объяснение:**
"yapmak" (делать) → "yapmadım" (я не делал). "kahvaltı yapmak" = "завтракать".

## 5. Вопросительная форма

### 5.1 Образование вопросов

Вопросительная частица **mi/mı/mu/mü** ставится **после** глагола с прошедшим временем, отделяясь пробелом:

```

Глагол в прошедшем времени + mi/mı/mu/mü + личное окончание?
```

**Example: Общий вопрос**

```

Dün geldin mi?
Ты вчера приходил?
```

**Объяснение:**
"geldin" (ты пришёл) + "mi" (вопросительная частица) = "geldin mi?" (ты пришёл?).

### 5.2 Вопросительная частица для всех лиц

**Example: Полное спряжение вопроса**

```

ben geldim mi? — я пришёл?
sen geldin mi? — ты пришёл?
o geldi mi? — он/она пришёл/пришла?
biz geldik mi? — мы пришли?
siz geldiniz mi? — вы пришли?
onlar geldiler mi? — они пришли?
```

**Объяснение:**
Вопросительная частица "mi" меняется по гармонии гласных и ставится после глагола.

### 5.3 Отрицательные вопросы

**Example: Вопрос с отрицанием**

```

Film izlemedin mi?
Ты не смотрел фильм?
```

**Объяснение:**
"izlemedin" (ты не смотрел) + "mi" = "izlemedin mi?" (ты не смотрел?).

**Example: Удивление**

```

Kahvaltı yapmadın mı?
Ты не завтракал?!
```

**Объяснение:**
Такой вопрос часто выражает удивление: "Как так, ты не завтракал?!"

## 6. Слова времени с прошедшим временем

### 6.1 Наречия прошедшего времени

Часто используемые слова времени:

| Турецкий | Русский |
|----------|---------|
| dün | вчера |
| geçen hafta | на прошлой неделе |
| geçen ay | в прошлом месяце |
| geçen yıl | в прошлом году |
| sabah | утром |
| akşam | вечером |
| bugün | сегодня |
| önceden | раньше, прежде |

**Example: С наречиями времени**

```

Geçen hafta İstanbul'a gittim.
На прошлой неделе я ездил в Стамбул.
```

**Объяснение:**
"geçen hafta" (на прошлой неделе) указывает на конкретное время в прошлом.

**Example: Несколько наречий**

```

Dün akşam eve geç geldim.
Вчера вечером я пришёл домой поздно.
```

**Объяснение:**
"dün akşam" (вчера вечером) + "geç" (поздно) уточняют время действия.

### 6.2 Предлоги времени

**Example: С предлогом önce (назад)**

```

İki gün önce onu gördüm.
Два дня назад я его видел.
```

**Объяснение:**
"önce" означает "назад". "iki gün önce" = "два дня назад".

## 7. Распространённые ошибки

### 7.1 Неправильная гармония гласных

❌ **Неправильно:**

```

gel-dı (должно быть gel-di)
oku-dı (должно быть oku-du)
```

✅ **Правильно:**

```

gel-di (последняя гласная 'e' → используем -di)
oku-du (последняя гласная 'u' → используем -du)
```

### 7.2 Пропуск личных окончаний

❌ **Неправильно:**

```

Ben git (я пошёл) — нет прошедшего времени
```

✅ **Правильно:**

```

Ben gittim (я пошёл)
```

### 7.3 Неправильное место отрицания

❌ **Неправильно:**

```

gel-di-me-dim
```

✅ **Правильно:**

```

gel-me-dim (отрицание -me перед -di)
```

### 7.4 Вопросительная частица слитно

❌ **Неправильно:**

```

geldinmi? (слитно)
```

✅ **Правильно:**

```

geldin mi? (раздельно)
```

## 8. Практические примеры

### 8.1 Диалог в прошедшем времени

**Example: Беседа о выходных**

```

A: Hafta sonu ne yaptın?
B: Evde dinlendim. Sen ne yaptın?
A: Arkadaşlarımla sinemaya gittim.
B: Hangi filmi izlediniz?
A: Yeni bir komedi filmi izledik.

A: Что ты делал на выходных?
B: Я отдыхал дома. А ты что делал?
A: Я ходил в кино с друзьями.
B: Какой фильм вы смотрели?
A: Мы смотрели новую комедию.
```

**Объяснение:**
Все глаголы в прошедшем времени -di: yaptın (ты делал), dinlendim (я отдыхал), gittim (я ходил), izlediniz (вы смотрели), izledik (мы смотрели).

### 8.2 Рассказ о поездке

**Example: Путешествие**

```

Geçen ay Antalya'ya gittim. Orada denize girdim ve güneşlendim. 
Çok güzel restoranlar gördüm. Türk yemekleri yedim. 
Tatil çok güzeldi. Bir hafta sonra eve döndüm.

В прошлом месяце я ездил в Анталью. Там я купался в море и загорал.
Я видел очень красивые рестораны. Я ел турецкие блюда.
Отдых был очень хороший. Через неделю я вернулся домой.
```

**Объяснение:**
Серия действий в прошлом: gittim (я поехал), girdim (я вошёл/искупался), güneşlendim (я загорал), gördüm (я видел), yedim (я ел), döndüm (я вернулся).

### 8.3 Повседневные действия

**Example: Обычный день**

```

Bugün sabah 7'de kalktım. Kahvaltı yaptım. 
İşe gittim. Öğle yemeğinde sandviç yedim. 
Akşam 6'da eve döndüm. Televizyon izledim.

Сегодня утром я встал в 7. Я позавтракал.
Я пошёл на работу. В обед я съел сэндвич.
Вечером в 6 я вернулся домой. Я смотрел телевизор.
```

**Объяснение:**
Описание последовательности действий за день, все глаголы в прошедшем времени -di.

## 💡 Key Takeaways

- **-di/-dı/-du/-dü** — суффикс прошедшего определённого времени
- Выбор варианта зависит от **гармонии гласных**
- Используется для действий, которые **лично видел/совершил** говорящий
- Формула: **Основа + -di + личное окончание**
- Отрицание: **Основа + -me/-ma + -di + окончание**
- Вопрос: **Глагол + mi/mı/mu/mü?** (раздельно)
- Наречия времени: dün, geçen hafta, sabah помогают уточнить время действия

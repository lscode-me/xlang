## 1. Что такое повелительное наклонение

Повелительное наклонение (Imperative) используется для:

- Команд и приказов
- Инструкций и указаний
- Просьб и предложений
- Советов и рекомендаций

### 1.1 Основная форма

**Структура:**

```

Глагол (базовая форма без to)

Open the door! — Открой дверь!
Close the window! — Закрой окно!
Sit down! — Сядь!
Listen! — Слушай!
```

**Объяснение:**
В повелительном наклонении используется базовая форма глагола (инфинитив без "to"). Подлежащее ("you") не используется, оно подразумевается.

### 1.2 Когда используется

**Команды:**

```

Stop!
Стой!

Wait!
Подожди!

Run!
Беги!

Be quiet!
Тихо! (Будь тихим!)
```

**Инструкции:**

```

Turn right at the corner.
Поверни направо на углу.

Press the red button.
Нажми красную кнопку.

Mix the ingredients.
Смешай ингредиенты.

Open the file.
Открой файл.
```

## 2. Утвердительная форма (Affirmative)

### 2.1 Простые команды

**Примеры:**

```

Come here!
Иди сюда!

Go away!
Уходи!

Stand up!
Встань!

Sit down!
Сядь!

Look!
Смотри!

Listen!
Слушай!
```

### 2.2 Команды с дополнениями

**С прямым дополнением:**

```

Open the door!
Открой дверь!

Close your eyes!
Закрой глаза!

Read this book!
Прочитай эту книгу!

Write your name!
Напиши своё имя!

Take your bag!
Возьми свою сумку!
```

**С предлогами:**

```

Look at the board!
Посмотри на доску!

Listen to me!
Послушай меня!

Wait for us!
Подожди нас!

Go to school!
Иди в школу!

Come with me!
Пойдём со мной!
```

### 2.3 Более длинные инструкции

**Примеры:**

```

Turn on the computer and open the file.
Включи компьютер и открой файл.

Take the bus and get off at the station.
Сядь на автобус и выйди на станции.

Go straight and turn left at the traffic lights.
Иди прямо и поверни налево на светофоре.

Open your book, read the text and answer the questions.
Открой книгу, прочитай текст и ответь на вопросы.
```

## 3. Отрицательная форма (Negative)

### 3.1 Структура с Don't

**Формула:**

```

Don't + глагол (базовая форма)

Don't go! — Не ходи!
Don't run! — Не беги!
Don't worry! — Не волнуйся!
Don't be late! — Не опаздывай!
```

**Объяснение:**
Для образования отрицания добавляем "don't" перед глаголом. "Don't" — это сокращение от "do not".

### 3.2 Примеры отрицательных команд

**Запреты:**

```

Don't touch it!
Не трогай это!

Don't open the window!
Не открывай окно!

Don't eat that!
Не ешь это!

Don't talk!
Не разговаривай!

Don't move!
Не двигайся!
```

**Предупреждения и советы:**

```

Don't forget your keys!
Не забудь ключи!

Don't be late!
Не опаздывай!

Don't worry!
Не волнуйся!

Don't be sad!
Не грусти!

Don't be afraid!
Не бойся!
```

### 3.3 Don't be + прилагательное

**Примеры:**

```

Don't be stupid!
Не будь глупым!

Don't be angry!
Не злись!

Don't be nervous!
Не нервничай!

Don't be shy!
Не стесняйся!

Don't be rude!
Не будь грубым!
```

## 4. Вежливые просьбы с Please

### 4.1 Please в начале предложения

**Структура:**

```

Please + глагол...

Please come in.
Пожалуйста, входите.

Please sit down.
Пожалуйста, садитесь.

Please help me.
Пожалуйста, помоги мне.

Please be quiet.
Пожалуйста, тише.
```

### 4.2 Please в конце предложения

**Структура:**

```

Глагол..., please.

Come in, please.
Входите, пожалуйста.

Sit down, please.
Садитесь, пожалуйста.

Help me, please.
Помоги мне, пожалуйста.

Open the door, please.
Открой дверь, пожалуйста.
```

**Объяснение:**
"Please" можно ставить как в начале, так и в конце предложения. Обе формы вежливые и правильные. В конце предложения перед "please" ставится запятая.

### 4.3 Please с отрицанием

**Примеры:**

```

Please don't go.
Пожалуйста, не уходи.

Please don't be late.
Пожалуйста, не опаздывай.

Don't forget, please.
Не забудь, пожалуйста.

Please don't worry.
Пожалуйста, не волнуйся.
```

## 6. Let's для предложений

### 6.1 Структура Let's

**Формула:**

```

Let's + глагол (базовая форма)

Let's go! — Пойдём!
Let's eat! — Давай поедим!
Let's dance! — Давай потанцуем!
```

**Объяснение:**
"Let's" (сокращение от "let us") используется для предложений что-то сделать вместе. Это форма повелительного наклонения для первого лица множественного числа.

### 6.2 Примеры с Let's

**Предложения:**

```

Let's go to the cinema!
Давай пойдём в кино!

Let's have lunch together!
Давай пообедаем вместе!

Let's play football!
Давай поиграем в футбол!

Let's start!
Давай начнём!

Let's take a break!
Давай сделаем перерыв!
```

### 6.3 Отрицательная форма Let's

**Примеры:**

```

Let's not go there.
Давай не пойдём туда.

Let's not waste time.
Давай не будем тратить время.

Let's not argue.
Давай не будем спорить.

Let's not be late.
Давай не опоздаем.
```

## 7. Типичные ошибки русскоговорящих

### ❌ Ошибка 1: Добавление "to" перед глаголом

**Неправильно:**
```

✗ To open the door!
✗ Please to sit down.
✗ Don't to go there!
```

**Правильно:**
```

✓ Open the door!
✓ Please sit down.
✓ Don't go there!
```

**Объяснение:**
В повелительном наклонении используется базовая форма глагола БЕЗ "to".

### ❌ Ошибка 2: Использование подлежащего "you"

**Неправильно:**
```

✗ You come here!
✗ You open the book!
✗ You don't go!
```

**Правильно:**
```

✓ Come here!
✓ Open the book!
✓ Don't go!
```

**Объяснение:**
В повелительном наклонении подлежащее "you" НЕ используется, оно подразумевается. (Исключение: "You be quiet!" — для эмфазы, но редко используется.)

### ❌ Ошибка 3: Неправильное образование отрицания

**Неправильно:**
```

✗ Not go there!
✗ No open the window!
✗ Don't to run!
```

**Правильно:**
```

✓ Don't go there!
✓ Don't open the window!
✓ Don't run!
```

**Объяснение:**
Отрицание образуется с помощью "don't" перед глаголом (без "to").

### ❌ Ошибка 4: Спряжение глагола to be

**Неправильно:**
```

✗ Are quiet!
✗ Is careful!
✗ Am happy!
```

**Правильно:**
```

✓ Be quiet!
✓ Be careful!
✓ Be happy!
```

**Объяснение:**
В повелительном наклонении используется базовая форма "be", а не формы "am/is/are".

### ❌ Ошибка 5: Путаница Let's и Let

**Неправильно:**
```

✗ Let go to the park! (без 's)
✗ Lets go to the park! (неправильный апостроф)
✗ Let's goes to the park! (лишнее -s)
```

**Правильно:**
```

✓ Let's go to the park!
```

**Объяснение:**
"Let's" — это сокращение от "let us", нужен апостроф. После "let's" используется базовая форма глагола.

### ❌ Ошибка 6: Неправильное место please

**Неправильно:**
```

✗ Open please the door.
✗ Please, don't the window open.
```

**Правильно:**
```

✓ Please open the door. / Open the door, please.
✓ Please don't open the window.
```

**Объяснение:**
"Please" ставится либо в начале предложения, либо в конце (с запятой). Не разрывайте глагол и дополнение.

## 💡 Key Takeaways

После изучения этого модуля запомните:

- **Повелительное наклонение** = базовая форма глагола (без "to")

- **Подлежащее "you" НЕ используется** (подразумевается)

- **Отрицание:** Don't + глагол

- **Вежливые просьбы:** Please в начале или конце

- **Предложения:** Let's + глагол

- **Команды:** Open the door! Don't run!

- **Советы:** Be careful! Don't worry!

- **С глаголом to be:** используется форма "be", а не am/is/are

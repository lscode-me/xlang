## 1. Введение в Purpose, Reason and Result Clauses

### 1.1 Что это такое?

В английском языке, как и в русском, мы часто хотим объяснить **зачем** мы что-то делаем (цель), **почему** что-то происходит (причина) или **к какому результату** что-то приводит (результат). Для этого используются специальные придаточные предложения.

```
PURPOSE (Цель): I study hard so that I can pass the exam.
Я усердно учусь, чтобы сдать экзамен.

REASON (Причина): I'm tired because I didn't sleep well.
Я устал, потому что плохо спал.

RESULT (Результат): It was so cold that we stayed inside.
Было так холодно, что мы остались дома.
```

### 1.2 Три типа придаточных предложений

| Тип | Вопрос | Союзы | Пример |
|-----|--------|-------|--------|
| Purpose (Цель) | Зачем? Для чего? | so that, in order to, to | I left early so that I could catch the train. |
| Reason (Причина) | Почему? | because, as, since | I left early because I had a meeting. |
| Result (Результат) | С каким результатом? | so...that, such...that | I was so tired that I fell asleep immediately. |

### 1.3 Визуальное сравнение

```
ACTION                    CLAUSE TYPE              EFFECT
─────────────────────────────────────────────────────────────────
I study hard    ←───    PURPOSE (so that)    ───→   to pass the exam
(действие)              (ЗАЧЕМ я делаю?)            (будущий результат)

I'm tired       ←───    REASON (because)     ←───   I didn't sleep well
(состояние)             (ПОЧЕМУ это так?)           (причина в прошлом)

It was so cold  ───→    RESULT (so...that)   ───→   we stayed inside
(состояние)             (ЧТО произошло?)            (результат)
```

### 1.4 Сравнение с русским языком

| Английский | Русский | Тип |
|------------|---------|-----|
| so that | чтобы | Цель |
| in order to | для того, чтобы | Цель |
| because | потому что | Причина |
| as, since | так как, поскольку | Причина |
| so...that | так...что | Результат |
| such...that | такой...что | Результат |

## 2. Purpose Clauses: So That

### 2.1 Основная конструкция

**So that** используется для объяснения **цели** действия — зачем мы что-то делаем.

```
Subject + Verb + so that + Subject + can/could/will/would + Verb
```

**Примеры с can/could:**

```
I'm saving money so that I can buy a car.
Я коплю деньги, чтобы купить машину.

She spoke slowly so that we could understand.
Она говорила медленно, чтобы мы могли понять.

He moved to the front so that he could see better.
Он пересел вперёд, чтобы лучше видеть.
```

### 2.2 Выбор модального глагола

Выбор модального глагола в придаточном предложении зависит от времени главного предложения:

| Главное предложение | Придаточное с so that |
|--------------------|----------------------|
| Present / Future | can, will |
| Past | could, would |

**Примеры с настоящим временем:**

```
I wake up early so that I can exercise before work.
Я просыпаюсь рано, чтобы успеть позаниматься до работы.

She works hard so that she will get a promotion.
Она много работает, чтобы получить повышение.

They are learning English so that they can communicate abroad.
Они учат английский, чтобы общаться за границей.
```

**Примеры с прошедшим временем:**

```
I woke up early so that I could exercise before work.
Я проснулся рано, чтобы успеть позаниматься до работы.

She worked hard so that she would get a promotion.
Она много работала, чтобы получить повышение.

They learned English so that they could communicate abroad.
Они учили английский, чтобы общаться за границей.
```

### 2.3 Отрицательная цель

Для выражения отрицательной цели используйте **so that + subject + won't/wouldn't/can't/couldn't**:

```
I'm whispering so that nobody can hear us.
Я шепчу, чтобы нас никто не услышал.

She left early so that she wouldn't be late.
Она ушла рано, чтобы не опоздать.

He put the money in a safe so that it couldn't be stolen.
Он положил деньги в сейф, чтобы их не украли.

I wrote it down so that I wouldn't forget.
Я записал это, чтобы не забыть.
```

### 2.4 So that vs Just "so"

В разговорной речи часто опускается "that":

```
ФОРМАЛЬНО: I left early so that I could catch the train.
РАЗГОВОРНО: I left early so I could catch the train.

ФОРМАЛЬНО: She spoke loudly so that everyone could hear.
РАЗГОВОРНО: She spoke loudly so everyone could hear.
```

**Важно:** Не путайте "so" в значении цели с "so" в значении "поэтому":

```
PURPOSE (цель): I study hard so (that) I can pass. 
(Я учусь, ЧТОБЫ сдать.)

RESULT (результат/поэтому): I studied hard, so I passed.
(Я учился усердно, ПОЭТОМУ сдал.)
```

### 2.5 Примеры в различных контекстах

**В повседневной жизни:**

```
I set three alarms so that I won't oversleep.
Я поставил три будильника, чтобы не проспать.

She always takes an umbrella so that she won't get wet.
Она всегда берёт зонт, чтобы не промокнуть.

We left a light on so that the house would look occupied.
Мы оставили свет включённым, чтобы дом казался обитаемым.
```

**В деловом контексте:**

```
We scheduled the meeting early so that everyone could attend.
Мы назначили встречу рано, чтобы все могли присутствовать.

The company provides training so that employees can develop new skills.
Компания проводит обучение, чтобы сотрудники могли развивать новые навыки.

I'm sending this email so that you will have all the information you need.
Я отправляю это письмо, чтобы у вас была вся необходимая информация.
```

## 3. Purpose Clauses: In Order To / So As To

### 3.1 In order to — формальная конструкция

**In order to** — более формальный способ выразить цель. Используется с инфинитивом:

```
Subject + Verb + in order to + Verb (infinitive)
```

**Примеры:**

```
I'm learning English in order to get a better job.
Я учу английский, чтобы получить лучшую работу.

She arrived early in order to find a good seat.
Она пришла рано, чтобы найти хорошее место.

We need to act quickly in order to solve this problem.
Нам нужно действовать быстро, чтобы решить эту проблему.
```

### 3.2 Сравнение: in order to vs so that

| In order to | So that |
|-------------|---------|
| + инфинитив | + подлежащее + глагол |
| Одно подлежащее | Может быть разные подлежащие |
| Более формально | Менее формально |

```
ОДНО ПОДЛЕЖАЩЕЕ:
In order to pass the exam, she studied every day.
She studied every day so that she could pass the exam.
(Чтобы сдать экзамен, она занималась каждый день.)

РАЗНЫЕ ПОДЛЕЖАЩИЕ:
She spoke slowly so that we could understand.
(In order to — НЕЛЬЗЯ, разные подлежащие!)
(Она говорила медленно, чтобы мы могли понять.)
```

### 3.3 In order not to — отрицательная цель

```
Subject + Verb + in order not to + Verb (infinitive)
```

**Примеры:**

```
I set an alarm in order not to oversleep.
Я поставил будильник, чтобы не проспать.

She spoke quietly in order not to wake the baby.
Она говорила тихо, чтобы не разбудить малыша.

He left early in order not to miss the train.
Он ушёл рано, чтобы не опоздать на поезд.

We need to save money in order not to go into debt.
Нам нужно экономить, чтобы не влезть в долги.
```

### 3.4 So as to — ещё одна формальная конструкция

**So as to** работает аналогично "in order to":

```
I arrived early so as to avoid the traffic.
Я приехал рано, чтобы избежать пробок.

She trained hard so as to win the competition.
Она усердно тренировалась, чтобы выиграть соревнование.

He speaks softly so as not to disturb others.
Он говорит тихо, чтобы не мешать другим.
```

### 3.5 Простой инфинитив с to

В неформальной речи часто используется просто **to + infinitive**:

```
ФОРМАЛЬНО: I went to the shop in order to buy some milk.
НЕФОРМАЛЬНО: I went to the shop to buy some milk.
Я пошёл в магазин, чтобы купить молока.

ФОРМАЛЬНО: She's studying hard in order to get good grades.
НЕФОРМАЛЬНО: She's studying hard to get good grades.
Она усердно учится, чтобы получить хорошие оценки.
```

**Уровни формальности:**

| Уровень | Конструкция | Пример |
|---------|-------------|--------|
| Самый формальный | in order to | I came in order to help. |
| Формальный | so as to | I came so as to help. |
| Нейтральный | so that | I came so that I could help. |
| Неформальный | to | I came to help. |

## 4. Purpose Clauses: For + Noun/Gerund

### 4.1 For + существительное

**For** используется с существительным для выражения цели:

```
Subject + Verb + for + Noun
```

**Примеры:**

```
I went to the shop for some milk.
Я пошёл в магазин за молоком.

She came for a meeting.
Она пришла на встречу.

We stopped for lunch.
Мы остановились на обед.

He called for help.
Он позвал на помощь.
```

### 4.2 For + Gerund (для описания назначения)

**For + V-ing** используется для описания **назначения** предмета:

```
This knife is for cutting bread.
Этот нож — для нарезки хлеба.

The machine is used for washing clothes.
Эта машина используется для стирки одежды.

This room is for studying.
Эта комната — для занятий.
```

**Важно:** Не путайте "for + gerund" (назначение) и "to + infinitive" (цель действия):

```
НАЗНАЧЕНИЕ (что делает этот предмет):
This knife is for cutting bread.
Этот нож — для нарезки хлеба.

ЦЕЛЬ (зачем я использую):
I used the knife to cut the bread.
Я использовал нож, чтобы нарезать хлеб.
```

### 4.3 What...for? — Вопрос о цели

```
What did you come here for?
Зачем ты сюда пришёл?

What is this tool for?
Для чего этот инструмент?

What are you saving money for?
Для чего ты копишь деньги?
```

## 5. Reason Clauses: Because

### 5.1 Основная конструкция

**Because** — самый распространённый союз для выражения причины:

```
Main clause + because + reason clause
Because + reason clause, + main clause
```

**Примеры:**

```
I'm tired because I didn't sleep well last night.
Я устал, потому что плохо спал прошлой ночью.

She was late because her car broke down.
Она опоздала, потому что её машина сломалась.

We stayed home because it was raining heavily.
Мы остались дома, потому что шёл сильный дождь.

Because the weather was bad, we cancelled the picnic.
Так как погода была плохой, мы отменили пикник.
```

### 5.2 Позиция because-clause

**Because-clause в конце (без запятой):**

```
I can't come because I have a lot of work.
Я не могу прийти, потому что у меня много работы.

She's happy because she got the job.
Она счастлива, потому что получила работу.
```

**Because-clause в начале (с запятой):**

```
Because I have a lot of work, I can't come.
Так как у меня много работы, я не могу прийти.

Because she got the job, she's happy.
Так как она получила работу, она счастлива.
```

### 5.3 Because vs Because of

| Because | Because of |
|---------|------------|
| + clause (подлежащее + глагол) | + noun/pronoun/gerund |
| because it rained | because of the rain |
| because she was ill | because of her illness |

**Примеры:**

```
BECAUSE + clause:
I stayed home because it was raining.
Я остался дома, потому что шёл дождь.

BECAUSE OF + noun:
I stayed home because of the rain.
Я остался дома из-за дождя.

BECAUSE + clause:
She couldn't work because she was ill.
Она не могла работать, потому что болела.

BECAUSE OF + noun:
She couldn't work because of her illness.
Она не могла работать из-за болезни.

BECAUSE OF + gerund:
He was fired because of being late every day.
Его уволили из-за того, что он каждый день опаздывал.
```

### 5.4 Эмоциональный контекст с because

Because часто используется для объяснения эмоций и состояний:

```
I'm happy because I passed my exams.
Я счастлив, потому что сдал экзамены.

She's upset because nobody remembered her birthday.
Она расстроена, потому что никто не помнил о её дне рождения.

He's nervous because he has an interview tomorrow.
Он нервничает, потому что завтра у него собеседование.

They're excited because they're going on holiday.
Они взволнованы, потому что едут в отпуск.
```

## 6. Reason Clauses: As and Since

### 6.1 As — причина как фон

**As** часто ставится в начале предложения и представляет причину как уже известный факт или фон:

```
As + reason clause, + main clause
```

**Примеры:**

```
As it was getting dark, we decided to go home.
Так как темнело, мы решили пойти домой.

As I was tired, I went to bed early.
Так как я устал, я лёг спать рано.

As you know, the meeting has been postponed.
Как вы знаете, собрание перенесено.

As we had plenty of time, we walked instead of taking the bus.
Поскольку у нас было много времени, мы пошли пешком, а не поехали на автобусе.
```

### 6.2 Since — причина как известный факт

**Since** похож на as и также указывает на известную причину:

```
Since + reason clause, + main clause
Main clause + since + reason clause
```

**Примеры:**

```
Since you're here, can you help me?
Раз уж ты здесь, можешь мне помочь?

Since it's raining, let's stay inside.
Поскольку идёт дождь, давай останемся дома.

I'll drive since you're tired.
Я поведу, раз ты устал.

Since we have no other option, we'll have to accept.
Поскольку у нас нет другого выбора, нам придётся согласиться.
```

**Важно:** Не путайте since (причина) и since (с тех пор):

```
REASON (причина):
Since you're leaving, I'll say goodbye now.
Раз ты уходишь, я попрощаюсь сейчас.

TIME (с тех пор):
I haven't seen him since 2020.
Я не видел его с 2020 года.
```

### 6.3 Сравнение: Because vs As vs Since

| Союз | Характеристика | Пример |
|------|----------------|--------|
| Because | Новая, важная информация | I stayed home because I was ill. (важная причина) |
| As | Фоновая, второстепенная причина | As I was ill, I stayed home. (фон) |
| Since | Известный факт | Since you already know this, I won't explain. |

**Нюансы использования:**

```
Because (главная причина):
Q: Why didn't you come to the party?
A: I didn't come because I was ill.
(Причина — главная информация)

As (фоновая причина):
As I was ill, I spent the evening reading a book.
(Болезнь — фон, главное — что я делал)

Since (известный факт):
Since you've already read the book, let's discuss it.
(То, что вы читали книгу — уже известно)
```

### 6.4 Формальность

| Союз | Формальность | Использование |
|------|--------------|---------------|
| because | Нейтральный | Любой контекст |
| as | Немного формальный | Письменная речь, деловой стиль |
| since | Немного формальный | Письменная речь, формальный стиль |

```
НЕФОРМАЛЬНО:
I couldn't call you because my phone died.
Я не мог позвонить, потому что телефон разрядился.

ФОРМАЛЬНО:
As my phone had run out of battery, I was unable to contact you.
Поскольку мой телефон разрядился, я не смог с вами связаться.
```

## 7. Result Clauses: So...That

### 7.1 Основная конструкция

**So + adjective/adverb + that** используется для выражения результата:

```
Subject + Verb + so + adjective/adverb + that + result clause
```

**Примеры с прилагательными:**

```
It was so cold that we stayed inside.
Было так холодно, что мы остались дома.

She was so tired that she fell asleep immediately.
Она была так устала, что сразу заснула.

The movie was so boring that I left before the end.
Фильм был такой скучный, что я ушёл до конца.

He is so tall that he can touch the ceiling.
Он такой высокий, что может достать до потолка.
```

**Примеры с наречиями:**

```
He spoke so quietly that nobody could hear him.
Он говорил так тихо, что никто его не слышал.

She runs so fast that nobody can catch her.
Она бегает так быстро, что никто не может её догнать.

The train arrived so late that we missed our connection.
Поезд прибыл так поздно, что мы не успели на пересадку.
```

### 7.2 So + adjective/adverb без that

В разговорной речи "that" часто опускается:

```
It was so cold (that) we stayed inside.
She was so tired (that) she fell asleep.
He spoke so quietly (that) I couldn't hear him.
```

### 7.3 So + many/much/few/little + that

С исчисляемыми и неисчисляемыми существительными:

```
SO MANY + countable plural:
There were so many people that we couldn't find a seat.
Было так много людей, что мы не могли найти место.

SO MUCH + uncountable:
She has so much money that she doesn't know what to do with it.
У неё так много денег, что она не знает, что с ними делать.

SO FEW + countable plural:
There were so few guests that the party was cancelled.
Было так мало гостей, что вечеринку отменили.

SO LITTLE + uncountable:
I had so little time that I couldn't finish.
У меня было так мало времени, что я не смог закончить.
```

### 7.4 Эмфатическое использование

**So...that** часто используется для эмоционального усиления:

```
I was so happy that I started crying.
Я был так счастлив, что расплакался.

He was so angry that he couldn't speak.
Он был так зол, что не мог говорить.

The news was so shocking that nobody knew what to say.
Новость была такой шокирующей, что никто не знал, что сказать.
```

## 8. Result Clauses: Such...That

### 8.1 Основная конструкция

**Such + (adjective) + noun + that** используется, когда мы хотим подчеркнуть существительное:

```
Subject + Verb + such + (a/an) + (adjective) + noun + that + result clause
```

**Примеры:**

```
She is such a good teacher that everyone loves her.
Она такой хороший учитель, что все её любят.

It was such a beautiful day that we went for a walk.
Это был такой прекрасный день, что мы пошли гулять.

They are such nice people that I want to see them again.
Они такие приятные люди, что я хочу увидеть их снова.

He told such funny jokes that everyone laughed.
Он рассказывал такие смешные анекдоты, что все смеялись.
```

### 8.2 Правила использования артикля

| Структура | Пример |
|-----------|--------|
| such + a/an + adj + singular noun | such a nice day |
| such + adj + plural noun | such nice people |
| such + adj + uncountable noun | such nice weather |

**Примеры:**

```
SINGULAR (такой/такая):
It was such a long movie that I fell asleep.
Это был такой длинный фильм, что я заснул.

PLURAL (такие):
They were such expensive shoes that I couldn't afford them.
Это были такие дорогие туфли, что я не мог их себе позволить.

UNCOUNTABLE (такая):
It was such bad weather that we stayed home.
Была такая плохая погода, что мы остались дома.
```

### 8.3 Such без прилагательного

**Such + a/an + noun** может использоваться без прилагательного, когда существительное само по себе выразительно:

```
He is such a fool that he believes everything.
Он такой дурак, что верит всему.

It was such a surprise that I didn't know what to say.
Это был такой сюрприз, что я не знал, что сказать.

She is such an inspiration to us all.
Она такое вдохновение для всех нас.
```

### 8.4 Such + a lot of

```
There was such a lot of traffic that we were late.
Было столько пробок, что мы опоздали.

She has such a lot of experience that she's perfect for the job.
У неё столько опыта, что она идеально подходит для этой работы.
```

## 9. So vs Such: Сравнение

### 9.1 Ключевое различие

| So | Such |
|----|------|
| + adjective/adverb (без существительного) | + (adjective) + noun |
| so beautiful | such a beautiful day |
| so quickly | such a quick response |

### 9.2 Сравнительная таблица

| So + | Such + |
|------|--------|
| so hot | such a hot day |
| so interesting | such an interesting book |
| so quickly | such a quick decision |
| so many people | such a lot of people |
| so much work | such a lot of work |
| so few options | such few options* |

*Примечание: "such few" встречается редко, обычно используется "so few"

### 9.3 Примеры для сравнения

```
SO + ADJECTIVE:
The weather was so hot that we went swimming.
Погода была такой жаркой, что мы пошли купаться.

SUCH + (ADJECTIVE) + NOUN:
It was such a hot day that we went swimming.
Это был такой жаркий день, что мы пошли купаться.

SO + ADVERB:
He speaks so clearly that everyone understands.
Он говорит так чётко, что все понимают.

SUCH + (ADJECTIVE) + NOUN:
He gives such clear explanations that everyone understands.
Он даёт такие чёткие объяснения, что все понимают.
```

### 9.4 Типичные ошибки

```
❌ НЕПРАВИЛЬНО: It was such hot that we...
✅ ПРАВИЛЬНО: It was so hot that we...

❌ НЕПРАВИЛЬНО: She is so a nice person that...
✅ ПРАВИЛЬНО: She is such a nice person that...

❌ НЕПРАВИЛЬНО: There were such many people that...
✅ ПРАВИЛЬНО: There were so many people that...

❌ НЕПРАВИЛЬНО: I have so much work to do.
✅ ПРАВИЛЬНО: I have such a lot of work to do. / I have so much work to do.
```

### 9.5 Эмфатическое so/such без that

В восклицаниях so и such часто используются без that:

```
You are so kind!
Ты такой добрый!

It's such a lovely day!
Какой прекрасный день!

She has such beautiful eyes!
У неё такие красивые глаза!

He speaks so well!
Он так хорошо говорит!
```

## 10. Комбинированные конструкции

### 10.1 Purpose + Reason

```
I left early because I wanted to catch the first train.
Я ушёл рано, потому что хотел успеть на первый поезд.
(Reason объясняет Purpose)

Because I need to pass the exam, I'm studying so that I can remember everything.
Потому что мне нужно сдать экзамен, я учусь, чтобы всё запомнить.
(Reason + Purpose)
```

### 10.2 Reason + Result

```
Because he was so tired, he fell asleep immediately.
Так как он был так устал, он сразу заснул.
(Because причина → so...that результат подразумевается)

Since the movie was so boring, I left early.
Поскольку фильм был такой скучный, я ушёл рано.
(Since причина + so результат)
```

### 10.3 Purpose + Result

```
She practiced so hard (in order) to win that she injured herself.
Она так усердно тренировалась, чтобы победить, что травмировалась.
(Purpose + неожиданный Result)
```

### 10.4 Сложные предложения

```
As it was so cold outside, I put on extra layers so that I wouldn't freeze.
Поскольку на улице было так холодно, я надел дополнительные слои, чтобы не замёрзнуть.
(As причина + so холодно + so that цель)

Because she works such long hours, she's so tired that she falls asleep on the sofa every evening.
Потому что она работает так много часов, она так устаёт, что каждый вечер засыпает на диване.
(Because причина + such + so...that результат)
```

## 11. Позиция придаточных предложений и пунктуация

### 11.1 Purpose clauses

```
В КОНЦЕ (без запятой):
I left early so that I could catch the train.
He works hard in order to support his family.

В НАЧАЛЕ (с запятой):
In order to catch the train, I left early.
So that we wouldn't be late, we took a taxi.
To save time, I took a shortcut.
```

### 11.2 Reason clauses

```
В КОНЦЕ (обычно без запятой):
I stayed home because I was ill.
She couldn't come as she was busy.

В НАЧАЛЕ (с запятой):
Because I was ill, I stayed home.
As she was busy, she couldn't come.
Since you're here, you can help.
```

### 11.3 Result clauses

```
ВСЕГДА ПОСЛЕ главного предложения:
It was so cold that we stayed inside.
She is such a good teacher that everyone loves her.

❌ НЕПРАВИЛЬНО: That we stayed inside, it was so cold.
```

### 11.4 Сводная таблица пунктуации

| Тип | В конце | В начале |
|-----|---------|----------|
| Purpose (so that) | без запятой | с запятой |
| Purpose (in order to) | без запятой | с запятой |
| Purpose (to) | без запятой | с запятой |
| Reason (because) | без запятой* | с запятой |
| Reason (as/since) | без запятой | с запятой |
| Result (so/such...that) | без запятой | ❌ |

*Иногда перед because ставится запятая для ясности

## 12. Формальный и неформальный стиль

### 12.1 Purpose: от формального к неформальному

| Уровень | Конструкция | Пример |
|---------|-------------|--------|
| Очень формальный | in order that + may/might | I write in order that you may understand. |
| Формальный | in order to | I write in order to explain. |
| Формальный | so as to | I write so as to explain. |
| Нейтральный | so that + can/will | I write so that you can understand. |
| Неформальный | so + can/will | I write so you can understand. |
| Очень неформальный | to | I write to explain. |

### 12.2 Reason: от формального к неформальному

| Уровень | Конструкция | Пример |
|---------|-------------|--------|
| Формальный | due to the fact that | Due to the fact that I was ill, I couldn't attend. |
| Формальный | owing to | Owing to illness, I couldn't attend. |
| Формальный | as/since | As I was ill, I couldn't attend. |
| Нейтральный | because | I couldn't attend because I was ill. |
| Неформальный | 'cause (spoken) | I couldn't come 'cause I was sick. |

### 12.3 Деловая переписка

```
ФОРМАЛЬНО:
In order to process your request, we require additional documentation.
Для обработки вашего запроса нам требуется дополнительная документация.

Since you have not responded to our previous correspondence, 
we assume you are no longer interested.
Поскольку вы не ответили на нашу предыдущую корреспонденцию,
мы предполагаем, что вы больше не заинтересованы.

The delay was such that we were unable to meet the deadline.
Задержка была такой, что мы не смогли уложиться в срок.
```

### 12.4 Разговорная речь

```
НЕФОРМАЛЬНО:
I called to check if you're okay.
Я позвонил проверить, как ты.

I'm not coming 'cause I'm tired.
Я не приду, потому что устал.

It's so hot I can't think!
Так жарко, что думать не могу!
```

## 13. Типичные ошибки и как их избежать

### 13.1 Ошибки с so that vs so...that

```
❌ НЕПРАВИЛЬНО (смешение конструкций):
I study hard so that I can so tired.

✅ ПРАВИЛЬНО:
I study hard so that I can pass. (цель)
I study so hard that I get tired. (результат)
```

### 13.2 Ошибки с so vs such

```
❌ НЕПРАВИЛЬНО:
It was so a beautiful day.
She is such tired.

✅ ПРАВИЛЬНО:
It was such a beautiful day. (such + noun)
She is so tired. (so + adjective)
```

### 13.3 Ошибки с because vs because of

```
❌ НЕПРАВИЛЬНО:
I stayed home because of I was ill.
I stayed home because the rain.

✅ ПРАВИЛЬНО:
I stayed home because I was ill. (because + clause)
I stayed home because of the rain. (because of + noun)
```

### 13.4 Ошибки с in order to

```
❌ НЕПРАВИЛЬНО:
I study hard in order to I can pass.
In order to can pass, I study hard.

✅ ПРАВИЛЬНО:
I study hard in order to pass. (in order to + infinitive)
```

### 13.5 Ошибки с временем глагола

```
❌ НЕПРАВИЛЬНО:
I studied hard so that I can pass. (несогласование времён)

✅ ПРАВИЛЬНО:
I studied hard so that I could pass. (past → could)
I study hard so that I can pass. (present → can)
```

### 13.6 Двойные союзы

```
❌ НЕПРАВИЛЬНО:
Because since I was tired, I went to bed.
The reason why because I left was...

✅ ПРАВИЛЬНО:
Because I was tired, I went to bed.
The reason why I left was...
The reason I left was because...
```

## 14. Практические упражнения и паттерны

### 14.1 Паттерны для purpose (цели)

**Шаблон 1: Простая цель**

```
I [action] to [goal].
I exercise to stay healthy.
```

**Шаблон 2: Формальная цель**

```
I [action] in order to [goal].
I exercise regularly in order to maintain good health.
```

**Шаблон 3: Цель с разными субъектами**

```
I [action] so that [someone] can/could [result].
I turned on the lights so that everyone could see.
```

**Шаблон 4: Негативная цель**

```
I [action] so that I won't/wouldn't [negative result].
I set an alarm so that I wouldn't oversleep.
```

### 14.2 Паттерны для reason (причины)

**Шаблон 1: Простая причина**

```
I [result] because [reason].
I'm happy because I passed my exam.
```

**Шаблон 2: Причина как фон**

```
As/Since [reason], I [result].
Since you're already here, you can help me.
```

**Шаблон 3: Причина с существительным**

```
I [result] because of [noun].
I was late because of the traffic.
```

### 14.3 Паттерны для result (результата)

**Шаблон 1: So + adjective + that**

```
It was so [adjective] that [result].
It was so cold that we stayed inside.
```

**Шаблон 2: Such + noun + that**

```
It was such a [adjective + noun] that [result].
It was such a cold day that we stayed inside.
```

**Шаблон 3: So + adverb + that**

```
She [verb] so [adverb] that [result].
She spoke so quietly that nobody heard.
```

**Шаблон 4: So many/much + that**

```
There were/was so many/much [noun] that [result].
There was so much traffic that we were late.
```

## 15. Контекстные примеры

### 15.1 В повседневной жизни

```
PURPOSE:
I'm going to the supermarket to buy groceries.
Я иду в супермаркет, чтобы купить продукты.

I left my phone on silent so that it wouldn't ring during the meeting.
Я оставил телефон на беззвучном режиме, чтобы он не звонил во время встречи.

REASON:
I can't go out tonight because I have an early start tomorrow.
Я не могу выйти сегодня вечером, потому что завтра рано вставать.

As it's your birthday, I made your favourite cake.
Раз сегодня твой день рождения, я испекла твой любимый торт.

RESULT:
The coffee was so hot that I burned my tongue.
Кофе был такой горячий, что я обжёг язык.

She makes such delicious cakes that I always ask for more.
Она печёт такие вкусные торты, что я всегда прошу добавки.
```

### 15.2 В учебном контексте

```
PURPOSE:
I'm taking extra classes so that I can improve my grades.
Я беру дополнительные занятия, чтобы улучшить оценки.

She's studying medicine in order to become a doctor.
Она изучает медицину, чтобы стать врачом.

REASON:
He failed the exam because he didn't study enough.
Он провалил экзамен, потому что мало занимался.

Since the library was closed, I studied at home.
Поскольку библиотека была закрыта, я занимался дома.

RESULT:
The test was so difficult that most students failed.
Тест был такой сложный, что большинство студентов провалились.

It was such an interesting lecture that nobody wanted to leave.
Это была такая интересная лекция, что никто не хотел уходить.
```

### 15.3 В рабочем контексте

```
PURPOSE:
We need to hire more staff so that we can meet the deadline.
Нам нужно нанять больше персонала, чтобы уложиться в срок.

The company is investing in training in order to improve productivity.
Компания инвестирует в обучение, чтобы повысить производительность.

REASON:
The project was delayed because of budget constraints.
Проект был задержан из-за бюджетных ограничений.

As the client requested changes, we had to revise the proposal.
Поскольку клиент запросил изменения, нам пришлось пересмотреть предложение.

RESULT:
The presentation was so successful that we got the contract.
Презентация была настолько успешной, что мы получили контракт.

She has such extensive experience that she was promoted immediately.
У неё такой большой опыт, что её сразу повысили.
```

### 15.4 В путешествии

```
PURPOSE:
We left early so that we could avoid the traffic.
Мы выехали рано, чтобы избежать пробок.

I'm learning Spanish to communicate with locals on my trip.
Я учу испанский, чтобы общаться с местными в поездке.

REASON:
Our flight was cancelled because of bad weather.
Наш рейс отменили из-за плохой погоды.

Since we had some free time, we visited the local museum.
Поскольку у нас было свободное время, мы посетили местный музей.

RESULT:
The scenery was so beautiful that I took hundreds of photos.
Пейзаж был такой красивый, что я сделал сотни фотографий.

It was such an amazing trip that we're already planning to go back.
Это была такая потрясающая поездка, что мы уже планируем вернуться.
```

## 💡 Key Takeaways

### Purpose (Цель):
- **So that** + subject + can/could/will/would + verb — для цели с разными субъектами
- **In order to / So as to** + infinitive — формальный стиль, один субъект
- **To** + infinitive — простейшая форма для цели
- **For** + noun — для существительных (цель или назначение)

### Reason (Причина):
- **Because** + clause — главная, важная причина
- **As / Since** + clause — фоновая или известная причина
- **Because of** + noun — причина, выраженная существительным

### Result (Результат):
- **So + adjective/adverb + that** — результат с прилагательным/наречием
- **Such (+ a/an) + (adjective) + noun + that** — результат с существительным
- **So many/much/few/little + that** — результат с количеством

### Различия:
- **So** + adjective/adverb (no noun)
- **Such** + (adjective) + noun
- **Because** + clause vs **Because of** + noun
- **So that** (цель) vs **so...that** (результат)

## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Backshift — процесс сдвига времен назад в косвенной речи |
| 2 | C | Present Simple → Past Simple: work → worked |
| 3 | D | Present Continuous → Past Continuous: am studying → was studying |
| 4 | B | Present Perfect → Past Perfect: have finished → had finished |
| 5 | D | Past Simple → Past Perfect: saw → had seen |
| 6 | C | will → would: will help → would help |
| 7 | B | can → could: can swim → could swim |
| 8 | B | must (обязанность) → had to: must leave → had to leave |
| 9 | C | Tell требует объект: told me. Say используется без объекта или с to |
| 10 | A | "She told me" и "She said" — оба варианта правильные |
| 11 | C | I → she, my → her: Mary said that she loved her job |
| 12 | D | you (обращение к рассказчику) → me: would call me |
| 13 | D | today → that day |
| 14 | A | tomorrow → the next day / the following day |
| 15 | D | yesterday → the day before |
| 16 | B | here → there, will → would |
| 17 | B | this → that |
| 18 | B | Общий вопрос: if + утвердительный порядок слов |
| 19 | D | В косвенных вопросах используется утвердительный порядок слов |
| 20 | C | Whether используется для общих вопросов (если/ли) |
| 21 | A | Wh-word + утвердительный порядок слов: where I lived |
| 22 | A | Утвердительный порядок + backshift: what my name was |
| 23 | A | When + утвердительный порядок + would: when I would arrive |
| 24 | B | Why + утвердительный порядок: why I was late |
| 25 | A | Who как подлежащее: порядок слов не меняется, Past Simple → Past Perfect |
| 26 | C | Команда: tell + object + to-infinitive |
| 27 | C | Отрицательная команда: tell + object + not to + infinitive |
| 28 | D | Просьба: ask + object + to-infinitive |
| 29 | D | Advise — лучший глагол для передачи совета |
| 30 | D | Warn — глагол для предупреждения об опасности |
| 31 | C | Suggest + -ing: suggested going |
| 32 | A | Suggest + that + (should) + V1: take или should take |
| 33 | D | Если reporting verb в настоящем времени, backshift не нужен |
| 34 | C | Для общеизвестных истин оба варианта возможны |
| 35 | C | Should не меняется в косвенной речи |
| 36 | D | Might не меняется в косвенной речи |
| 37 | D | Ошибка: "where did I live" — нужен утвердительный порядок "where I lived" |
| 38 | A | Ошибка: "said me" — нужно "told me" или "said to me" |
| 39 | B | Косвенный вопрос — это утверждение, заканчивается точкой |
| 40 | A | If и whether взаимозаменяемы в общих вопросах |

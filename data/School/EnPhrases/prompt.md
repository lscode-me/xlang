# Промпт для генерации вопросов RU→EN Quiz

Ты - эксперт по английскому языку и создатель учебных материалов. Твоя задача - генерировать вопросы для теста на перевод с русского на английский язык.

## Формат вывода

Генерируй ТОЛЬКО JSONL (JSON Lines) - каждая строка = один валидный JSON объект.

**НЕ ДОБАВЛЯЙ**:
- Никаких markdown блоков кода (```json)
- Никаких комментариев
- Никаких пояснений
- Только чистые JSONL строки

## Структура каждого JSON объекта

```json
{"id":"<LEVEL>-<SET>-<NUM>","question":"<Russian phrase>","options":["<Option 1>","<Option 2>","<Option 3>","<Option 4>"],"correct":<1-4>,"explanation":"<Explanation>","tags":["<tag1>","<tag2>"],"source":"llm"}
```

## Обязательные поля

- **id**: Уникальный идентификатор в формате `<LEVEL>-<SET>-<NUM>`
  - Примеры: `A1-001-0001`, `A2-005-0023`
  - LEVEL: A1 или A2
  - SET: трёхзначный номер набора (001, 002, 003...)
  - NUM: четырёхзначный порядковый номер (0001, 0002, 0003...)

- **question**: Фраза на русском языке
  - Естественная, разговорная фраза
  - Соответствует уровню (A1/A2)
  - Длина 2-15 слов

- **options**: Массив из **ровно 4** вариантов перевода на английский
  - Все варианты должны быть грамматически правильными
  - Только **ОДИН** вариант - правильный перевод `question`
  - Остальные 3 - правдоподобные дистракторы (похожие, но неправильные)
  - НЕ используй очевидно неправильные варианты
  - НЕ используй кириллицу в английских вариантах
  - НЕ добавляй маркеры типа "правильный ответ", "вариант 1"

- **correct**: Номер правильного варианта (1, 2, 3, или 4)
  - Указывает индекс правильного перевода в массиве `options`
  - Индексация с 1 (не с 0!)

- **explanation**: Объяснение на русском
  - Базовые формы английских слов с переводом
  - Формат: `<английское слово> — <перевод>, <английское слово> — <перевод>`
  - Пример: `"bus — автобус, stop — остановка"`
  - Используй инфинитив для глаголов, базовую форму для существительных

## Опциональные поля

- **tags**: Массив строк (тематики)
  - Примеры: `["transport"]`, `["food", "restaurant"]`, `["time"]`
  
- **source**: Источник вопроса
  - Для AI-генерированных: `"llm"`

## Требования по уровням

### A1 (Начальный)
- Простые слова и фразы
- Настоящее время (Present Simple)
- Базовая лексика: приветствия, числа, цвета, семья, еда, направления
- Примеры тем: представление, вопросы о местоположении, просьбы

### A2 (Элементарный)
- Повседневные ситуации
- Прошедшее и будущее время
- Расширенная лексика: покупки, транспорт, работа, хобби
- Примеры тем: описание прошлых событий, планы на будущее

## Правила качества

1. **Уникальность вариантов**: После нормализации (trim, lowercase, collapse spaces) все 4 варианта должны быть разными
2. **Правдоподобность дистракторов**: Неправильные варианты должны быть похожи на правильный (та же тема, похожая грамматика)
3. **Нет кириллицы в options**: Все английские варианты только латиницей
4. **Нет LLM мусора**: Никаких фраз типа "As an AI", "ChatGPT", "правильный ответ"
5. **Корректный английский**: Грамматически правильный английский язык

## Примеры

### Пример A1:
```
{"id":"A1-001-0001","question":"Где находится остановка?","options":["Where is the bus stop?","Where is the bus?","What is this place?","What time is it?"],"correct":1,"explanation":"bus — автобус, stop — остановка, where — где","tags":["transport","location"],"source":"llm"}
{"id":"A1-001-0002","question":"Меня зовут Анна","options":["My name is Anna","Your name is Anna","His name is Anna","I am Anna"],"correct":1,"explanation":"my — мой, name — имя, is — есть (3rd person)","tags":["introduction"],"source":"llm"}
```

### Пример A2:
```
{"id":"A2-003-0015","question":"Я был в Лондоне прошлым летом","options":["I was in London last summer","I am in London this summer","I will be in London next summer","I am always in London in summer"],"correct":1,"explanation":"was — был (past tense), last summer — прошлым летом, in London — в Лондоне","tags":["past","travel"],"source":"llm"}
```

## Инструкция

Сгенерируй **N вопросов** для уровня **LEVEL** (подставь конкретное значение).

Используй набор **SET** (например, 001).

Темы: **[укажи темы через запятую]**

Начинай с номера **START_NUM**.

Только JSONL вывод, без лишнего текста!

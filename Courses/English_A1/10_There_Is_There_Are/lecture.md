## 1. Что такое There is / There are

Конструкция "there is / there are" используется для того, чтобы сказать, что что-то существует, находится или присутствует в каком-то месте.

### 1.1 Основная концепция

**There is** - для единственного числа (есть, находится - один предмет)
**There are** - для множественного числа (есть, находятся - несколько предметов)

```

There is a book on the table.
На столе (есть) книга.

There are three books on the table.
На столе (есть) три книги.
```

**Объяснение:**
"There is/are" переводится как "есть", "находится", "имеется". Это безличная конструкция, которая сообщает о наличии чего-либо где-либо. Слово "there" здесь не означает "там" - это часть конструкции.

### 1.2 Структура предложения

**Структура:** There + is/are + что + где

```

There is a cat in the garden.
В саду (есть) кот.

There are two cats in the garden.
В саду (есть) два кота.

There is a bank near here.
Здесь рядом есть банк.

There are many shops in this street.
На этой улице много магазинов.
```

**Объяснение:**
После "there is/are" обычно идет предмет/объект, а затем место, где он находится.

## 2. There is - единственное число

### 2.1 Утвердительные предложения с There is

**Структура:** There is + a/an + существительное (ед. число) + место

```

There is a book on the table.
На столе книга.

There is an apple in the basket.
В корзине яблоко.

There is a car in the garage.
В гараже машина.

There is a dog in the yard.
Во дворе собака.

There is a bank on this street.
На этой улице есть банк.

There is a problem.
Есть проблема.
```

**С неисчисляемыми существительными:**

```

There is water in the bottle.
В бутылке вода.

There is milk in the fridge.
В холодильнике молоко.

There is sugar in the bowl.
В миске сахар.

There is money on the table.
На столе деньги.
```

**Сокращенная форма:**

```

There is = There's

There's a book on the table.
There's a problem.
There's milk in the fridge.
```

### 2.2 Примеры в разных ситуациях

**Описание комнаты:**

```

There is a bed in the bedroom.
В спальне кровать.

There is a TV in the living room.
В гостиной телевизор.

There is a mirror on the wall.
На стене зеркало.
```

**Описание места:**

```

There is a park near my house.
Рядом с моим домом парк.

There is a restaurant on the corner.
На углу ресторан.

There is a bus stop over there.
Там автобусная остановка.
```

## 3. There are - множественное число

### 3.1 Утвердительные предложения с There are

**Структура:** There are + число/some + существительное (мн. число) + место

```

There are two books on the table.
На столе две книги.

There are three apples in the basket.
В корзине три яблока.

There are many cars in the parking lot.
На парковке много машин.

There are five students in the classroom.
В классе пять студентов.

There are some people in the park.
В парке (есть) люди.
```

**С числительными:**

```

There are ten chairs in the room.
В комнате десять стульев.

There are fifty students in my school.
В моей школе пятьдесят студентов.

There are 365 days in a year.
В году 365 дней.
```

**С неопределенными количествами:**

```

There are many books in the library.
В библиотеке много книг.

There are some flowers in the garden.
В саду (есть) цветы.

There are a lot of people here.
Здесь много людей.

There are several shops on this street.
На этой улице несколько магазинов.
```

### 3.2 Примеры в разных ситуациях

**Описание комнаты:**

```

There are three bedrooms in my house.
В моем доме три спальни.

There are two bathrooms upstairs.
Наверху две ванные.

There are many pictures on the walls.
На стенах много картин.
```

**Описание города:**

```

There are five parks in our city.
В нашем городе пять парков.

There are many restaurants downtown.
В центре много ресторанов.

There are two universities here.
Здесь два университета.
```

## 4. Отрицательные предложения

### 4.1 There is not / There are not

**Отрицание:** There is not (isn't) / There are not (aren't)

**С единственным числом:**

```

There is not a book on the table.
На столе нет книги.

There isn't a car in the garage.
В гараже нет машины.

There's no milk in the fridge.
В холодильнике нет молока.

There isn't a bank near here.
Здесь рядом нет банка.
```

**С множественным числом:**

```

There are not any books on the table.
На столе нет книг.

There aren't any students in the classroom.
В классе нет студентов.

There are no cars in the parking lot.
На парковке нет машин.

There aren't any apples in the basket.
В корзине нет яблок.
```

### 4.2 Not any vs No

Два способа выразить отсутствие:

**1. There isn't/aren't + any:**

```

There isn't any milk.
There aren't any students.
```

**2. There is/are + no:**

```

There is no milk.
There are no students.
```

**Объяснение:**
Оба варианта правильные и означают одно и то же. "No" немного более категоричное.

**Примеры:**

```

There isn't any sugar in my coffee.
= There is no sugar in my coffee.
В моем кофе нет сахара.

There aren't any people in the room.
= There are no people in the room.
В комнате нет людей.
```

## 5. Вопросительные предложения

### 5.1 Общие вопросы (Yes/No questions)

**Структура:** Is there...? / Are there...?

**С единственным числом:**

```

Is there a book on the table?
На столе есть книга?

Is there a bank near here?
Здесь рядом есть банк?

Is there a problem?
Есть проблема?

Is there any milk in the fridge?
В холодильнике есть молоко?
```

**С множественным числом:**

```

Are there any books on the table?
На столе есть книги?

Are there any students in the classroom?
В классе есть студенты?

Are there any apples in the basket?
В корзине есть яблоки?

Are there many people in the park?
В парке много людей?
```

### 5.2 Краткие ответы

**С единственным числом:**

```

Is there a book on the table?
- Yes, there is. / No, there isn't.
- Да, есть. / Нет.

Is there a bank near here?
- Yes, there is. / No, there isn't.
- Да, есть. / Нет.
```

**С множественным числом:**

```

Are there any students in the classroom?
- Yes, there are. / No, there aren't.
- Да, есть. / Нет.

Are there many people here?
- Yes, there are. / No, there aren't.
- Да, много. / Нет.
```

### 5.3 Специальные вопросы

**How many...?** (Сколько...?)

```

How many books are there on the table?
Сколько книг на столе?
- There are five books.
- Пять книг.

How many students are there in your class?
Сколько студентов в твоем классе?
- There are twenty students.
- Двадцать студентов.

How many rooms are there in your house?
Сколько комнат в твоем доме?
- There are three rooms.
- Три комнаты.
```

**What...?** (Что...?)

```

What is there in the box?
Что в коробке?
- There is a toy.
- Там игрушка.

What is there on the table?
Что на столе?
- There are some books.
- Там книги.
```

## 6. There is/are с несколькими предметами

### 6.1 Когда первый предмет в единственном числе

Если в списке первый предмет в единственном числе, используем **there is**:

```

There is a book and two pens on the table.
На столе книга и две ручки.

There is one teacher and twenty students in the classroom.
В классе один учитель и двадцать студентов.

There is a cat and three dogs in the yard.
Во дворе кот и три собаки.
```

### 6.2 Когда первый предмет во множественном числе

Если в списке первый предмет во множественном числе, используем **there are**:

```

There are two pens and a book on the table.
На столе две ручки и книга.

There are twenty students and one teacher in the classroom.
В классе двадцать студентов и один учитель.

There are three dogs and a cat in the yard.
Во дворе три собаки и кот.
```

**Объяснение:**
Выбор is/are зависит от первого существительного после there.

## 7. Практические примеры и диалоги

### 7.1 Описание комнаты

```

This is my living room.
There is a sofa near the window.
There is a TV on the wall.
There are two armchairs.
There are many books on the shelves.
There is a coffee table in the middle.
There aren't any plants in this room.

Это моя гостиная.
У окна диван.
На стене телевизор.
Есть два кресла.
На полках много книг.
Посередине журнальный столик.
В этой комнате нет растений.
```

### 7.2 Поиск места

```

A: Excuse me. Is there a bank near here?
B: Yes, there is. There's a bank on Main Street.
A: How far is it?
B: It's about 5 minutes' walk from here.
A: Are there any ATMs around here?
B: Yes, there are two ATMs in the shopping center.

A: Извините. Здесь рядом есть банк?
B: Да, есть. На Главной улице есть банк.
A: Как далеко?
B: Примерно 5 минут ходьбы отсюда.
A: Здесь есть банкоматы?
B: Да, в торговом центре два банкомата.
```

### 7.3 В ресторане

```

A: Is there a table for two?
B: Yes, there is. There's a table by the window.
A: Great! Is there a menu in English?
B: Yes, there is.
A: Are there any vegetarian dishes?
B: Yes, there are several vegetarian options.

A: Есть столик на двоих?
B: Да, есть. Есть столик у окна.
A: Отлично! Есть меню на английском?
B: Да, есть.
A: Есть вегетарианские блюда?
B: Да, есть несколько вегетарианских вариантов.
```

### 7.4 Описание города

```

My city is very nice.
There are many parks and gardens.
There is a big shopping mall in the center.
There are two cinemas.
There is a beautiful river.
There are many restaurants and cafes.
There isn't a metro, but there are many buses.
There are three universities.

Мой город очень хороший.
Здесь много парков и садов.
В центре большой торговый центр.
Есть два кинотеатра.
Есть красивая река.
Много ресторанов и кафе.
Метро нет, но много автобусов.
Есть три университета.
```

## 8. Типичные ошибки русскоговорящих

### 8.1 Пропуск артикля

❌ **Неправильно:**

```

There is book on the table.
There is cat in the garden.
```

✅ **Правильно:**

```

There is a book on the table.
There is a cat in the garden.
```

**Объяснение:**
После "there is" с исчисляемым существительным в единственном числе нужен артикль a/an.

### 8.2 Неправильный выбор is/are

❌ **Неправильно:**

```

There is three books on the table.
There are a book on the table.
```

✅ **Правильно:**

```

There are three books on the table.
There is a book on the table.
```

**Объяснение:**
"There is" для единственного числа, "there are" для множественного числа.

### 8.3 Путаница there и it/they

❌ **Неправильно:**

```

Is there a book on the table? - Yes, it is.
Are there any students? - Yes, they are.
```

✅ **Правильно:**

```

Is there a book on the table? - Yes, there is.
Are there any students? - Yes, there are.
```

**Объяснение:**
В кратких ответах на вопросы с "there is/are" используем "there is/are", а не "it is/they are".

### 8.4 Использование "there" как "там"

❌ **Неправильно:**

```

The book is there is. (пытаясь сказать "книга там")
```

✅ **Правильно:**

```

The book is there. (книга там)
There is a book there. (там есть книга)
```

**Объяснение:**
"There is/are" - это конструкция для выражения наличия. Слово "там" переводится как "there" отдельно (The book is there).

### 8.5 Двойное подлежащее

❌ **Неправильно:**

```

There is a book it is on the table.
There are students they are in the classroom.
```

✅ **Правильно:**

```

There is a book on the table.
(или: The book is on the table.)

There are students in the classroom.
(или: The students are in the classroom.)
```

**Объяснение:**
Не нужно использовать и "there is/are", и "it/they" в одном предложении для одного предмета.

## 💡 Key Takeaways

После изучения этого модуля запомните:

- **There is** - для единственного числа и неисчисляемых существительных

- **There are** - для множественного числа

- **Структура:** There + is/are + what + where

- **Отрицание:** There isn't / There aren't (или There is/are no...)

- **Вопросы:** Is there...? / Are there...?

- **Краткие ответы:** Yes, there is/are. No, there isn't/aren't.
- После "there is" нужен артикль: There is **a** book (не There is book)
- "There" в этой конструкции не означает "там" - это часть выражения
- Используется для описания наличия чего-либо в каком-либо месте

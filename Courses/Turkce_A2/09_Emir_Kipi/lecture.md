## 1. Что такое повелительное наклонение

Повелительное наклонение (emir kipi) используется для:

- **Команд** и приказов

- **Просьб** и пожеланий

- **Инструкций** и указаний

- **Советов** и рекомендаций

### 1.1 Основное значение

Императив выражает желание говорящего, чтобы собеседник совершил действие.

**Example: Простая команда**

```

Gel!
Иди сюда! / Приходи!
```

**Объяснение:**
Самая простая и прямая форма команды — это основа глагола без окончаний (для 2-го лица единственного числа "sen").

### 1.2 Когда использовать императив

**Use cases:**

- **Команды**: Otur! (Сиди!)

- **Просьбы**: Yardım et! (Помоги!)

- **Инструкции**: Düğmeye bas! (Нажми на кнопку!)

- **Приглашения**: İçeri gir! (Заходи!)

## 2. Образование повелительного наклонения

### 2.1 Формула для разных лиц

Турецкий язык имеет формы императива для нескольких лиц:

| Лицо | Форма | Пример (gelmek) | Перевод |
|------|-------|-----------------|---------|
| sen (ты) | основа | gel | приходи |
| siz (вы) | основа + -(y)in/-(y)ın | gelin | приходите |
| o (он/она) | основа + -sin/-sın | gelsin | пусть придёт |
| biz (мы) | основа + -(y)elim/-(y)alım | gelelim | давай придём |
| onlar (они) | основа + -sinler/-sınlar | gelsinler | пусть придут |

> **💡 Pro Tip:**  
> Самая распространённая форма — для "sen" (просто основа глагола) и "siz" (основа + -(y)in/-(y)ın).

### 2.2 Sen (ты) — самая простая форма

Для 2-го лица единственного числа используется **чистая основа** глагола:

**Example: Команды для "sen"**

```

gel-mek → Gel! (Приходи!)
git-mek → Git! (Иди!)
otur-mak → Otur! (Садись!)
bak-mak → Bak! (Смотри!)
yaz-mak → Yaz! (Пиши!)
konuş-mak → Konuş! (Говори!)
```

**Объяснение:**
Убираем -mek/-mak, остаётся чистая основа — это и есть команда для "sen".

### 2.3 Siz (вы) — вежливая форма

Для 2-го лица множественного числа (или вежливого обращения) добавляем **-(y)in/-(y)ın/-(y)un/-(y)ün**:

**Правило выбора суффикса (гармония гласных):**

| Последняя гласная основы | Суффикс |
|--------------------------|---------|
| e, i                     | -in     |
| a, ı                     | -ın     |
| o, u                     | -un     |
| ö, ü                     | -ün     |

**Example: Команды для "siz"**

```

gel → Gelin! (Приходите!)
git → Gidin! (Идите!)
otur → Oturun! (Садитесь!)
bak → Bakın! (Смотрите!)
yaz → Yazın! (Пишите!)
konuş → Konuşun! (Говорите!)
```

**Объяснение:**
Буква (y) в скобках означает, что если основа заканчивается на гласную, добавляется -y- как буфер.

**Example: С буфером -y-**

```

oku (читать) → Okuyun! (Читайте!)
söyle (говорить) → Söyleyin! (Говорите!)
anla (понимать) → Anlayın! (Понимайте!)
```

## 3. Другие формы императива

### 3.1 O (он/она) — "пусть сделает"

Для 3-го лица используется суффикс **-sin/-sın/-sun/-sün**:

**Example: Команды для "o"**

```

gelsin — пусть придёт
gitsin — пусть идёт
otursun — пусть сядет
baksın — пусть посмотрит
yapsın — пусть сделает
```

**Использование:**

```

O eve gitsin.
Пусть он идёт домой.

Ali bu işi yapsın.
Пусть Али сделает эту работу.
```

### 3.2 Biz (мы) — "давайте сделаем"

Для 1-го лица множественного числа используется **-(y)elim/-(y)alım**:

**Example: Предложения для "biz"**

```

gelelim — давайте придём
gidelim — давайте пойдём
oturalım — давайте сядем
bakalım — давайте посмотрим
yapalım — давайте сделаем
```

**Использование:**

```

Sinemaya gidelim.
Давайте пойдём в кино.

Kahve içelim.
Давайте выпьем кофе.
```

### 3.3 Onlar (они) — "пусть сделают"

Для 3-го лица множественного числа добавляем **-ler/-lar** к форме "o":

**Example: Команды для "onlar"**

```

gelsinler — пусть придут
gitsinler — пусть идут
otursunlar — пусть сядут
baksınlar — пусть посмотрят
yapsınlar — пусть сделают
```

## 4. Отрицательная форма императива

### 4.1 Образование отрицательного императива

Отрицательная форма образуется с суффиксом **-me/-ma**:

```

Основа + -me/-ma + форма императива
```

**Выбор -me/-ma:**

- **-me** после e, i, ö, ü

- **-ma** после a, ı, o, u

### 4.2 Отрицательные команды для "sen"

**Example: Запреты для "sen"**

```

gel → Gelme! (Не приходи!)
git → Gitme! (Не уходи!)
otur → Oturma! (Не садись!)
bak → Bakma! (Не смотри!)
yap → Yapma! (Не делай!)
konuş → Konuşma! (Не говори!)
```

**Объяснение:**
К основе добавляется -me/-ma, затем для "sen" больше ничего не нужно.

### 4.3 Отрицательные команды для "siz"

**Example: Запреты для "siz"**

```

Gelmeyin! (Не приходите!)
Gitmeyin! (Не уходите!)
Oturmayın! (Не садитесь!)
Bakmayın! (Не смотрите!)
Yapmayın! (Не делайте!)
Konuşmayın! (Не говорите!)
```

**Формула:**

```

Основа + -me/-ma + -yin/-yın/-yun/-yün
```

> **💡 Pro Tip:**  
> После отрицательного -me/-ma всегда используется форма с -y- (а не просто -in/-ın).

### 4.4 Отрицательные формы для других лиц

**Example: Полная таблица (gelmek)**

| Лицо | Отрицательная форма | Перевод |
|------|---------------------|---------|
| sen | gelme | не приходи |
| siz | gelmeyin | не приходите |
| o | gelmesin | пусть не приходит |
| biz | gelmeyelim | давайте не придём |
| onlar | gelmesinler | пусть не придут |

## 5. Вежливые формы и степени вежливости

### 5.1 Использование "lütfen" (пожалуйста)

Слово **"lütfen"** (пожалуйста) смягчает команду и делает её просьбой:

**Example: Вежливые просьбы**

```

Lütfen bekleyin. — Пожалуйста, подождите.
Lütfen oturun. — Пожалуйста, садитесь.
Lütfen gelin. — Пожалуйста, приходите.
Lütfen konuşun. — Пожалуйста, говорите.
```

**Объяснение:**
"Lütfen" обычно ставится в начале предложения, но может быть и в конце.

**Example: "Lütfen" в конце**

```

Bekleyin, lütfen. — Подождите, пожалуйста.
Oturun, lütfen. — Садитесь, пожалуйста.
```

### 5.2 Степени вежливости

**Шкала вежливости от грубой до очень вежливой:**

1. **Прямая команда (грубо):**

   ```

   Gel! — Иди сюда! (очень прямо)
   ```

2. **С суффиксом -sene/-sana (дружески):**

   ```

   Gelsene! — Да иди же! (для близких)
   ```

3. **Форма "siz" (вежливо):**

   ```

   Gelin! — Приходите! (уважительно)
   ```

4. **С "lütfen" (очень вежливо):**

   ```

   Lütfen gelin! — Пожалуйста, приходите!
   ```

5. **С суффиксом -(y)iniz (формально):**

   ```

   Geliniz! — Приходите! (очень формально, архаично)
   ```

### 5.3 Дружеские формы с -sene/-sana

Суффиксы **-sene/-sana** используются с близкими людьми для выражения нетерпения или побуждения:

**Example: Дружеские побуждения**

```

Gelsene! — Да иди же! / Ну иди!
Baksana! — Да посмотри же!
Anlatsana! — Да расскажи же!
Yapsana! — Да сделай же!
```

**Объяснение:**
Эти формы добавляют эмоциональность и используются только с друзьями и семьёй.

## 6. Практические примеры и ситуации

### 6.1 Example: В классе

**Команды учителя:**

```

— Oturun, lütfen. (Садитесь, пожалуйста.)
— Kitaplarınızı açın. (Откройте ваши книги.)
— Dinleyin. (Слушайте.)
— Tekrar edin. (Повторите.)
— Yazmayın, sadece dinleyin. (Не пишите, только слушайте.)
```

### 6.2 Example: На улице

**Указания прохожему:**

```

— Afedersiniz, postane nerede?
— Извините, где почта?

— Düz gidin, sonra sağa dönün.
— Идите прямо, затем поверните направо.

— Köşede sola dönün.
— На углу поверните налево.

— İlk sokaktan girin.
— Заходите на первую улицу.
```

### 6.3 Example: В ресторане

**Официант даёт рекомендации:**

```

— Buyurun, oturun.
— Пожалуйста, садитесь.

— Menüyü alın.
— Возьмите меню.

— Bu yemeği deneyin. Çok lezzetli.
— Попробуйте это блюдо. Очень вкусно.

— Afiyet olsun! (желание приятного аппетита)
— Приятного аппетита!
```

### 6.4 Example: Дома (семья)

**Разговор между родителями и детьми:**

```

РОДИТЕЛЬ:
— Ellerini yıka! (Помой руки!)
— Ödevini yap! (Делай домашнее задание!)
— Televizyon seyretme! (Не смотри телевизор!)
— Odanı topla! (Убери свою комнату!)

РЕБЁНОК:
— Tamam, yapıyorum. (Хорошо, делаю.)
```

## 9. Распространённые ошибки

### 9.1 Ошибка: Добавление -in к "sen"

**❌ Неправильно:**

```

Gelin! (для "sen")
```

**✅ Правильно:**

```

Gel! (для "sen")
Gelin! (для "siz")
```

**Объяснение:**
Для "sen" используется просто основа, -in/-ın добавляется только для "siz".

### 9.2 Ошибка: Неправильная форма отрицания

**❌ Неправильно:**

```

Gelmeyin! (для "sen")
Gelme! (для "siz")
```

**✅ Правильно:**

```

Gelme! (для "sen")
Gelmeyin! (для "siz")
```

### 9.3 Ошибка: Пропуск буфера -y-

**❌ Неправильно:**

```

Okuın! (должно быть okuyun)
Anlaın! (должно быть anlayın)
```

**✅ Правильно:**

```

Okuyun! (читайте)
Anlayın! (понимайте)
```

**Объяснение:**
Когда основа заканчивается на гласную, перед -in/-ın добавляется -y-.

## 10. Культурные особенности

### 10.1 Турецкая вежливость

В турецкой культуре очень важно использовать вежливые формы:

**Example: Вежливое общение**

```

СО ВЗРОСЛЫМИ И НЕЗНАКОМЫМИ:
Lütfen gelin. (не просто "gel")
Lütfen oturun. (не просто "otur")

С ДРУЗЬЯМИ И СЕМЬЁЙ:
Gel! Gelsene! (можно неформально)
```

### 10.2 Выражение "Buyrun" / "Buyurun"

Очень распространённое турецкое выражение вежливости:

**Example: Использование "buyurun"**

```

Buyurun, girin. — Пожалуйста, заходите.
Buyurun, oturun. — Пожалуйста, садитесь.
Buyurun, alın. — Пожалуйста, возьмите.
Buyurun. — Пожалуйста (предложение чего-либо).
```

**Объяснение:**
"Buyurun" — это форма повелительного наклонения от глагола "buyurmak" (жалов ать, изволить) и выражает глубокое уважение и гостеприимство.

## 🔑 Key Takeaways

1. **Sen**: чистая основа глагола (Gel!)
2. **Siz**: основа + -(y)in/-(y)ın (Gelin!)
3. **O**: основа + -sin/-sın (gelsin)
4. **Biz**: основа + -(y)elim/-(y)alım (gelelim)
5. **Отрицание**: основа + -me/-ma (Gelme! / Gelmeyin!)
6. **Вежливость**: используйте "lütfen" и форму "siz"
7. **Дружеские формы**: -sene/-sana (Gelsene!)
8. **Буфер -y-**: после гласных (okuyun, söyleyin)

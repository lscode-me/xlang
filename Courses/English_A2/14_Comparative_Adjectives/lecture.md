## 1. Введение в сравнительную степень

**Сравнительная степень прилагательных (Comparative Adjectives)** используется для сравнения двух предметов, людей или явлений.

**Основная структура:**

```

A is [comparative adjective] than B.
A [сравнительная форма] чем B.
```

**Примеры:**

```

John is taller than Mary.
Джон выше, чем Мэри.

This book is more interesting than that one.
Эта книга интереснее, чем та.

Today is better than yesterday.
Сегодня лучше, чем вчера.
```

---

## 2. Короткие прилагательные (Short Adjectives)

### 2.1 Правило образования

**Короткие прилагательные** — это прилагательные из **1-2 слогов**.

**Формула:** прилагательное + **-er**

| Прилагательное | Сравнительная форма | Пример |
|----------------|---------------------|---------|
| tall (высокий) | taller | He is taller. |
| old (старый) | older | She is older. |
| young (молодой) | younger | I'm younger. |
| cheap (дешевый) | cheaper | It's cheaper. |
| fast (быстрый) | faster | This is faster. |
| slow (медленный) | slower | It's slower. |
| small (маленький) | smaller | It's smaller. |
| cold (холодный) | colder | It's colder. |
| warm (теплый) | warmer | It's warmer. |

### 2.2 Примеры в предложениях

```

He is tall. → He is taller than me.
Он высокий. → Он выше, чем я.

This car is fast. → This car is faster than that one.
Эта машина быстрая. → Эта машина быстрее, чем та.

She is young. → She is younger than her sister.
Она молодая. → Она моложе, чем ее сестра.

Winter is cold. → Winter is colder than autumn.
Зима холодная. → Зима холоднее, чем осень.

This phone is cheap. → This phone is cheaper than that one.
Этот телефон дешевый. → Этот телефон дешевле, чем тот.
```

**Больше примеров:**

```

My house is small, but yours is smaller.
Мой дом маленький, но твой меньше.

Coffee is hot, but tea is hotter.
Кофе горячий, но чай горячее.

He is rich, but his brother is richer.
Он богатый, но его брат богаче.

This test was hard, but that test was harder.
Этот тест был трудным, но тот тест был труднее.

The water is clean here, but it's cleaner in the mountains.
Вода здесь чистая, но в горах она чище.
```

## 3. Особые правила орфографии

### 3.1 Удвоение конечной согласной

Если прилагательное оканчивается на **одну гласную + одну согласную**, конечная согласная **удваивается**.

| Прилагательное | Сравнительная форма | Пример |
|----------------|---------------------|---------|
| big (большой) | big**g**er | It's bigger. |
| hot (горячий) | hot**t**er | It's hotter. |
| thin (тонкий) | thin**n**er | It's thinner. |
| fat (толстый) | fat**t**er | It's fatter. |
| sad (грустный) | sad**d**er | He's sadder. |
| wet (мокрый) | wet**t**er | It's wetter. |

**Примеры:**

```

This bag is big, but that bag is bigger.
Эта сумка большая, но та сумка больше.

Yesterday was hot, but today is hotter.
Вчера было жарко, но сегодня жарче.

She is thin, but her sister is thinner.
Она худая, но ее сестра худее.
```

**⚠️ Важно:** Это правило НЕ применяется, если:
- Два гласных подряд: cheap → cheaper (не cheappper)
- Две согласных: cold → colder (не collder)

### 3.2 Прилагательные на -y

Если прилагательное оканчивается на **согласную + y**, то **y → ier**.

| Прилагательное | Сравнительная форма | Пример |
|----------------|---------------------|---------|
| happy (счастливый) | happier | She's happier. |
| easy (легкий) | easier | It's easier. |
| busy (занятой) | busier | I'm busier. |
| early (ранний) | earlier | It's earlier. |
| pretty (красивый) | prettier | She's prettier. |
| dirty (грязный) | dirtier | It's dirtier. |
| heavy (тяжелый) | heavier | It's heavier. |
| lucky (счастливый) | luckier | He's luckier. |

**Примеры:**

```

I am happy, but she is happier.
Я счастлив, но она счастливее.

This task is easy, but that task is easier.
Это задание легкое, но то задание легче.

Monday is busy, but Friday is busier.
Понедельник занятой, но пятница более занятая.

My bag is heavy, but yours is heavier.
Моя сумка тяжелая, но твоя тяжелее.
```

**⚠️ Важно:** Если перед -y стоит гласная, правило НЕ работает:
- grey → greyer (НЕ greier)

### 3.3 Прилагательные на -e

Если прилагательное оканчивается на **-e**, добавляем только **-r**.

| Прилагательное | Сравнительная форма | Пример |
|----------------|---------------------|---------|
| nice (милый) | nicer | It's nicer. |
| large (большой) | larger | It's larger. |
| late (поздний) | later | It's later. |
| safe (безопасный) | safer | It's safer. |
| wide (широкий) | wider | It's wider. |
| close (близкий) | closer | It's closer. |

**Примеры:**

```

This hotel is nice, but that hotel is nicer.
Этот отель милый, но тот отель милее.

My room is large, but your room is larger.
Моя комната большая, но твоя комната больше.

The meeting starts late, but the party starts later.
Встреча начинается поздно, но вечеринка начинается позже.
```

## 4. Длинные прилагательные (Long Adjectives)

### 4.1 Правило образования

**Длинные прилагательные** — это прилагательные из **2 слогов (некоторые) и 3+ слогов**.

**Формула:** **more** + прилагательное

| Прилагательное | Сравнительная форма | Пример |
|----------------|---------------------|---------|
| interesting (интересный) | more interesting | It's more interesting. |
| expensive (дорогой) | more expensive | It's more expensive. |
| beautiful (красивый) | more beautiful | She's more beautiful. |
| difficult (трудный) | more difficult | It's more difficult. |
| important (важный) | more important | It's more important. |
| comfortable (удобный) | more comfortable | It's more comfortable. |
| dangerous (опасный) | more dangerous | It's more dangerous. |
| popular (популярный) | more popular | It's more popular. |

### 4.2 Примеры в предложениях

```

This book is interesting. → This book is more interesting than that one.
Эта книга интересная. → Эта книга интереснее, чем та.

Paris is beautiful. → Paris is more beautiful than my city.
Париж красивый. → Париж красивее, чем мой город.

This car is expensive. → This car is more expensive than mine.
Эта машина дорогая. → Эта машина дороже, чем моя.

Math is difficult. → Math is more difficult than English.
Математика трудная. → Математика труднее, чем английский.
```

**Больше примеров:**

```

This chair is comfortable, but that sofa is more comfortable.
Этот стул удобный, но тот диван более удобный.

Driving is dangerous, but racing is more dangerous.
Вождение опасно, но гонки более опасны.

Coffee is popular, but tea is more popular in China.
Кофе популярен, но чай популярнее в Китае.

This information is important, but that information is more important.
Эта информация важна, но та информация важнее.
```

### 4.3 Какие прилагательные используют "more"?

**Всегда используем "more" с:**

1. **Прилагательными на -ful, -less, -ing, -ed:**
```

careful → more careful (осторожный)
useful → more useful (полезный)
hopeless → more hopeless (безнадежный)
boring → more boring (скучный)
interesting → more interesting (интересный)
tired → more tired (уставший)
excited → more excited (взволнованный)
```

2. **Трехсложными и более:**
```

expensive → more expensive
beautiful → more beautiful
comfortable → more comfortable
intelligent → more intelligent
```

**⚠️ Важно:** НЕ говорим "more + прилагательное + -er":
- ❌ more cheaper
- ✅ cheaper
- ❌ more better
- ✅ better

## 5. Неправильные формы (Irregular Forms)

Некоторые прилагательные имеют **неправильные сравнительные формы**, которые нужно запомнить.

### 5.1 Основные неправильные формы

| Прилагательное | Сравнительная форма | Перевод |
|----------------|---------------------|---------|
| **good** (хороший) | **better** | лучше |
| **bad** (плохой) | **worse** | хуже |
| **far** (далекий) | **farther / further** | дальше |
| **little** (маленький) | **less** | меньше |
| **much / many** (много) | **more** | больше |

### 5.2 Good → Better

```

This restaurant is good, but that restaurant is better.
Этот ресторан хороший, но тот ресторан лучше.

My English is good, but her English is better.
Мой английский хороший, но ее английский лучше.

Yesterday was a good day, but today is better.
Вчера был хороший день, но сегодня лучше.

This film is good, but the book is better.
Этот фильм хороший, но книга лучше.

Your idea is good, but his idea is better.
Твоя идея хорошая, но его идея лучше.
```

### 5.3 Bad → Worse

```

This situation is bad, but that situation is worse.
Эта ситуация плохая, но та ситуация хуже.

My headache is bad, but his headache is worse.
У меня головная боль, но у него головная боль хуже.

The weather was bad yesterday, but it's worse today.
Погода была плохой вчера, но сегодня она хуже.

This news is bad, but the next news is worse.
Эта новость плохая, но следующая новость хуже.
```

### 5.4 Far → Farther / Further

**Farther** — физическое расстояние
**Further** — абстрактное расстояние или "дополнительный"

```

Moscow is far from here, but Vladivostok is farther.
Москва далеко отсюда, но Владивосток дальше.

I can't walk any farther.
Я не могу идти дальше.

We need further information.
Нам нужна дополнительная информация.

For further details, call us.
Для дополнительных деталей позвоните нам.
```

### 5.5 Much/Many → More

```

I have much work, but she has more work.
У меня много работы, но у нее больше работы.

He has many books, but I have more books.
У него много книг, но у меня больше книг.

I need more time.
Мне нужно больше времени.

We need more information.
Нам нужно больше информации.
```

## 6. Использование "than"

### 6.1 Основная структура

**После сравнительной формы обычно следует "than" (чем):**

```

Subject + verb + comparative adjective + than + object
```

**Примеры:**

```

I am taller than you.
Я выше, чем ты.

She is more beautiful than her sister.
Она красивее, чем ее сестра.

This book is better than that book.
Эта книга лучше, чем та книга.

Cars are faster than bicycles.
Машины быстрее, чем велосипеды.

Gold is more expensive than silver.
Золото дороже, чем серебро.
```

### 6.2 Than + местоимение

После "than" можно использовать:

1. **Объектное местоимение (me, you, him, her, us, them)** — разговорный стиль
2. **Субъектное местоимение + глагол** — формальный стиль

```

РАЗГОВОРНЫЙ:
He is taller than me.
Он выше, чем я.

She is smarter than him.
Она умнее, чем он.

ФОРМАЛЬНЫЙ:
He is taller than I am.
Он выше, чем я (есть).

She is smarter than he is.
Она умнее, чем он (есть).
```

### 6.3 Без "than"

Иногда "than" опускается, если контекст понятен:

```

— Which car is faster?
— The red one is faster. (faster than the blue one — понятно из контекста)
— Какая машина быстрее?
— Красная быстрее.

I want a bigger house.
Я хочу дом побольше. (чем тот, что у меня сейчас)

Can you speak louder?
Можешь говорить громче? (чем сейчас)
```

## 8. Усиление сравнения

### 8.1 Much / A lot / Far + comparative

Чтобы усилить сравнение, используем **much, a lot, far** (намного, гораздо):

```

He is much taller than me.
Он намного выше, чем я.

This is a lot more expensive than that.
Это намного дороже, чем то.

She is far better at math than me.
Она намного лучше в математике, чем я.

Today is much hotter than yesterday.
Сегодня намного жарче, чем вчера.

This book is far more interesting.
Эта книга гораздо интереснее.
```

### 8.2 A little / A bit / Slightly + comparative

Для небольшой разницы используем **a little, a bit, slightly** (немного, чуть):

```

He is a little taller than me.
Он немного выше, чем я.

This is a bit more expensive.
Это чуть дороже.

She is slightly older than him.
Она немного старше, чем он.

Today is a little warmer.
Сегодня чуть теплее.
```

## 9. Типичные ошибки

### 9.1 Использование -er и more одновременно

```

❌ more better
✅ better

❌ more cheaper
✅ cheaper

❌ more easier
✅ easier

❌ more bigger
✅ bigger
```

### 9.2 Неправильное образование степени

```

❌ gooder
✅ better

❌ badder
✅ worse

❌ expensiver
✅ more expensive

❌ beautifuler
✅ more beautiful
```

### 9.3 Забывание "than"

```

❌ He is taller me.
✅ He is taller than me.

❌ This is more expensive that.
✅ This is more expensive than that.
```

### 9.4 Неправильное удвоение согласной

```

❌ biger
✅ bigger

❌ hotter (если hot)
✅ hotter ✓ (это правильно!)

❌ cheapper
✅ cheaper (две гласных подряд — не удваиваем)
```

## 💡 Key Takeaways

- **Короткие прилагательные (1-2 слога):** добавляем **-er**
  - tall → taller, fast → faster
- **Длинные прилагательные (3+ слога):** используем **more**
  - expensive → more expensive, beautiful → more beautiful
- **Особые правила орфографии:**
  - big → big**g**er (удвоение согласной)
  - happy → happ**ier** (y → ier)
  - nice → nic**er** (только -r)
- **Неправильные формы:** запомнить!
  - good → **better**, bad → **worse**, far → **farther/further**
- После сравнительной формы используем **than** (чем)
  - She is taller **than** me.
- Усиление: **much/far** + comparative (намного лучше)
  - much better, far more expensive

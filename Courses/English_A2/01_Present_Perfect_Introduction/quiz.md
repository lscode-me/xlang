## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Present Perfect образуется: have/has + Past Participle (V3). |
| 2 | D | С "she" (3-е лицо ед. числа) используется "has". |
| 3 | A | Правильные глаголы: Past Participle = Past Simple (work → worked). |
| 4 | A | "go" — неправильный глагол: go → went → gone. |
| 5 | C | Правильная структура: I + have + visited. |
| 6 | A | С "he" используется "has", форма "see" → "seen". |
| 7 | A | Отрицание с I: I + haven't + been. |
| 8 | B | Отрицание с she: she + hasn't + called. |
| 9 | D | Вопрос: Have + you + finished? |
| 10 | A | Вопрос с he: Has + he + visited? |
| 11 | B | Краткий ответ: Yes, I have. |
| 12 | D | Краткий ответ с she: No, she hasn't. |
| 13 | A | Правильно: I have never been there. |
| 14 | A | Present Perfect используется без конкретного времени. |
| 15 | B | "Yesterday" требует Past Simple. |
| 16 | D | "just" ставится между have/has и Past Participle. |
| 17 | B | "eat" → "eaten", с "they" используется "have". |
| 18 | A | "write" → "written", с "she" используется "has". |
| 19 | B | Специальный вопрос: What + have + you + done? |
| 20 | D | "I've" = "I have". |
| 21 | D | "I have lost" описывает результат в настоящем. |
| 22 | C | Опыт: Have you ever + eaten? |
| 23 | C | "make" → "made" (неправильный глагол). |
| 24 | C | "buy" → "bought", с "we" используется "have". |
| 25 | B | Нельзя: Present Perfect + yesterday. Правильно: I saw him yesterday. |
| 26 | B | Отрицание с "yet": haven't + arrived + yet. |
| 27 | A | "be" → "been". |
| 28 | D | С "they" используется "have visited". |
| 29 | C | Вопрос: How many books + have + you + read? |
| 30 | A | "drink" → "drunk", с "I" используется "have". |

## Scoring Guide

- 27-30 правильных ответов: Отлично! Вы полностью освоили Present Perfect.
- 23-26 правильных ответов: Хорошо! Повторите формы неправильных глаголов.
- 18-22 правильных ответов: Неплохо, но нужно больше практики с образованием форм.
- Меньше 18 правильных ответов: Рекомендуется повторить лекцию и выучить формы Past Participle.

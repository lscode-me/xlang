# Промпт для генерации словарных вопросов RU→EN Quiz (Words)

Ты - эксперт по английскому языку и создатель учебных материалов. Твоя задача - генерировать вопросы для теста на перевод **отдельных слов** с русского на английский язык.

## Формат вывода

Генерируй ТОЛЬКО JSONL (JSON Lines) - каждая строка = один валидный JSON объект.

**НЕ ДОБАВЛЯЙ**:
- Никаких markdown блоков кода (```json)
- Никаких комментариев
- Никаких пояснений
- Только чистые JSONL строки

## Структура каждого JSON объекта

```json
{"id":"<LEVEL>-<SET>-<NUM>","question":"<Russian word>","options":["<Option 1>","<Option 2>","<Option 3>","<Option 4>"],"correct":<1-4>,"explanation":"<Explanation>","tags":["<tag1>","<tag2>"],"source":"llm"}
```

## Обязательные поля

- **id**: Уникальный идентификатор в формате `<LEVEL>-<SET>-<NUM>`
  - Примеры: `A1-001-0001`, `A2-005-0023`
  - LEVEL: A1 или A2
  - SET: трёхзначный номер набора (001, 002, 003...)
  - NUM: четырёхзначный порядковый номер (0001, 0002, 0003...)

- **question**: **ОДНО СЛОВО** на русском языке
  - Существительное, прилагательное, глагол (в инфинитиве), наречие
  - НЕ фраза, НЕ предложение - только одно слово!
  - Соответствует уровню (A1/A2)
  - Примеры: "дом", "красный", "есть", "быстро"

- **options**: Массив из **ровно 4** вариантов перевода на английский
  - Все варианты - **одиночные слова** (не фразы!)
  - Только **ОДИН** вариант - правильный перевод `question`
  - Остальные 3 - правдоподобные дистракторы из той же тематики
  - Для существительных: используй базовую форму (единственное число)
  - Для глаголов: используй инфинитив (to + verb) или базовую форму без "to"
  - НЕ используй очевидно неправильные варианты
  - НЕ используй кириллицу в английских вариантах

- **correct**: Номер правильного варианта (1, 2, 3, или 4)
  - Указывает индекс правильного перевода в массиве `options`
  - Индексация с 1 (не с 0!)

- **explanation**: Объяснение на русском
  - Дополнительная информация о слове
  - Для существительных: множественное число (если нестандартное), артикли
  - Для глаголов: неправильные формы (past, past participle), особенности использования
  - Для прилагательных: степени сравнения (если нестандартные)
  - Примеры: 
    - `"house — дом (мн.ч. houses)"`
    - `"eat — есть (ate, eaten)"`
    - `"big — большой (bigger, biggest)"`

## Опциональные поля

- **tags**: Массив строк (тематики и категории)
  - Категория слова: `"noun"`, `"verb"`, `"adjective"`, `"adverb"`
  - Тематика: `"food"`, `"transport"`, `"colors"`, `"family"`, `"animals"`, etc.
  - Примеры: `["noun", "food"]`, `["verb", "daily"]`, `["adjective", "colors"]`
  
- **source**: Источник вопроса
  - Для AI-генерированных: `"llm"`

## Требования по уровням

### A1 (Начальный)
- Базовая лексика: 500-700 наиболее частотных слов
- Темы: 
  - Числа (0-100)
  - Цвета
  - Семья (мать, отец, сын, дочь)
  - Еда (хлеб, вода, молоко, яблоко)
  - Дом (дом, комната, дверь, окно)
  - Тело (голова, рука, нога, глаз)
  - Время (день, ночь, час, минута)
  - Базовые глаголы (быть, идти, есть, пить, делать)
  - Базовые прилагательные (большой, маленький, хороший, плохой)

### A2 (Элементарный)
- Расширенная лексика: 1000-1500 слов
- Темы:
  - Профессии
  - Транспорт
  - Погода
  - Одежда
  - Покупки
  - Город и места
  - Образование
  - Здоровье (базовое)
  - Эмоции
  - Природа (базовая)

## Правила качества

1. **Только одно слово**: В поле `question` должно быть ровно одно слово, не фраза
2. **Уникальность вариантов**: Все 4 варианта должны быть разными
3. **Правдоподобность дистракторов**: Неправильные варианты из той же тематики и категории
4. **Базовые формы**: 
   - Существительные в единственном числе
   - Глаголы в инфинитиве или базовой форме (без "to")
   - Прилагательные в положительной степени
5. **Нет кириллицы в en**: Все английские варианты только латиницей
6. **Нет LLM мусора**: Никаких фраз типа "As an AI", "ChatGPT"
7. **Корректный английский**: Правильные формы слов, правильное написание

## Примеры правильных дистракторов

### Для существительных (та же тематика):
- "дом" → `["house", "building", "apartment", "room"]` (все про жилье)
- "яблоко" → `["apple", "pear", "banana", "orange"]` (все фрукты)
- "кошка" → `["cat", "dog", "bird", "fish"]` (все животные)

### Для глаголов (похожие действия):
- "идти" → `["go", "come", "run", "walk"]` (все про движение)
- "есть" → `["eat", "drink", "take", "give"]` (базовые действия)

### Для прилагательных (та же категория):
- "красный" → `["red", "blue", "green", "yellow"]` (все цвета)
- "большой" → `["big", "small", "medium", "long"]` (все размеры)

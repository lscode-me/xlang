## 1. Введение в модальный глагол should

**Should** — это модальный глагол, который используется для:
- Советов и рекомендаций
- Мнений о правильности действий
- Мягкой критики
- Ожиданий

**Примеры:**

```

You should see a doctor.
Тебе следует обратиться к врачу.
(Совет)

You shouldn't eat so much sugar.
Тебе не следует есть так много сахара.
(Рекомендация)

Should I call him?
Мне позвонить ему?
(Спрашиваю совета)
```

---

## 2. Образование и использование should

### 2.1 Утвердительная форма

**Формула:** Subject + should + V1 (инфинитив без "to")

**Характеристики should:**

- Одинаковая форма для всех лиц (I/you/he/she/it/we/they)
- НЕ изменяется (нет should**s**, should**ed**)
- После should — инфинитив БЕЗ "to"
- Не используется с другими вспомогательными глаголами

**Примеры:**

```

I should study more.
Мне следует больше учиться.

You should rest.
Тебе следует отдохнуть.

He should apologize.
Ему следует извиниться.

She should take a break.
Ей следует сделать перерыв.

We should leave now.
Нам следует уйти сейчас.

They should be more careful.
Им следует быть осторожнее.
```

### 2.2 Произношение

**Should** произносится [ʃʊd]

**⚠️ Важно:** Буква "l" не произносится!

```

should [ʃʊd] — НЕ [ʃuːld]
shouldn't [ˈʃʊdnt]
```

### 2.3 Когда используется should

#### 2.3.1 Советы и рекомендации

Самое распространенное использование should — давать советы:

```

You should see this film. It's great!
Тебе следует посмотреть этот фильм. Он отличный!

You should try this restaurant.
Тебе следует попробовать этот ресторан.

You should learn English. It's useful.
Тебе следует учить английский. Это полезно.

You should talk to her.
Тебе следует поговорить с ней.

We should go to bed earlier.
Нам следует ложиться спать раньше.
```

#### 2.3.2 Мнения о правильности

**Should** выражает мнение о том, что правильно или хорошо:

```

People should respect each other.
Люди должны уважать друг друга.

Teachers should be patient.
Учителя должны быть терпеливыми.

Everyone should have the right to education.
Каждый должен иметь право на образование.

We should protect the environment.
Мы должны защищать окружающую среду.
```

#### 2.3.3 Что правильно делать в определенной ситуации

```

When you meet someone, you should shake hands.
Когда встречаешь кого-то, следует пожать руку.

You should say "thank you" when someone helps you.
Следует говорить "спасибо", когда кто-то помогает.

In a library, you should be quiet.
В библиотеке следует быть тихим.

You should arrive on time for a job interview.
Следует приходить вовремя на собеседование.
```

#### 2.3.4 Ожидания

**Should** может выражать ожидание, что что-то произойдет:

```

She should be here soon.
Она должна быть здесь скоро.
(Я ожидаю, что она скоро придет)

The package should arrive tomorrow.
Посылка должна прибыть завтра.
(Ожидается)

It shouldn't take long.
Это не должно занять много времени.
(Ожидание)

This should be easy.
Это должно быть легко.
(Предположение)
```

## 3. Отрицательная форма: shouldn't

### 3.1 Образование

**Формула:** Subject + should not / shouldn't + V1

**Примеры:**

```

You shouldn't smoke. It's bad for your health.
Тебе не следует курить. Это вредно для здоровья.

You shouldn't eat so much fast food.
Тебе не следует есть так много фастфуда.

He shouldn't drive so fast.
Ему не следует ездить так быстро.

She shouldn't worry so much.
Ей не следует так беспокоиться.

We shouldn't waste time.
Нам не следует тратить время.

They shouldn't be rude.
Им не следует быть грубыми.
```

### 3.2 Советы "что не делать"

```

You shouldn't go to bed late.
Тебе не следует ложиться спать поздно.

You shouldn't drink too much coffee.
Тебе не следует пить слишком много кофе.

You shouldn't be late for work.
Тебе не следует опаздывать на работу.

You shouldn't tell lies.
Тебе не следует лгать.

You shouldn't spend all your money.
Тебе не следует тратить все свои деньги.
```

## 4. Вопросительная форма

### 4.1 Общие вопросы

**Формула:** Should + Subject + V1?

**Примеры:**

```

Should I call him?
Мне позвонить ему?

Should I tell her the truth?
Мне сказать ей правду?

Should we go now?
Нам идти сейчас?

Should I buy this dress?
Мне купить это платье?

Should they come with us?
Им идти с нами?
```

### 4.2 Краткие ответы

**Утвердительные:**

- Yes, you should.
- Yes, I think you should.
- Yes, definitely.

**Отрицательные:**

- No, you shouldn't.
- No, I don't think you should.
- No, definitely not.

**Примеры диалогов:**

```

— Should I take an umbrella?
— Yes, you should. It might rain.
— Мне взять зонт?
— Да, следует. Может пойти дождь.

— Should I quit my job?
— No, you shouldn't. It's a good job.
— Мне уволиться с работы?
— Нет, не следует. Это хорошая работа.

— Should we wait for them?
— Yes, I think we should.
— Нам ждать их?
— Да, думаю, следует.
```

### 4.3 Специальные вопросы

**Формула:** Wh-word + should + Subject + V1?

**Примеры:**

```

What should I do?
Что мне делать?

Where should we go?
Куда нам пойти?

When should I call you?
Когда мне позвонить тебе?

How should I tell him?
Как мне сказать ему?

Who should I ask?
Кого мне спросить?

Which one should I choose?
Какой мне выбрать?
```

## 5. Should vs Must / Have to

Это очень важное различие!

### 5.1 Основная разница

| Should | Must / Have to |
|--------|----------------|
| Совет, рекомендация | Обязанность, необходимость |
| Можно не делать | Обязательно нужно делать |
| Мягче | Сильнее |

### 5.2 Сравнительные примеры

```

SHOULD (совет):
You should see a doctor.
Тебе следует обратиться к врачу.
(Совет, но можешь не идти)

MUST (обязанность):
You must see a doctor. You're very ill.
Ты должен обратиться к врачу. Ты очень болен.
(Обязательно нужно)

SHOULD (рекомендация):
You should study for the exam.
Тебе следует готовиться к экзамену.
(Рекомендация)

MUST (необходимость):
You must study. The exam is tomorrow!
Ты должен учиться. Экзамен завтра!
(Необходимо)

SHOULD (мнение):
People should be kind.
Люди должны быть добрыми.
(Мое мнение о правильности)

MUST (правило):
You must wear a helmet.
Ты должен носить шлем.
(Правило, закон)
```

### 5.3 Сила утверждения

```

Самое слабое → Самое сильное:

You could see a doctor. (возможность)
You should see a doctor. (совет)
You ought to see a doctor. (более формальный совет)
You have to see a doctor. (необходимость)
You must see a doctor. (сильная необходимость)
```

## 6. Критика действий

**Should / shouldn't** используется для мягкой критики прошлых или настоящих действий:

### 6.1 Критика прошлых действий (should have + V3)

```

You should have told me!
Тебе следовало сказать мне!
(Критика: ты не сказал)

He should have studied harder.
Ему следовало учиться усерднее.
(Критика: он недостаточно учился)

You shouldn't have done that!
Тебе не следовало этого делать!
(Критика действия)

She should have called me.
Ей следовало позвонить мне.
(Критика: она не позвонила)
```

**⚠️ Примечание:** should have + V3 — это продвинутая грамматика (уровень B1), но важно знать базовую концепцию.

### 6.2 Критика настоящих действий

```

You shouldn't eat so much.
Тебе не следует есть так много.

He shouldn't drive so fast.
Ему не следует ездить так быстро.

You should be more careful.
Тебе следует быть осторожнее.

They shouldn't waste money like that.
Им не следует так тратить деньги.
```

## 7. Практическое применение

### 7.1 Практические ситуации

#### 7.1.1 Совет другу

```

— I have a headache.
— You should take an aspirin.
— У меня болит голова.
— Тебе следует принять аспирин.

— I'm always tired.
— You should sleep more.
— Я всегда уставший.
— Тебе следует больше спать.

— I want to lose weight.
— You should exercise more and eat less.
— Я хочу похудеть.
— Тебе следует больше заниматься спортом и меньше есть.
```

#### 7.1.2 В ресторане

```

You should try the pasta. It's delicious!
Тебе следует попробовать пасту. Она вкусная!

You shouldn't order the fish. It's not fresh.
Тебе не следует заказывать рыбу. Она не свежая.

We should ask for the menu.
Нам следует попросить меню.
```

#### 7.1.3 На работе

```

You should arrive on time.
Тебе следует приходить вовремя.

You shouldn't use your phone during meetings.
Тебе не следует пользоваться телефоном на встречах.

We should finish this project by Friday.
Нам следует закончить этот проект к пятнице.

You should talk to your boss about a raise.
Тебе следует поговорить с начальником о повышении.
```

#### 7.1.4 Здоровье

```

You should eat more vegetables.
Тебе следует есть больше овощей.

You shouldn't smoke.
Тебе не следует курить.

You should exercise regularly.
Тебе следует регулярно заниматься спортом.

You shouldn't drink too much alcohol.
Тебе не следует пить слишком много алкоголя.

You should get a check-up every year.
Тебе следует проходить осмотр каждый год.
```

#### 7.1.5 Путешествия

```

You should visit the museum. It's amazing!
Тебе следует посетить музей. Он потрясающий!

You shouldn't travel alone at night.
Тебе не следует путешествовать в одиночку ночью.

You should book your hotel in advance.
Тебе следует забронировать отель заранее.

You should try the local food.
Тебе следует попробовать местную еду.
```

### 7.2 Распространенные выражения с should

#### 7.2.1 Советы о здоровье

```

You should get some rest.
Тебе следует отдохнуть.

You should take care of yourself.
```

#### 7.2.3 Советы о поведении

## 8. Выражение советов: I think you should...

### 8.1 Мягкие советы с "I think"

Очень распространенная конструкция для мягких советов:

```

I think you should see a doctor.
Думаю, тебе следует обратиться к врачу.

I don't think you should go there.
Не думаю, что тебе следует туда идти.

I think she should know the truth.
Думаю, ей следует знать правду.
```

**Это звучит мягче, чем просто "You should..."**

### 8.2 Should в косвенной речи

**Should** используется для передачи советов в косвенной речи:

```

Direct: "You should see a doctor."
Reported: He said (that) I should see a doctor.

Direct: "You shouldn't eat so much."
Reported: She told me (that) I shouldn't eat so much.
```

## 9. Типичные ошибки и Ought to

### 9.1 Типичные ошибки

**❌ Неправильно:** You should to go home.
**✅ Правильно:** You should go home.

**❌ Неправильно:** He shoulds study more.
**✅ Правильно:** He should study more.

**❌ Неправильно:** Do I should go?
**✅ Правильно:** Should I go?

**❌ Неправильно:** You should wear a seatbelt. (когда это закон)
**✅ Правильно:** You must wear a seatbelt.

### 9.2 Ought to

**Ought to** — синоним should, но более формальный и менее распространенный:

```

You ought to see a doctor. = You should see a doctor.
Тебе следует обратиться к врачу.
```

**⚠️ Важно:** В современном английском **should** используется гораздо чаще.

## 10. Сводная таблица и вежливые предложения

### 10.1 Сравнение модальных глаголов

| Критерий | Should | Must | Have to |
|----------|--------|------|---------|
| **Значение** | Совет, рекомендация | Обязанность, необходимость | Обязанность |
| **Сила** | Слабее | Сильнее | Сильнее |
| **Можно не делать?** | ✅ Да | ❌ Нет | ❌ Нет |
| **Отрицание** | shouldn't (не следует) | mustn't (нельзя) | don't have to (не обязательно) |
| **Для советов** | ✅ | ❌ | ❌ |
| **Для правил** | ❌ | ✅ | ✅ |

### 10.2 Should для вежливых предложений

```

Should we go now?
Может, нам пойти сейчас?

Should I help you?
Может, мне помочь тебе?

Should we invite them?
Может, нам пригласить их?
```

## 💡 Key Takeaways

- **Should** = совет, рекомендация, мнение о правильности

- **Should** одинаковая форма для всех лиц
- После should — инфинитив БЕЗ "to"
- **Shouldn't** = не следует (совет не делать что-то)

- **Should** слабее, чем must/have to

- **Should** для советов, **must** для обязанностей
- Вопросы: Should I...? Should we...?
- **I think you should...** — мягкий совет
- Произношение: [ʃʊd], буква "l" не произносится
- **Should** НЕ требует вспомогательных глаголов (не "do should")

- **Should** можно использовать для вежливых предложений

## 1. Инфинитив как именная форма

Инфинитив -mak/-mek может использоваться не только как форма словаря, но и как именная форма глагола, выражающая абстрактное действие.

### 1.1 Абстрактное действие

Инфинитив выражает действие как абстрактную концепцию, без указания на конкретного субъекта или время.

**Пример: Абстрактное действие**

```
Türkçe öğrenmek zor.
Изучать турецкий трудно (абстрактно).
```

**Объяснение:**
-mak выражает действие "изучать турецкий" как абстрактную концепцию, без указания на конкретного человека или время.

**Пример: Другой случай**

```
Erken kalkmak iyi.
Вставать рано хорошо (абстрактно).
```

**Объяснение:**
-mak выражает общую истину о действии, без привязки к конкретному лицу.

---

## 2. Использование после прилагательных

### 2.1 Прилагательные оценки

Инфинитив часто используется после прилагательных, выражающих оценку действия: zor (трудно), kolay (легко), iyi (хорошо), kötü (плохо), güzel (красиво), önemli (важно).

**Пример: С прилагательными**

```
Türkçe öğrenmek zor.
Изучать турецкий трудно.

Erken kalkmak iyi.
Вставать рано хорошо.

Sigara içmek kötü.
Курить плохо.
```

**Объяснение:**
Инфинитив используется для выражения оценки действия как абстрактной концепции.

### 2.2 Другие прилагательные

**Пример: С другими прилагательными**

```
Kitap okumak güzel.
Читать книги красиво (приятно).

Spor yapmak önemli.
Заниматься спортом важно.
```

**Объяснение:**
Инфинитив может использоваться с различными прилагательными для выражения оценки действия.

### 2.3 Полный список прилагательных

**Таблица прилагательных с -mak:**

| Прилагательное | Значение | Пример |
|---------------|----------|--------|
| zor | трудно | Türkçe öğrenmek zor |
| kolay | легко | Yüzmek kolay |
| iyi | хорошо | Erken kalkmak iyi |
| kötü | плохо | Sigara içmek kötü |
| güzel | красиво/приятно | Kitap okumak güzel |
| önemli | важно | Spor yapmak önemli |
| sağlıklı | полезно | Yüzmek sağlıklı |
| tehlikeli | опасно | Hızlı araba kullanmak tehlikeli |

**Пример: С разными прилагательными**

```
Yüzmek sağlıklı.
Плавать полезно для здоровья.

Hızlı araba kullanmak tehlikeli.
Быстро водить машину опасно.

Düzenli çalışmak önemli.
Регулярно работать важно.
```

**Объяснение:**
Инфинитив может использоваться с широким спектром прилагательных для выражения различных оценок действия.

### 2.4 Структура предложений с прилагательными

**Формула:**
```
Инфинитив (-mak/-mek) + прилагательное
```

**Пример: Разные структуры**

```
Türkçe öğrenmek zor ama önemli.
Изучать турецкий трудно, но важно.

Erken kalkmak iyi, geç kalkmak kötü.
Вставать рано хорошо, вставать поздно плохо.

Yüzmek hem sağlıklı hem eğlenceli.
Плавать и полезно для здоровья, и весело.
```

**Объяснение:**
Инфинитив может использоваться в сложных предложениях с несколькими прилагательными.

## 3. Отличие от формы -ma

### 3.1 Абстрактное vs конкретное

Инфинитив -mak выражает абстрактное действие, а форма -ma — конкретное действие с субъектом.

**Пример: Сравнение**

```
Türkçe öğrenmek zor. (абстрактно)
Изучать турецкий трудно.

Türkçe öğrenmeyi seviyorum. (конкретно)
Я люблю изучать турецкий (конкретное действие).
```

**Объяснение:**
-mak выражает абстрактную концепцию, а -ma с падежом выражает конкретное действие, которое выполняет говорящий.

### 3.2 Когда использовать -mak

Используйте -mak для:
- Абстрактных высказываний
- Общих истин
- Оценки действия (после прилагательных)
- Без указания на конкретного субъекта

**Пример: Абстрактное высказывание**

```
Yüzmek sağlıklı.
Плавать полезно для здоровья.
```

**Объяснение:**
-mak используется, потому что речь идет об общей истине, без указания на конкретного человека.

## 4. Инфинитив с падежами

### 4.1 Исходный падеж -maktan / -mekten

Инфинитив может использоваться с исходным падежом для выражения причины.

**Пример: Причина**

```
Çok çalışmaktan yoruldum.
Я устал от того, что много работал (от много работы).
```

**Объяснение:**
-maktan выражает причину усталости — много работы.

**Пример: Другие случаи причины**

```
Çok yemekten kilo aldım.
Я поправился от того, что много ел.

Koşmaktan nefesim kesildi.
Я задыхался от бега.

Gülmekten karnım ağrıdı.
У меня заболел живот от смеха.
```

**Объяснение:**
-maktan/-mekten используется для выражения различных причин физических состояний и эмоций.

### 4.2 Отношение к действию

**Пример: С глаголом hoşlanmak**

```
Çalışmaktan hoşlanmıyorum.
Мне не нравится работать (от работы мне не нравится).

Yüzmekten hoşlanıyorum.
Мне нравится плавать.

Kitap okumaktan hoşlanıyorum.
Мне нравится читать книги.
```

**Объяснение:**
-maktan используется для выражения отношения к действию после глагола hoşlanmak.

**Пример: С другими глаголами**

```
Erken kalkmaktan nefret ediyorum.
Я ненавижу рано вставать.

Yalan söylemekten kaçınıyorum.
Я избегаю лгать.

Geç kalmaktan çekiniyorum.
Я стесняюсь опаздывать.
```

**Объяснение:**
-maktan может использоваться с различными глаголами для выражения отношения к действию.

### 4.3 Эмоциональные реакции

**Пример: Страх и беспокойство**

```
Geç kalmaktan korkuyorum.
Я боюсь опоздать.

Hata yapmaktan endişeleniyorum.
Я беспокоюсь о том, что сделаю ошибку.

Yanlış yapmaktan utanıyorum.
Мне стыдно делать неправильно.
```

**Объяснение:**
-maktan используется для выражения эмоциональных реакций на действие.

```
Yüzmek sağlıklı.

**Объяснение:**
Инфинитив используется для выражения общих истин о здоровье.

```

**Объяснение:**
Инфинитив используется для выражения различных аспектов работы.

## 6. Частые ошибки

### 6.1 Ошибка: Смешение -mak и -ma

❌ **Неправильно:**

```
Kitap okumak seviyorum. (неправильно)
Я люблю читать книги.
```

✅ **Правильно:**

```
Kitap okumayı seviyorum. (правильно)
Я люблю читать книги.
```

**Объяснение:**
После глаголов управления (sevmek, istemek) нужно использовать -ma с падежом, а не -mak.

**Пример: Другие случаи ошибки**

❌ **Неправильно:**

```
Yüzmek hoşlanmıyorum. (неправильно)
Мне не нравится плавать.
```

✅ **Правильно:**

```
Yüzmeyi hoşlanmıyorum. (правильно - но лучше)
Yüzmekten hoşlanmıyorum. (правильно - с исходным падежом)
Мне не нравится плавать.
```

**Объяснение:**
После глагола hoşlanmak можно использовать либо -mayı, либо -maktan. -maktan более естественно.

### 6.2 Ошибка: Неправильное использование после прилагательных

❌ **Неправильно:**

```
Türkçe öğrenmeyi zor. (неправильно)
Изучать турецкий трудно.
```

✅ **Правильно:**

```
Türkçe öğrenmek zor. (правильно)
Изучать турецкий трудно.
```

**Объяснение:**
После прилагательных оценки нужно использовать -mak, а не -ma.

**Пример: Другие случаи ошибки**

❌ **Неправильно:**

```
Erken kalkmayı iyi. (неправильно)
Вставать рано хорошо.
```

✅ **Правильно:**

```
Erken kalkmak iyi. (правильно)
Вставать рано хорошо.
```

**Объяснение:**
После прилагательных всегда используется -mak, а не -ma.

### 6.3 Ошибка: Неправильный падеж

❌ **Неправильно:**

```
Çalışmak için yoruldum. (неправильно для причины)
Я устал для работы.
```

✅ **Правильно:**

```
Çok çalışmaktan yoruldum. (правильно)
Я устал от того, что много работал.
```

**Объяснение:**
Для выражения причины нужно использовать исходный падеж -maktan, а не дательный -mek için.

## 7. Дополнительные примеры и практика

### 7.1 Пример: Полный разбор предложения

**Разберем предложение:**

```
Türkçe öğrenmek zor ama önemli.
Изучать турецкий трудно, но важно.
```

**Разбор:**
- `Türkçe öğrenmek` — изучать турецкий (инфинитив как подлежащее)
- `zor` — трудно (прилагательное оценки)
- `ama` — но (союз)
- `önemli` — важно (прилагательное оценки)

**Объяснение:**
В этом предложении инфинитив является подлежащим, а прилагательные выражают оценку действия.

### 7.2 Пример: Сравнение с формой -ma

**Сравнение:**

```
Türkçe öğrenmek zor. (-mak - абстрактно)
Изучать турецкий трудно (вообще).

Türkçe öğrenmeyi seviyorum. (-ma - конкретно)
Я люблю изучать турецкий (конкретное действие).
```

**Объяснение:**
-mak используется для абстрактных высказываний, а -ma — для конкретных действий.

### 7.3 Пример: Практические упражнения

**Упражнение 1: Составьте предложения с прилагательными**

```
Yüzmek → Yüzmek sağlıklı.
Плавать → Плавать полезно для здоровья.

Erken kalkmak → Erken kalkmak iyi.
Вставать рано → Вставать рано хорошо.

Sigara içmek → Sigara içmek kötü.
Курить → Курить плохо.
```

**Объяснение:**
Практикуйтесь в составлении предложений с инфинитивом и прилагательными оценки.

**Упражнение 2: Выразите причину**

```
Çok çalışmak → Çok çalışmaktan yoruldum.
Много работать → Я устал от того, что много работал.

Çok yemek → Çok yemekten kilo aldım.
Много есть → Я поправился от того, что много ел.
```

**Объяснение:**
Практикуйтесь в выражении причины с помощью -maktan.

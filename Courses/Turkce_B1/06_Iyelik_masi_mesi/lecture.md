## 1. Что такое притяжательная форма -ması / -mesi

Притяжательная форма -ması/-mesi указывает на то, чьё действие происходит. Она связывает действие с конкретным субъектом через притяжательные суффиксы.

### 1.1 Основная концепция

**Пример: Притяжательная форма**

```
Onun gelmesi önemli.
Его приход важен (буквально: его приход важен).
```

**Объяснение:**
-mesi указывает на то, что действие "приходить" принадлежит третьему лицу (onun - его). Притяжательный суффикс -si указывает на третье лицо единственного числа.

**Пример: Другой случай**

```
Ali'nin geç kalması beni kızdırdı.
Опоздание Али меня разозлило (буквально: Али опоздание меня разозлило).
```

**Объяснение:**
-ması указывает на то, что действие "опоздать" принадлежит Али. Притяжательный суффикс -sı указывает на третье лицо единственного числа.

---

## 2. Образование формы -ması / -mesi

### 2.1 Правило образования

**Формула:**
```
Основа глагола + -ma/-me + притяжательный суффикс
```

**Таблица притяжательных суффиксов:**

| Лицо | Суффикс | Пример |
|------|---------|--------|
| 1 лицо ед.ч. | -m | gelmem (мой приход) |
| 2 лицо ед.ч. | -n | gelmen (твой приход) |
| 3 лицо ед.ч. | -sı/-si | gelmesi (его/её приход) |
| 1 лицо мн.ч. | -mız/-miz | gelmemiz (наш приход) |
| 2 лицо мн.ч. | -nız/-niz | gelmeniz (ваш приход) |
| 3 лицо мн.ч. | -ları/-leri | gelmeleri (их приход) |

**Пример: Образование**

```
gelmek → gelme + -si = gelmesi (его приход)
çalışmak → çalışma + -sı = çalışması (его работа)
okumak → okuma + -sı = okuması (его чтение)
```

**Объяснение:**
Выбор между -ması и -mesi зависит от гармонии гласных. Притяжательный суффикс -sı/-si указывает на третье лицо единственного числа.

### 2.2 Процесс образования

**Шаги образования:**

1. Берем инфинитив глагола (например, gelmek)
2. Убираем суффикс -mak/-mek (остается основа gel-)
3. Добавляем -ma/-me (gelme)
4. Добавляем притяжательный суффикс (gelmesi)

**Пример: Детальный разбор**

```
Глагол: gelmek (приходить)
Шаг 1: Инфинитив - gelmek
Шаг 2: Основа - gel-
Шаг 3: Добавляем -me → gelme
Шаг 4: Добавляем притяжательный суффикс -si → gelmesi
Результат: Onun gelmesi önemli.
Его приход важен.
```

**Объяснение:**
Образование -ması/-mesi происходит в четыре этапа.

### 2.3 Таблица образования для всех лиц

**Таблица для глагола gelmek:**

| Лицо | Форма | Пример |
|------|-------|--------|
| 1 лицо ед.ч. | gelmem | Benim gelmem önemli |
| 2 лицо ед.ч. | gelmen | Senin gelmen önemli |
| 3 лицо ед.ч. | gelmesi | Onun gelmesi önemli |
| 1 лицо мн.ч. | gelmemiz | Bizim gelmemiz önemli |
| 2 лицо мн.ч. | gelmeniz | Sizin gelmeniz önemli |
| 3 лицо мн.ч. | gelmeleri | Onların gelmeleri önemli |

**Объяснение:**
Притяжательные формы могут использоваться для всех лиц и чисел.

## 3. Использование с субъектом

### 3.1 Указание субъекта

**Пример: С именем собственным**

```
Ali'nin gelmesi önemli.
Приход Али важен.
```

**Объяснение:**
Ali'nin указывает на субъект действия (Али), а -mesi указывает на то, что действие принадлежит третьему лицу.

**Пример: С местоимением**

```
Onun çalışması başarılı.
Его работа успешна.
```

**Объяснение:**
Onun указывает на субъект (он), а -ması указывает на то, что действие принадлежит третьему лицу.

### 3.2 Субъект в родительном падеже

**Правило:**
Субъект действия всегда стоит в родительном падеже (genitive case) с суффиксом -in/-ın/-un/-ün.

**Пример: С разными субъектами**

```
Benim gelmem önemli. (benim - мой)
Мой приход важен.

Senin çalışman güzel. (senin - твой)
Твоя работа хороша.

Onun okuması hızlı. (onun - его)
Его чтение быстрое.

Ali'nin geç kalması beni kızdırdı. (Ali'nin - Али)
Опоздание Али меня разозлило.
```

**Объяснение:**
Субъект всегда стоит в родительном падеже, независимо от лица.

### 3.3 Когда субъект обязателен

**Правило:**
При использовании -ması/-mesi субъект обязателен, так как форма указывает на конкретное лицо.

**Пример: Обязательность субъекта**

```
Onun gelmesi önemli. (правильно - есть субъект)
Его приход важен.

Gelmesi önemli. (неправильно - нет субъекта)
Приход важен.
```

**Объяснение:**
Без субъекта форма -ması/-mesi теряет смысл, так как неясно, чье действие имеется в виду.

## 4. Практические примеры

### 4.1 Пример: Разные лица

```
Benim gelmem önemli. (1 лицо)
Мой приход важен.

Senin çalışman güzel. (2 лицо)
Твоя работа хороша.

Onun okuması hızlı. (3 лицо)
Его чтение быстрое.

Bizim gelmemiz önemli. (1 лицо мн.ч.)
Наш приход важен.

Sizin çalışmanız güzel. (2 лицо мн.ч.)
Ваша работа хороша.

Onların okumaları hızlı. (3 лицо мн.ч.)
Их чтение быстрое.
```

**Объяснение:**
В этом примере показано использование притяжательных форм для всех лиц и чисел.

### 4.2 Пример: Реальные ситуации

**Пример: Разговор о действиях других**

```
Ali'nin geç kalması beni kızdırdı.
Опоздание Али меня разозлило.

Onun çalışması başarılı.
Его работа успешна.

Senin gelmen önemli.
Твой приход важен.
```

**Объяснение:**
-ması/-mesi используется в реальных ситуациях для выражения действий других людей.

**Пример: Разговор о важности действий**

```
Onun gelmesi önemli.
Его приход важен.

Ali'nin çalışması gerekli.
Работа Али необходима.

Senin okuman faydalı.
Твое чтение полезно.
```

**Объяснение:**
-ması/-mesi используется для выражения важности или необходимости действий.

### 4.3 Пример: Сложные предложения

```
Ali'nin geç kalması beni kızdırdı, ama onun çalışması başarılı.
Опоздание Али меня разозлило, но его работа успешна.

Onun gelmesi önemli, çünkü toplantı başlayacak.
Его приход важен, потому что начнется собрание.
```

**Объяснение:**
-ması/-mesi может использоваться в сложных предложениях для выражения различных аспектов действий.

-ması/-mesi часто используется с прилагательными для выражения оценки действий.

## 6. Отличие от формы -ma

### 6.1 -ma vs -ması

**Пример: Сравнение**

```
Çalışma önemli. (-ma без субъекта)
Работа важна (вообще).

Onun çalışması önemли. (-ması с субъектом)
Его работа важна (конкретно).
```

**Объяснение:**
-ma выражает действие без указания на конкретного субъекта, а -ması указывает на конкретного субъекта действия.

### 6.2 Когда использовать -ma, когда -ması

**Используйте -ma для:**
- Абстрактных действий
- Общих высказываний
- Без указания на конкретного субъекта

**Используйте -ması для:**
- Конкретных действий с субъектом
- Когда нужно указать, чье действие
- С притяжательными суффиксами

**Пример: Выбор формы**

```
Çalışma önemli. (-ma - абстрактно)
Работа важна (вообще).

Onun çalışması önemли. (-ması - конкретно)
Его работа важна (конкретно).
```

**Объяснение:**
Выбор формы зависит от того, нужно ли указывать конкретного субъекта действия.

---

## 6. Частые ошибки

### 6.1 Ошибка: Отсутствие субъекта

❌ **Неправильно:**

```
Gelmesi önemli. (неправильно - нет субъекта)
```

✅ **Правильно:**

```
Onun gelmesi önemli. (правильно - есть субъект)
Его приход важен.
```

**Объяснение:**
При использовании -ması/-mesi нужно указывать субъект действия (onun, Ali'nin и т.д.).

## 💡 Key Takeaways

- **Притяжательная форма**: -ması/-mesi указывает на субъект действия
- **Связь с субъектом**: Действие связывается с субъектом через притяжательные суффиксы
- **Отличие от -ma**: -ması указывает на конкретного субъекта, -ma - нет
- **Притяжательные суффиксы**: -m, -n, -sı/-si, -mız/-miz, -nız/-niz, -ları/-leri
- **Основа понимания**: Понимание -ması необходимо для всех именных форм с субъектом

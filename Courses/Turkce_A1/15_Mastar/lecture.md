## 1. Что такое инфинитив

Инфинитив в турецком языке - это словарная форма глагола, которая не изменяется по лицам, числам и временам. Это базовая форма глагола, которая используется в словарях и для образования различных конструкций.

### 1.1 Основная функция

Инфинитив используется для:

- Словарной формы глагола (как в словаре)
- Образования конструкций с модальными глаголами
- Использования глагола как существительного
- Выражения цели действия
- Образования сложных конструкций

**Пример: Базовое использование**

```

çalışmak [чалышмак] - работать
okumak [окумак] - читать
yemek [йемек] - есть
gelmek [гельмек] - приходить
```

**Объяснение:**
Инфинитив - это неизменяемая форма глагола, которая показывает основное значение действия без указания на лицо, время или число.

---

## 2. Образование инфинитива

### 2.1 Суффиксы инфинитива

**Суффиксы:**

- -mek/-mak (в зависимости от гармонии гласных)

**Таблица:**

| Последняя гласная основы | Суффикс | Пример |
|-------------------------|---------|--------|
| a, ı, o, u (твердые) | -mak | çalışmak |
| e, i, ö, ü (мягкие) | -mek | okumak |

**Пример: Базовое использование**

```

çalışmak [чалышмак] - работать (основа: çalış-)
okumak [окумак] - читать (основа: oku-)
yemek [йемек] - есть (основа: ye-)
gelmek [гельмек] - приходить (основа: gel-)
gitmek [гитмек] - идти (основа: git-)
```

**Объяснение:**
Выбор суффикса зависит от последней гласной основы глагола. Твердые гласные требуют -mak, мягкие - -mek.

### 2.2 Правило выбора суффикса

**Шаги выбора:**

1. Определить основу глагола (убрать личные окончания)
2. Определить последнюю гласную основы
3. Если гласная твердая (a, ı, o, u) → использовать -mak
4. Если гласная мягкая (e, i, ö, ü) → использовать -mek

**Пример: Процесс выбора**

```

Глагол: çalışıyorum (я работаю)
Основа: çalış- (последняя гласная "a" - твердая)
Результат: çalışmak (используется -mak)
```

**Объяснение:**
В основе "çalış-" последняя гласная "a" твердая, поэтому используется суффикс -mak.

### 3.1 Глаголы с твердыми гласными

**Пример: С -mak**

```

çalışmak [чалышмак] - работать
okumak [окумак] - читать

almak [алмак] - брать, покупать

**Объяснение:**
В этих глаголах последняя гласная основы твердая, поэтому используется суффикс -mak.

**Пример: Детальный разбор**

```

çalışmak:
- Основа: çalış-
- Последняя гласная: a (твердая)
- Суффикс: -mak
- Результат: çalışmak

okumak:
- Основа: oku-
- Последняя гласная: u (твердая)
- Суффикс: -mak
- Результат: okumak
```

### 3.2 Глаголы с мягкими гласными

**Пример: С -mek**

gelmek [гельмек] - приходить

yemek [йемек] - есть
istemek [истемек] - хотеть
sevmek [севмек] - любить
```

**Объяснение:**
В этих глаголах последняя гласная основы мягкая, поэтому используется суффикс -mek.

**Пример: Детальный разбор**

```

gelmek:
- Основа: gel-

- Суффикс: -mek
- Результат: gelmek

gitmek:
- Основа: git-
- Последняя гласная: i (мягкая)
- Суффикс: -mek
- Результат: gitmek
```

## 4. Инфинитив как существительное

### 4.1 Использование как подлежащее

Инфинитив может использоваться как существительное и быть подлежащим в предложении.

**Пример: Как подлежащее**

```

Çalışmak güzel. [Чалышмак гюзель] - Работать хорошо.
Okumak önemli. [Окумак ёнемли] - Читать важно.
Yemek yemek sağlıklı. [Йемек йемек саглыклы] - Есть еду полезно.
```

**Объяснение:**
Инфинитив может быть подлежащим в предложении, выполняя функцию существительного.

### 4.2 Использование как дополнение

**Пример: Как дополнение**

```

Ben çalışmayı seviyorum. [Бен чалышмайы севийорум] - Я люблю работать.
O okumayı tercih ediyor. [О окумайы терджих эдийор] - Он/Она предпочитает читать.
```

**Объяснение:**
Инфинитив может быть дополнением в предложении, особенно с глаголами предпочтения.

### 4.3 С прилагательными

**Пример: С прилагательными**

```

Çalışmak güzel. [Чалышмак гюзель] - Работать хорошо.
Okumak önemli. [Окумак ёнемли] - Читать важно.
Yüzmek sağlıklı. [Юзмек саглыклы] - Плавать полезно.
```

**Объяснение:**
Инфинитив может использоваться с прилагательными для выражения оценки действия.

## 5. Инфинитив в конструкциях

### 5.1 С модальными глаголами

Инфинитив широко используется с модальными глаголами для выражения различных значений.

**Пример: С istemek (хотеть)**

```

Kahve içmek istiyorum. [Кахве ичмек истийорум] - Я хочу пить кофе.
Evde kalmak istiyorum. [Эвде калмак истийорум] - Я хочу остаться дома.
```

**Объяснение:**
Инфинитив используется с глаголом "istemek" для выражения желания.

**Пример: С sevmek (любить)**

```

Kitap okumayı seviyorum. [Китап окумайы севийорум] - Я люблю читать книги.
Müzik dinlemeyi seviyorum. [Мюзик динлемейи севийорум] - Я люблю слушать музыку.
```

**Объяснение:**
Инфинитив в винительном падеже используется с глаголом "sevmek" для выражения предпочтений.

### 5.2 С глаголом gerek (нужно)

**Пример: С gerek**

```

Gitmem gerek. [Гитмем герек] - Мне нужно идти.
Çalışman gerek. [Чалышман герек] - Тебе нужно работать.
```

**Объяснение:**
Инфинитив с личными окончаниями используется с глаголом "gerek" для выражения необходимости.

## 6. Инфинитив в дательном падеже

### 6.1 Выражение цели

Инфинитив в дательном падеже (-maya/-meye) выражает цель действия.

**Пример: Цель действия**

```

Çalışmaya gidiyorum. [Чалышмайа гидийорум] - Я иду работать.
Okumaya geliyorum. [Окумайа гелийорум] - Я прихожу читать.
Yemeye gidiyorum. [Йемейе гидийорум] - Я иду есть.
```

**Объяснение:**
Инфинитив в дательном падеже показывает цель движения или действия.

### 6.2 Образование дательного падежа инфинитива

**Таблица:**

| Инфинитив | Дательный падеж | Пример |
|-----------|-----------------|--------|
| çalışmak | çalışmaya | Çalışmaya gidiyorum |
| okumak | okumaya | Okumaya geliyorum |
| yemek | yemeye | Yemeye gidiyorum |

**Объяснение:**
Дательный падеж инфинитива образуется заменой -mak/-mek на -maya/-meye.

## 7. Практические примеры

### 7.1 Пример: В словаре

**Пример: Словарная форма**

```

çalışmak - работать
okumak - читать
yemek - есть
gelmek - приходить
gitmek - идти
```

**Объяснение:**
В словарях глаголы приводятся в форме инфинитива, это стандартная форма для поиска.

### 7.2 Пример: В предложениях

**Пример: Разные использования**

```

Çalışmak güzel. [Чалышмак гюзель] - Работать хорошо.
Ben çalışmak istiyorum. [Бен чалышмак истийорум] - Я хочу работать.
Çalışmaya gidiyorum. [Чалышмайа гидийорум] - Я иду работать.
```

**Объяснение:**
Инфинитив может использоваться в разных функциях: как существительное, с модальными глаголами, в дательном падеже.

### 7.3 Пример: Диалог

**Диалог:**

```

A: Ne yapmak istiyorsun? [Не япмак истийорсун?] - Что ты хочешь делать?
B: Ben okumak istiyorum. [Бен окумак истийорум] - Я хочу читать.
A: Hangi kitabı okumak istiyorsun? [Ханги китабы окумак истийорсун?] - Какую книгу ты хочешь читать?
B: Bu kitabı okumak istiyorum. [Бу китабы окумак истийорум] - Я хочу читать эту книгу.
```

**Объяснение:**
В разговорах инфинитив используется для выражения желаний и планов.

## 9. Частые ошибки

### 9.1 Ошибка: Неправильный выбор суффикса

❌ **Неправильно:**

```

çalışmak → çalışmek (неправильный суффикс)
```

✅ **Правильно:**

```

çalışmak [чалышмак] - работать
```

**Why:** В основе "çalış-" последняя гласная "a" твердая, поэтому используется -mak, а не -mek.

### 9.2 Ошибка: Путаница с личными формами

❌ **Неправильно:**

```

Ben çalışıyorum (личная форма вместо инфинитива в конструкции)
```

✅ **Правильно:**

```

Ben çalışmak istiyorum. [Бен чалышмак истийорум] - Я хочу работать.
```

**Why:** В конструкциях с модальными глаголами используется инфинитив, а не личная форма глагола.

### 9.3 Ошибка: Неправильная гармония гласных

❌ **Неправильно:**

```

gelmak (неправильная гармония)
```

✅ **Правильно:**

```

gelmek [гельмек] - приходить
```

**Why:** В основе "gel-" последняя гласная "e" мягкая, поэтому используется -mek, а не -mak.

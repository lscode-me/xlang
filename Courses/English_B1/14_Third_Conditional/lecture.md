## 1. Введение в Third Conditional

Third Conditional (Условные предложения третьего типа) — это грамматическая конструкция, которая используется для описания **нереальных ситуаций в прошлом** и их воображаемых последствий. Мы говорим о том, что **не произошло**, но могло бы произойти при других обстоятельствах.

### 1.1 Основная идея Third Conditional

**Third Conditional отвечает на вопрос:** "Что было бы, если бы в прошлом всё сложилось иначе?"

```
If I had studied harder, I would have passed the exam.
Если бы я учился усерднее, я бы сдал экзамен.
(Реальность: я не учился усердно, и я не сдал экзамен)

If she had known about the party, she would have come.
Если бы она знала о вечеринке, она бы пришла.
(Реальность: она не знала и не пришла)
```

**Ключевой момент:** Мы говорим о прошлом, которое уже нельзя изменить. Third Conditional — это способ размышлять о том, как всё могло бы быть иначе.

### 1.2 Сравнение трёх типов условных предложений

| Тип | Время | Реальность | Пример |
|-----|-------|------------|--------|
| First | Настоящее → Будущее | Реальная возможность | If it rains, I will stay home. |
| Second | Настоящее/Будущее | Нереальная/маловероятная | If I won the lottery, I would buy a house. |
| **Third** | **Прошлое** | **Невозможная (уже не случилось)** | **If I had won the lottery, I would have bought a house.** |

### 1.3 Визуализация на временной линии

```
PAST ←─────────────────────── NOW ─────────────────────→ FUTURE
   │                           │
   │  ┌─────────────────────┐  │
   │  │ IF clause:          │  │
   │  │ Past Perfect        │  │
   │  │ (had + V3)          │  │
   │  └─────────────────────┘  │
   │           │               │
   │           ↓               │
   │  ┌─────────────────────┐  │
   │  │ RESULT clause:      │  │
   │  │ would have + V3     │  │
   │  │ (воображаемый       │  │
   │  │  результат)         │  │
   │  └─────────────────────┘  │
   │                           │
   X──────────────────────────────
   (момент, о котором мы размышляем — уже в прошлом)
```

**Важно:** Обе части предложения относятся к прошлому, которое уже невозможно изменить.

### 1.4 Эмоциональный аспект

Third Conditional часто используется для выражения:

- **Сожаления (regret):** "Если бы я только..."
- **Критики:** "Если бы ты сделал это правильно..."
- **Облегчения:** "К счастью, если бы я сел в тот поезд..."
- **Размышлений:** "Что было бы, если бы...?"

```
If I had known it was your birthday, I would have bought you a present.
Если бы я знал, что у тебя день рождения, я бы купил тебе подарок.
(сожаление)

If you had listened to me, you wouldn't have made that mistake.
Если бы ты меня послушал, ты бы не совершил эту ошибку.
(критика)
```

## 2. Структура Third Conditional

### 2.1 Основная формула

**Third Conditional состоит из двух частей:**

```
IF clause (условие)     +     RESULT clause (результат)
If + Past Perfect            would have + Past Participle (V3)
If + had + V3                would have + V3
```

**Полная формула:**

```
If + Subject + had + V3, Subject + would have + V3
```

**Примеры:**

```
If I had studied harder, I would have passed the exam.
Если бы я учился усерднее, я бы сдал экзамен.

If she had called me, I would have helped her.
Если бы она позвонила мне, я бы помог ей.

If they had arrived earlier, they would have met the manager.
Если бы они приехали раньше, они бы встретили менеджера.
```

### 2.2 Порядок частей предложения

Части Third Conditional можно менять местами:

**IF clause + RESULT clause (запятая нужна):**

```
If I had known, I would have told you.
Если бы я знал, я бы тебе сказал.
```

**RESULT clause + IF clause (запятая не нужна):**

```
I would have told you if I had known.
Я бы тебе сказал, если бы я знал.
```

**Правило пунктуации:**
- Если предложение начинается с IF clause — ставим запятую перед главной частью
- Если IF clause идёт в конце — запятая обычно не нужна

### 2.3 Таблица форм

**Утвердительная форма:**

| Subject | IF clause (Past Perfect) | RESULT clause (would have + V3) |
|---------|--------------------------|----------------------------------|
| I | If I had known... | ...I would have come. |
| You | If you had asked... | ...I would have helped. |
| He/She | If he had studied... | ...he would have passed. |
| We | If we had left earlier... | ...we would have arrived on time. |
| They | If they had told me... | ...I would have understood. |

### 2.4 Сокращённые формы

В разговорной речи часто используются сокращения:

**Сокращения в IF clause:**

| Полная форма | Сокращение |
|--------------|------------|
| If I had | If I'd |
| If you had | If you'd |
| If he had | If he'd |
| If she had | If she'd |
| If we had | If we'd |
| If they had | If they'd |

**Сокращения в RESULT clause:**

| Полная форма | Сокращение |
|--------------|------------|
| I would have | I'd have / I would've |
| You would have | You'd have / You would've |
| He would have | He'd have / He would've |
| She would have | She'd have / She would've |
| We would have | We'd have / We would've |
| They would have | They'd have / They would've |

**Примеры с сокращениями:**

```
If I'd known, I'd have told you.
Если бы я знал, я бы тебе сказал.

If she'd asked, I would've helped.
Если бы она попросила, я бы помог.

They'd have come if they'd known about the party.
Они бы пришли, если бы знали о вечеринке.
```

> **💡 Pro Tip:**  
> Обратите внимание: сокращение **'d** может означать и **had**, и **would**. Контекст помогает понять:
> - После IF → 'd = had (If I'd known = If I had known)
> - В главной части → 'd = would (I'd have told = I would have told)

## 3. Отрицательная форма

### 3.1 Отрицание в IF clause

Чтобы сделать условие отрицательным, используем **had not (hadn't) + V3**:

**Формула:**

```
If + Subject + had not (hadn't) + V3, Subject + would have + V3
```

**Примеры:**

```
If I hadn't missed the train, I would have arrived on time.
Если бы я не опоздал на поезд, я бы приехал вовремя.

If she hadn't forgotten her keys, she wouldn't have been locked out.
Если бы она не забыла ключи, она бы не оказалась за дверью.

If they hadn't helped us, we wouldn't have finished the project.
Если бы они нам не помогли, мы бы не закончили проект.
```

### 3.2 Отрицание в RESULT clause

Чтобы сделать результат отрицательным, используем **would not have (wouldn't have) + V3**:

**Формула:**

```
If + Subject + had + V3, Subject + would not have (wouldn't have) + V3
```

**Примеры:**

```
If I had known the truth, I wouldn't have trusted him.
Если бы я знал правду, я бы ему не доверял.

If she had listened to the advice, she wouldn't have made that mistake.
Если бы она послушала совет, она бы не совершила эту ошибку.

If we had taken a taxi, we wouldn't have been late.
Если бы мы взяли такси, мы бы не опоздали.
```

### 3.3 Двойное отрицание

В некоторых случаях обе части могут быть отрицательными:

```
If I hadn't seen it, I wouldn't have believed it.
Если бы я не увидел это, я бы не поверил.

If she hadn't been so rude, he wouldn't have left.
Если бы она не была такой грубой, он бы не ушёл.

If they hadn't warned us, we wouldn't have known about the danger.
Если бы они нас не предупредили, мы бы не знали об опасности.
```

## 4. Вопросительная форма

### 4.1 Общие вопросы (Yes/No questions)

Для образования общего вопроса инвертируем **would** и подлежащее в главной части:

**Формула:**

```
Would + Subject + have + V3 + if + Subject + had + V3?
```

**Примеры:**

```
Would you have helped me if I had asked?
Ты бы помог мне, если бы я попросил?
— Yes, I would have. / No, I wouldn't have.

Would she have come if she had known about the party?
Она бы пришла, если бы знала о вечеринке?
— Yes, she would have. / No, she wouldn't have.

Would they have believed us if we had told them the truth?
Они бы поверили нам, если бы мы сказали им правду?
— Yes, they would have. / No, they wouldn't have.
```

### 4.2 Специальные вопросы (Wh-questions)

**Формула:**

```
Wh-word + would + Subject + have + V3 + if + Subject + had + V3?
```

**Примеры:**

```
What would you have done if you had seen him?
Что бы ты сделал, если бы увидел его?

Where would she have gone if she had had more money?
Куда бы она поехала, если бы у неё было больше денег?

How would they have reacted if they had known the truth?
Как бы они отреагировали, если бы знали правду?

Why would he have left if everything had been fine?
Почему бы он ушёл, если бы всё было хорошо?

Who would have helped you if I hadn't been there?
Кто бы тебе помог, если бы меня там не было?
```

### 4.3 Краткие ответы

```
Would you have gone to the party if you had been invited?
— Yes, I would have. (Да, пошёл бы.)
— No, I wouldn't have. (Нет, не пошёл бы.)

Would she have passed the exam if she had studied harder?
— Yes, she would have. (Да, сдала бы.)
— No, she wouldn't have. (Нет, не сдала бы.)
```

## 5. Использование Third Conditional

### 5.1 Выражение сожаления (Regret)

Одно из главных использований Third Conditional — выражение сожаления о том, что произошло или не произошло в прошлом.

**Примеры:**

```
If I had studied medicine, I would have become a doctor.
Если бы я изучал медицину, я бы стал врачом.
(Сожаление о выборе профессии)

If I had saved more money, I would have bought that house.
Если бы я откладывал больше денег, я бы купил тот дом.
(Сожаление о финансовых решениях)

If I had been more careful, I wouldn't have broken my leg.
Если бы я был осторожнее, я бы не сломал ногу.
(Сожаление о неосторожности)

If we had left earlier, we wouldn't have missed the flight.
Если бы мы выехали раньше, мы бы не опоздали на рейс.
(Сожаление о планировании)
```

**Типичные фразы для выражения сожаления:**

```
If only I had known...
Если бы только я знал...

I wish I had studied harder.
Жаль, что я не учился усерднее.

If I had known then what I know now...
Если бы я тогда знал то, что знаю сейчас...
```

### 5.2 Критика прошлых действий (Criticism)

Third Conditional часто используется для критики чьих-либо действий в прошлом.

**Примеры:**

```
If you had listened to my advice, you wouldn't have lost all your money.
Если бы ты послушал мой совет, ты бы не потерял все свои деньги.

If he had checked the map, he wouldn't have got lost.
Если бы он посмотрел карту, он бы не заблудился.

If she had been more organized, she wouldn't have forgotten the meeting.
Если бы она была более организованной, она бы не забыла о встрече.

If they had followed the instructions, they wouldn't have broken the machine.
Если бы они следовали инструкциям, они бы не сломали машину.
```

### 5.3 Выражение облегчения (Relief)

Third Conditional может выражать облегчение о том, что что-то НЕ произошло.

**Примеры:**

```
If I had taken that flight, I would have been in the crash.
Если бы я сел на тот рейс, я бы попал в авиакатастрофу.
(К счастью, я не сел)

If she hadn't called the doctor, the situation would have been much worse.
Если бы она не позвонила врачу, ситуация была бы намного хуже.
(К счастью, она позвонила)

If we hadn't noticed the fire, the whole house would have burned down.
Если бы мы не заметили пожар, весь дом бы сгорел.
(К счастью, мы заметили)
```

### 5.4 Размышления о прошлом (Speculation)

Third Conditional используется для размышлений о том, как могла бы сложиться история.

**Примеры:**

```
If Columbus hadn't discovered America, what would have happened?
Если бы Колумб не открыл Америку, что бы произошло?

If the internet hadn't been invented, how would people have communicated?
Если бы не изобрели интернет, как бы люди общались?

If I had been born in a different country, my life would have been completely different.
Если бы я родился в другой стране, моя жизнь была бы совершенно другой.
```

### 5.5 Объяснение причин (Explaining reasons)

**Примеры:**

```
I would have called you if I had known your number.
Я бы позвонил тебе, если бы знал твой номер.
(Объяснение, почему не позвонил)

She would have come to the party if she hadn't been sick.
Она бы пришла на вечеринку, если бы не была больна.
(Объяснение отсутствия)

They would have won the match if their best player hadn't been injured.
Они бы выиграли матч, если бы их лучший игрок не был травмирован.
(Объяснение поражения)
```

## 6. Альтернативные модальные глаголы

### 6.1 Could have вместо would have

**Could have** используется, когда мы говорим о возможности или способности:

```
If I had had more time, I could have finished the project.
Если бы у меня было больше времени, я мог бы закончить проект.
(возможность)

If she had studied harder, she could have got a better grade.
Если бы она училась усерднее, она могла бы получить лучшую оценку.
(возможность)

If they had trained more, they could have won the championship.
Если бы они больше тренировались, они могли бы выиграть чемпионат.
(способность/возможность)
```

**Разница между would have и could have:**

| would have | could have |
|------------|------------|
| Определённый результат | Возможный результат |
| "Я бы точно сделал" | "Я мог бы сделать" |

```
If I had known, I would have helped. (Я бы точно помог)
If I had known, I could have helped. (Я мог бы помочь)
```

### 6.2 Might have вместо would have

**Might have** используется, когда результат менее определённый:

```
If I had applied for that job, I might have got it.
Если бы я подал заявку на ту работу, я, возможно, получил бы её.
(неуверенность в результате)

If she had gone to the party, she might have met someone interesting.
Если бы она пошла на вечеринку, она, возможно, встретила бы кого-то интересного.
(возможность, не уверенность)

If they had invested earlier, they might have become rich.
Если бы они инвестировали раньше, они, возможно, разбогатели бы.
(неопределённый результат)
```

### 6.3 Should have в условных предложениях

**Should have** редко используется в главной части Third Conditional, но может использоваться в IF clause:

```
If you should have any questions, let me know.
(более формальный вариант: If you have any questions...)
```

### 6.4 Сравнительная таблица модальных глаголов

| Модальный глагол | Значение | Пример |
|------------------|----------|--------|
| would have | определённый результат | I would have come. (Я бы пришёл) |
| could have | возможность/способность | I could have come. (Я мог бы прийти) |
| might have | вероятность | I might have come. (Я, возможно, пришёл бы) |

## 7. Third Conditional vs Second Conditional

### 7.1 Ключевые различия

| Аспект | Second Conditional | Third Conditional |
|--------|-------------------|-------------------|
| Время | Настоящее/Будущее | Прошлое |
| Реальность | Нереальная/маловероятная | Невозможная (прошлое) |
| IF clause | Past Simple | Past Perfect |
| RESULT clause | would + V1 | would have + V3 |

### 7.2 Сравнительные примеры

**Нереальная ситуация сейчас (Second Conditional):**

```
If I had more money, I would buy a new car.
Если бы у меня было больше денег, я бы купил новую машину.
(Сейчас у меня нет денег, но теоретически это возможно в будущем)
```

**Нереальная ситуация в прошлом (Third Conditional):**

```
If I had had more money, I would have bought a new car.
Если бы у меня было больше денег (тогда), я бы купил новую машину.
(В прошлом у меня не было денег, и я не купил машину — это уже не изменить)
```

### 7.3 Ещё примеры сравнения

**Second Conditional (гипотетическое настоящее/будущее):**

```
If I knew her number, I would call her.
Если бы я знал её номер, я бы ей позвонил.
(Я не знаю её номер сейчас)

If he spoke English, he would get a better job.
Если бы он говорил по-английски, он получил бы лучшую работу.
(Он не говорит по-английски)
```

**Third Conditional (нереальное прошлое):**

```
If I had known her number, I would have called her.
Если бы я знал её номер, я бы ей позвонил.
(Я не знал её номер тогда)

If he had spoken English, he would have got a better job.
Если бы он говорил по-английски, он получил бы лучшую работу.
(Он не говорил по-английски тогда)
```

### 7.4 Как выбрать правильный тип

**Задайте себе вопрос:** Это ситуация в прошлом, которую нельзя изменить?

- **Да** → Third Conditional
- **Нет (гипотетическое настоящее/будущее)** → Second Conditional

```
"Если бы я был богат..." (гипотеза о настоящем)
→ If I were rich, I would travel the world. (Second)

"Если бы я был богат тогда..." (о прошлом)
→ If I had been rich, I would have travelled the world. (Third)
```

## 8. Mixed Conditionals

### 8.1 Что такое Mixed Conditionals

Mixed Conditionals (смешанные условные предложения) — это комбинации разных типов условных предложений, когда время в IF clause и RESULT clause различается.

### 8.2 Тип 1: Прошлое условие → Настоящий результат

Когда действие в прошлом влияет на настоящее:

**Формула:**

```
If + Past Perfect (had + V3), Subject + would + V1
```

**Примеры:**

```
If I had studied medicine, I would be a doctor now.
Если бы я изучал медицину, я бы сейчас был врачом.
(Прошлое решение → настоящий результат)

If she had married him, she would be rich now.
Если бы она вышла за него замуж, она бы сейчас была богатой.

If we had moved to London, we would live there now.
Если бы мы переехали в Лондон, мы бы сейчас там жили.

If I had learned to drive, I wouldn't need to take the bus.
Если бы я научился водить, мне бы не нужно было ездить на автобусе.
```

### 8.3 Тип 2: Настоящее условие → Прошлый результат

Когда постоянная характеристика объясняет прошлое действие:

**Формула:**

```
If + Past Simple, Subject + would have + V3
```

**Примеры:**

```
If I spoke French, I would have understood the conversation.
Если бы я говорил по-французски, я бы понял тот разговор.
(Я не говорю по-французски — это постоянное свойство)

If she weren't so shy, she would have asked him out.
Если бы она не была такой застенчивой, она бы пригласила его на свидание.
(Она застенчивая — это её характеристика)

If he were more careful, he wouldn't have had the accident.
Если бы он был более осторожным, у него бы не было аварии.
(Он неосторожный человек по натуре)
```

### 8.4 Сравнение: Third vs Mixed

**Third Conditional (оба в прошлом):**

```
If I had studied medicine, I would have become a doctor.
Если бы я изучал медицину, я бы стал врачом.
(Тогда я стал бы врачом — акцент на прошлом результате)
```

**Mixed Conditional (прошлое → настоящее):**

```
If I had studied medicine, I would be a doctor now.
Если бы я изучал медицину, я бы сейчас был врачом.
(Сейчас я был бы врачом — акцент на настоящем результате)
```

## 10. Типичные ошибки

### 10.1 Ошибка: Использование would в IF clause

❌ **Неправильно:**

```
If I would have known, I would have told you.
If she would have studied, she would have passed.
```

✅ **Правильно:**

```
If I had known, I would have told you.
Если бы я знал, я бы тебе сказал.

If she had studied, she would have passed.
Если бы она училась, она бы сдала.
```

**Правило:** В IF clause Third Conditional используется Past Perfect (had + V3), НЕ would have!

### 10.2 Ошибка: Смешивание времён

❌ **Неправильно:**

```
If I knew, I would have told you. (mixed — но неправильный смысл)
If I had known, I will tell you.
If I had known, I would tell you. (если не Mixed Conditional)
```

✅ **Правильно:**

```
If I had known, I would have told you.
Если бы я знал, я бы тебе сказал.
```

### 10.3 Ошибка: Забыть have в результате

❌ **Неправильно:**

```
If I had studied, I would passed the exam.
If she had asked, I would helped.
```

✅ **Правильно:**

```
If I had studied, I would have passed the exam.
Если бы я учился, я бы сдал экзамен.

If she had asked, I would have helped.
Если бы она попросила, я бы помог.
```

### 10.4 Ошибка: Использование Past Simple вместо Past Perfect

❌ **Неправильно:**

```
If I knew about the party, I would have come.
If she called me, I would have helped her.
```

✅ **Правильно:**

```
If I had known about the party, I would have come.
Если бы я знал о вечеринке, я бы пришёл.

If she had called me, I would have helped her.
Если бы она позвонила мне, я бы помог ей.
```

### 10.5 Ошибка: Неправильное сокращение

❌ **Неправильно:**

```
I'd helped you if I'd known. (I'd helped = I had helped — неправильно в главной части)
```

✅ **Правильно:**

```
I'd have helped you if I'd known.
I would have helped you if I had known.
Я бы помог тебе, если бы знал.
```

**Помните:**
- В IF clause: 'd = had (If I'd known = If I had known)
- В RESULT clause: 'd = would (I'd have = I would have)

## 11. Практические контексты

### 11.1 Разговор о карьерных решениях

```
A: Do you ever regret your career choice?
B: Sometimes. If I had studied law, I would have become a lawyer.
   I might have earned more money.
A: But would you have been happier?
B: Probably not. If I had become a lawyer, I wouldn't have had time
   for my hobbies. I'm happy with my decision.

A: Ты когда-нибудь жалеешь о выборе карьеры?
B: Иногда. Если бы я изучал право, я бы стал юристом.
   Возможно, я заработал бы больше денег.
A: Но был бы ты счастливее?
B: Вероятно, нет. Если бы я стал юристом, у меня не было бы времени
   на хобби. Я доволен своим решением.
```

### 11.2 Обсуждение путешествия

```
A: How was your trip to Paris?
B: It was good, but it could have been better. If I had booked
   a better hotel, I would have slept more comfortably. And if I
   had learned some French before the trip, I would have been able
   to communicate better with the locals.
A: What would you have done differently?
B: If I had had more time, I would have visited more museums.
   And if I had known about the long queues at the Louvre, I would
   have bought tickets online in advance.

A: Как прошла твоя поездка в Париж?
B: Хорошо, но могло быть лучше. Если бы я забронировал
   лучший отель, я бы спал комфортнее. И если бы я
   выучил немного французского перед поездкой, я бы смог
   лучше общаться с местными.
A: Что бы ты сделал по-другому?
B: Если бы у меня было больше времени, я бы посетил больше музеев.
   И если бы я знал о длинных очередях в Лувр, я бы
   купил билеты онлайн заранее.
```

### 11.3 Размышления об отношениях

```
If I had been more patient, we wouldn't have argued so much.
Если бы я был более терпеливым, мы бы не ссорились так часто.

If she had told me how she felt, I would have understood.
Если бы она сказала мне, что чувствует, я бы понял.

If we had communicated better, our relationship would have worked out.
Если бы мы лучше общались, наши отношения бы сложились.
```

If the Roman Empire hadn't fallen, what would have happened to Europe?
Если бы Римская империя не пала, что бы произошло с Европой?

Если бы Эйнштейн не разработал теорию относительности, кто-то другой

## 💡 Key Takeaways

- **Структура:** If + Past Perfect (had + V3), would have + V3 — запомните обе части
- **Значение:** Нереальные условия в прошлом — то, что НЕ произошло, но могло бы
- **Использование:** Сожаления, критика, облегчение, исторические размышления
- **IF clause:** Используется Past Perfect (had + V3), НЕ would!
- **Сокращения:** If I'd known, I'd have told you ('d = had в IF clause, 'd = would в результате)
- **Альтернативы:** could have (возможность), might have (вероятность)
- **Mixed Conditionals:** Комбинация прошлого условия с настоящим результатом возможна
- **Отличие от Second:** Second = нереальное настоящее/будущее, Third = нереальное прошлое

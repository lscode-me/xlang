# Промпт для генерации грамматических вопросов RU→AV Quiz (Grammar)

Ты - эксперт по аварскому языку и создатель учебных материалов. Твоя задача - генерировать вопросы для теста на **грамматику** аварского языка.

## Формат вывода

Генерируй ТОЛЬКО JSONL (JSON Lines) - каждая строка = один валидный JSON объект.

## Структура каждого JSON объекта

```json
{"id":"<LEVEL>-<KEY>-<NUM>","question":"<Russian phrase>","options":["<Option 1>","<Option 2>","<Option 3>","<Option 4>"],"correct":<1-4>,"explanation":"<Explanation>","tags":["<tag1>","<tag2>"],"source":"llm"}
```

## Обязательные поля

- **id**: Уникальный идентификатор в формате `<LEVEL>-<KEY>-<NUM>`
  - Примеры: `A1-GRAM-0001`, `B1-CASES-0023`
  - LEVEL: A1, A2, B1, B2, или C1
  - KEY: Код темы (например, GRAM, CASES, CLASS)

- **question**: Фраза или предложение на русском языке.
  - Четко иллюстрирует определенное грамматическое правило (класс, падеж, время и т.д.).

- **options**: Массив из **ровно 4** вариантов перевода на аварский.
  - Все 4 варианта должны быть **одним и тем же предложением**, отличающимся ТОЛЬКО грамматической формой (суффиксом или классным показателем).
  - Используй корректную аварскую орфографию с "I".

- **correct**: Номер правильного варианта.

- **explanation**: Объяснение грамматики на русском.

## Темы для аварского языка (A1-C1)

1. **Грамматические классы**:
   - Мужской (в), Женский (й), Средний/Вещный (б), Множественное число (р).
   - Согласование глаголов, прилагательных и местоимений по классам.
2. **Падежная система**:
   - Именительный (основной), Эргативный (актив), Родительный, Дательный.
   - Местные падежи (серии: на, в, под, у и т.д.).
3. **Глагол**:
   - Времена (настоящее, прошедшее, будущее).
   - Наклонения (изъявительное, повелительное, вопросительное).
   - Причастия и деепричастия.
4. **Конструкции предложения**:
   - Эргативная конструкция (подлежащее в эргативе при переходном глаголе).
   - Аффективная конструкция (при глаголах чувственного восприятия).

## Правила качества

1. **Фокус на классах**: Аварский язык сильно опирается на классы. Тесты на согласование очень важны.
2. **Эргатив**: Важно проверять умение отличать именительный падеж от эргативного.
3. **Местные падежи**: Тесты на правильный выбор локативной серии.

## Примеры

### Пример A1 (Классное согласование):
```json
{"id":"A1-CLASS-0001","question":"Мальчик красивый","options":["Вас берцинав вуго","Вас берцинай йиго","Вас берцинаб буго","Вас берцинал руго"],"correct":1,"explanation":"Вас (мальчик) — мужской класс (в). Прилагательное 'берцинав' и связка 'вуго' должны иметь показатель 'в'.","tags":["grammar","class"],"source":"llm"}
```

### Пример A2 (Местные падежи):
```json
{"id":"A2-CASES-0010","question":"На столе (лежит)","options":["Столалда","Столалдаса","Столалде","Столалдухъ"],"correct":1,"explanation":"Столалда (на столе) — местный падеж (суперэссив). -лда указывает на нахождение 'на поверхности'.","tags":["grammar","cases","locative"],"source":"llm"}
```

Сгенерируй **N вопросов** с фокусом на **ГРАММАТИКУ** для уровня **LEVEL**.
Фокус: **[укажи тему]**
Начинай с номера **START_NUM**.

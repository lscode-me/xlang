## 1. Что такое форма -dik / -diği

Форма -dik/-diği превращает прошедшее действие в существительное, выражая значение "то, что..." или "то, что сделал/сделала...". Это ключевая форма для выражения прошедших действий как объектов мысли.

### 1.1 Основная концепция

**Пример: Прошедшее действие как объект**

```
Geldiğini biliyorum.
Я знаю, что он пришел (буквально: я знаю его приход).
```

**Объяснение:**
-diği выражает прошедшее действие "пришел" и превращает его в объект глагола "знать". Притяжательный суффикс -ği указывает на третье лицо единственного числа (onun - его).

**Пример: Другой случай**

```
Yaptığın işi beğendim.
Мне понравилась работа, которую ты сделал (буквально: твоя сделанная работа мне понравилась).
```

**Объяснение:**
-dığın выражает прошедшее действие "сделал" и связывает его с субъектом через притяжательный суффикс -ın (senin - твой).

## 2. Образование формы -dik / -diği

### 2.1 Правило образования

**Формула:**

```
Основа глагола + прошедшее время (-di/-dı/-du/-dü) + притяжательный суффикс
```

**Шаги образования:**

1. Берем основу глагола
2. Добавляем прошедшее время -di/-dı/-du/-dü (с учетом гармонии гласных)
3. Добавляем притяжательный суффикс (-ğim, -ğin, -ği, -ğimiz, -ğiniz, -ğleri)

**Пример: Процесс образования**

```
Глагол: gelmek (приходить)
Шаг 1: Основа - gel-
Шаг 2: Добавляем прошедшее время -di → geldi
Шаг 3: Добавляем притяжательный суффикс -ği → geldiği
Результат: Onun geldiğini biliyorum.
Я знаю, что он пришел.
```

**Объяснение:**
Образование -dik/-diği происходит в три этапа: основа → прошедшее время → притяжательный суффикс. Буква "k" в -dik меняется на "ğ" перед гласными.

### 2.2 Таблица форм для разных лиц

**Таблица образования:**

| Лицо | Форма | Пример |
|------|-------|--------|
| 1 лицо ед.ч. | -diğim/-dığım | geldiğim (мой приход) |
| 2 лицо ед.ч. | -diğin/-dığın | geldiğin (твой приход) |
| 3 лицо ед.ч. | -diği/-dığı | geldiği (его приход) |
| 1 лицо мн.ч. | -diğimiz/-dığımız | geldiğimiz (наш приход) |
| 2 лицо мн.ч. | -diğiniz/-dığınız | geldiğiniz (ваш приход) |
| 3 лицо мн.ч. | -dikleri/-dıkları | geldikleri (их приход) |

**Пример: Для разных лиц**

```
Benim geldiğimi biliyor. (1 лицо)
Он знает, что я пришел.

Senin geldiğini biliyor. (2 лицо)
Он знает, что ты пришел.

Onun geldiğini biliyor. (3 лицо)
Он знает, что он пришел.
```

**Объяснение:**
Форма меняется в зависимости от лица субъекта прошедшего действия. Притяжательный суффикс согласуется с лицом.

### 2.3 Изменение k → ğ

**Важное правило:**

Перед гласными буква "k" в -dik меняется на "ğ".

**Пример: Изменение**

```
geldi + -ği = geldiği (не geldiki)
yaptı + -ğı = yaptığı (не yaptıkı)
```

**Объяснение:**
Это правило гармонии гласных и фонетики турецкого языка. "k" смягчается до "ğ" перед гласными.

## 3. Значение "то, что..."

### 3.1 Выражение прошедшего факта

**Пример: Прошедший факт**

```
Ne yaptığını bilmiyorum.
Я не знаю, что он сделал (буквально: я не знаю его сделанное).
```

**Объяснение:**
-dığı выражает прошедшее действие "сделал" и превращает его в объект вопроса "что".

**Пример: Другой случай**

```
Buraya geldiğini duydum.
Я слышал, что он пришел сюда (буквально: я слышал его приход сюда).
```

**Объяснение:**
-diği выражает прошедшее действие "пришел" и превращает его в объект глагола "слышать".

### 3.2 С притяжательными суффиксами

**Пример: С разными лицами**

```
Yaptığın işi beğendim. (2 лицо)
Мне понравилась работа, которую ты сделал.

Yaptığım işi beğendiler. (1 лицо)
Им понравилась работа, которую я сделал.
```

**Объяснение:**
Притяжательный суффикс указывает на то, кто выполнил действие в прошлом.

## 4. Использование с глаголами

### 4.1 Глаголы знания и восприятия

**Пример: С глаголом bilmek (знать)**

```
Geldiğini biliyorum.
Я знаю, что он пришел.
```

**Объяснение:**
-diği используется после глагола bilmek для выражения знания о прошедшем действии.

**Пример: С глаголом duymak (слышать)**

```
Ne söylediğini duydum.
Я слышал, что он сказал.
```

**Объяснение:**
-diği используется после глагола duymak для выражения того, что было услышано.

**Пример: С глаголом görmek (видеть)**

```
Ne yaptığını gördüm.
Я видел, что он сделал.
```

**Объяснение:**
-dığı используется после глагола görmek для выражения того, что было увидено.

### 4.2 Другие глаголы

**Пример: С глаголом anlamak (понимать)**

```
Ne demek istediğini anlamadım.
Я не понял, что он хотел сказать.
```

**Объяснение:**
-diği используется после глагола anlamak для выражения понимания прошедшего действия.

**Пример: С глаголом beğenmek (нравиться)**

```
Yaptığın işi beğendim.
Мне понравилась работа, которую ты сделал.
```

**Объяснение:**
-dığın используется для выражения отношения к прошедшему действию другого лица.

## 6. Практические примеры

### 6.1 Пример: Разные контексты

```
Geldiğini biliyorum. (знать)
Я знаю, что он пришел.

Ne yaptığını anlamadım. (понимать)
Я не понял, что он сделал.

Yaptığın işi beğendim. (нравиться)
Мне понравилась работа, которую ты сделал.
```

**Объяснение:**
В этом примере показано использование -dik/-diği с разными глаголами для выражения прошедших действий как объектов.

### 6.2 Пример: Реальные ситуации

**Пример: Разговор о прошлом**

```
Geldiğini biliyorum.
Я знаю, что он пришел.

Ne yaptığını anlamadım.
Я не понял, что он сделал.

Yaptığın işi beğendim.
Мне понравилась работа, которую ты сделал.
```

**Объяснение:**
-dik/-diği используется в реальных ситуациях для обсуждения прошедших действий и событий.

**Пример: Разговор о работе**

```
Yaptığın işi beğendim.
Мне понравилась работа, которую ты сделал.

Çalıştığın projeyi gördüm.
Я видел проект, над которым ты работал.

Başardığın işi kutluyorum.
Я праздную работу, которую ты выполнил.
```

**Объяснение:**
-dik/-diği используется для выражения отношения к прошедшим действиям других.

### 6.3 Пример: Сложные предложения

```
Ne yaptığını bilmiyorum, ama geldiğini biliyorum.
Я не знаю, что он сделал, но знаю, что он пришел.

Geldiğini duydum, ancak ne yaptığını görmedim.
Я слышал, что он пришел, однако не видел, что он сделал.
```

**Объяснение:**
-dik/-diği может использоваться в сложных предложениях для выражения нескольких прошедших действий.

## 6. Отличие от других форм

### 6.1 -dik vs -ma

**Пример: Сравнение**

```
Gelmeni istiyorum. (-ma - будущее/настоящее действие)
Я хочу, чтобы ты пришел.

Geldiğini biliyorum. (-dik - прошедшее действие)
Я знаю, что ты пришел.
```

**Объяснение:**
-ma используется для будущих или настоящих действий, а -dik используется для прошедших действий.

### 6.2 -dik vs -miş

**Пример: Сравнение**

```
Geldiğini biliyorum. (-dik - уверенность)
Я знаю, что он пришел (я уверен).

Gelmiş. (-miş - информация от других)
Он пришел (я так узнал).
```

**Объяснение:**
-dik выражает уверенность в прошедшем действии, а -miş выражает информацию, полученную от других.

## 8. Частые ошибки

### 8.1 Ошибка: Смешение -dik и -ma

❌ **Неправильно:**

```
Dün gelmeni biliyorum. (неправильно для прошедшего)
Я знаю твой вчерашний приход.
```

✅ **Правильно:**

```
Dün geldiğini biliyorum. (правильно для прошедшего)
Я знаю, что он пришел вчера.
```

**Объяснение:**
Для прошедших действий нужно использовать -dik, а не -ma.

### 8.2 Ошибка: Неправильное изменение k → ğ

❌ **Неправильно:**

```
Geldiki biliyorum. (неправильно)
Я знаю, что он пришел.
```

✅ **Правильно:**

```
Geldiğini biliyorum. (правильно)
Я знаю, что он пришел.
```

**Объяснение:**
Перед гласными "k" в -dik меняется на "ğ".

### 8.3 Ошибка: Отсутствие притяжательного суффикса

❌ **Неправильно:**

```
Geldik biliyorum. (неправильно - нет притяжательного суффикса)
Я знаю приход.
```

✅ **Правильно:**

```
Geldiğini biliyorum. (правильно - есть притяжательный суффикс)
Я знаю, что он пришел.
```

**Объяснение:**
Для выражения прошедшего действия как объекта обязательно нужно использовать притяжательный суффикс с формой -dik/-diği.

### 8.4 Ошибка: Неправильная гармония гласных

❌ **Неправильно:**

```
Geldak biliyorum. (неправильно - неправильная гармония)
Я знаю, что он пришел.
```

✅ **Правильно:**

```
Geldiğini biliyorum. (правильно)
Я знаю, что он пришел.
```

**Объяснение:**
Нужно правильно выбирать суффикс -di/-dı/-du/-dü в зависимости от последней гласной основы глагола.

## 9. Дополнительные примеры и практика

### 9.1 Пример: Полный разбор предложения

**Разберем предложение:**

```
Geldiğini biliyorum.
Я знаю, что он пришел.
```

**Разбор:**
- `gel-` — приходить (основа глагола)
- `geldi` — пришел (прошедшее время)
- `geldiği` — его приход (прошедшее время с притяжательным суффиксом)
- `geldiğini` — его приход (винительный падеж)
- `biliyorum` — я знаю (основной глагол)

**Объяснение:**
В этом предложении "что он пришел" превращается в "его приход" (onun geldiği) с винительным падежом, который становится объектом глагола "знать".

### 9.2 Пример: Практические упражнения

**Упражнение 1: Образуйте форму -dik/-diği**

```
gelmek → geldiği (его приход)
yapmak → yaptığı (его делание)
çalışmak → çalıştığı (его работа)
```

**Объяснение:**
Практикуйтесь в образовании формы -dik/-diği от различных глаголов с притяжательными суффиксами.

**Упражнение 2: Составьте предложения**

```
Gelmek + bilmek → Geldiğini biliyorum.
Yapmak + görmek → Ne yaptığını gördüm.
Çalışmak + beğenmek → Çalıştığın işi beğendim.
```

**Объяснение:**
Практикуйтесь в составлении предложений с формой -dik/-diği для выражения прошедших действий как объектов.

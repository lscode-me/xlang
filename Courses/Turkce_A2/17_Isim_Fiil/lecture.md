## 1. Что такое именная форма глагола (-me/-ma)

Именная форма глагола (isim-fiil) -me/-ma превращает глагол в существительное, которое может принимать падежные окончания. Это аналог русского отглагольного существительного или инфинитива в винительном падеже.

Ключевое отличие от инфинитива: именная форма **может принимать падежные окончания**, в то время как инфинитив -mak/-mek используется ограниченно.

### 1.1 Основное значение

Форма -me/-ma называет действие как предмет, процесс.

**Example: Базовое использование**

```

Yüzmeyi seviyorum.
Я люблю плавать (люблю плавание).
```

**Объяснение:**

- "yüzmek" (плавать, инфинитив) → "yüzme" (плавание, процесс)
- "yüzmeyi" = винительный падеж от "yüzme"
- Глагол "sevmek" требует винительного падежа объекта

### 1.2 Когда использовать

**Use cases:**

- После глаголов, требующих объект: sevmek (любить), istemek (хотеть), başlamak (начинать)
- Для выражения действия как процесса или занятия
- С падежными окончаниями для уточнения отношения к действию
- Вместо инфинитива в большинстве контекстов

## 2. Образование формы -me/-ma

Образование следует принципу гармонии гласных.

### 2.1 Правило образования

**Формула: основа глагола + me/ma**

Выбор между -me и -ma зависит от последней гласной основы:

| Последняя гласная | Форма |
|-------------------|-------|
| e, i, ö, ü        | -me   |
| a, ı, o, u        | -ma   |

**Example: Гармония гласных**

```

gelmek (приходить) → gelme (приход, прихождение)
bakmak (смотреть) → bakma (смотрение, взгляд)
okumak (читать) → okuma (чтение)
görmek (видеть) → görme (видение, зрение)
yazmak (писать) → yazma (писание, письмо)
içmek (пить) → içme (питьё)
```

**Объяснение:**

- gel**me**k → последняя гласная "e" → gel + **me**
- bak**ma**k → последняя гласная "a" → bak + **ma**
- oku**ma**k → последняя гласная "u" → oku + **ma**
- gör**me**k → последняя гласная "ö" → gör + **me**

### 2.2 Базовая форма как существительное

**Example: Использование как существительное**

```

1. Yüzme sağlıklıdır.
   Плавание полезно для здоровья.

2. Okuma önemlidir.
   Чтение важно.

3. Koşma spordur.
   Бег — это спорт.

4. Yazma bir sanattır.
   Письмо — это искусство.
```

**Объяснение:**

- В этих примерах форма -me/-ma выступает как подлежащее
- Она функционирует как обычное существительное
- Можно использовать с прилагательными и связками

## 3. Именная форма с падежами

Именная форма может принимать любые падежные окончания, что делает её очень гибкой.

### 3.1 С винительным падежом (-yi/-yı/-yu/-yü)

Винительный падеж используется после глаголов, требующих прямого объекта.

**Example: Винительный падеж**

```

1. Yüzmeyi seviyorum.
   Я люблю плавать (плавание).

2. Okumayı tercih ediyorum.
   Я предпочитаю читать.

3. Dans etmeyi öğreniyorum.
   Я учусь танцевать.

4. Yemek yapmayı biliyorum.
   Я умею готовить.
```

**Объяснение:**

- yüzme + yi → yüzmeyi (плавание-винительный падеж)
- okuma + yı → okumayı (чтение-винительный падеж)
- Глаголы sevmek, tercih etmek, öğrenmek, bilmek требуют винительного падежа

### 3.2 С дательным падежом (-ye/-ya)

Дательный падеж показывает направление или цель.

**Example: Дательный падеж**

```

1. Kitap okumaya başladım.
   Я начал читать книгу.

2. Türkçe öğrenmeye devam ediyorum.
   Я продолжаю учить турецкий.

3. Spor yapmaya hazırım.
   Я готов заниматься спортом.

4. Çalışmaya gidiyorum.
   Я иду на работу (работать).
```

**Объяснение:**

- okuma + ya → okumaya (к чтению, для чтения)
- öğrenme + ye → öğrenmeye (к учению)
- Глаголы başlamak, devam etmek, hazır olmak требуют дательного падежа

### 3.3 С аблативом (-den/-dan)

Аблатив показывает исходную точку, причину или избегание.

**Example: Аблатив**

```

1. Yüzmeden korkuyorum.
   Я боюсь плавать.

2. Konuşmaktan sıkıldım.
   Я устал от разговоров.

3. Beklemeden bıktım.
   Я устал ждать.

4. Ders çalışmadan vazgeçtim.
   Я отказался от учёбы.
```

**Объяснение:**

- yüzme + den → yüzmeden (от плавания)
- konuşmak + tan → konuşmaktan (от говорения)
- Глаголы korkmak, sıkılmak, bıkmak, vazgeçmek требуют аблатива

### 3.4 С местным падежом (-de/-da)

Местный падеж показывает место или контекст действия.

**Example: Местный падеж**

```

1. Yüzmede iyiyim.
   Я хорош в плавании.

2. Koşmada başarılısın.
   Ты успешен в беге.

3. Türkçe öğrenmede zorlanıyorum.
   Мне трудно даётся изучение турецкого.
```

**Объяснение:**

- yüzme + de → yüzmede (в плавании)
- koşma + da → koşmada (в беге)
- Используется для описания навыков и способностей

## 4. Глаголы, требующие именную форму

Определённые глаголы требуют использования именной формы с конкретными падежами.

### 4.1 С sevmek (любить) — винительный падеж

**Example: Что вы любите делать**

```

1. Kitap okumayı severim.
   Я люблю читать книги.

2. Müzik dinlemeyi severim.
   Я люблю слушать музыку.

3. Film izlemeyi severim.
   Я люблю смотреть фильмы.

4. Yemek yapmayı severim.
   Я люблю готовить.
```

**Объяснение:**

- sevmek всегда требует винительного падежа (-yi/-yı/-yu/-yü)
- Схема: [действие]-yi sevmek

### 4.2 С istemek (хотеть) — винительный падеж

**Example: Что вы хотите делать**

```

1. Türkiye'ye gitmeyi istiyorum.
   Я хочу поехать в Турцию.

2. Türkçe öğrenmeyi istiyorum.
   Я хочу учить турецкий.

3. Bu işi bitirmeyi istiyorum.
   Я хочу закончить эту работу.

4. Seni görmeyi istiyorum.
   Я хочу увидеть тебя.
```

**Объяснение:**

- istemek также требует винительного падежа
- Более сильное желание, чем sevmek

### 4.3 С başlamak (начинать) — дательный падеж

**Example: Начало действия**

```

1. Ders çalışmaya başladım.
   Я начал учиться.

2. Kitap okumaya başladım.
   Я начал читать книгу.

3. Spor yapmaya başladım.
   Я начал заниматься спортом.

4. Türkçe konuşmaya başladım.
   Я начал говорить по-турецки.
```

**Объяснение:**

- başlamak требует дательного падежа (-ye/-ya)
- Показывает начало нового действия

### 4.4 С devam etmek (продолжать) — дательный падеж

**Example: Продолжение действия**

```

1. Çalışmaya devam ediyorum.
   Я продолжаю работать.

2. Beklemeye devam ediyorum.
   Я продолжаю ждать.

3. Türkçe öğrenmeye devam ediyorum.
   Я продолжаю учить турецкий.
```

**Объяснение:**

- devam etmek также требует дательного падежа
- Выражает продолжение уже начатого действия

## 5. С притяжательными окончаниями

Именная форма может принимать притяжательные окончания для указания, кто совершает действие.

### 5.1 Структура с притяжательными окончаниями

**Example: Чьё действие**

```

1. Gelmemin sebebi bu.
   Причина моего прихода — это.

2. Gitmeni istiyorum.
   Я хочу, чтобы ты пошёл.

3. Okumasını seviyorum.
   Я люблю, как он/она читает.

4. Çalışmamız gerekli.
   Наша работа необходима.
```

**Объяснение:**

- gelme + im → gelmem (моё прихождение) + родительный падеж -in → gelmemin
- gitme + in → gitmen (твоё уход) + винительный → gitmeni
- okuma + sı → okuması (его/её чтение) + винительный → okumasını
- Притяжательное окончание указывает, кто совершает действие

### 5.2 С падежными окончаниями

**Example: Комбинация притяжательных и падежных окончаний**

```

1. Senin gelmene çok sevindim.
   Я очень рад твоему приходу.

2. Onun gitmesine üzüldüm.
   Я огорчён его/её уходом.

3. Bizim kazanmamıza inanıyorum.
   Я верю в нашу победу.
```

**Объяснение:**

- Схема: притяжательное окончание + падежное окончание
- senin (твой) gelme + n + e (датив) → gelmene
- onun (его/её) gitme + si + ne (датив) → gitmesine

## 6. Отличие от инфинитива -mak/-mek

Важно понимать разницу между именной формой и инфинитивом.

### 6.1 Использование инфинитива

**Example: Инфинитив**

```

1. Yüzmek sağlıklıdır.
   Плавать полезно.

2. Kitap okumak faydalıdır.
   Читать книги полезно.
```

**Объяснение:**

- Инфинитив используется как подлежащее
- НЕ может принимать падежные окончания (кроме аблатива)
- Более абстрактное, общее значение

### 6.2 Использование именной формы

**Example: Именная форма**

```

1. Yüzmeyi seviyorum.
   Я люблю плавать.

2. Kitap okumayı seviyorum.
   Я люблю читать книги.
```

**Объяснение:**

- Именная форма используется как объект глагола
- МОЖЕТ принимать падежные окончания
- Более конкретное значение, связанное с действием

### 6.3 Когда можно использовать оба

**Example: Синонимичное использование**

```

1. Yüzmek/Yüzme sağlıklıdır.
   Плавать/Плавание полезно.

2. Okumak/Okuma önemlidir.
   Читать/Чтение важно.
```

**Объяснение:**

- В роли подлежащего можно использовать обе формы
- Значение почти одинаковое
- Инфинитив чуть более абстрактный

## 7. Распространённые конструкции

Существуют типичные конструкции с именной формой глагола.

### 7.1 Запреты с -me/-ma

Форма -me/-ma используется для создания запретов (императив 2 лица ед.ч.).

**Example: Запреты**

```

1. Gitme! = Не уходи!
   gel + me → gelme

2. Bakma! = Не смотри!
   bak + ma → bakma

3. Konuşma! = Не говори!
   konuş + ma → konuşma

4. Yeme! = Не ешь!
   ye + me → yeme
```

**Объяснение:**

- Это омонимичная форма (выглядит так же, но имеет другое значение)
- Используется только в повелительном наклонении
- Контекст определяет значение

### 7.2 С lazy (лень), zamanı (время для)

**Example: Идиоматические конструкции**

```

1. Ders çalışma zamanı.
   Время для учёбы.

2. Artık gitme zamanı.
   Уже время уходить.

3. Çalışmaya üşeniyorum.
   Мне лень работать.
```

## 8. Практические примеры

Давайте рассмотрим практическое применение в различных ситуациях.

### 8.1 О хобби и интересах

**Example: Рассказ о себе**

```

1. Ben yüzmeyi, koşmayı ve bisiklet sürmeyi severim.
   Я люблю плавать, бегать и кататься на велосипеде.

2. Müzik dinlemeyi ve dans etmeyi seviyorum.
   Я люблю слушать музыку и танцевать.

3. Arkadaşlarımla vakit geçirmeyi severim.
   Я люблю проводить время с друзьями.

4. Film izlemeyi ve kitap okumayı tercih ederim.
   Я предпочитаю смотреть фильмы и читать книги.
```

### 8.2 О планах и желаниях

**Example: Будущие планы**

```

1. İtalya'ya gitmeyi istiyorum.
   Я хочу поехать в Италию.

2. Yeni bir iş bulmayı planlıyorum.
   Я планирую найти новую работу.

3. İspanyolca öğrenmeyi düşünüyorum.
   Я думаю выучить испанский.

4. Kendi işimi kurmayı istiyorum.
   Я хочу открыть свой бизнес.
```

### 8.3 О страхах и проблемах

**Example: Что вас беспокоит**

```

1. Uçmaktan korkuyorum.
   Я боюсь летать.

2. Topluluk önünde konuşmaktan çekiniyorum.
   Я стесняюсь говорить перед публикой.

3. Erken kalkmakta zorlanıyorum.
   Мне трудно рано вставать.

4. Matematik öğrenmede problem yaşıyorum.
   У меня проблемы с изучением математики.
```

### 8.4 О способностях и навыках

**Example: Ваши умения**

```

1. Yemek yapmayı biliyorum.
   Я умею готовить.

2. Araba kullanmayı öğrendim.
   Я научился водить машину.

3. Gitarı çalmayı öğreniyorum.
   Я учусь играть на гитаре.

4. İyi yüzmeyi biliyorum.
   Я хорошо умею плавать.
```

## 📝 Key Takeaways

- **-me/-ma** образуется от основы глагола и превращает его в отглагольное существительное
- Выбор между -me и -ma зависит от гармонии гласных (e/i/ö/ü → -me; a/ı/o/u → -ma)
- Именная форма **может принимать падежные окончания**, в отличие от инфинитива
- Основные падежи: винительный (sevmek, istemek), дательный (başlamak, devam etmek), аблатив (korkmak)
- Глаголы требуют конкретных падежей: sevmek/istemek + -yi, başlamak/devam etmek + -ye
- Может принимать притяжательные окончания для указания субъекта действия
- Отличается от инфинитива -mak/-mek гибкостью в использовании
- Омонимична с формой запрета в императиве

## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | "This" — для одного предмета близко (это). |
| 2 | C | "Those" — для нескольких предметов далеко (те). |
| 3 | C | "These" (множ. число) + are: These are my books. |
| 4 | A | "This" (ед. число) + is: This book is interesting. |
| 5 | C | "These" — множественное число от "this". |
| 6 | A | Краткий ответ заменяет this/that на it: Yes, it is. |
| 7 | D | "What is this?" — вопрос с единственным числом. |
| 8 | B | Для предмета в руках (близко) используется "this". |
| 9 | D | "These" + are: These are my keys. |
| 10 | C | "That" — для одного предмета далеко: That is my car. |
| 11 | D | В ответе these/those заменяются на they: Yes, they are. |
| 12 | B | Для одного предмета рядом: How much is this? |
| 13 | C | "These" (множ. число) перед существительным во множ. числе: These cars. |
| 14 | B | По телефону представляемся с "this": This is Maria speaking. |
| 15 | C | "These" + aren't (множ. число): These aren't my keys. |
| 16 | C | Для предметов на столе перед вами (близко, множ.): These pens. |
| 17 | D | По телефону спрашиваем с "this" (близко) или "that" (на расстоянии): Is this/that John? |
| 18 | D | "Over there" указывает на расстояние — используем "that": That house over there. |
| 19 | C | Для одного предмета далеко: How much is that? |
| 20 | D | "Those" — множественное число от "that". |

## Scoring Guide

- 18-20 правильных ответов: Отлично! Вы полностью освоили материал.
- 15-17 правильных ответов: Хорошо! Повторите некоторые моменты.
- 10-14 правильных ответов: Неплохо, но нужно больше практики.
- Меньше 10 правильных ответов: Рекомендуется повторить лекцию.

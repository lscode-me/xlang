## 1. Что такое косвенная речь

Косвенная речь — это передача информации без прямой цитаты. В турецком языке косвенная речь выражается через именные формы глагола, а не через союзы "что" или "чтобы".

### 1.1 Основная концепция

**Пример: Косвенная речь**

```
Geleceğini söyledi.
Он сказал, что придет (буквально: он сказал его приход).
```

**Объяснение:**
Вместо прямой цитаты "Ben geleceğim" (Я приду) используется именная форма -eceği, которая превращает будущее действие в объект глагола "сказать".

**Пример: Другой случай**

```
Hasta olduğunu duydum.
Я слышал, что он заболел (буквально: я слышал его болезнь).
```

**Объяснение:**
Вместо прямой информации используется именная форма -duğu, которая превращает прошедшее действие в объект глагола "слышать".

---

## 2. Косвенная речь с прошедшим временем

### 2.1 Использование формы -dik

**Пример: Прошедшее действие**

```
Geldiğini söyledi.
Он сказал, что пришел.
```

**Объяснение:**
-diği используется для передачи прошедшего действия в косвенной речи.

**Пример: С разными глаголами**

```
Ne yaptığını anladım.
Я понял, что он сделал.

Buraya geldiğini duydum.
Я слышал, что он пришел сюда.

Başarılı olduğunu biliyorum.
Я знаю, что он стал успешным.
```

**Объяснение:**
-dik/-diği используется после различных глаголов для передачи прошедших действий в косвенной речи.

### 2.2 Передача информации от других

**Пример: Информация от других**

```
Ali'nin geldiğini söylediler.
Они сказали, что Али пришел.

Hasta olduğunu duydum.
Я слышал, что он заболел.

Geç kalacağını öğrendim.
Я узнал, что он опоздает.
```

**Объяснение:**
Косвенная речь используется для передачи информации, полученной от других людей.

## 3. Косвенная речь с будущим временем

### 3.1 Использование формы -ecek

**Пример: Будущее действие**

```
Geleceğini söyledi.
Он сказал, что придет.
```

**Объяснение:**
-eceği используется для передачи будущего действия в косвенной речи.

**Пример: С разными глаголами**

```
Ne yapacağını biliyorum.
Я знаю, что он сделает.

Gideceğini duydum.
Я слышал, что он поедет.

Başarılı olacağını umuyorum.
Я надеюсь, что он станет успешным.
```

**Объяснение:**
-ecek/-eceği используется после различных глаголов для передачи будущих действий в косвенной речи.

### 3.2 Планы и намерения

**Пример: Планы**

```
Yarın geleceğini söyledi.
Он сказал, что придет завтра.

Ne yapacağını planlıyor.
Он планирует, что сделает.

Gideceğini kararlaştırdık.
Мы решили, что поедем.
```

**Объяснение:**
Косвенная речь используется для передачи планов и намерений.

---

## 4. Косвенная речь с настоящим временем

### 4.1 Использование формы -yor

**Пример: Настоящее действие**

```
Çalıştığını söyledi.
Он сказал, что работает (буквально: он сказал его работу).
```

**Объяснение:**
Для настоящего времени в косвенной речи также используется форма -dik, но с глаголом в настоящем времени.

**Пример: Другой способ**

```
İstanbul'da yaşadığını biliyorum.
Я знаю, что он живет в Стамбуле.
```

**Объяснение:**
-dığı используется для передачи настоящего действия в косвенной речи.

## 5. Глаголы, используемые в косвенной речи

### 5.1 Глаголы передачи информации

**Пример: С глаголом söylemek (сказать)**

```
Geleceğini söyledi.
Он сказал, что придет.

Ne yaptığını söyledi.
Он сказал, что сделал.
```

**Объяснение:**
söylemek используется для передачи информации в косвенной речи.

**Пример: С глаголом demek (говорить)**

```
Gelmediğini dedi.
Он сказал, что не придет.

Başarılı olduğunu dedi.
Он сказал, что стал успешным.
```

**Объяснение:**
demek также используется для передачи информации в косвенной речи.

### 5.2 Глаголы восприятия

**Пример: С глаголом duymak (слышать)**

```
Hasta olduğunu duydum.
Я слышал, что он заболел.

Geldiğini duydum.
Я слышал, что он пришел.
```

**Объяснение:**
duymak используется для передачи услышанной информации.

**Пример: С глаголом görmek (видеть)**

```
Ne yaptığını gördüm.
Я видел, что он сделал.

Geldiğini gördüm.
Я видел, что он пришел.
```

**Объяснение:**
görmek используется для передачи увиденной информации.

### 5.3 Глаголы знания и понимания

**Пример: С глаголом bilmek (знать)**

```
Ne yaptığını biliyorum.
Я знаю, что он сделал.

Geleceğini biliyorum.
Я знаю, что он придет.
```

**Объяснение:**
bilmek используется для передачи известной информации.

**Пример: С глаголом anlamak (понимать)**

```
Ne demek istediğini anladım.
Я понял, что он хотел сказать.

Ne yaptığını anlamadım.
Я не понял, что он сделал.
```

**Объяснение:**
anlamak используется для передачи понимания информации.

## 6. Практические примеры

### 6.1 Пример: Разные времена

```
Geldiğini söyledi. (прошедшее)
Он сказал, что пришел.

Geleceğini söyledi. (будущее)
Он сказал, что придет.

Çalıştığını söyledi. (настоящее)
Он сказал, что работает.
```

**Объяснение:**
В этом примере показано использование косвенной речи для разных времен.

### 6.2 Пример: Сложные предложения

```
Ali'nin geldiğini söyledi, ama ben görmedim.
Он сказал, что Али пришел, но я не видел.

Ne yapacağını biliyorum, ama söylemedim.
Я знаю, что он сделает, но не сказал.
```

**Объяснение:**
Косвенная речь может использоваться в сложных предложениях.

## 7. Отличие от прямой речи

### 7.1 Прямая речь vs косвенная речь

**Пример: Прямая речь**

```
Ali: "Ben geleceğim."
Али: "Я приду."
```

**Пример: Косвенная речь**

```
Ali geleceğini söyledi.
Али сказал, что придет.
```

**Объяснение:**
В прямой речи используются кавычки и точная цитата. В косвенной речи используется именная форма глагола.

### 7.2 Преимущества косвенной речи

**Пример: Преимущества**

```
Ali'nin geleceğini söyledi. (косвенная речь - более естественно)
Он сказал, что Али придет.

Ali "Ben geleceğim" dedi. (прямая речь - менее естественно в письменной речи)
Али сказал: "Я приду."
```

**Объяснение:**
Косвенная речь более естественна в письменной речи и позволяет лучше интегрировать информацию в текст.

## 8. Частые ошибки

### 8.1 Ошибка: Смешение прямой и косвенной речи

❌ **Неправильно:**

```
Ali "Ben geleceğim" söyledi. (неправильно)
Али сказал "Я приду".
```

✅ **Правильно:**

```
Ali geleceğini söyledi. (правильно)
Али сказал, что придет.
```

**Объяснение:**
В турецком языке для косвенной речи нужно использовать именные формы, а не прямые цитаты с кавычками.

### 8.2 Ошибка: Неправильное использование времен

❌ **Неправильно:**

```
Dün geleceğini söyledi. (неправильно для прошедшего)
Он сказал вчера, что придет.
```

✅ **Правильно:**

```
Dün geldiğini söyledi. (правильно для прошедшего)
Он сказал вчера, что пришел.
```

**Объяснение:**
Для прошедших действий нужно использовать -dik, а не -ecek.

## 💡 Key Takeaways

- **Косвенная речь**: Передача информации без прямой цитаты через именные формы
- **Прошедшее время**: Используется -dik/-diği для прошедших действий
- **Будущее время**: Используется -ecek/-eceği для будущих действий
- **Глаголы передачи**: söylemek, demek, duymak, görmek, bilmek, anlamak
- **Основа понимания**: Понимание косвенной речи необходимо для уровня B1 и выше

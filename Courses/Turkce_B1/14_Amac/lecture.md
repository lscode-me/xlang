## 1. Выражение цели действия

### 1.1 Форма -mek için

**Пример: Цель с -mek için**

```
Türkçe öğrenmek için çalışıyorum.
Я учусь, чтобы выучить турецкий (буквально: для изучения турецкого я учусь).
```

**Объяснение:**
-mek için используется для выражения цели действия. için означает "для" или "чтобы". Цель выражается инфинитивом.

**Пример: Другой случай**

```
Para kazanmak için çalışıyorum.
Я работаю, чтобы заработать деньги.
```

**Объяснение:**
-mek için выражает цель работы — заработать деньги.

### 1.2 Форма -mesi için

**Пример: Цель с -mesi için**

```
Gelmen için seni aradım.
Я позвонил тебе, чтобы ты пришел (буквально: для твоего прихода я позвонил тебе).
```

**Объяснение:**
-mesi için используется для выражения цели действия другого лица. -mesi указывает на действие другого лица, а için означает "для" или "чтобы".

**Пример: Другой случай**

```
Ali'nin çalışması için ona yardım ettim.
Я помог Али, чтобы он работал (буквально: для работы Али я помог ему).
```

**Объяснение:**
-ması için выражает цель помощи — чтобы Али работал.

---

## 2. Сравнение форм

### 2.1 -mek için vs -mesi için

**Пример: Сравнение**

```
Türkçe öğrenmek için çalışıyorum. (-mek için - моя цель)
Я учусь, чтобы выучить турецкий (моя цель).

Gelmen için seni aradım. (-mesi için - цель другого)
Я позвонил тебе, чтобы ты пришел (цель для другого).
```

**Объяснение:**
-mek için используется для выражения собственной цели, а -mesi için — для выражения цели другого лица.

### 2.2 Когда использовать какую форму

**Используйте -mek için для:**
- Собственной цели
- Цели действия говорящего
- Абстрактной цели

**Используйте -mesi için для:**
- Цели другого лица
- Цели действия другого человека
- Конкретной цели с субъектом

## 3. Практические примеры

### 3.1 Пример: Разные формы

```
Para kazanmak için çalışıyorum. (-mek için)
Я работаю, чтобы заработать деньги.

Gelmen için seni aradım. (-mesi için)
Я позвонил тебе, чтобы ты пришел.

Başarılı olmak için çok çalışıyorum. (-mek için)
Я много работаю, чтобы стать успешным.
```

**Объяснение:**
В этом примере показано использование разных форм для выражения цели.

### 3.2 Пример: Реальные ситуации

**Пример: Разговор о работе**

```
Para kazanmak için çalışıyorum.
Я работаю, чтобы заработать деньги.

Başarılı olmak için çok çalışıyorum.
Я много работаю, чтобы стать успешным.

Ali'nin çalışması için ona yardım ettim.
Я помог Али, чтобы он работал.
```

**Объяснение:**
Формы цели используются в реальных ситуациях для выражения намерений и мотивов.

**Пример: Разговор о учебе**

```
Türkçe öğrenmek için çalışıyorum.
Я учусь, чтобы выучить турецкий.

İyi not almak için çok okuyorum.
Я много читаю, чтобы получить хорошие оценки.

Senin başarılı olman için sana yardım ediyorum.
Я помогаю тебе, чтобы ты стал успешным.
```

**Объяснение:**
Формы цели используются для выражения различных целей в учебе.

### 3.3 Пример: Сложные предложения

```
Türkçe öğrenmek için çalışıyorum, ama gelmen için seni aradım.
Я учусь, чтобы выучить турецкий, но позвонил тебе, чтобы ты пришел.

Para kazanmak için çalışıyorum, ama Ali'nin çalışması için ona yardım ettim.
Я работаю, чтобы заработать деньги, но помог Али, чтобы он работал.
```

**Объяснение:**
Формы цели могут использоваться в сложных предложениях с разными целями.

## 4. Дополнительные примеры

### 4.1 Пример: С разными глаголами

**Пример: С глаголом çalışmak**

```
Türkçe öğrenmek için çalışıyorum.
Я учусь, чтобы выучить турецкий.

Para kazanmak için çalışıyorum.
Я работаю, чтобы заработать деньги.

Başarılı olmak için çalışıyorum.
Я работаю, чтобы стать успешным.
```

**Объяснение:**
-mek için используется с различными глаголами для выражения разных целей.

**Пример: С глаголом aramak**

```
Gelmen için seni aradım.
Я позвонил тебе, чтобы ты пришел.

Bilmen için seni aradım.
Я позвонил тебе, чтобы ты знал.

Hazır olman için seni aradım.
Я позвонил тебе, чтобы ты был готов.
```

**Объяснение:**
-mesi için используется для выражения цели звонка.

### 4.2 Пример: С притяжательными суффиксами

**Пример: Для разных лиц**

```
Benim gelmem için seni aradım. (1 лицо)
Я позвонил тебе, чтобы я пришел.

Senin gelmen için seni aradım. (2 лицо)
Я позвонил тебе, чтобы ты пришел.

Onun gelmesi için seni aradım. (3 лицо)
Я позвонил тебе, чтобы он пришел.
```

**Объяснение:**
-mesi için может использоваться для разных лиц с соответствующими притяжательными суффиксами.

## 5. Частые ошибки

### 4.1 Ошибка: Смешение форм

❌ **Неправильно:**

```
Gelmen için çalışıyorum. (неправильно, если цель моя)
Я работаю, чтобы ты пришел.
```

✅ **Правильно:**

```
Para kazanmak için çalışıyorum. (правильно для моей цели)
Я работаю, чтобы заработать деньги.
```

**Объяснение:**
Для собственной цели нужно использовать -mek için, а не -mesi для.

### 5.2 Ошибка: Неправильный выбор формы

❌ **Неправильно:**

```
Türkçe öğrenmesi için çalışıyorum. (неправильно, если цель моя)
Я учусь, чтобы его изучение турецкого.
```

✅ **Правильно:**

```
Türkçe öğrenmek için çalışıyorum. (правильно для моей цели)
Я учусь, чтобы выучить турецкий.
```

**Объяснение:**
Для собственной цели нужно использовать -mek için, а не -mesi için.

### 5.3 Ошибка: Отсутствие için

❌ **Неправильно:**

```
Türkçe öğrenmek çalışıyorum. (неправильно - нет için)
Я учусь выучить турецкий.
```

✅ **Правильно:**

```
Türkçe öğrenmek için çalışıyorum. (правильно - есть için)
Я учусь, чтобы выучить турецкий.
```

**Объяснение:**
Для выражения цели обязательно нужно использовать için после формы -mek/-mesi.

### 5.4 Ошибка: Неправильная гармония гласных

❌ **Неправильно:**

```
Türkçe öğrenmak için çalışıyorum. (неправильно - неправильная гармония)
Я учусь, чтобы выучить турецкий.
```

✅ **Правильно:**

```
Türkçe öğrenmek için çalışıyorum. (правильно)
Я учусь, чтобы выучить турецкий.
```

**Объяснение:**
Нужно правильно выбирать суффикс -mak/-mek в зависимости от последней гласной основы глагола.

## 6. Дополнительные примеры и практика

### 6.1 Пример: Полный разбор предложения

**Разберем предложение:**

```
Türkçe öğrenmek için çalışıyorum.
Я учусь, чтобы выучить турецкий.
```

**Разбор:**
- `Türkçe` — турецкий (существительное)
- `öğren-` — учить (основа глагола)
- `öğrenmek` — учить (инфинитив)
- `öğrenmek için` — чтобы выучить (цель)
- `çalışıyorum` — я учусь (основной глагол)

**Объяснение:**
В этом предложении "чтобы выучить турецкий" выражается через инфинитив с для (Türkçe öğrenmek için), который указывает на цель действия "учиться".

### 6.2 Пример: Практические упражнения

**Упражнение 1: Выберите правильную форму**

```
Собственная цель → Türkçe öğrenmek için çalışıyorum (-mek için)
Цель другого → Gelmen için seni aradım (-mesi için)
```

**Объяснение:**
Выбор формы зависит от того, чья цель выражается.

**Упражнение 2: Составьте предложения**

```
Türkçe öğrenmek → Türkçe öğrenmek için çalışıyorum
Para kazanmak → Para kazanmak için çalışıyorum
Gelmen → Gelmen için seni aradım
```

**Объяснение:**
Практикуйтесь в составлении предложений с формами цели для различных ситуаций.

## 💡 Key Takeaways

- **-mek için**: Собственная цель действия
- **-mesi için**: Цель действия другого лица
- **Выбор формы**: Зависит от того, чья цель выражается
- **Для/чтобы**: için означает "для" или "чтобы"
- **Основа понимания**: Понимание цели действия необходимо для уровня B1

## 1. Выражение причины

### 1.1 Форма -diği için

**Пример: Причина с -diği için**

```
Hasta olduğu için gelmedi.
Он не пришел, потому что заболел (буквально: из-за его болезни он не пришел).
```

**Объяснение:**
-diği için используется для выражения конкретной причины прошедшего действия. Форма -diği указывает на прошедшее действие, а için означает "из-за" или "потому что".

**Пример: Другой случай**

```
Çok çalıştığı için yoruldu.
Он устал, потому что много работал.
```

**Объяснение:**
-diği için выражает причину усталости — много работы в прошлом.

### 1.2 Образование формы -diği için

**Правило образования:**

**Формула:**
```
Именная форма прошедшего -dik/-diği + için
```

**Шаги образования:**

1. Берем глагол в прошедшем времени
2. Образуем именную форму -dik/-diği с притяжательным суффиксом
3. Добавляем için

**Пример: Процесс образования**

```
Глагол: olmak (быть) → oldu (был)
Шаг 1: Прошедшее время - oldu
Шаг 2: Именная форма с притяжательным суффиксом - olduğu
Шаг 3: Добавляем için → olduğu için
Результат: Hasta olduğu için gelmedi.
Он не пришел, потому что заболел.
```

**Объяснение:**
Образование -diği için происходит в три этапа: прошедшее время → именная форма с притяжательным суффиксом → için.

**Пример: С разными глаголами**

```
Hasta olduğu için gelmedi. (olmak)
Он не пришел, потому что заболел.

Çok çalıştığı için yoruldu. (çalışmak)
Он устал, потому что много работал.

Geç kaldığı için özür diledi. (kalmak)
Он извинился, потому что опоздал.
```

**Объяснение:**
-diği için может использоваться с различными глаголами для выражения причин прошедших действий.

### 1.3 Форма -maktan dolayı

**Пример: Причина с -maktan dolayı**

```
Koşmaktan dolayı yoruldum.
Я устал из-за бега (буквально: из-за бега я устал).
```

**Объяснение:**
-maktan dolayı используется для выражения общей причины действия. dolayı означает "из-за" или "по причине".

**Пример: Другой случай**

```
Çok yemekten dolayı kilo aldım.
Я поправился из-за того, что много ел.
```

**Объяснение:**
-maktan dolayı выражает общую причину — много еды как привычка или общее действие.

### 1.4 Образование формы -maktan dolayı

**Правило образования:**

**Формула:**
```
Инфинитив -mak/-mek + исходный падеж -tan/-ten + dolayı
```

**Шаги образования:**

1. Берем инфинитив глагола (например, koşmak)
2. Добавляем исходный падеж -tan/-ten → koşmaktan
3. Добавляем dolayı → koşmaktan dolayı

**Пример: Процесс образования**

```
Глагол: koşmak (бегать)
Шаг 1: Инфинитив - koşmak
Шаг 2: Добавляем исходный падеж -tan → koşmaktan
Шаг 3: Добавляем dolayı → koşmaktan dolayı
Результат: Koşmaktan dolayı yoruldum.
Я устал из-за бега.
```

**Объяснение:**
Образование -maktan dolayı происходит в три этапа: инфинитив → исходный падеж → dolayı.

**Пример: С разными глаголами**

```
Koşmaktan dolayı yoruldum. (koşmak)
Я устал из-за бега.

Çok yemekten dolayı kilo aldım. (yemek)
Я поправился из-за того, что много ел.

Çok çalışmaktan dolayı başarılı oldum. (çalışmak)
Я стал успешным из-за того, что много работал.
```

**Объяснение:**
-maktan dolayı может использоваться с различными глаголами для выражения общих причин.

### 1.5 Форма -diğinden

**Пример: Причина с -diğinden**

```
Hasta olduğundan gelmedi.
Он не пришел, потому что заболел.
```

**Объяснение:**
-diğinden используется для выражения причины через исходный падеж. -den/-dan означает "из-за" или "от".

**Пример: Другой случай**

```
Geç kaldığından özür diledi.
Он извинился, потому что опоздал.
```

**Объяснение:**
-diğinden выражает причину извинения — опоздание.

### 1.6 Образование формы -diğinden

**Правило образования:**

**Формула:**
```
Именная форма прошедшего -dik/-diği + исходный падеж -den/-dan
```

**Шаги образования:**

1. Берем глагол в прошедшем времени
2. Образуем именную форму -dik/-diği с притяжательным суффиксом
3. Добавляем исходный падеж -den/-dan

**Пример: Процесс образования**

```
Глагол: olmak (быть) → oldu (был)
Шаг 1: Прошедшее время - oldu
Шаг 2: Именная форма с притяжательным суффиксом - olduğu
Шаг 3: Добавляем исходный падеж -dan → olduğundan
Результат: Hasta olduğundan gelmedi.
Он не пришел, потому что заболел.
```

**Объяснение:**
Образование -diğinden происходит в три этапа: прошедшее время → именная форма с притяжательным суффиксом → исходный падеж.

**Пример: С разными глаголами**

```
Hasta olduğundan gelmedi. (olmak)
Он не пришел, потому что заболел.

Geç kaldığından özür diledi. (kalmak)
Он извинился, потому что опоздал.

Çok çalıştığından yoruldu. (çalışmak)
Он устал, потому что много работал.
```

**Объяснение:**
-diğinden может использоваться с различными глаголами для выражения причин прошедших действий.

## 2. Сравнение форм

### 2.1 -diği için vs -maktan dolayı

**Пример: Сравнение**

```
Hasta olduğu için gelmedi. (-diği için - конкретная причина)
Он не пришел, потому что заболел (конкретное событие).

Çok çalışmaktan dolayı yoruldum. (-maktan dolayı - общая причина)
Я устал из-за того, что много работал (общая привычка).
```

**Объяснение:**
-diği için используется для конкретных причин в прошлом, а -maktan dolayı — для общих причин или привычек.

### 2.2 -diği için vs -diğinden

**Пример: Сравнение**

```
Hasta olduğu için gelmedi. (-diği için - более формально)
Он не пришел, потому что заболел.

Hasta olduğundan gelmedi. (-diğinden - менее формально)
Он не пришел, потому что заболел.
```

**Объяснение:**
-diği için более формально, а -diğinden более разговорно. Оба выражают одну и ту же причину.

## 3. Дополнительные примеры

### 3.1 Пример: С разными временами

**Пример: С настоящим временем**

```
Hasta olduğu için gelmiyor. (настоящее)
Он не приходит, потому что заболел.

Çok çalıştığı için yoruluyor. (настоящее)
Он устает, потому что много работает.
```

**Объяснение:**
Формы причины могут использоваться с разными временами основного глагола.

**Пример: С будущим временем**

```
Hasta olduğu için gelmeyecek. (будущее)
Он не придет, потому что заболел.

Çok çalıştığı için yorulacak. (будущее)
Он устанет, потому что много работает.
```

**Объяснение:**
Формы причины могут использоваться для выражения причин будущих действий.

### 3.2 Пример: С разными лицами

**Пример: Для разных лиц**

```
Ben hasta olduğum için gelmedim. (1 лицо)
Я не пришел, потому что заболел.

Sen çok çalıştığın için yoruldun. (2 лицо)
Ты устал, потому что много работал.

O geç kaldığı için özür diledi. (3 лицо)
Он извинился, потому что опоздал.
```

**Объяснение:**
Формы причины могут использоваться для разных лиц с соответствующими притяжательными суффиксами.

## 4. Практические примеры

### 4.1 Пример: Разные формы

```
Hasta olduğu için gelmedi. (-diği için)
Он не пришел, потому что заболел.

Koşmaktan dolayı yoruldum. (-maktan dolayı)
Я устал из-за бега.

Geç kaldığından özür diledi. (-diğinden)
Он извинился, потому что опоздал.
```

**Объяснение:**
В этом примере показано использование разных форм для выражения причины.

### 4.2 Пример: Реальные ситуации

**Пример: Разговор о работе**

```
Çok çalıştığı için yoruldu.
Он устал, потому что много работал.

Çok çalışmaktan dolayı başarılı oldu.
Он стал успешным из-за того, что много работал.

Geç kaldığından özür diledi.
Он извинился, потому что опоздал.
```

**Объяснение:**
Формы причины используются в реальных ситуациях для объяснения действий и их последствий.

**Пример: Разговор о здоровье**

```
Hasta olduğu için gelmedi.
Он не пришел, потому что заболел.

Çok yemekten dolayı kilo aldım.
Я поправился из-за того, что много ел.

Koşmaktan dolayı yoruldum.
Я устал из-за бега.
```

**Объяснение:**
Формы причины используются для объяснения физических состояний и их причин.

### 4.3 Пример: Сложные предложения

```
Çok çalıştığı için yoruldu, ama başarılı oldu.
Он устал, потому что много работал, но стал успешным.

Hasta olduğu için gelmedi, ama yarın gelecek.
Он не пришел, потому что заболел, но завтра придет.
```

**Объяснение:**
Формы причины могут использоваться в сложных предложениях для выражения различных аспектов.

## 5. Частые ошибки

### 5.1 Ошибка: Смешение форм

❌ **Неправильно:**

```
Çok çalışmaktan için yoruldum. (неправильно)
Я устал из-за того, что много работал.
```

✅ **Правильно:**

```
Çok çalıştığı için yoruldum. (правильно)
Я устал, потому что много работал.
```

**Объяснение:**
Нельзя смешивать -maktan и için. Нужно использовать либо -diği için, либо -maktan dolayı.

### 5.2 Ошибка: Неправильное использование -diği için

❌ **Неправильно:**

```
Çok çalışmak için yoruldum. (неправильно)
Я устал для того, чтобы много работать.
```

✅ **Правильно:**

```
Çok çalıştığı için yoruldum. (правильно)
Я устал, потому что много работал.
```

**Объяснение:**
Для выражения причины прошедшего действия нужно использовать -diği için, а не -mek için.

### 5.3 Ошибка: Неправильное использование -maktan dolayı

❌ **Неправильно:**

```
Hasta olmaktan dolayı gelmedi. (неправильно для конкретного события)
Он не пришел из-за того, что заболел.
```

✅ **Правильно:**

```
Hasta olduğu için gelmedi. (правильно для конкретного события)
Он не пришел, потому что заболел.
```

**Объяснение:**
Для конкретных причин прошедшего действия лучше использовать -diği için, а не -maktan dolayı.

## 6. Дополнительные примеры и практика

### 6.1 Пример: Полный разбор предложения

**Разберем предложение:**

```
Hasta olduğu için gelmedi.
Он не пришел, потому что заболел.
```

**Разбор:**
- `Hasta` — больной (прилагательное)
- `olduğu` — его бытие (именная форма прошедшего с притяжательным суффиксом)
- `için` — из-за/потому что (союз причины)
- `gelmedi` — он не пришел (основной глагол)

**Объяснение:**
В этом предложении "потому что заболел" выражается через именную форму прошедшего с союзом için.

### 6.2 Пример: Практические упражнения

**Упражнение 1: Выберите правильную форму**

```
Конкретная причина прошедшего → Hasta olduğu için gelmedi.
Общая причина → Çok çalışmaktan dolayı yoruldum.
Разговорная причина → Geç kaldığından özür diledi.
```

**Объяснение:**
Выбор формы зависит от типа причины и стиля речи.

**Упражнение 2: Составьте предложения**

```
Hasta olmak → Hasta olduğu için gelmedi.
Çok çalışmak → Çok çalıştığı için yoruldu.
Geç kalmak → Geç kaldığından özür diledi.
```

**Объяснение:**
Практикуйтесь в составлении предложений с формами причины.

## 💡 Key Takeaways

- **-diği için**: Конкретная причина прошедшего действия (формально)
- **-maktan dolayı**: Общая причина или привычка
- **-diğinden**: Причина через исходный падеж (разговорно)
- **Выбор формы**: Зависит от контекста и стиля речи
- **Основа понимания**: Понимание причинно-следственных связей необходимо для уровня B1

## 1. Что такое отрицание

Отрицание в турецком языке образуется с помощью частицы -me/-ma, которая вставляется между основой глагола и суффиксом времени. Это один из важнейших грамматических элементов, который позволяет выражать отрицательные значения.

### 1.1 Основное правило

**Формула отрицания:**
```

Основа глагола + -me/-ma + суффикс времени + личное окончание
```

**Пример: Базовое отрицание**

```

çalışmak (работать) → çalış-ma-mak (не работать)
çalışıyorum (я работаю) → çalışmıyorum (я не работаю)
```

**Объяснение:**
Частица -me/-ma вставляется между основой глагола и суффиксом времени (-yor).

### 1.2 Основная функция

Отрицание используется для:

- Выражения того, что действие не происходит
- Описания отсутствия действия
- Построения отрицательных вопросов
- Выражения отрицательных значений

**Пример: Разные использования**

```

Ben çalışmıyorum. [Бен чалышмыорум] - Я не работаю.
Sen okumuyorsun. [Сен окумуйорсун] - Ты не читаешь.
O gitmiyor. [О гитмийор] - Он/Она не идет.
```

**Объяснение:**
Отрицание позволяет выражать, что действие не происходит или не будет происходить.

## 2. Выбор частицы -me/-ma

### 2.1 Гармония гласных в отрицании

Выбор между -me и -ma зависит от последней гласной основы глагола.

**Таблица выбора:**

| Последняя гласная основы | Частица отрицания | Пример |
|-------------------------|-------------------|--------|
| a, ı, o, u (твердые) | -ma | çalışmak → çalışma- |
| e, i, ö, ü (мягкие) | -me | gelmek → gelme- |

**Пример: С твердыми гласными**

```

çalışmak (работать) → çalış-ma- (последняя гласная "ı" - твердая)
okumak (читать) → oku-ma- (последняя гласная "u" - твердая)
almak (брать) → al-ma- (последняя гласная "a" - твердая)
```

**Объяснение:**
Если последняя гласная основы твердая, используется -ma.

**Пример: С мягкими гласными**

```

yemek (есть) → ye-me- (последняя гласная "e" - мягкая)
gelmek (приходить) → gel-me- (последняя гласная "e" - мягкая)
gitmek (идти) → git-me- (последняя гласная "i" - мягкая)
```

**Объяснение:**
Если последняя гласная основы мягкая, используется -me.

### 2.2 Правило выбора

**Шаги выбора:**

1. Определить основу глагола
2. Определить последнюю гласную основы
3. Если гласная твердая (a, ı, o, u) → использовать -ma
4. Если гласная мягкая (e, i, ö, ü) → использовать -me

**Пример: Процесс выбора**

```

Глагол: çalışmak
Основа: çalış-
Последняя гласная: ı (твердая)
Частица отрицания: -ma
Результат: çalışma-
```

**Объяснение:**
В основе "çalış-" последняя гласная "ı" твердая, поэтому используется -ma.

## 3. Образование отрицательных форм

### 3.1 Структура образования

**Шаги:**

1. Берем основу глагола
2. Добавляем -me/-ma (с учетом гармонии)
3. Добавляем -yor (который изменяется на -mıyor/-miyor/-muyor/-müyor)
4. Добавляем личное окончание

**Пример: Процесс образования**

```

Глагол: çalışmak (работать)
Шаг 1: Основа - çalış-
Шаг 2: Добавляем -ma → çalışma-
Шаг 3: Добавляем -yor (изменяется на -mıyor) → çalışmıyor
Шаг 4: Добавляем личное окончание → çalışmıyorum (для "ben")
Результат: Ben çalışmıyorum. [Бен чалышмыорум] - Я не работаю.
```

**Объяснение:**
Образование отрицательной формы происходит в четыре этапа с учетом гармонии гласных.

### 3.2 Изменение -yor в отрицании

В отрицательных формах -yor изменяется:

- -ıyor → -mıyor
- -iyor → -miyor
- -uyor → -muyor
- -üyor → -müyor

**Пример: Изменение -yor**

```

çalışıyor → çalışmıyor (ıyor → mıyor)
okuyor → okumuyor (uyor → muyor)
yiyor → yemiyor (iyor → miyor)
görüyor → görmüyor (üyor → müyor)
```

**Объяснение:**
В отрицательных формах "y" в -yor заменяется на "m", и добавляется соответствующая гласная в зависимости от гармонии.

**Таблица изменений:**

| Утвердительная форма | Отрицательная форма | Пример |
|---------------------|---------------------|--------|
| -ıyor | -mıyor | çalışıyor → çalışmıyor |
| -iyor | -miyor | geliyor → gelmiyor |
| -uyor | -muyor | okuyor → okumuyor |
| -üyor | -müyor | görüyor → görmüyor |

## 4. Отрицательные формы для всех лиц

### 4.1 Таблица отрицательных форм

**Пример: Глагол "çalışmak" (работать)**

```

Ben çalışmıyorum. [Бен чалышмыорум] - Я не работаю.
Sen çalışmıyorsun. [Сен чалышмыорсун] - Ты не работаешь.
O çalışmıyor. [О чалышмыор] - Он/Она не работает.
Biz çalışmıyoruz. [Биз чалышмыоруз] - Мы не работаем.
Siz çalışmıyorsunuz. [Сиз чалышмыорсунуз] - Вы не работаете.
Onlar çalışmıyorlar. [Онлар чалышмыорлар] - Они не работают.
```

**Объяснение:**
В глаголе "çalışmak" последняя гласная "ı" твердая, поэтому используется -ma, которое превращается в -mıyor.

**Пример: Глагол "okumak" (читать)**

```

Ben okumuyorum. [Бен окумуйорум] - Я не читаю.
Sen okumuyorsun. [Сен окумуйорсун] - Ты не читаешь.
O okumuyor. [О окумуёр] - Он/Она не читает.
Biz okumuyoruz. [Биз окумуйоруз] - Мы не читаем.
Siz okumuyorsunuz. [Сиз окумуйорсунуз] - Вы не читаете.
Onlar okumuyorlar. [Онлар окумуйорлар] - Они не читают.
```

**Объяснение:**
В глаголе "okumak" последняя гласная "u" твердая, поэтому используется -ma, которое превращается в -muyor.

**Пример: Глагол "yemek" (есть)**

```

Ben yemiyorum. [Бен йемийорум] - Я не ем.
Sen yemiyorsun. [Сен йемийорсун] - Ты не ешь.
O yemiyor. [О йемиёр] - Он/Она не ест.
Biz yemiyoruz. [Биз йемийоруз] - Мы не едим.
Siz yemiyorsunuz. [Сиз йемийорсунуз] - Вы не едите.
Onlar yemiyorlar. [Онлар йемийорлар] - Они не едят.
```

**Объяснение:**
В глаголе "yemek" последняя гласная "e" мягкая, поэтому используется -me, которое превращается в -miyor.

**Пример: Глагол "gelmek" (приходить)**

```

Ben gelmiyorum. [Бен гельмийорум] - Я не прихожу.
Sen gelmiyorsun. [Сен гельмийорсун] - Ты не приходишь.
O gelmiyor. [О гельмийор] - Он/Она не приходит.
Biz gelmiyoruz. [Биз гельмийоруз] - Мы не приходим.
Siz gelmiyorsunuz. [Сиз гельмийорсунуз] - Вы не приходите.
Onlar gelmiyorlar. [Онлар гельмийорлар] - Они не приходят.
```

**Объяснение:**
В глаголе "gelmek" последняя гласная "e" мягкая, поэтому используется -me, которое превращается в -miyor.

## 5. Отрицательные предложения

### 5.1 Базовые отрицательные предложения

**Пример: Простые отрицательные предложения**

```

Ben kahve içmiyorum. [Бен кахве ичмийорум] - Я не пью кофе.
Sen kitap okumuyorsun. [Сен китап окумуйорсун] - Ты не читаешь книгу.
O televizyon izlemiyor. [О телевизьон излемийор] - Он/Она не смотрит телевизор.
Biz çalışmıyoruz. [Биз чалышмыоруз] - Мы не работаем.
Siz okuyorsunuz. [Сиз окуйорсунуз] - Вы читаете (утвердительное).
Onlar gelmiyorlar. [Онлар гельмийорлар] - Они не приходят.
```

**Объяснение:**
Порядок слов сохраняется: подлежащее + дополнение + отрицательное сказуемое.

### 5.2 Отрицательные предложения с обстоятельствами

**Пример: С обстоятельством времени**

```

Ben bugün çalışmıyorum. [Бен бугюн чалышмыорум] - Я сегодня не работаю.
Sen şimdi ne yapmıyorsun? [Сен шимди не япмыорсун?] - Что ты сейчас не делаешь?
O yarın gitmiyor. [О яран гитмийор] - Он/Она завтра не идет.
```

**Пример: С обстоятельством места**

```

Ben evde okumuyorum. [Бен эвде окумуйорум] - Я дома не читаю.
O okulda çalışmıyor. [О окулда чалышмыор] - Он/Она в школе не работает.
Biz parkta yürümüyoruz. [Биз паркта юрюмюйоруз] - Мы в парке не гуляем.
```

**Объяснение:**
Обстоятельства времени и места размещаются так же, как в утвердительных предложениях.

### 5.3 Сравнение утвердительных и отрицательных предложений

**Пример: Сравнение**

```

Утвердительное: Ben çalışıyorum. [Бен чалышыорум] - Я работаю.
Отрицательное: Ben çalışmıyorum. [Бен чалышмыорум] - Я не работаю.

Утвердительное: Sen okuyorsun. [Сен окуйорсун] - Ты читаешь.
Отрицательное: Sen okumuyorsun. [Сен окумуйорсун] - Ты не читаешь.
```

**Объяснение:**
Разница между утвердительными и отрицательными предложениями заключается в добавлении частицы -me/-ma и изменении -yor.

## 6. Отрицательные вопросы

### 6.1 Общие отрицательные вопросы

Для образования отрицательных вопросов используется вопросительная частица после отрицательного глагола.

**Пример: Общие отрицательные вопросы**

```

Sen çalışmıyor musun? [Сен чалышмыор мусун?] - Ты не работаешь?
O okumuyor mu? [О окумуёр му?] - Он/Она не читает?
Biz gitmiyor muyuz? [Биз гитмийор муйуз?] - Мы не идем?
Siz gelmiyor musunuz? [Сиз гельмийор мусунуз?] - Вы не приходите?
```

**Объяснение:**
Вопросительная частица выбирается в зависимости от последней гласной в отрицательной форме глагола.

### 6.2 Специальные отрицательные вопросы

**Пример: Вопросы с "ne"**

```

Sen ne yapmıyorsun? [Сен не япмыорсун?] - Что ты не делаешь?
O ne okumuyor? [О не окумуёр?] - Что он/она не читает?
Ne içmiyorsun? [Не ичмийорсун?] - Что ты не пьешь?
```

**Пример: Вопросы с "kim"**

```

Kim çalışmıyor? [Ким чалышмыор?] - Кто не работает?
Kim gelmiyor? [Ким гельмийор?] - Кто не приходит?
```

**Объяснение:**
В специальных отрицательных вопросах порядок слов сохраняется, глагол остается в отрицательной форме.

## 7. Особые случаи

### 7.1 Глаголы, оканчивающиеся на гласную

**Пример: Глаголы на гласную**

```

yemek (есть) → yemiyor (не ест)
demek (говорить) → demiyor (не говорит)
istemek (хотеть) → istemiyor (не хочет)
```

**Объяснение:**
Для глаголов, оканчивающихся на гласную, правила остаются теми же - выбирается -me или -ma в зависимости от последней гласной.

### 7.2 Глаголы с изменением основы

**Пример: Изменения в основе**

```

gitmek (идти) → gitmiyor (не идет) - изменение t → d не происходит в отрицании
etmek (делать) → etmiyor (не делает)
```

**Объяснение:**
В отрицательных формах изменения основы глагола могут не происходить или происходить по-другому, чем в утвердительных формах.

### 7.3 Глаголы с удвоением согласных

**Пример: С удвоением согласных**

```

almak (брать) → almıyor (не берет)
vermek (давать) → vermiyor (не дает)
```

**Объяснение:**
Некоторые глаголы могут иметь особенности в образовании отрицательных форм, но правило гармонии гласных сохраняется.

## 8. Практические примеры

### 8.1 Пример: Описание того, что не делается

**Текст:**

```

Ben şimdi çalışmıyorum. [Бен шимди чалышмыорум] - Я сейчас не работаю.
Sen ne yapmıyorsun? [Сен не япмыорсун?] - Что ты не делаешь?

Biz evde kalmıyoruz. [Биз эвде калмыоруз] - Мы не остаемся дома.
```

**Объяснение:**
Отрицательные предложения используются для описания действий, которые не происходят.

### 8.2 Пример: Диалог

**Диалог:**

```

A: Sen çalışmıyor musun? [Сен чалышмыор мусун?] - Ты не работаешь?
B: Hayır, ben çalışmıyorum. [Хайыр, бен чалышмыорум] - Нет, я не работаю.
A: Ne yapıyorsun? [Не япыйорсун?] - Что ты делаешь?
B: Ben kitap okuyorum. [Бен китап окуйорум] - Я читаю книгу.

A: O neden gitmiyor? [О неден гитмийор?] - Почему он/она не идет?
B: O yorgun, bu yüzden gitmiyor. [О йоргун, бу юзден гитмийор] - Он/Она устал, поэтому не идет.
```

**Объяснение:**
В разговорах отрицательные предложения используются для обсуждения того, что не происходит, и причин этого.

### 8.3 Пример: Сравнение утвердительных и отрицательных

**Пример: Параллельные предложения**

```

Утвердительное: Ben çalışıyorum. [Бен чалышыорум] - Я работаю.
Отрицательное: Ben çalışmıyorum. [Бен чалышмыорум] - Я не работаю.

Утвердительное: Sen okuyorsun. [Сен окуйорсун] - Ты читаешь.
Отрицательное: Sen okumuyorsun. [Сен окумуйорсун] - Ты не читаешь.

Утвердительное: O geliyor. [О гелийор] - Он/Она приходит.
Отрицательное: O gelmiyor. [О гельмийор] - Он/Она не приходит.
```

**Объяснение:**
Сравнение утвердительных и отрицательных форм помогает понять разницу в образовании.

## 9. Частые ошибки

### 9.1 Ошибка: Неправильный выбор -me/-ma

❌ **Неправильно:**
```

Ben çalışmiyorum. (неправильная частица)
```

✅ **Правильно:**
```

Ben çalışmıyorum. [Бен чалышмыорум] - Я не работаю.
```

**Why:** В глаголе "çalışmak" последняя гласная "ı" твердая, поэтому используется -ma (которое превращается в -mıyor), а не -me.

### 9.2 Ошибка: Неправильное изменение -yor

❌ **Неправильно:**
```

Ben çalışmayorum. (неправильное изменение -yor)
```

✅ **Правильно:**
```

Ben çalışmıyorum. [Бен чалышмыорум] - Я не работаю.
```

**Why:** В отрицании -ıyor изменяется на -mıyor (y заменяется на m, добавляется ı).

### 9.3 Ошибка: Забыть отрицание

❌ **Неправильно:**
```

Ben çalışıyorum. (утвердительная форма вместо отрицательной)
```

✅ **Правильно:**
```

Ben çalışmıyorum. [Бен чалышмыорум] - Я не работаю.
```

**Why:** Для отрицания обязательно нужно использовать частицу -me/-ma и правильное изменение -yor.

### 9.4 Ошибка: Неправильная гармония гласных

❌ **Неправильно:**
```

gelmak → gelmayor (неправильная гармония)
```

✅ **Правильно:**
```

gelmek → gelmiyor [гельмийор] - не приходит
```

**Why:** В глаголе "gelmek" последняя гласная "e" мягкая, поэтому используется -me, которое превращается в -miyor.

## 💡 Key Takeaways

- **Отрицание** образуется с помощью частицы **-me/-ma**, которая вставляется между основой и суффиксом времени

- **Выбор -me/-ma** зависит от последней гласной основы глагола (гармония гласных)

- **В отрицании -yor изменяется**: -ıyor → -mıyor, -iyor → -miyor, -uyor → -muyor, -üyor → -müyor

- **Порядок слов** в отрицательных предложениях такой же, как в утвердительных

- **Отрицательные вопросы** образуются добавлением вопросительной частицы после отрицательного глагола

- **Гармония гласных** критически важна при образовании отрицательных форм

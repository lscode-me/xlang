# Промпт для генерации грамматических вопросов RU→TR Quiz (Grammar)

Ты - эксперт по турецкому языку и создатель учебных материалов. Твоя задача - генерировать вопросы для теста на **грамматику** турецкого языка.

## Формат вывода

Генерируй ТОЛЬКО JSONL (JSON Lines) - каждая строка = один валидный JSON объект.

**НЕ ДОБАВЛЯЙ**:
- Никаких markdown блоков кода (```json)
- Никаких комментариев
- Никаких пояснений
- Только чистые JSONL строки

## Структура каждого JSON объекта

```json
{"id":"<LEVEL>-<KEY>-<NUM>","ru":"<Russian phrase>","tr":["<Option 1>","<Option 2>","<Option 3>","<Option 4>"],"correct":<1-4>,"explain_ru":"<Explanation>","tags":["<tag1>","<tag2>"],"source":"llm"}
```

## Обязательные поля

- **id**: Уникальный идентификатор в формате `<LEVEL>-<KEY>-<NUM>`
  - Примеры: `A1-GRAM-0001`, `A2-CASES-0023`, `B1-TENSE-0010`
  - LEVEL: A1, A2, или B1
  - KEY: Код темы (например, GRAM, CASES, TENSE, POSS) или номер набора (001)
  - NUM: четырёхзначный порядковый номер

- **ru**: Фраза или предложение на русском языке
  - Четко иллюстрирует определенное грамматическое правило (падеж, время, лицо и т.д.)
  - Примеры: "Я иду **в школу**" (направление), "Это **твоя** книга" (притяжательность)

- **tr**: Массив из **ровно 4** вариантов перевода на турецкий
  - **ВАЖНО**: Все 4 варианта должны быть **одним и тем же предложением**, отличающимся ТОЛЬКО грамматической формой.
  - Используй одну и ту же лексику (те же корни слов).
  - Меняй только суффиксы (падежи, притяжательные, времена, личные окончания).
  - Только **ОДИН** вариант - правильный перевод.
  - Остальные 3 - неправильные формы (другой падеж, другое время, другое лицо).
  - Варианты должны быть сами по себе грамматически возможными (реальные слова), но неверными по смыслу перевода.

- **correct**: Номер правильного варианта (1, 2, 3, или 4)
  - Индексация с 1.

- **explain_ru**: Объяснение грамматики на русском
  - Объясни, почему выбран именно этот суффикс/форма.
  - Укажи название падежа, времени или правила.
  - Пример: `"В школу (куда?) — дательный падеж (-a/-e). Okula gidiyorum."`
  - Пример: `"Вчера (когда?) — прошедшее время (-dı/-di). Geldim."`

## Опциональные поля

- **tags**: Массив строк (темы грамматики)
  - Примеры: `["grammar", "dative"]`, `["tenses", "past"]`, `["possessive"]`
  
- **source**: `"llm"`

## Требования по грамматике и уровням

### A1 (Базовая грамматика)
- **Падежи**: Местный (где?), Исходный (откуда?), Дательный (куда?), Винительный (кого/что?).
  - *Пример:* Evde (дома), Evden (из дома), Eve (домой), Evi (дом).
- **Настоящее время** (Şimdiki Zaman -iyor).
- **Повелительное наклонение** (Emir Kipi).
  - *Пример:* Gel (приди), Gelin (придите), Gelsin (пусть придет).
- **Личные аффиксы/Местоимения** (Я, Ты, Он...).
  - *Пример:* Ben doktorum, Sen doktorsun.
- **Притяжательные аффиксы** (Мой, Твой...).
  - *Пример:* Evim, Evin.
- **Вопросительная частица** (mı/mi/mu/mü).
- **Множественное число** (-lar/-ler).
- **Базовые послелоги** (ile - с).

### A2 (Элементарная грамматика)
- **Прошедшее определенное** (Geçmiş Zaman -dı/-di).
- **Прошедшее неопределенное** (Duyulan Geçmiş Zaman -mış/-miş).
- **Широкое время** (Geniş Zaman -ar/-er) и его **Отрицание** (-maz/-mez).
  - *Пример:* Yaparım (делаю), Yapmam (не делаю), Yapmaz (не делает).
- **Желательное наклонение** (İstek Kipi -ayım/-alım).
  - *Пример:* Yapayım (давай я сделаю), Gidelim (давайте пойдем).
- **Будущее время** (Gelecek Zaman -acak/-ecek).
- **Модальность** (istiyorum - хочу, -abil/-ebil - мочь).
- **Степени сравнения** (daha, en).
- **Изафет** (одноаффиксный и двухаффиксный).
- **Изафетные цепочки** (Zincirleme Ad Tamlaması).
- **Местоимения и квантификаторы**: Hiçbir (никой), Herkes (все), Kimse (никто), Bazı (некоторые).
- **Послелоги**: İçin (для), Gibi (как), Kadar (до/как), Göre (по мнению/согласно).

### B1 (Средняя грамматика)
- **Модальность (продвинутая)**: -malı/-meli (должен), lazım/gerek.
- **Обязательство/Вынужденность**:
  - **Zorunda** (olmak/kalmak): *Gitmek zorundayım* (я вынужден идти).
  - **Mecburiyetinde**: *Yapmak mecburiyetindeyim*.
- **Залоги глагола** (Voice):
  - **Страдательный** (Edilgen -il/-in): *Yazıldı* (было написано).
  - **Возвратный** (Dönüşlü -in): *Yıkandı* (помылся).
  - **Взаимный** (İşteş -ış): *Tanıştık* (познакомились).
  - **Понудительный** (Ettirgen -dir/-t): *Yaptırdım* (заставил сделать / поручил).
- **Условное наклонение** (Şart -sa/-se) и Реальный условный (-sa ... yapar).
- **Деепричастия и формы глагола**:
  - **-ken** (когда/в то время как): *Okula giderken* (по дороге в школу).
  - **-ip** (последовательность действий).
  - **-arak/-erek** (инструментальное/образ действия).
  - **-dıkça** (по мере того как).
- **Управление глаголов (Инфинитивы с падежами)**:
  - **-maya/-meye** (направленность): *Yapmaya başladım* (начал делать).
  - **-mekten/-maktan** (исход): *Konuşmaktan korkuyor* (боится говорить).
  - **-mek** (винительный/объект): *Yüzmeyi seviyorum* (люблю плавать).

## Инструкция

Сгенерируй **N вопросов** с фокусом на **ГРАММАТИКУ** для уровня **LEVEL**.

Используй набор/тему **KEY** (например "CASES" или "001").

Фокус: **[укажи конкретную грамматическую тему, например: Падежи]**

Начинай с номера **START_NUM**.

Помни: Варианты ответа должны отличаться **только грамматической формой**!

## 1. Что такое множественное число

Множественное число в турецком языке показывает, что речь идет о нескольких предметах, людях или явлениях. Это одна из базовых грамматических категорий, которую необходимо освоить на начальном этапе изучения турецкого языка.

### 1.1 Основная функция

Множественное число используется для:

- Указания на несколько предметов
- Говорения о группе людей
- Описания множественных явлений
- Выражения обобщений

**Пример: Базовое использование**

```

kitap → kitaplar [китаплар] - книга → книги
öğrenci → öğrenciler [ёренджилер] - студент → студенты
ev → evler [эвлер] - дом → дома
```

**Объяснение:**
Множественное число показывает, что речь идет не об одном предмете, а о нескольких.

---

## 2. Образование множественного числа

### 2.1 Базовое правило

Множественное число в турецком языке образуется добавлением суффикса -ler или -lar к существительному.

**Формула:**
```

Существительное + -ler/-lar
```

**Выбор суффикса:**

- -ler — после мягких гласных (e, i, ö, ü)
- -lar — после твердых гласных (a, ı, o, u)

**Пример: С мягкими гласными**

```

öğrenci → öğrenciler [ёренджилер] - студенты
ev → evler [эвлер] - дома
şehir → şehirler [шехирлер] - города
```

**Объяснение:**
Выбор между -ler и -lar зависит от последней гласной существительного. Это правило гармонии гласных.

### 2.2 Правило гармонии гласных

**Таблица выбора:**

| Последняя гласная | Суффикс | Пример |
|------------------|---------|--------|
| a, ı, o, u (твердые) | -lar | kitap → kitaplar |
| e, i, ö, ü (мягкие) | -ler | ev → evler |

**Пример: Правило в действии**

```

kitap (последняя гласная "a" - твердая) → kitaplar
okul (последняя гласная "u" - твердая) → okullar
öğrenci (последняя гласная "i" - мягкая) → öğrenciler
ev (последняя гласная "e" - мягкая) → evler
```

**Объяснение:**
Гармония гласных - это ключевое правило турецкого языка. Все гласные в слове должны быть одного типа (твердые или мягкие).

## 3. Примеры образования

### 3.1 Существительные с твердыми гласными

**Пример: С -lar**

```

kitap → kitaplar [китаплар] - книги
okul → okullar [окуллар] - школы
kapı → kapılar [капылар] - двери
masa → masalar [масалар] - столы
araba → arabalar [арабалар] - машины
```

**Объяснение:**
В словах "kitap", "okul", "kapı", "masa", "araba" последние гласные (a, u, ı, a, a) твердые, поэтому используется -lar.

### 3.2 Существительные с мягкими гласными

**Пример: С -ler**

```

öğrenci → öğrenciler [ёренджилер] - студенты
ev → evler [эвлер] - дома
şehir → şehirler [шехирлер] - города
kalem → kalemler [калемлер] - ручки
gül → güller [гюллер] - розы
```

**Объяснение:**
В словах "öğrenci", "ev", "şehir", "kalem", "gül" последние гласные (i, e, i, e, ü) мягкие, поэтому используется -ler.

### 3.3 Слова, оканчивающиеся на согласную

**Пример: С согласной**

```

kalem → kalemler [калемлер] - ручки (последняя гласная "e" - мягкая)
masa → masalar [масалар] - столы (последняя гласная "a" - твердая)
kitap → kitaplar [китаплар] - книги (последняя гласная "a" - твердая)
```

**Объяснение:**
Для слов, оканчивающихся на согласную, выбор -ler/-lar зависит от последней гласной слова, а не от согласной.

### 3.4 Слова, оканчивающиеся на гласную

**Пример: С гласной**

```

anne → anneler [аннелер] - мамы (последняя гласная "e" - мягкая)
baba → babalar [бабалар] - папы (последняя гласная "a" - твердая)
öğretmen → öğretmenler [ёретменлер] - учителя (последняя гласная "e" - мягкая)
```

**Объяснение:**
Для слов, оканчивающихся на гласную, правило остается тем же - выбор зависит от последней гласной.

## 4. Использование в предложениях

### 4.1 Множественное число как подлежащее

**Пример: В предложениях**

```

Kitaplar masada. [Китаплар масада] - Книги на столе.
Öğrenciler okulda. [Ёренджилер окулда] - Студенты в школе.
Evler büyük. [Эвлер буюк] - Дома большие.
Arabalar hızlı. [Арабалар хызлы] - Машины быстрые.
```

**Объяснение:**
Множественное число используется так же, как единственное, но указывает на несколько предметов.

### 4.2 С указательными местоимениями

**Пример: С указательными местоимениями**

```

Bu kitaplar. [Бу китаплар] - Эти книги.
Şu evler. [Шу эвлер] - Те дома.
O öğrenciler. [О ёренджилер] - Те студенты.
Bunlar güzel. [Бунлар гюзель] - Эти красивые.
```

**Объяснение:**
Указательные местоимения во множественном числе (bunlar, şunlar, onlar) используются с существительными во множественном числе.

### 4.3 С прилагательными

**Пример: С прилагательными**

```

Büyük evler. [Буюк эвлер] - Большие дома.
Güzel kitaplar. [Гюзель китаплар] - Красивые книги.
Yeni arabalar. [Йени арабалар] - Новые машины.
```

**Объяснение:**
Прилагательные не изменяются во множественном числе, они остаются в той же форме.

---

## 5. Особые случаи

### 5.1 Слова с особыми окончаниями

**Пример: Слова на -lık/-lik**

```

arkadaşlık → arkadaşlıklar [аркадашлыклар] - дружбы
öğrencilik → öğrencilikler [ёренджиликлер] - студенчества
```

**Объяснение:**
Для сложных слов правило гармонии гласных применяется к последней гласной всего слова.

### 5.2 Заимствованные слова

**Пример: Заимствованные слова**

```

telefon → telefonlar [телефонлар] - телефоны
radyo → radyolar [радьолар] - радио
```

**Объяснение:**
Заимствованные слова также подчиняются правилу гармонии гласных при образовании множественного числа.

### 5.3 Слова, которые не изменяются

**Пример: Некоторые слова**

```

insan → insanlar [инсанлар] - люди (не "insanler")
```

**Объяснение:**
Некоторые слова могут иметь особенности в образовании множественного числа, но правило гармонии гласных обычно сохраняется.

## 6. Практические примеры

### 6.1 Пример: Описание класса

**Текст:**

```

Bu bir sınıf. [Бу бир сыныф] - Это класс.
Sınıfta öğrenciler var. [Сыныфта ёренджилер вар] - В классе есть студенты.
Öğrenciler masalarda oturuyor. [Ёренджилер масаларда отуруёр] - Студенты сидят за столами.
Kitaplar masalarda. [Китаплар масаларда] - Книги на столах.
```

**Объяснение:**
В описании класса множественное число используется для указания на несколько предметов и людей.

### 6.2 Пример: В магазине

**Диалог:**

```

A: Bu kitaplar ne kadar? [Бу китаплар не кадар?] - Сколько стоят эти книги?
B: Bu kitaplar 50 lira. [Бу китаплар 50 лира] - Эти книги 50 лир.
A: Şu kalemler ne kadar? [Шу калемлер не кадар?] - Сколько стоят те ручки?
B: Şu kalemler 10 lira. [Шу калемлер 10 лира] - Те ручки 10 лир.
```

**Объяснение:**
В ситуациях покупок множественное число используется для указания на несколько предметов.

### 6.3 Пример: Описание семьи

**Текст:**

```

Benim ailemde anneler var. [Беним айлемде аннелер вар] - В моей семье есть мамы.
Babalar çalışıyor. [Бабалар чалышыор] - Папы работают.
Çocuklar okula gidiyor. [Чоджуклар окула гидийор] - Дети идут в школу.
```

**Объяснение:**
При описании семьи множественное число используется для указания на нескольких членов семьи.

## 7. Вопросы с множественным числом

### 7.1 Вопросы "Что это?"

**Пример: Вопросы**

```

Bunlar ne? [Бунлар не?] - Что это? (множественное число)
Bunlar kitaplar. [Бунлар китаплар] - Это книги.
Şunlar ne? [Шунлар не?] - Что то? (множественное число)
Şunlar evler. [Шунлар эвлер] - То дома.
```

**Объяснение:**
В вопросах множественное число используется для уточнения, что речь идет о нескольких предметах.

### 7.2 Вопросы "Сколько?"

**Пример: Вопросы о количестве**

```

Kaç kitap var? [Кач китап вар?] - Сколько книг есть?
Kaç öğrenci var? [Кач ёренджи вар?] - Сколько студентов есть?
```

**Объяснение:**
Вопрос "kaç" (сколько) используется с существительными, которые могут быть как в единственном, так и во множественном числе.

## 8. Частые ошибки

### 8.1 Ошибка: Неправильный выбор суффикса

❌ **Неправильно:**
```

öğrenci → öğrencilar (неправильный суффикс)
```

✅ **Правильно:**
```

öğrenci → öğrenciler [ёренджилер] - студенты
```

**Why:** В слове "öğrenci" последняя гласная "i" мягкая, поэтому используется -ler, а не -lar.

### 8.2 Ошибка: Забыть множественное число

❌ **Неправильно:**
```

Bu kitap (когда речь о нескольких книгах)
```

✅ **Правильно:**
```

Bu kitaplar. [Бу китаплар] - Эти книги.
```

**Why:** Когда речь идет о нескольких предметах, нужно использовать множественное число как указательного местоимения, так и существительного.

### 8.3 Ошибка: Неправильная гармония гласных

❌ **Неправильно:**
```

kitap → kitapler (неправильная гармония)
```

✅ **Правильно:**
```

kitap → kitaplar [китаплар] - книги
```

**Why:** В слове "kitap" последняя гласная "a" твердая, поэтому используется -lar, а не -ler.

## 💡 Key Takeaways

- **Множественное число** образуется добавлением -ler/-lar к существительному

- **Выбор суффикса** зависит от гармонии гласных последней гласной слова

- **-ler** используется после мягких гласных (e, i, ö, ü)

- **-lar** используется после твердых гласных (a, ı, o, u)

- **Гармония гласных** - ключевое правило при образовании множественного числа

- **Прилагательные** не изменяются во множественном числе

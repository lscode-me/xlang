## 1. Что такое деепричастие -ken

Конструкция **-ken/-iken** выражает **одновременность** двух действий или состояний.

### 1.1 Основное значение

Суффикс -ken передаёт значения:

- **"в то время как"** — два действия происходят одновременно

- **"когда"** — момент, в который происходит что-то ещё

- **"пока"** — одно действие происходит в процессе другого

**Example: Одновременность действий**

```

Müzik dinlerken çalışıyorum.
Я работаю, слушая музыку. / Я работаю, пока слушаю музыку.
```

**Объяснение:**

- dinle- (основа глагола "слушать")
- -r (настоящее время широкое)
- -ken (одновременность)
Два действия происходят одновременно: слушать и работать.

### 1.2 Когда использовать

**Use cases:**

- **Параллельные действия:** Yürürken konuşuyoruz. (Мы разговариваем, идя / пока идём.)

- **Фоновое действие:** TV izlerken uyudum. (Я уснул, смотря телевизор.)

- **Контраст состояний:** Küçükken çok oyun oynardım. (Когда я был маленьким, я много играл.)

## 2. Образование -ken с глаголами

С глаголами -ken присоединяется к **основе настоящего времени широкого** (Geniş Zaman).

### 2.1 Формула с глаголами

**Формула:** основа + **-r/-ır/-ir/-ur/-ür** + **-ken**

Гармония гласных для -r/-ar/-er:

- **-ar/-ır** — после a, ı, o, u (задние гласные)

- **-er/-ir** — после e, i, ö, ü (передние гласные)

**Example: С разными глаголами**

```

yürürken — идя (yürü- + r + ken)
okurken — читая (oku- + r + ken)
gelirken — приходя (gel- + ir + ken)
```

### 2.2 Спряжение

**Example: Полное спряжение**

```

Ben yürürken — пока я иду
Sen yürürken — пока ты идёшь
O yürürken — пока он/она идёт
Biz yürürken — пока мы идём
Siz yürürken — пока вы идёте
Onlar yürürken — пока они идут
```

**Объяснение:**

-ken не изменяется по лицам. Личное местоимение показывает субъект.

### 2.3 Примеры в предложениях

**Example: Одновременные действия**

```

Kahve içerken gazete okuyorum.
Я читаю газету, попивая кофе.

Yemek yerken televizyon izlemeyin.
Не смотрите телевизор во время еды.

Eve gelirken Ali'yi gördüm.
Я увидел Али, когда шёл домой.
```

**Объяснение:**
Действие с -ken — это фоновое действие, основное действие выражено главным глаголом.

## 3. Образование -ken с существительными и прилагательными

С существительными и прилагательными используется форма **-iken** (с буфером i).

### 3.1 С существительными

**Формула:** существительное + **-iken**

**Example: С существительными**

```

Çocukken çok oyun oynardım.
Когда я был ребёнком, я много играл.

Öğrenciyken çok çalışırdım.
Когда я был студентом, я много занимался.
```

**Объяснение:**

- çocuk (ребёнок) + ken → çocukken
- öğrenci (студент) + y + ken → öğrenciyken (буфер y после гласной)

### 3.2 С прилагательными

**Example: С прилагательными**

```

Hastayken çok su içmelisin.
Когда болеешь, нужно пить много воды.

Yorgunken erken yat.
Когда устал, ложись спать рано.
```

**Объяснение:**

- hasta (больной) + y + ken → hastayken
- yorgun (уставший) + ken → yorgunken

### 3.3 С местоимениями

**Example: С местоимениями**

```

Benyken bu böyle değildi.
Когда был я, так не было. (Раньше, при мне...)

Sensen her şey kolay.
Когда ты, всё легко. (С тобой всё легко.)
```

## 4. Буфер в конструкции -ken

### 4.1 Буфер -i- (после согласных)

После некоторых согласных может добавляться буфер -i-:

**Example: С буфером**

```

evken → eviken (когда дома)
hastaken → hastayken (когда болен)
```

### 4.2 Буфер -y- (после гласных)

После гласных добавляется буфер -y-:

**Example: С буфером -y-**

```

öğrenci + ken → öğrenciyken
hasta + ken → hastayken
```

**Объяснение:**
Буфер -y- предотвращает столкновение двух гласных.

### 4.3 Без буфера

С глаголами (после -r/-ar/-er) буфер не нужен:

**Example: Без буфера**

```

yürürken (не yürüriken)
okurken (не okuriken)
```

## 5. Позиция -ken в предложении

### 5.1 В начале предложения

**Example: Начальная позиция**

```

Yürürken düştüm.
Идя, я упал. / Когда я шёл, я упал.
```

### 5.2 В середине предложения

**Example: Средняя позиция**

```

Eve gelirken Ali'yi gördüm.
Когда я шёл домой, я увидел Али.
```

### 5.3 Акцент на одновременности

**Example: Подчёркивание одновременности**

```

Ben yemek yerken, sen ne yapıyordun?
Пока я ел, что ты делал?

O uyurken, biz çalışıyorduk.
Пока он спал, мы работали.
```

**Объяснение:**
Запятая разделяет две части, подчёркивая параллельность действий.

## 6. Типичные конструкции с -ken

### 6.1 Выражение прерванного действия

**Example: Прерывание**

```

Uyurken telefon çaldı.
Когда я спал, зазвонил телефон. (действие прервано)

Kitap okurken uyudum.
Я уснул, читая книгу.
```

### 6.2 Описание фона

**Example: Фоновое действие**

```

Müzik dinlerken dans ediyorlar.
Они танцуют под музыку. (слушая музыку)

Yağmur yağarken dışarı çıkmayın.
Не выходите, пока идёт дождь.
```

### 6.3 Контраст между прошлым и настоящим

**Example: Временной контраст**

```

Gençken çok spor yapardım.
Когда был молодым, я много занимался спортом.

Türkiye'deyken çok seyahat ettim.
Когда был в Турции, я много путешествовал.
```

### 6.4 С наречиями времени

**Example: С временными указателями**

```

Dün eve gelirken yağmur yağıyordu.
Вчера, когда я шёл домой, шёл дождь.

Her sabah kahvaltı yaparken haberleri izlerim.
Каждое утро, завтракая, я смотрю новости.
```

## 7. Разница между -ken и другими конструкциями

### 7.1 -ken vs -ince/-ınca

- **-ken** — одновременность (в то время как)

- **-ince/-ınca** — последовательность (когда, после того как)

**Example: Сравнение**

```

Eve gelirken yağmur yağıyordu.
Когда я шёл домой, шёл дождь. (одновременно)

Eve gelince yağmur başladı.
Когда я пришёл домой, начался дождь. (последовательно)
```

### 7.2 -ken vs çünkü

- **-ken** — временная связь (когда, пока)

- **çünkü** — причинная связь (потому что)

**Example: Сравнение**

```

Yorgunken uyudum.
Когда устал, я уснул. (временная связь)

Uyudum, çünkü yorgundum.
Я уснул, потому что устал. (причинная связь)
```

## 8. Типичные ошибки

### 8.1 Неправильное образование с глаголами

❌ **Неправильно:** yürüken (пропущен -r-)
✅ **Правильно:** yürürken

**Объяснение:**
С глаголами нужен показатель настоящего времени -r/-ar/-er перед -ken.

### 8.2 Лишний буфер с глаголами

❌ **Неправильно:** yürüriken
✅ **Правильно:** yürürken

**Объяснение:**
После -r/-ar/-er буфер не нужен.

### 8.3 Забытый буфер -y- с существительными

❌ **Неправильно:** öğrenciken
✅ **Правильно:** öğrenciyken

**Объяснение:**
После гласной (i в öğrenci) нужен буфер -y-.

### 8.4 Смешение с -ince

❌ **Неправильно:** Eve gelincen yağmur yağıyordu. (для одновременности)
✅ **Правильно:** Eve gelirken yağmur yağıyordu.

**Объяснение:**
Для одновременности используется -ken, а не -ince.

## 9. Разговорные выражения с -ken

### 9.1 Устойчивые фразы

**Example: Популярные выражения**

```

Ne derken? — Что ты говорил? / Что ты сказал?
Sen yokken — Пока тебя не было
Ben varken — Пока я здесь
Giderken — Когда уходил/По пути
Gelirken — Когда приходил/По пути сюда
```

**Объяснение:**
Эти выражения часто используются в разговорной речи.

### 9.2 С временными выражениями

**Example: Время суток**

```

Sabahken — Пока было утро / Утром
Geceyken — Ночью / Пока была ночь
Genken — Пока молодой
Küçükken — Когда был маленьким
```

## 10. Практические диалоги

### 10.1 Повседневная беседа

**Example: Диалог 1**

```

A: Dün eve gelirken kimi gördün?
B: Ali'yi gördüm. Süpermarkette alışveriş yapıyordu.
A: Sen de alışveriş yaptın mı?
B: Hayır, eve giderken sadece merhaba dedim.

A: Кого ты видел вчера, когда шёл домой?
B: Я видел Али. Он делал покупки в супермаркете.
A: Ты тоже сделал покупки?
B: Нет, я только поздоровался, когда шёл домой.
```

**Объяснение:**
"gelirken" и "giderken" — очень частые конструкции для описания действий по пути.

### 10.2 Воспоминания

**Example: Диалог 2**

```

A: Çocukken ne yapardın?
B: Çok oyun oynardım. Genelde arkadaşlarımla futbol oynardım.
A: Öğrenciyken çok ders çalışır mıydın?
B: Evet, özellikle sınavlardan önceyken çok çalışırdım.

A: Что ты делал в детстве?
B: Я много играл. Обычно играл в футбол с друзьями.
A: Когда был студентом, ты много занимался?
B: Да, особенно перед экзаменами я много занимался.
```

**Объяснение:**
С "çocukken" и "öğrenciyken" часто используется прошедшее привычное время для описания регулярных действий.

## 💡 Key Takeaways

- **-ken** выражает **одновременность** двух действий или состояний
- С глаголами: **основа + -r/-ar/-er + -ken** (показатель настоящего времени обязателен)
- С существительными/прилагательными: **слово + (-y-) + -ken**
- Буфер **-y-** используется после гласных: öğrenciyken, hastayken
- **Нет личных окончаний** в конструкции -ken
- Может стоять в **начале или середине** предложения
- **Отличие от -ince**: -ken = одновременность, -ince = последовательность
- Описывает **фоновое или параллельное** действие
- Часто используется с временными выражениями: çocukken, genken, sabahken

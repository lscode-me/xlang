## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Артикль "a" используется перед существительными, начинающимися с согласного звука: a cat. |
| 2 | A | Артикль "an" используется перед словами, начинающимися с гласного звука: an apple. |
| 3 | A | Слово "hour" начинается с немой H, поэтому используется "an hour" [ən ˈaʊər]. |
| 4 | A | При втором упоминании предмета используется определённый артикль "the". |
| 5 | C | С профессиями используется неопределённый артикль: He is a doctor. |
| 6 | D | С неисчисляемыми существительными в общем значении артикль не используется: I like coffee. |
| 7 | C | Слово "university" начинается со звука [j], поэтому используется "a university". |
| 8 | C | С единственными в своём роде объектами используется "the": the sun, the moon. |
| 9 | A | С названиями большинства стран артикль не используется: Russia, France, Japan. |
| 10 | D | С существительными во множественном числе в общем значении артикль не нужен. |
| 11 | A | Первое упоминание — "a", второе упоминание того же предмета — "the". |
| 12 | A | С музыкальными инструментами используется "the": play the piano, the guitar. |
| 13 | D | С днями недели артикль обычно не используется: on Monday. |
| 14 | C | Слово "honest" начинается с немой H, поэтому используется "an honest". |
| 15 | C | "A student" (профессия с артиклем), "a university" (звук [j] в начале). |
| 16 | A | The moon — единственный объект, используется определённый артикль. |
| 17 | D | "European" начинается со звука [j], поэтому "a European country". |
| 18 | D | С приёмами пищи артикль обычно не используется: have breakfast/lunch/dinner. |
| 19 | B | С горными цепями используется "the" (The Himalayas), с превосходной степенью тоже "the" (the highest). |
| 20 | C | При обобщении (все собаки) артикль не нужен: Dogs are friendly animals. |

## Scoring Guide

- 18-20 правильных ответов: Отлично! Вы полностью освоили материал.
- 15-17 правильных ответов: Хорошо! Повторите некоторые моменты.
- 10-14 правильных ответов: Неплохо, но нужно больше практики.
- Меньше 10 правильных ответов: Рекомендуется повторить лекцию.

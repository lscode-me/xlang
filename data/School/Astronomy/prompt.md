# Промпт для генерации продвинутых тестов по астрономии

Ты — опытный астроном и преподаватель, который умеет делать задания не просто на факты,
а на понимание устройства Вселенной, масштабов космоса и физики небесных тел.

Твоя задача — генерировать вопросы для тестов по астрономии
с продуманными дистракторами и объяснениями, расширяющими кругозор.

## Формат вывода

Генерируй ТОЛЬКО JSONL (JSON Lines).
Каждая строка — один валидный JSON-объект.

НЕ ДОБАВЛЯЙ:
- Markdown-блоки
- Комментарии
- Любой текст вне JSON

## Структура JSON-объекта

{"id":"<LEVEL>-<SET>-<NUM>","question":"<Вопрос>","options":["<Option 1>","<Option 2>","<Option 3>","<Option 4>"],"correct":<1-4>,"explanation":"<Объяснение>","tags":["<topic1>","<topic2>"],"source":"llm"}

## LEVEL (уровень)

- I1 — Введение (базовые понятия, созвездия, планеты)
- I2 — Предмет (звезды, галактики, космология, астрофизика)

## Требования к вопросам

- Вопрос должен иметь ОДИН однозначно правильный ответ
- Формулировка — ясная, увлекательная
- Использование современных астрономических данных

## Требования к вариантам ответов (ОЧЕНЬ ВАЖНО)

- РОВНО 4 варианта
- Все варианты должны быть **похожи по форме**
- Неправильные варианты (дистракторы) должны:
  - быть связаны с темой вопроса (например, названия других планет или типов звезд)
  - отражать типичные заблуждения (путаница между размерами, расстояниями или природой объектов)
- Запрещены явно случайные числа
- Отгадывание “на глаз” должно быть затруднено

## Требования к explanation (ОБЯЗАТЕЛЬНО)

Explanation — это **мини-урок**, а не просто ответ.

Он должен включать:
- научное объяснение явления
- интересный факт или сравнение для лучшего запоминания
- уточнение масштабов или физической природы объекта

## Темы по уровням

### I1 (Введение)
- Видимое движение светил (звездное небо, созвездия)
- Солнечная система (планеты земной группы, гиганты, малые тела)
- Луна и ее фазы, затмения
- История астрономии и освоения космоса

### I2 (Предмет)
- Солнце — ближайшая к нам звезда
- Звезды: характеристики, жизненный цикл, классификация
- Наша Галактика (Млечный Путь) и другие галактики
- Основы космологии (Большой взрыв, расширение Вселенной)
- Методы астрономических исследований (телескопы, спектральный анализ)

## Инструкция

Сгенерируй N вопросов для уровня LEVEL.
Используй набор SET.
Начни с номера START_NUM.
Темы: [укажи темы через запятую]

Выводи ТОЛЬКО JSONL.

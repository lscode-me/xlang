## 1. Что такое наречия времени

Наречия времени в турецком языке указывают, когда происходит действие. Они отвечают на вопрос "когда?" и помогают точно выразить временные отношения в предложении.

### 1.1 Основная функция

Наречия времени используются для:

- Указания времени действия
- Выражения временных отношений
- Описания распорядка дня
- Обсуждения планов и расписаний

**Пример: Базовое использование**

```

Şimdi çalışıyorum. [Шимди чалышыорум] - Я сейчас работаю.
Bugün okula gidiyorum. [Бугюн окула гидийорум] - Я сегодня иду в школу.
Yarın evde kalacağım. [Яран эвде каладжагым] - Я завтра останусь дома.
```

**Объяснение:**
Наречия времени обычно стоят в начале предложения или после подлежащего.

## 2. Основные наречия времени

### 2.1 Базовые наречия

**Таблица:**

| Наречие | Перевод | Пример |
|---------|---------|--------|
| şimdi | сейчас | Şimdi çalışıyorum |
| bugün | сегодня | Bugün çalışıyorum |
| yarın | завтра | Yarın gidiyorum |
| dün | вчера | Dün geldim |
| sabah | утром | Sabah kalkıyorum |
| öğle | днем | Öğle yemek yiyorum |
| akşam | вечером | Akşam yemek yiyorum |
| gece | ночью | Gece uyuyorum |

**Пример: Использование**

```

Şimdi çalışıyorum. [Шимди чалышыорум] - Я сейчас работаю.
Bugün okula gidiyorum. [Бугюн окула гидийорум] - Я сегодня иду в школу.
Yarın evde kalacağım. [Яран эвде каладжагым] - Я завтра останусь дома.
Dün okuldaydım. [Дюн окулдайдым] - Я вчера был в школе.
```

**Объяснение:**
Наречия времени обычно стоят в начале предложения или после подлежащего.

### 2.2 Детальное описание наречий

**Şimdi (сейчас)**

```

Şimdi çalışıyorum. [Шимди чалышыорум] - Я сейчас работаю.
Şimdi ne yapıyorsun? [Шимди не япыйорсун?] - Что ты сейчас делаешь?
```

**Объяснение:**
"Şimdi" указывает на текущий момент, прямо сейчас.

**Bugün (сегодня)**

```

Bugün çalışıyorum. [Бугюн чалышыорум] - Сегодня я работаю.
Bugün ne yapıyorsun? [Бугюн не япыйорсун?] - Что ты сегодня делаешь?
```

**Объяснение:**
"Bugün" указывает на сегодняшний день.

**Yarın (завтра)**

```

Yarın gidiyorum. [Яран гидийорум] - Завтра я иду.
Yarın ne yapıyorsun? [Яран не япыйорсун?] - Что ты завтра делаешь?
```

**Объяснение:**
"Yarın" указывает на завтрашний день.

**Dün (вчера)**

```

Dün geldim. [Дюн гельдим] - Вчера я пришел.
Dün ne yaptın? [Дюн не яптын?] - Что ты вчера делал?
```

**Объяснение:**
"Dün" указывает на вчерашний день.

## 3. Наречия времени суток

### 3.1 Части дня

**Таблица:**

| Наречие | Перевод | Пример |
|---------|---------|--------|
| sabah | утром | Sabah kalkıyorum |
| öğle | днем | Öğle yemek yiyorum |
| akşam | вечером | Akşam yemek yiyorum |
| gece | ночью | Gece uyuyorum |

**Пример: Использование**

```

Sabah kalkıyorum. [Сабах калькыйорум] - Я встаю утром.
Öğle yemek yiyorum. [Ёле йемек йийорум] - Я ем днем.
Akşam yemek yiyorum. [Акшам йемек йийорум] - Я ем вечером.
Gece uyuyorum. [Гедже уйуйорум] - Я сплю ночью.
```

**Объяснение:**
Наречия времени суток указывают на конкретное время дня.

### 3.2 Детальное описание

**Sabah (утром)**

```

Sabah kalkıyorum. [Сабах калькыйорум] - Я встаю утром.
Sabah çalışıyorum. [Сабах чалышыорум] - Я работаю утром.
```

**Öğle (днем)**

```

Öğle yemek yiyorum. [Ёле йемек йийорум] - Я ем днем.
Öğle dinleniyorum. [Ёле динленийорум] - Я отдыхаю днем.
```

**Akşam (вечером)**

```

Akşam yemek yiyorum. [Акшам йемек йийорум] - Я ем вечером.
Akşam televizyon izliyorum. [Акшам телевизьон излийорум] - Я смотрю телевизор вечером.
```

**Gece (ночью)**

```

Gece uyuyorum. [Гедже уйуйорум] - Я сплю ночью.
Gece çalışıyorum. [Гедже чалышыорум] - Я работаю ночью.
```

## 4. Использование в предложениях

### 4.1 Позиция наречий

**Пример: В начале предложения**

```

Bugün çalışıyorum. [Бугюн чалышыорум] - Сегодня я работаю.
Yarın gidiyorum. [Яран гидийорум] - Завтра я иду.
Şimdi okuyorum. [Шимди окуйорум] - Я сейчас читаю.
```

**Объяснение:**
Наречия времени часто стоят в начале предложения для акцента на времени.

**Пример: После подлежащего**

```

Ben bugün çalışıyorum. [Бен бугюн чалышыорум] - Я сегодня работаю.
Sen yarın gidiyorsun. [Сен яран гидийорсун] - Ты завтра идешь.
O şimdi okuyor. [О шимди окуёр] - Он/Она сейчас читает.
```

**Объяснение:**
Наречия времени могут стоять после подлежащего для более естественного порядка слов.

### 4.2 С разными временами

**Пример: С настоящим временем**

```

Şimdi çalışıyorum. [Шимди чалышыорум] - Я сейчас работаю.
Bugün okula gidiyorum. [Бугюн окула гидийорум] - Я сегодня иду в школу.
```

**Пример: С прошедшим временем**

```

Dün geldim. [Дюн гельдим] - Вчера я пришел.
Dün okuldaydım. [Дюн окулдайдым] - Я вчера был в школе.
```

**Пример: С будущим временем**

```

Yarın gideceğim. [Яран гиджеджегим] - Завтра я пойду.
Yarın evde kalacağım. [Яран эвде каладжагым] - Я завтра останусь дома.
```

## 5. Практические примеры

### 5.1 Пример: Описание распорядка дня

**Текст:**

```

Sabah kalkıyorum. [Сабах калькыйорум] - Я встаю утром.
Sabah kahvaltı yapıyorum. [Сабах кахвальты япыйорум] - Я завтракаю утром.
Öğle yemek yiyorum. [Ёле йемек йийорум] - Я ем днем.
Akşam televizyon izliyorum. [Акшам телевизьон излийорум] - Я смотрю телевизор вечером.
Gece uyuyorum. [Гедже уйуйорум] - Я сплю ночью.
```

**Объяснение:**
Наречия времени используются для описания ежедневного распорядка.

### 5.2 Пример: Диалог

**Диалог:**

```

A: Ne zaman çalışıyorsun? [Не заман чалышыорсун?] - Когда ты работаешь?
B: Ben sabah çalışıyorum. [Бен сабах чалышыорум] - Я работаю утром.

A: Bugün ne yapıyorsun? [Бугюн не япыйорсун?] - Что ты сегодня делаешь?
B: Bugün okula gidiyorum. [Бугюн окула гидийорум] - Сегодня я иду в школу.

A: Yarın ne yapacaksın? [Яран не япаджагсын?] - Что ты завтра будешь делать?
B: Yarın evde kalacağım. [Яран эвде каладжагым] - Завтра я останусь дома.
```

**Объяснение:**
В разговорах наречия времени используются для обсуждения планов и расписаний.

## 6. Вопросы о времени

### 6.1 Вопрос "Ne zaman?" (когда?)

**Пример: Вопросы**

```

Ne zaman çalışıyorsun? [Не заман чалышыорсун?] - Когда ты работаешь?
Ne zaman gidiyorsun? [Не заман гидийорсун?] - Когда ты идешь?
Ne zaman geliyorsun? [Не заман гелийорсун?] - Когда ты приходишь?
```

**Объяснение:**
Вопрос "ne zaman" (когда) используется для уточнения времени действия.

### 6.2 Ответы на вопросы

**Пример: Ответы**

```

A: Ne zaman çalışıyorsun? [Не заман чалышыорсун?] - Когда ты работаешь?
B: Ben sabah çalışıyorum. [Бен сабах чалышыорум] - Я работаю утром.

A: Ne zaman gidiyorsun? [Не заман гидийорсун?] - Когда ты идешь?
B: Ben yarın gidiyorum. [Бен яран гидийорум] - Я иду завтра.

A: Ne zaman geliyorsun? [Не заман гелийорсун?] - Когда ты приходишь?
B: Ben öğleden sonra geliyorum. [Бен ёледен сонра гелийорум] - Я прихожу после обеда.
```

**Объяснение:**
В ответах на вопросы о времени используются наречия времени для указания конкретного времени действия.

### 6.3 Сложные временные выражения

**Пример: Сложные выражения**

```

Bugün sabah çalışıyorum. [Бугюн сабах чалышыорум] - Сегодня утром я работаю.
Yarın akşam gidiyorum. [Яран акшам гидийорум] - Завтра вечером я иду.
Dün gece uyuyordum. [Дюн гедже уйуйордум] - Вчера ночью я спал.
```

**Объяснение:**
Наречия времени могут комбинироваться для более точного указания времени действия.

## 7. Частые ошибки

### 7.1 Ошибка: Неправильная позиция

❌ **Неправильно:**

```

Çalışıyorum bugün (наречие в конце)
```

✅ **Правильно:**

```

Bugün çalışıyorum. [Бугюн чалышыорум] - Сегодня я работаю.
```

**Why:** Наречия времени обычно стоят в начале предложения или после подлежащего, а не в конце.

### 7.2 Ошибка: Путаница наречий

❌ **Неправильно:**

```

Dün gidiyorum (прошедшее наречие с настоящим временем)
```

✅ **Правильно:**

```

Dün gittim. [Дюн гиттим] - Вчера я пошел (прошедшее время).
Yarın gidiyorum. [Яран гидийорум] - Завтра я иду (настоящее время для будущего).
```

**Why:** Наречия времени должны соответствовать времени глагола.

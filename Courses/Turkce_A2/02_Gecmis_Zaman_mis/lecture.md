## 1. Что такое прошедшее неопределённое время (-miş)

Прошедшее неопределённое время (-miş) используется для:

- Действий, о которых вы **узнали от других** (пересказ)
- Действий, **результат которых виден сейчас**
- Выражения **удивления** при обнаружении чего-то
- **Предположений** о прошлом

Это второе по важности прошедшее время в турецком языке.

### 1.1 Три основных значения -miş

**1. Косвенный опыт (пересказ)**

```

Ali gelmiş.
Али пришёл (мне сказали / я слышал).
```

**Объяснение:**
Говорящий не видел, как Али пришёл, но узнал об этом от других или по косвенным признакам.

**2. Результат виден сейчас**

```

Kar yağmış!
Снег выпал! (я вижу снег на земле)
```

**Объяснение:**
Говорящий не видел, как шёл снег, но видит результат — снег на земле.

**3. Удивление**

```

Sen çok yorulmuşsun!
Ты очень устал! (я вижу, что ты устал)
```

**Объяснение:**
Говорящий делает вывод по внешнему виду собеседника.

### 1.2 Когда использовать -miş

**Use cases:**

- **Пересказ**: Ali dedi ki, film çok iyiymiş (Али сказал, что фильм был очень хороший)

- **Результат**: Araba bozulmuş (Машина сломалась — я вижу, что она не работает)

- **Удивление**: Çok büyümüşsün! (Ты так вырос!)

- **Сказки и истории**: Bir varmış bir yokmuş... (Жил-был...)

## 2. Образование прошедшего времени -miş

### 2.1 Формула образования

```

Основа глагола + -miş/-mış/-muş/-müş + личное окончание
```

Выбор варианта -miş зависит от **гармонии гласных**:

| Последняя гласная основы | Суффикс |
|--------------------------|---------|
| e, i                     | -miş    |
| a, ı                     | -mış    |
| o, u                     | -muş    |
| ö, ü                     | -müş    |

**Example: Гармония гласных**

```

gel-mek (приходить) → gel-miş (пришёл)
çalış-mak (работать) → çalış-mış (работал)
oku-mak (читать) → oku-muş (читал)
gör-mek (видеть) → gör-müş (видел)
```

**Объяснение:**
Суффикс меняется так же, как и в -di, следуя правилу гармонии гласных.

### 2.2 Личные окончания

После суффикса -miş добавляются личные окончания:

| Лицо | Окончание | Пример (gelmek) |
|------|-----------|-----------------|
| ben (я) | -im/-ım/-um/-üm | gelmişim |
| sen (ты) | -sin/-sın/-sun/-sün | gelmişsin |
| o (он/она) | — | gelmiş |
| biz (мы) | -iz/-ız/-uz/-üz | gelmişiz |
| siz (вы) | -siniz/-sınız/-sunuz/-sünüz | gelmişsiniz |
| onlar (они) | -ler/-lar | gelmişler |

**Example: Полное спряжение глагола "gitmek" (идти)**

```

ben gitmişim — я (оказывается) ходил
sen gitmişsin — ты (оказывается) ходил
o gitmiş — он/она (оказывается) ходил/а
biz gitmişiz — мы (оказывается) ходили
siz gitmişsiniz — вы (оказывается) ходили
onlar gitmişler — они (оказывается) ходили
```

**Объяснение:**
Личные окончания для -miş отличаются от окончаний для -di. Они следуют гармонии гласных.

### 2.3 Особенность для "ben"

Для первого лица часто опускается окончание в разговорной речи:

**Example: Разговорная форма**

```

Формальная: Ben eve gitmişim
Разговорная: Ben eve gitmiş

Оказывается, я ушёл домой.
```

**Объяснение:**
В устной речи часто говорят просто "gitmiş" вместо "gitmişim" для первого лица.

## 3. Основные значения -miş

### 3.1 Пересказ (Hearsay)

Используется, когда вы передаёте информацию, полученную от других:

**Example: Новость от друга**

```

Ahmet dün İstanbul'a gitmiş.
Ахмет вчера поехал в Стамбул (мне сказали).
```

**Объяснение:**
Говорящий не видел, как Ахмет уехал, но узнал об этом от кого-то.

**Example: Слух**

```

Bu restoran çok pahalıymış.
Этот ресторан (говорят) очень дорогой.
```

**Объяснение:**
Говорящий слышал это от других людей, сам ещё не был в ресторане.

### 3.2 Результат виден сейчас

Используется, когда вы видите результат действия:

**Example: Обнаружение**

```

Kahvem bitmiş!
Мой кофе закончился! (я вижу пустую чашку)
```

**Объяснение:**
Говорящий обнаруживает, что кофе закончился, не заметив, когда это произошло.

**Example: След действия**

```

Pencere kırılmış.
Окно разбито. (я вижу разбитое окно)
```

**Объяснение:**
Говорящий видит результат, но не знает, когда и как окно разбилось.

### 3.3 Удивление и новое осознание

Используется при обнаружении неожиданного факта:

**Example: Удивление**

```

Çok geç olmuş!
Уже так поздно! (я не заметил, как стало поздно)
```

**Объяснение:**
Говорящий с удивлением обнаруживает, что время прошло незаметно.

**Example: Осознание**

```

Unutmuşum!
Я забыл! (только что понял)
```

**Объяснение:**
Говорящий только что осознал, что что-то забыл.

## 4. Отрицательная форма

### 4.1 Образование отрицания

Отрицание образуется добавлением **-me/-ma** перед суффиксом -miş:

```

Основа + -me/-ma + -miş + личное окончание
```

**Example: Отрицательное предложение**

```

Ali gelmemiş.
Али не пришёл (говорят / я вижу, что его нет).
```

**Объяснение:**
"gelmek" (приходить) → "gel" + "me" + "miş" = "gelmemiş" (не пришёл).

### 4.2 Примеры отрицания

**Example: Пересказ отрицания**

```

Ahmet dün çalışmamış.
Ахмет вчера не работал (мне сказали).
```

**Объяснение:**
Отрицательный суффикс -ma добавляется перед -mış.

**Example: Результат отрицания**

```

Yemek pişmemiş.
Еда не приготовилась (я вижу, что она сырая).
```

**Объяснение:**
"pişmek" (готовиться) → "pişmemiş" (не приготовилась).

---

## 5. Вопросительная форма

### 5.1 Образование вопросов

Вопросительная частица **mi/mı/mu/mü** ставится после глагола, как и с -di:

```

Глагол с -miş + mi/mı/mu/mü + личное окончание?
```

**Example: Общий вопрос**

```

Ali gelmiş mi?
Али пришёл? (ты слышал? / видишь его здесь?)
```

**Объяснение:**
"gelmiş" (пришёл) + "mi" (вопросительная частица) = "gelmiş mi?" (он пришёл?).

### 5.2 Вопросы с личными окончаниями

**Example: С окончанием для "sen"**

```

Sen gitmişsin, değil mi?
Ты ходил туда, правда?
```

**Объяснение:**
Говорящий делает предположение и просит подтверждения.

## 6. Сравнение -di и -miş

### 6.1 Основные различия

| Аспект | -di | -miş |
|--------|-----|------|
| Опыт | Лично видел/делал | Слышал/вижу результат |
| Уверенность | Высокая | Средняя |
| Время | Конкретное | Неопределённое |
| Использование | Факты | Пересказ, удивление |

**Example: Сравнение**

```

Dün sinemaya gittim. (Я точно знаю, я там был)
Ali sinemaya gitmiş. (Мне сказали / я так слышал)
```

**Объяснение:**
С -di говорящий был свидетелем, с -miş — узнал от других или делает вывод.

### 6.2 Примеры в контексте

**Example: Лично видел vs. Услышал**

```

A: Filmi gördün mü? (Ты видел фильм? — спрашиваю о личном опыте)
B: Evet, gördüm. (Да, видел — я сам смотрел)

A: Film nasılmış? (Как фильм? — спрашиваю, что говорят)
B: Çok güzelmiş. (Очень хороший, говорят)
```

**Объяснение:**
В первом случае спрашивается о личном опыте (-di), во втором — о мнении других (-miş).

## 7. Использование -miş в сказках

В турецких сказках традиционно используется -miş:

**Example: Начало сказки**

```

Bir varmış bir yokmuş.
Жил-был (дословно: был один, не был один).
```

**Объяснение:**
Сказки используют -miş, потому что это истории, передаваемые из поколения в поколение.

**Example: Сказочный текст**

```

Evvel zaman içinde, bir kral varmış. 
Bu kralın üç oğlu varmış.

Давным-давно был один король.
У этого короля было три сына.
```

**Объяснение:**
Все глаголы в форме -miş, так как это пересказ старой истории.

## 8. Практические примеры

### 8.1 Диалог с -miş

**Example: Обмен новостями**

```

A: Ahmet'i gördün mü?
B: Hayır, ama Ayşe dedi ki, hastaymış.
A: Gerçekten mi? Ne olmuş?
B: Bilmiyorum, ama evde dinleniyormuş.

A: Ты видел Ахмета?
B: Нет, но Айше сказала, что он болен.
A: Правда? Что случилось?
B: Не знаю, но он отдыхает дома (говорят).
```

**Объяснение:**
Используется -miş, потому что информация получена от Айше, не из первых рук.

### 8.2 Удивление при обнаружении

**Example: Неожиданность**

```

Saat 10 olmuş! Toplantıyı unuttum!
Уже 10 часов! Я забыл о встрече!
```

**Объяснение:**
Говорящий с удивлением обнаруживает время и осознаёт, что забыл о встрече.

### 8.3 Видимый результат

**Example: Наблюдение результата**

```

Bak! Çiçekler açmış.
Смотри! Цветы распустились.
```

**Объяснение:**
Говорящий видит распустившиеся цветы, но не видел процесса.

## 9. Распространённые ошибки

### 9.1 Смешивание -di и -miş

❌ **Неправильно:**

```

Dün sinemaya gitmişim (если вы там были)
```

✅ **Правильно:**

```

Dün sinemaya gittim (я сам ходил)
```

### 9.2 Неправильные личные окончания

❌ **Неправильно:**

```

Sen gelmiş (для "ты пришёл")
```

✅ **Правильно:**

```

Sen gelmişsin (окончание -sin для "sen")
```

### 9.3 Использование -miş для личного опыта

❌ **Неправильно:**

```

Sabah kahve içmişim (если вы точно помните, что пили)
```

✅ **Правильно:**

```

Sabah kahve içtim (я помню, как пил)
```

## 💡 Key Takeaways

- **-miş/-mış/-muş/-müş** — суффикс прошедшего неопределённого времени

- **Три основных значения**: пересказ, видимый результат, удивление
- Используется когда **не был свидетелем** действия
- Формула: **Основа + -miş + личное окончание**
- Отрицание: **Основа + -me/-ma + -miş + окончание**
- **Отличие от -di**: -di для личного опыта, -miş для косвенной информации
- В сказках всегда используется **-miş**

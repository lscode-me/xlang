## 1. Что такое деепричастие -ince

Конструкция **-ince/-ınca/-unca/-ünce** выражает **последовательность действий** или **момент времени**, когда происходит другое действие.

### 1.1 Основное значение

Суффикс -ince передаёт значения:

- **"когда"** — в момент, когда происходит действие

- **"после того как"** — после завершения действия

- **"как только"** — немедленный результат

**Example: Последовательность действий**

```

Eve gelince dinleneceğim.
Когда приду домой, я отдохну.
```

**Объяснение:**

- gel- (основа глагола "приходить")
- -ince (последовательность)
Сначала прийти домой, потом отдохнуть — действия следуют друг за другом.

### 1.2 Когда использовать

**Use cases:**

- **Последовательность:** Uyandım, kahvaltı yapınca işe gittim. (Проснулся, позавтракав, пошёл на работу.)

- **Условие-время:** Yağmur yağınca dışarı çıkmayız. (Когда идёт дождь, мы не выходим.)

- **Немедленная реакция:** Haberi duyunca çok sevindim. (Когда услышал новость, очень обрадовался.)

- **Момент осознания:** Telefonu açınca mesajı gördüm. (Когда открыл телефон, увидел сообщение.)

## 2. Образование конструкции -ince

Суффикс имеет **4 варианта** в зависимости от гармонии гласных.

### 2.1 Гармония гласных

| Последняя гласная основы | Суффикс | Пример |
|--------------------------|---------|---------|
| e, i | -ince | gel-ince (когда придёт) |
| a, ı | -ınca | bak-ınca (когда посмотрит) |
| o, u | -unca | oku-nca (когда прочитает) |
| ö, ü | -ünce | gör-ünce (когда увидит) |

**Example: Применение гармонии**

```

gel-ince (e → -ince)
bak-ınca (a → -ınca)
oku-nca (u → -unca)
gör-ünce (ö → -ünce)
```

### 2.2 Формула образования

**Формула:** основа глагола + **-ince/-ınca/-unca/-ünce**

**Example: Образование**

```

gelmek → gel + ince = gelince
bakmak → bak + ınca = bakınca
okumak → oku + nca = okunca (u выпадает перед n)
görmek → gör + ünce = görünce
```

**Объяснение:**
Присоединяется непосредственно к основе глагола, без промежуточных суффиксов.

### 2.3 Ассимиляция согласных

Если основа заканчивается на гласную, может происходить ассимиляция:

**Example: С основой на гласную**

```

okumak → oku + nca = okunca (u + u → u)
demek → de + yince = deyince (добавляется буфер y)
```

## 3. Использование в предложениях

### 3.1 Последовательность действий

**Example: Одно действие за другим**

```

İşten çıkınca eve gidiyorum.
Когда выхожу с работы, иду домой.

Yemek yiyince uyudum.
Поев, я уснул.
```

**Объяснение:**
Первое действие (с -ince) происходит раньше, второе — после него.

### 3.2 Момент времени

**Example: Конкретный момент**

```

Sabah olunca kuşlar ötmeye başlar.
Когда наступает утро, птицы начинают петь.

Saat 5 olunca eve gideceğim.
Когда будет 5 часов, я пойду домой.
```

### 3.3 Немедленная реакция

**Example: Мгновенный результат**

```

Haberi duyunca şok oldum.
Услышав новость, я был в шоке.

Onu görünce tanıdım.
Увидев его/её, я узнал.
```

**Объяснение:**

-ince часто выражает быструю реакцию на событие.

### 3.4 Условие-время

**Example: Общие истины**

```

Güneş batınca hava karanlık olur.
Когда солнце садится, становится темно.

Yağmur yağınca sokaklar ıslak olur.
Когда идёт дождь, улицы становятся мокрыми.
```

## 4. Позиция в предложении

### 4.1 В начале предложения

**Example: Начальная позиция**

```

Eve gelince seni ararım.
Когда приду домой, позвоню тебе.
```

### 4.2 В середине предложения

**Example: Средняя позиция**

```

Ben eve gelince, sen neredeydin?
Когда я пришёл домой, где ты был?
```

### 4.3 С разными субъектами

Когда субъекты разные, часто добавляется притяжательный суффикс:

**Example: Разные субъекты**

```

Sen gelince, ben gideceğim.
Когда ты придёшь, я уйду.

O telefon edince, cevap ver.
Когда он позвонит, ответь.
```

## 5. Разница между -ince и -ken

Это важное различие для понимания турецких временных конструкций.

### 5.1 -ince: последовательность

**Example: Последовательные действия**

```

Eve gelince yemek yedim.
Когда пришёл домой, я поел. (сначала пришёл, потом поел)
```

**Объяснение:**
Действия следуют друг за другом.

### 5.2 -ken: одновременность

**Example: Одновременные действия**

```

Eve gelirken yağmur yağıyordu.
Когда я шёл домой, шёл дождь. (оба действия одновременно)
```

**Объяснение:**
Действия происходят параллельно.

### 5.3 Сравнительная таблица

| Аспект | -ince | -ken |
|--------|-------|------|
| Время | Последовательность | Одновременность |
| Значение | "когда", "после того как" | "в то время как", "пока" |
| Образование | основа + -ince | основа + -r/-ar/-er + -ken |
| Пример | gelince (когда придёт) | gelirken (пока идёт) |

**Example: Прямое сравнение**

```

Kitabı okuyunca anladım.
Прочитав книгу, я понял. (сначала прочитал, потом понял)

Kitabı okurken uyudum.
Читая книгу, я уснул. (читал и в это время уснул)
```

## 6. С разными временами

### 6.1 С настоящим временем

**Example: Настоящее время**

```

Her sabah kalkınca kahvaltı yaparım.
Каждое утро, когда встаю, завтракаю.
```

### 6.2 С прошедшим временем

**Example: Прошедшее время**

```

Dün eve gelince, sen yoktun.
Вчера, когда я пришёл домой, тебя не было.

Film bitince eve gittik.
Когда фильм закончился, мы пошли домой.
```

### 6.3 С будущим временем

**Example: Будущее время**

```

İşim bitince seni arayacağım.
Когда работа закончится, я позвоню тебе.

Yaz gelince denize gideceğiz.
Когда придёт лето, мы пойдём на море.
```

## 7. Распространённые выражения

### 7.1 С временами суток

**Example: Время суток**

```

Sabah olunca kahvaltı yaparız.
Когда наступает утро, мы завтракаем.

Akşam olunca yorgun olurum.
Когда наступает вечер, я устаю.
```

### 7.2 С погодой

**Example: Погода**

```

Hava ısınınca pikniğe gidelim.
Когда потеплеет, пойдём на пикник.

Kar yağınca çocuklar sevinir.
Когда идёт снег, дети радуются.
```

### 7.3 Устойчивые выражения

**Example: Частые фразы**

```

İşten çıkınca — когда выхожу с работы
Evden ayrılınca — когда ухожу из дома
Uyandığımda / Uyandığında — когда я проснулся / ты проснулся
Büyüyünce — когда вырасту
```

## 8. Типичные ошибки

### 8.1 Неправильная гармония гласных

❌ **Неправильно:** gelunce (для gel-)
✅ **Правильно:** gelince

**Объяснение:**
После e (передняя гласная) используется -ince, а не -unca.

### 8.2 Смешение с -ken

❌ **Неправильно:** Eve gelince yağmur yağıyordu. (если действия одновременны)
✅ **Правильно:** Eve gelirken yağmur yağıyordu.

**Объяснение:**
Если действия одновременны, нужен -ken, а не -ince.

### 8.3 Добавление лишних суффиксов

❌ **Неправильно:** gelirince (с -r-)
✅ **Правильно:** gelince

**Объяснение:**

-ince присоединяется прямо к основе, без -r/-ar/-er.

### 8.4 Неправильный порядок действий

❌ **Неправильно:** Yemek yedim, eve gelince. (неправильная логика)
✅ **Правильно:** Eve gelince yemek yedim.

**Объяснение:**
Действие с -ince происходит первым.

## 9. Разговорные выражения с -ince/-ınca

### 9.1 Устойчивые фразы

**Example: Популярные выражения**

```

Gelince haber ver. — Когда придёшь, сообщи.
Bitirince söyle. — Когда закончишь, скажи.
Öğrenince anlarsın. — Когда узнаешь, поймёшь.
Görünce tanırsın. — Когда увидишь, узнаешь.
```

**Объяснение:**
Эти конструкции часто используются для выражения условий и последовательности в повседневной речи.

### 9.2 С модальными глаголами

**Example: С необходимостью и возможностью**

```

Eve varınca dinlenmeliyim.
Когда приду домой, мне нужно отдохнуть.

İşi bitirince dışarı çıkabiliriz.
Когда закончим работу, мы сможем выйти.

Yemeği yiyince uyumak istiyorum.
После того как поем, я хочу спать.
```

**Объяснение:**

-ince часто комбинируется с модальными конструкциями для выражения планов и намерений.

## 10. Практические диалоги

### 10.1 Планирование действий

**Example: Диалог 1**

```

A: Ne zaman çıkacağız?
B: İşim bitince çıkacağız.
A: Kaçta bitecek?
B: Saat 5'te bitince hemen geleceğim.

A: Когда мы выйдем?
B: Когда моя работа закончится, мы выйдем.
A: В котором часу закончится?
B: Когда закончится в 5, я сразу приду.
```

**Объяснение:**

-ince идеально подходит для описания последовательности событий в будущем.

### 10.2 Рассказ о прошлом

**Example: Диалог 2**

```

A: Dün ne yaptın?
B: Eve gelince önce duş aldım. Sonra yemek yedim.
A: Yemekten sonra ne yaptın?
B: Televizyon izleyince uyudum.

A: Что ты делал вчера?
B: Когда пришёл домой, сначала принял душ. Потом поел.
A: Что ты сделал после еды?
B: Посмотрев телевизор, я уснул.
```

**Объяснение:**

-ince помогает выстроить чёткую хронологию событий.

### 10.3 Причинно-следственные отношения

**Example: Диалог 3**

```

A: Neden geç kaldın?
B: Otobüsü kaçırınca taksi çağırdım. 
   Taksi gelince trafik çok yoğundu.
A: Anladım, sorun değil.

A: Почему ты опоздал?
B: Когда я пропустил автобус, я вызвал такси.
   Когда такси приехало, было сильное движение.
A: Понятно, ничего страшного.
```

**Объяснение:**

-ince часто используется для объяснения цепочки событий, которые привели к результату.

## 💡 Key Takeaways

- **-ince/-ınca/-unca/-ünce** выражает **последовательность действий**
- Значение: **"когда", "после того как", "как только"**
- Гармония гласных: **4 варианта** (e/i → -ince, a/ı → -ınca, o/u → -unca, ö/ü → -ünce)
- Формула: **основа глагола + -ince** (без промежуточных суффиксов -r/-ar/-er)
- **Отличие от -ken**: -ince = последовательность, -ken = одновременность
- Действие с -ince происходит **первым**, затем следует основное действие
- Может выражать **немедленную реакцию** или **условие-время**
- Используется со **всеми временами** (настоящее, прошедшее, будущее)
- Очень частая конструкция в **повседневной речи** для описания планов и действий

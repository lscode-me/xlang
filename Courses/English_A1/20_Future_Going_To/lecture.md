## 1. Что такое going to?

Конструкция going to используется для выражения будущих действий, планов и намерений. Это один из самых распространённых способов говорить о будущем в английском языке.

### 1.1 Когда используется going to?

**1. Планы и намерения** — то, что мы уже решили сделать:

```

I am going to study English tomorrow.
Я собираюсь изучать английский завтра.
```

**2. Предсказания, основанные на очевидных фактах** — то, что произойдёт, потому что есть признаки:

```

Look at those clouds! It's going to rain.
Посмотри на эти тучи! Пойдёт дождь.
```

### 1.2 Структура going to

**Формула:** подлежащее + am/is/are + going to + инфинитив (глагол без to)

```

I am going to work.
You are going to study.
He is going to play.
```

**Важно:** После going to идёт инфинитив БЕЗ частицы to:
- ✅ I am going to study (правильно)
- ❌ I am going to to study (неправильно)

## 2. Утвердительные предложения

### 2.1 Структура и образование

**Формула:** подлежащее + am/is/are + going to + глагол

**Полные формы:**

```

I am going to...
You are going to...
He is going to...
She is going to...
It is going to...
We are going to...
They are going to...
```

**Сокращённые формы (используются в разговорной речи):**

```

I'm going to...
You're going to...
He's going to...
She's going to...
It's going to...
We're going to...
They're going to...
```

### 2.2 Примеры утвердительных предложений

**Example 1: Личные планы**

```

I am going to study English tonight.
Я собираюсь изучать английский сегодня вечером.
```

**Объяснение:**
I am (сокращённо I'm) + going to + study (инфинитив без to). Выражает мой план на вечер.

**Example 2: Покупка**

```

She is going to buy a new car next month.
Она собирается купить новую машину в следующем месяце.
```

**Объяснение:**
She is (сокращённо She's) + going to + buy. Выражает её намерение, план на будущее.

**Example 3: Путешествие**

```

We are going to visit London this summer.
Мы собираемся посетить Лондон этим летом.
```

**Объяснение:**
We are (We're) + going to + visit. План на лето, который уже обсуждается.

**Example 4: Совместные планы**

```

They are going to watch a movie tonight.
Они собираются посмотреть фильм сегодня вечером.
```

**Объяснение:**
They are (They're) + going to + watch. Их общий план на вечер.

**Example 5: Предсказание**

```

Look at the sky! It is going to rain soon.
Посмотри на небо! Скоро пойдёт дождь.
```

**Объяснение:**
It is (It's) + going to + rain. Предсказание, основанное на видимых признаках (тучи на небе).

**Example 6: Решение о работе**

```

He is going to start a new job next week.
Он собирается начать новую работу на следующей неделе.
```

**Объяснение:**
He is (He's) + going to + start. План, который уже определён.

### 2.3 Различие: going to (движение) vs. going to (будущее время)

Важно различать going to как движение ("идти куда-то") и going to для будущего времени:

**Going to = движение (ходить, ехать):**

```

I am going to the park. (Я иду в парк - сейчас)
Я иду в парк.
```

**Going to = будущее время:**

```

I am going to play in the park. (Я собираюсь играть в парке - план)
Я собираюсь играть в парке.
```

**Объяснение:**

- В первом предложении "to the park" — предлог направления. Это настоящее время движения.
- Во втором предложении "to play" — часть конструкции going to для будущего. После going to идёт глагол.

## 3. Отрицательные предложения

### 3.1 Структура отрицания

**Формула:** подлежащее + am/is/are + not + going to + глагол

**Полные формы:**

```

I am not going to...
You are not going to...
He is not going to...
She is not going to...
It is not going to...
We are not going to...
They are not going to...
```

**Сокращённые формы:**

```

I'm not going to...
You aren't going to... / You're not going to...
He isn't going to... / He's not going to...
She isn't going to... / She's not going to...
It isn't going to... / It's not going to...
We aren't going to... / We're not going to...
They aren't going to... / They're not going to...
```

### 3.2 Примеры отрицательных предложений

**Example 1:**

```

I am not going to work tomorrow.
Я не собираюсь работать завтра.
```

**Объяснение:**
I am not (I'm not) + going to + work. Отрицание плана или намерения.

**Example 2:**

```

She isn't going to buy that dress.
Она не собирается покупать то платье.
```

**Объяснение:**
She is not (isn't) + going to + buy. Отрицание намерения.

**Example 3:**

```

We are not going to visit them this weekend.
Мы не собираемся навещать их в эти выходные.
```

**Объяснение:**
We are not (aren't / We're not) + going to + visit. Отсутствие плана.

**Example 4:**

```

They aren't going to come to the party.
Они не собираются приходить на вечеринку.
```

**Объяснение:**
They are not (aren't) + going to + come. Они решили не приходить.

**Example 5:**

```

It's not going to rain today.
Сегодня дождя не будет.
```

**Объяснение:**
It is not (It's not / It isn't) + going to + rain. Предсказание, что дождя не будет.

## 4. Вопросительные предложения

### 4.1 Общие вопросы (Yes/No questions)

**Формула:** Am/Is/Are + подлежащее + going to + глагол?

**Структура:**

```

Am I going to...?
Are you going to...?
Is he going to...?
Is she going to...?
Is it going to...?
Are we going to...?
Are they going to...?
```

**Example 1:**

```

Are you going to study tonight?
Ты будешь заниматься сегодня вечером?
```

**Объяснение:**
Are + you + going to + study? Вопрос о планах на вечер.

**Example 2:**

```

Is she going to come to the meeting?
Она собирается прийти на встречу?
```

**Объяснение:**
Is + she + going to + come? Вопрос о её намерениях.

**Example 3:**

```

Are they going to move to a new house?
Они собираются переехать в новый дом?
```

**Объяснение:**
Are + they + going to + move? Вопрос о их планах.

### 4.2 Специальные вопросы (Wh-questions)

**Формула:** Вопросительное слово + am/is/are + подлежащее + going to + глагол?

**Example 1: What (Что?)**

```

What are you going to do tomorrow?
Что ты собираешься делать завтра?
```

**Объяснение:**
What + are + you + going to + do? Вопрос о планах с вопросительным словом "что".

**Example 2: Where (Куда? Где?)**

```

Where is he going to work?
Где он будет работать?
```

**Объяснение:**
Where + is + he + going to + work? Вопрос о месте работы.

**Example 3: When (Когда?)**

```

When are they going to arrive?
Когда они собираются приехать?
```

**Объяснение:**
When + are + they + going to + arrive? Вопрос о времени.

**Example 4: Who (Кто?)**

```

Who is going to help you?
Кто собирается помочь тебе?
```

**Объяснение:**
Who + is + going to + help? Когда who — подлежащее, используем is.

**Example 5: Why (Почему?)**

```

Why are you going to leave?
Почему ты собираешься уходить?
```

**Объяснение:**
Why + are + you + going to + leave? Вопрос о причине.

**Example 6: How (Как?)**

```

How are you going to get there?
Как ты собираешься туда добраться?
```

**Объяснение:**
How + are + you + going to + get? Вопрос о способе.

### 4.3 Краткие ответы

**Example:**

```

Are you going to study English? 
Ты будешь изучать английский?

Yes, I am. / No, I'm not.
Да. / Нет.

Is she going to come?
Она придёт?

Yes, she is. / No, she isn't.
Да. / Нет.
```

**Объяснение:**
В кратких ответах используем am/is/are, как в вопросе. НЕ повторяем "going to" и глагол.

## 5. Использование going to в разных контекстах

### 5.1 Планы и намерения

**Example: Личные планы**

```

I'm going to learn French next year.
Я собираюсь изучать французский в следующем году.
```

**Объяснение:**
Это мой план, моё решение о будущем.

**Example: Карьерные планы**

```

She's going to become a doctor.
Она собирается стать врачом.
```

**Объяснение:**
Её намерение, цель на будущее.

### 5.2 Предсказания на основе очевидного

**Example: Погода**

```

Look at those dark clouds! It's going to rain.
Посмотри на эти тёмные тучи! Пойдёт дождь.
```

**Объяснение:**
Мы видим тучи (очевидный факт), поэтому предсказываем дождь.

**Example: Несчастный случай**

```

Be careful! You're going to fall!
Осторожно! Ты упадёшь!
```

**Объяснение:**
Мы видим, что человек теряет равновесие (очевидный факт), поэтому предсказываем падение.

**Example: Результат действий**

```

He's eating too much. He's going to be sick.
Он слишком много ест. Его стошнит.
```

**Объяснение:**
Видим, что он переедает, и предсказываем последствия.

### 5.3 Расписание событий

**Example: График на неделю**

```

What are you going to do this week?
Что ты собираешься делать на этой неделе?

On Monday, I'm going to meet my friend.
On Tuesday, I'm going to go to the gym.
On Wednesday, I'm going to study for my exam.
On Thursday, I'm going to visit my grandmother.
On Friday, I'm going to watch a movie.

В понедельник я встречусь с другом.
Во вторник я пойду в спортзал.
В среду я буду готовиться к экзамену.
В четверг я навещу бабушку.
В пятницу я посмотрю фильм.
```

**Объяснение:**
Перечисление планов на неделю. Каждое действие — запланировано.

## 6. Типичные ошибки русскоговорящих

### 6.1 Забывание "to be" (am/is/are)

❌ **Неправильно:** I going to study.
✅ **Правильно:** I am going to study.

❌ **Неправильно:** She going to work tomorrow.
✅ **Правильно:** She is going to work tomorrow.

**Объяснение:**
В русском языке мы говорим "Я собираюсь..." без глагола "быть", но в английском am/is/are обязательны.

### 6.2 Добавление лишнего "to" после going to

❌ **Неправильно:** I am going to to study.
✅ **Правильно:** I am going to study.

**Объяснение:**
После going to идёт инфинитив БЕЗ частицы to. "To" уже есть в "going to".

### 6.3 Неправильный порядок слов в вопросах

❌ **Неправильно:** You are going to study?
✅ **Правильно:** Are you going to study?

❌ **Неправильно:** What you are going to do?
✅ **Правильно:** What are you going to do?

**Объяснение:**
В вопросах am/is/are выносится перед подлежащим.

### 6.4 Использование will вместо going to для планов

❌ **Менее естественно:** I will study tomorrow. (когда это ваш план)
✅ **Более естественно:** I'm going to study tomorrow.

**Объяснение:**
Для планов и намерений более естественно использовать going to. Will чаще используется для спонтанных решений и обещаний (это вы изучите позже).

### 6.5 Путаница между going to (движение) и going to (будущее)

❌ **Неправильно:** I'm going to the cinema tomorrow to watch a movie. (смешение)
✅ **Правильно:** I'm going to go to the cinema tomorrow. (будущее)
✅ **Правильно:** I'm going to watch a movie at the cinema tomorrow. (будущее)

**Объяснение:**
Если хотите сказать о будущем походе в кино, используйте "going to go" или просто "going to watch" с указанием места.

### 6.6 Неправильная форма глагола to be

❌ **Неправильно:** They is going to come.
✅ **Правильно:** They are going to come.

❌ **Неправильно:** He are going to work.
✅ **Правильно:** He is going to work.

**Объяснение:**
Используйте правильную форму to be для каждого лица: I am, you are, he/she/it is, we/they are.

### 6.7 Неправильное использование в отрицании

❌ **Неправильно:** I am not go to study.
✅ **Правильно:** I am not going to study.

❌ **Неправильно:** She don't going to come.
✅ **Правильно:** She isn't going to come.

**Объяснение:**
Отрицание формируется добавлением not после am/is/are, а не через do/don't.

## 7. Going to vs. настоящее время

### 7.1 Различие между Present Continuous и going to

Иногда Present Continuous (am/is/are + глагол-ing) также используется для будущих планов, особенно когда время и место уже определены:

**Going to** — общие планы и намерения:
```

I'm going to study English. (план, но детали не определены)
Я собираюсь изучать английский.
```

**Present Continuous** — конкретные договорённости с деталями:
```

I'm meeting John at 5 o'clock. (конкретная встреча, время определено)
Я встречаюсь с Джоном в 5 часов.
```

**Оба варианта часто взаимозаменяемы:**
```

I'm going to meet John tomorrow. ✅
I'm meeting John tomorrow. ✅
```

## 8. Временные маркеры с going to

Часто с going to используются указатели времени для будущего:

**Tomorrow** (завтра):
```

I'm going to call you tomorrow.
Я позвоню тебе завтра.
```

**Next week/month/year** (на следующей неделе/в следующем месяце/году):
```

She's going to travel to Paris next month.
Она собирается поехать в Париж в следующем месяце.
```

**Tonight** (сегодня вечером):
```

We're going to watch a movie tonight.
Мы собираемся посмотреть фильм сегодня вечером.
```

**This weekend** (в эти выходные):
```

They're going to visit their parents this weekend.
Они собираются навестить родителей в эти выходные.
```

**Soon** (скоро):
```

It's going to rain soon.
Скоро пойдёт дождь.
```

**In the future** (в будущем):
```

I'm going to become a teacher in the future.
Я стану учителем в будущем.
```

## 9. Key Takeaways

✅ **Going to** используется для выражения планов, намерений и предсказаний на основе фактов.

✅ **Структура:** am/is/are + going to + глагол (без to).

✅ **Отрицание:** am/is/are + not + going to + глагол.

✅ **Вопрос:** Am/Is/Are + подлежащее + going to + глагол?

✅ **Обязательно** используйте am/is/are — нельзя сказать "I going to".

✅ **После going to** — инфинитив БЕЗ to (going to study, не going to to study).

✅ **Для планов** going to более естественно, чем will.

✅ **Различайте:** going to place (движение) и going to + verb (будущее время).

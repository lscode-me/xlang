## 1. Введение: мир нереализованных возможностей

### 1.1 Зачем говорить о том, чего не было?

В жизни мы часто размышляем о прошлом: что могли бы сделать иначе, о чем жалеем, какие возможности упустили. Английский язык имеет специальные конструкции для этих размышлений.

**Три ключевые конструкции:**

```
should have + V3  — сожаление, критика (надо было сделать, но не сделал)
could have + V3   — упущенная возможность (мог сделать, но не сделал)
would have + V3   — нереализованное намерение (сделал бы, но что-то помешало)
```

### 1.2 Основная идея

Все три конструкции говорят о действиях, которые **НЕ произошли** в прошлом, но могли бы произойти при других обстоятельствах.

```
┌─────────────────────────────────────────────────────────────────┐
│                    ПРОШЛОЕ                                      │
│                                                                 │
│   Что ПРОИЗОШЛО          vs        Что МОГЛО БЫ произойти      │
│   (реальность)                     (гипотетическая ситуация)   │
│                                                                 │
│   "I didn't study."                "I should have studied."    │
│   Я не учился.                     Мне надо было учиться.      │
│                                                                 │
│   "I didn't help."                 "I could have helped."      │
│   Я не помог.                      Я мог бы помочь.            │
│                                                                 │
│   "I didn't call."                 "I would have called."      │
│   Я не позвонил.                   Я бы позвонил.              │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 Формула

```
Subject + should/could/would + have + V3 (Past Participle)
```

**Ключевой момент:** Эти конструкции всегда относятся к **прошлому** и описывают **нереальную** (гипотетическую) ситуацию.

### 1.4 Эмоциональный контекст

| Конструкция | Эмоция | Пример |
|-------------|--------|--------|
| should have | Сожаление, критика | I should have listened. (Мне надо было слушать) |
| could have | Упущенная возможность | I could have won. (Я мог бы выиграть) |
| would have | Объяснение, оправдание | I would have helped. (Я бы помог) |

## 2. Should have + V3: сожаление и критика

### 2.1 Значение и использование

**Should have + V3** используется, когда говорящий считает, что действие было **правильным, разумным или необходимым**, но оно **НЕ было выполнено**.

**Формула:**

```
Subject + should have + V3
```

**Основные значения:**
1. **Сожаление о себе:** Мне надо было... (но я не сделал)
2. **Критика других:** Тебе/ему надо было... (но ты/он не сделал)
3. **Совет "задним числом":** Следовало бы... (но уже поздно)

### 2.2 Сожаление о собственных действиях

Когда мы жалеем о том, что не сделали что-то:

```
I should have studied harder for the exam.
Мне надо было больше готовиться к экзамену.
(Но я не готовился → результат плохой)

I should have listened to my parents.
Мне надо было слушать родителей.
(Но я не слушал → теперь понимаю, что они были правы)

I should have saved more money when I was young.
Мне надо было откладывать больше денег в молодости.
(Но я не откладывал → сейчас не хватает)

I should have been more careful.
Мне надо было быть осторожнее.
(Но я не был → что-то пошло не так)
```

### 2.3 Критика действий других людей

Когда мы критикуем кого-то за то, что он не сделал:

```
You should have told me earlier!
Тебе надо было сказать мне раньше!
(Но ты не сказал → теперь проблема)

She should have called the doctor immediately.
Ей надо было сразу вызвать врача.
(Но она не вызвала → ситуация ухудшилась)

They should have checked the weather forecast.
Им надо было проверить прогноз погоды.
(Но они не проверили → попали в шторм)

He should have apologized to her.
Ему надо было извиниться перед ней.
(Но он не извинился → они поссорились)
```

### 2.4 Should have been + V-ing (процесс)

Когда мы говорим о процессе, который должен был происходить:

```
You should have been paying attention in class.
Тебе надо было внимательно слушать на уроке.
(Но ты не слушал)

He should have been working, not watching TV.
Ему надо было работать, а не смотреть телевизор.
(Но он смотрел ТВ вместо работы)

They should have been preparing for the presentation.
Им надо было готовиться к презентации.
(Но они не готовились)
```

### 2.5 Should have been + прилагательное/существительное

```
I should have been more patient with her.
Мне надо было быть терпеливее с ней.

He should have been a better friend.
Ему надо было быть лучшим другом.

We should have been more careful about the details.
Нам надо было быть внимательнее к деталям.
```

### 2.6 Отрицательная форма: shouldn't have

**Shouldn't have + V3** выражает сожаление или критику за то, что было сделано (но не должно было быть):

```
I shouldn't have eaten so much.
Мне не надо было столько есть.
(Но я съел → теперь плохо)

You shouldn't have said that to her.
Тебе не надо было ей это говорить.
(Но ты сказал → обидел её)

She shouldn't have trusted him.
Ей не надо было ему доверять.
(Но она доверяла → он обманул)

We shouldn't have spent all our savings.
Нам не надо было тратить все сбережения.
(Но мы потратили → денег нет)
```

### 2.7 Типичные контексты использования

**После неудачи:**

```
I failed the test. I should have studied more.
Я провалил тест. Надо было больше учиться.
```

**После конфликта:**

```
We had a big fight. I shouldn't have raised my voice.
Мы сильно поругались. Мне не надо было повышать голос.
```

**После потери:**

```
I lost my job. I should have worked harder.
Я потерял работу. Надо было усерднее работать.
```

**После упущенной возможности:**

```
They sold the company. We should have invested earlier.
Они продали компанию. Нам надо было инвестировать раньше.
```

## 3. Could have + V3: упущенные возможности

### 3.1 Значение и использование

**Could have + V3** используется, когда говорящий указывает на **возможность**, которая существовала в прошлом, но **не была реализована**.

**Формула:**

```
Subject + could have + V3
```

**Основные значения:**
1. **Упущенная возможность:** Я мог бы... (но не сделал)
2. **Нереализованная способность:** У меня была возможность... (но я её не использовал)
3. **Альтернативный вариант:** Можно было бы... (но выбрали другое)

### 3.2 Упущенные возможности

```
I could have helped you, but you didn't ask.
Я мог бы тебе помочь, но ты не попросил.
(Возможность была, но не использована)

She could have become a doctor, but she chose art instead.
Она могла бы стать врачом, но выбрала искусство.
(Способности были, но выбор был другим)

We could have won the game if we had played better.
Мы могли бы выиграть игру, если бы играли лучше.
(Возможность победы была, но не реализована)

They could have arrived on time, but they left too late.
Они могли бы приехать вовремя, но выехали слишком поздно.
(Могли успеть, но не успели)
```

### 3.3 Нереализованные способности

```
He could have been a great musician. He was so talented.
Он мог бы стать великим музыкантом. Он был таким талантливым.
(Талант был, но не развит)

You could have learned Chinese when you lived in Beijing.
Ты мог бы выучить китайский, когда жил в Пекине.
(Возможность была, но не использована)

She could have made millions with her invention.
Она могла бы заработать миллионы на своем изобретении.
(Потенциал был, но не реализован)
```

### 3.4 Альтернативные варианты

```
We could have taken the train instead of driving.
Мы могли бы поехать на поезде вместо машины.
(Был выбор, выбрали другое)

You could have asked me — I would have told you.
Ты мог бы спросить меня — я бы тебе сказал.
(Вариант был, но не использован)

They could have stayed at a hotel, but they preferred camping.
Они могли бы остановиться в отеле, но предпочли кемпинг.
(Альтернатива была)
```

### 3.5 Could have been + V-ing

```
I could have been sleeping instead of working.
Я мог бы спать вместо того, чтобы работать.

She could have been traveling the world by now.
Она могла бы сейчас путешествовать по миру.

We could have been living in a bigger house.
Мы могли бы жить в доме побольше.
```

### 3.6 Отрицательная форма: couldn't have

**Couldn't have + V3** в контексте нереализованных действий означает **невозможность** сделать что-то:

```
I couldn't have finished without your help.
Я не смог бы закончить без твоей помощи.
(Было бы невозможно)

She couldn't have known about the surprise.
Она не могла знать о сюрпризе.
(Было невозможно узнать)

We couldn't have done it better.
Мы не могли бы сделать это лучше.
(Лучше было невозможно)
```

### 3.7 Критика с could have

**Could have** также используется для **мягкой критики** (менее резкой, чем should have):

```
You could have told me! (= Why didn't you tell me?)
Ты мог бы мне сказать! (Почему не сказал?)

She could have at least said thank you.
Она могла бы хотя бы сказать спасибо.

They could have been more considerate.
Они могли бы быть внимательнее.
```

### 3.8 Разница между should have и could have

| should have | could have |
|-------------|------------|
| Это было правильно/необходимо | Это было возможно |
| Моральная/логическая обязанность | Наличие возможности/способности |
| Более сильная критика | Более мягкое указание |

```
You should have called me. (Это было правильно/необходимо)
Тебе надо было мне позвонить.

You could have called me. (У тебя была возможность)
Ты мог бы мне позвонить.
```

## 4. Would have + V3: нереализованные намерения

### 4.1 Значение и использование

**Would have + V3** используется, когда говорящий хотел или собирался что-то сделать, но **обстоятельства помешали**.

**Формула:**

```
Subject + would have + V3
```

**Основные значения:**
1. **Нереализованное намерение:** Я бы сделал... (но что-то помешало)
2. **Условный результат:** Если бы..., то я бы...
3. **Объяснение/оправдание:** Я бы..., но...

### 4.2 Нереализованные намерения

```
I would have called you, but my phone died.
Я бы тебе позвонил, но телефон сел.
(Намерение было, но обстоятельства помешали)

She would have helped, but she was too busy.
Она бы помогла, но была слишком занята.
(Хотела помочь, но не могла)

We would have come to the party, but we were sick.
Мы бы пришли на вечеринку, но мы болели.
(Хотели прийти, но не могли)

He would have told you the truth, but he was afraid.
Он бы рассказал тебе правду, но он боялся.
(Хотел сказать, но страх помешал)
```

### 4.3 В условных предложениях (Third Conditional)

**Would have** часто используется в условных предложениях третьего типа:

```
If I had known, I would have helped.
Если бы я знал, я бы помог.

If she had studied harder, she would have passed.
Если бы она больше училась, она бы сдала.

If they had arrived earlier, they would have seen the show.
Если бы они приехали раньше, они бы увидели шоу.

If we had had more time, we would have visited more places.
Если бы у нас было больше времени, мы бы посетили больше мест.
```

### 4.4 Would have been + V-ing

```
I would have been waiting for you, but I got the wrong time.
Я бы тебя ждал, но перепутал время.

She would have been working here by now if she had accepted the offer.
Она бы сейчас здесь работала, если бы приняла предложение.

We would have been celebrating if we had won.
Мы бы праздновали, если бы выиграли.
```

### 4.5 Would have been + прилагательное

```
It would have been nice to see you.
Было бы приятно тебя увидеть.

That would have been wonderful!
Это было бы замечательно!

Life would have been different if we had stayed.
Жизнь была бы другой, если бы мы остались.
```

### 4.6 Отрицательная форма: wouldn't have

**Wouldn't have + V3** выражает то, что человек **не сделал бы** что-то при определенных условиях:

```
I wouldn't have said that if I had known.
Я бы этого не сказал, если бы знал.

She wouldn't have gone without you.
Она бы не пошла без тебя.

We wouldn't have succeeded without your support.
Мы бы не добились успеха без твоей поддержки.

They wouldn't have believed it anyway.
Они бы всё равно не поверили.
```

### 4.7 Объяснения и оправдания

**Would have** часто используется для объяснения, почему что-то не было сделано:

```
A: Why didn't you come to my party?
B: I would have come, but I had to work.

A: Почему ты не пришёл на мою вечеринку?
B: Я бы пришёл, но мне пришлось работать.

A: Why didn't you tell me earlier?
B: I would have told you, but I couldn't reach you.

A: Почему ты не сказал раньше?
B: Я бы сказал, но не мог до тебя дозвониться.
```

### 4.8 Сравнение would have и could have

| would have | could have |
|------------|------------|
| Желание/намерение | Возможность/способность |
| "Я хотел/собирался" | "У меня была возможность" |
| Объясняет, почему не сделал | Указывает на альтернативу |

```
I would have helped. (Я хотел помочь)
I could have helped. (У меня была возможность помочь)

She would have come. (Она собиралась прийти)
She could have come. (Она могла прийти)
```

## 5. Сравнение трех конструкций

### 5.1 Сравнительная таблица

| Конструкция | Значение | Эмоция | Пример |
|-------------|----------|--------|--------|
| should have | Надо было (но не сделал) | Сожаление, критика | I should have studied. |
| could have | Мог бы (но не сделал) | Упущенная возможность | I could have won. |
| would have | Сделал бы (но помешало) | Объяснение, оправдание | I would have called. |

### 5.2 Одна ситуация — три перспективы

**Ситуация:** Вы опоздали на важную встречу.

```
SHOULD HAVE (сожаление/самокритика):
I should have left home earlier.
Мне надо было выйти из дома раньше.
(Это было бы правильно)

COULD HAVE (упущенная возможность):
I could have taken a taxi instead of the bus.
Я мог бы взять такси вместо автобуса.
(У меня была такая возможность)

WOULD HAVE (объяснение):
I would have arrived on time, but there was an accident on the road.
Я бы приехал вовремя, но на дороге была авария.
(Я хотел приехать вовремя, но обстоятельства помешали)
```

### 5.3 Практическое сравнение

**Ситуация:** Ваш друг не сдал экзамен.

```
Критика (should have):
You should have prepared better.
Тебе надо было лучше подготовиться.

Альтернатива (could have):
You could have asked me for help.
Ты мог бы попросить меня о помощи.

Сочувствие (would have):
I would have helped you if you had asked.
Я бы тебе помог, если бы ты попросил.
```

### 5.4 Визуальная схема

```
┌─────────────────────────────────────────────────────────────────┐
│                      НЕРЕАЛИЗОВАННЫЕ ДЕЙСТВИЯ                   │
│                                                                 │
│   SHOULD HAVE        COULD HAVE         WOULD HAVE              │
│   (надо было)        (мог бы)           (сделал бы)             │
│        │                 │                   │                  │
│        ▼                 ▼                   ▼                  │
│   Сожаление        Упущенная           Намерение               │
│   Критика          возможность         + препятствие           │
│        │                 │                   │                  │
│        ▼                 ▼                   ▼                  │
│   "Это было           "Была               "Я хотел,            │
│    правильно"          возможность"        но..."              │
└─────────────────────────────────────────────────────────────────┘
```

## 6. Комбинации и сложные случаи

### 6.1 Комбинация в одном предложении

```
I should have called, and I would have, but my phone was dead.
Мне надо было позвонить, и я бы позвонил, но телефон сел.

You could have told me — I would have understood.
Ты мог бы мне сказать — я бы понял.

She should have listened to us. She could have avoided this.
Ей надо было нас послушать. Она могла бы избежать этого.
```

### 6.2 В условных предложениях

**Third Conditional (Type 3):**

```
If + Past Perfect, would/could/might have + V3

If I had known about the party, I would have come.
Если бы я знал о вечеринке, я бы пришёл.

If she had asked, I could have helped her.
Если бы она попросила, я мог бы ей помочь.

If we had left earlier, we would have caught the train.
Если бы мы вышли раньше, мы бы успели на поезд.
```

### 6.3 Mixed Conditionals

Иногда условие относится к прошлому, а результат — к настоящему:

```
If I had studied medicine, I would be a doctor now.
Если бы я изучал медицину, я бы сейчас был врачом.

If she had accepted the job, she wouldn't be unemployed now.
Если бы она приняла работу, она бы сейчас не была безработной.
```

### 6.4 Усиление с наречиями

```
I really should have listened to you.
Мне действительно надо было тебя послушать.

You definitely could have done better.
Ты определённо мог бы сделать лучше.

He certainly would have helped if he had known.
Он точно бы помог, если бы знал.
```

### 6.5 С вопросительными словами

```
What should I have done differently?
Что мне надо было сделать по-другому?

Where could we have gone instead?
Куда мы могли бы пойти вместо этого?

How would you have reacted?
Как бы ты отреагировал?

Why shouldn't I have said that?
Почему мне не надо было это говорить?
```

## 7. Образование форм: детальный разбор

### 7.1 Утвердительные формы

```
Should have + V3:
I should have gone.
You should have told me.
He/She should have known.
We should have prepared.
They should have waited.

Could have + V3:
I could have helped.
You could have called.
He/She could have won.
We could have stayed.
They could have come.

Would have + V3:
I would have come.
You would have liked it.
He/She would have helped.
We would have enjoyed it.
They would have understood.
```

### 7.2 Отрицательные формы

```
Shouldn't have + V3:
I shouldn't have said that.
You shouldn't have worried.
She shouldn't have trusted him.

Couldn't have + V3:
I couldn't have done it without you.
She couldn't have known.
They couldn't have arrived earlier.

Wouldn't have + V3:
I wouldn't have gone anyway.
He wouldn't have believed you.
We wouldn't have minded.
```

### 7.3 Вопросительные формы

```
Should + subject + have + V3?
Should I have called earlier?
Should we have told them?

Could + subject + have + V3?
Could you have done it differently?
Could they have arrived on time?

Would + subject + have + V3?
Would you have helped me?
Would she have come to the party?
```

### 7.4 Сокращенные формы

```
should have → should've [ʃʊdəv]
could have → could've [kʊdəv]
would have → would've [wʊdəv]

I should've known.
You could've told me.
He would've helped.

should not have → shouldn't have [ʃʊdntəv]
could not have → couldn't have [kʊdntəv]
would not have → wouldn't have [wʊdntəv]
```

**Важно:** "should of", "could of", "would of" — это **ОШИБКИ**!

```
❌ I should of called.
✅ I should've called.
✅ I should have called.
```

## 8. Типичные ошибки и как их избежать

### 8.1 Ошибка: Использование V2 вместо V3

❌ **Неправильно:**

```
I should have went there.
She could have saw the problem.
He would have took the job.
```

✅ **Правильно:**

```
I should have gone there.
Мне надо было туда пойти.

She could have seen the problem.
Она могла бы увидеть проблему.

He would have taken the job.
Он бы взял эту работу.
```

### 8.2 Ошибка: Пропуск have

❌ **Неправильно:**

```
You should called me.
I could helped you.
She would come.
```

✅ **Правильно:**

```
You should have called me.
Тебе надо было мне позвонить.

I could have helped you.
Я мог бы тебе помочь.

She would have come.
Она бы пришла.
```

### 8.3 Ошибка: "should of" вместо "should have"

❌ **Неправильно:**

```
I should of studied.
You could of told me.
We would of helped.
```

✅ **Правильно:**

```
I should have studied.
You could have told me.
We would have helped.
```

### 8.4 Ошибка: Неправильный порядок слов в вопросах

❌ **Неправильно:**

```
What I should have done?
Why you would have said that?
How she could have known?
```

✅ **Правильно:**

```
What should I have done?
Что мне надо было сделать?

Why would you have said that?
Почему бы ты это сказал?

How could she have known?
Как она могла узнать?
```

### 8.5 Ошибка: Путаница should have и must have

```
should have = надо было сделать (но не сделал) — нереализованное действие
must have = должно быть, сделал — предположение о прошлом

She should have studied harder. (Ей надо было больше учиться — но не учила)
She must have studied hard. (Она, должно быть, много училась — предположение)
```

### 8.6 Ошибка: Использование would без условия

**Would have** часто требует контекста или условия:

❌ **Неясно:**

```
I would have helped. (Почему? При каких условиях?)
```

✅ **Понятно:**

```
I would have helped, but I was busy.
I would have helped if you had asked.
```

## 9. Практические контексты использования

### 9.1 Ретроспективный анализ

```
Looking back, I should have made different choices. I could have 
gone to university, but I decided to work instead. I would have 
had better opportunities if I had gotten a degree. But at the 
time, I didn't realize how important education was.

Оглядываясь назад, мне надо было сделать другой выбор. Я мог 
бы пойти в университет, но решил работать. У меня были бы 
лучшие возможности, если бы я получил диплом. Но тогда я не 
понимал, как важно образование.
```

### 9.2 Обсуждение ошибок на работе

```
Manager: The project failed. What went wrong?

Employee: We should have started planning earlier. We could 
have hired more people, but the budget was limited. I would 
have asked for an extension, but I thought we could manage.

Manager: You should have communicated these problems sooner.
We could have found solutions together.

---

Менеджер: Проект провалился. Что пошло не так?

Сотрудник: Нам надо было начать планировать раньше. Мы могли 
бы нанять больше людей, но бюджет был ограничен. Я бы попросил 
продление, но думал, что справимся.

Менеджер: Тебе надо было сообщить об этих проблемах раньше.
Мы могли бы вместе найти решения.
```

### 9.3 Личные отношения

```
A: I'm so sorry about what happened.

B: You should have been honest with me from the beginning. 
   You could have just told me the truth. I would have 
   understood.

A: I know. I shouldn't have lied. I was scared of your 
   reaction. I would have told you everything, but I 
   didn't know how.

---

A: Мне так жаль о том, что произошло.

B: Тебе надо было быть честным с самого начала. Ты мог 
   бы просто сказать мне правду. Я бы понял.

A: Я знаю. Мне не надо было врать. Я боялся твоей 
   реакции. Я бы рассказал тебе всё, но не знал как.
```

### 9.4 Спортивные комментарии

```
The team lost the championship, but they could have won. 
The coach should have made substitutions earlier. The 
striker should have passed the ball instead of shooting. 
If the goalkeeper hadn't been injured, they would have 
won easily.

Команда проиграла чемпионат, но могла победить. Тренеру 
надо было сделать замены раньше. Нападающему надо было 
отдать пас вместо удара. Если бы вратарь не травмировался, 
они бы легко выиграли.
```

### 9.5 Исторические размышления

```
What if events had gone differently? The war could have 
been avoided if the leaders had communicated better. They 
should have sought peaceful solutions. Many lives would 
have been saved.

Что если бы события развивались иначе? Войны можно было 
избежать, если бы лидеры лучше общались. Им надо было 
искать мирные решения. Многие жизни были бы спасены.
```

### 9.6 Повседневные ситуации

**Потерянные вещи:**

```
I can't find my keys!
— You should have put them in the same place every time.
— You could have used a key finder app.
— I would have helped you look, but I have to leave now.
```

**Опоздание:**

```
Why are you late?
— I should have set my alarm earlier.
— I could have taken a taxi, but I didn't have cash.
— I would have been on time if the bus hadn't been delayed.
```

**Плохое решение:**

```
I bought the wrong size!
— You should have tried it on first.
— You could have checked the size chart online.
— I would have warned you, but you didn't ask me.
```

## 10. Эмоциональные оттенки и интонация

### 10.1 Выражение сильного сожаления

```
I really should have listened to you.
Мне действительно надо было тебя послушать.

I never should have said those things.
Мне никогда не надо было говорить такое.

If only I had known! I would have done everything differently.
Если бы только я знал! Я бы всё сделал по-другому.
```

### 10.2 Выражение разочарования

```
You could at least have called!
Ты мог бы хотя бы позвонить!

She should have known better.
Ей надо было лучше соображать.

They could have tried harder.
Они могли бы больше постараться.
```

### 10.3 Выражение облегчения (отрицательная форма)

```
Thank goodness I didn't go. It would have been a disaster!
Слава богу, я не пошёл. Это была бы катастрофа!

I'm glad I didn't say anything. I shouldn't have interfered.
Я рад, что ничего не сказал. Мне не надо было вмешиваться.
```

### 10.4 Смягчение критики

Сравните силу критики:

```
Сильная критика:
You should have told me! (Тебе НАДО было мне сказать!)

Мягче:
You could have told me. (Ты МОГ бы мне сказать.)

Ещё мягче:
It would have been nice if you had told me.
(Было бы неплохо, если бы ты мне сказал.)
```

## 11. Особые случаи и нюансы

### 11.1 Could have = might have (предположение)

**Could have** иногда используется для предположений (как might have):

```
Where's John? — He could have gone home. (= He might have gone home)
Где Джон? — Возможно, он ушёл домой.
```

**Контекст определяет значение:**

```
A: Why didn't John come?
B: He could have had other plans. (= might have — предположение)
   Возможно, у него были другие планы.

A: John had such potential!
B: Yes, he could have been a great leader. (упущенная возможность)
   Да, он мог бы стать великим лидером.
```

### 11.2 Would have в вежливых конструкциях

```
I would have thought you knew. (Я бы подумал, что ты знаешь)
= I'm surprised you don't know

I would have expected better service. (Я бы ожидал лучшего сервиса)
= I'm disappointed with the service
```

### 11.3 Needn't have vs Didn't need to

```
needn't have + V3 = сделал, но не надо было
didn't need to = не нужно было (и возможно не делал)

I needn't have worried. (Мне не надо было волноваться — но я волновался)
I didn't need to worry. (Мне не нужно было волноваться — неясно, волновался ли)
```

### 11.4 Was/Were supposed to vs Should have

```
I was supposed to call her. (По плану/договоренности)
Я должен был ей позвонить.

I should have called her. (Это было бы правильно)
Мне надо было ей позвонить.
```

### 12.1 Полная таблица форм

|-------------|-------------|-----------|--------|

| could have | I could have done | I couldn't have done | Could I have done? |

### 12.2 Быстрая справка по значениям

| Конструкция | Ключевое значение | Русский эквивалент |
|-------------|-------------------|-------------------|
| should have + V3 | Сожаление, критика | Надо было / Следовало |
| shouldn't have + V3 | Не надо было делать | Не надо было |
| could have + V3 | Упущенная возможность | Мог бы |
| couldn't have + V3 | Невозможность | Не мог бы |
| would have + V3 | Нереализованное намерение | Сделал бы |
| wouldn't have + V3 | Не сделал бы | Не стал бы |

### 12.3 Когда использовать какую конструкцию

| Ситуация | Конструкция | Пример |
|----------|-------------|--------|
| Критика за несделанное | should have | You should have studied. |
| Критика за сделанное | shouldn't have | You shouldn't have lied. |
| Упущенная возможность | could have | I could have helped. |
| Невозможность | couldn't have | I couldn't have known. |
| Намерение + препятствие | would have | I would have come, but... |
| Условный результат | would have | If I had known, I would have... |

## 💡 Key Takeaways

- **Should have + V3** выражает сожаление или критику: "I should have studied" (мне надо было учиться)
- **Could have + V3** указывает на упущенную возможность: "I could have helped" (я мог бы помочь)
- **Would have + V3** описывает нереализованное намерение: "I would have called" (я бы позвонил)
- Все три конструкции говорят о действиях, которые **НЕ произошли** в прошлом
- "Should of", "could of", "would of" — это **ОШИБКИ**; правильно: should've, could've, would've
- Контекст и эмоция помогают выбрать правильную конструкцию

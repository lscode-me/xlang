## 1. Выражение ограничения времени

### 1.1 Форма -ene kadar / -inceye kadar

**Пример: Ограничение времени**

```
Eve gelene kadar bekle.
Жди, пока не придешь домой (буквально: до твоего прихода домой жди).
```

**Объяснение:**
-ene kadar используется для выражения ограничения времени — действие продолжается до момента выполнения другого действия. kadar означает "до" или "пока не".

**Пример: Другой случай**

```
İş bitinceye kadar çalışacağız.
Мы будем работать, пока не закончим работу (буквально: до окончания работы мы будем работать).
```

**Объяснение:**
-inceye kadar выражает ограничение времени — работа продолжается до момента окончания.

---

## 2. Образование форм

### 2.1 Правило образования

**Формула:**

```
Глагол в форме -ene/-inceye + kadar
```

**Шаги образования:**

1. Берем основу глагола
2. Добавляем форму -ene/-inceye (с учетом гармонии гласных)
3. Добавляем kadar

**Пример: Процесс образования**

```
Глагол: gelmek (приходить)
Шаг 1: Основа - gel-
Шаг 2: Добавляем -ene → gelene
Шаг 3: Добавляем kadar → gelene kadar
Результат: Eve gelene kadar bekle.
Жди, пока не придешь домой.
```

**Объяснение:**
Образование формы ограничения происходит в три этапа: основа → форма -ene/-inceye → kadar.

### 2.2 Таблица форм

**Таблица образования:**

| Последняя гласная | Форма | Пример |
|------------------|-------|--------|
| a, ı | -ana kadar | çalışana kadar |
| e, i | -ene kadar | gelene kadar |
| o, u | -una kadar | okuna kadar |
| ö, ü | -üne kadar | görüne kadar |

**Пример: Для разных глаголов**

```
gelmek → gelene kadar
çalışmak → çalışana kadar
okumak → okuna kadar
görmek → görüne kadar
```

**Объяснение:**
Выбор формы зависит от последней гласной основы глагола.

## 3. Детальное изучение форм

### 3.1 Форма -ene kadar

**Пример: С разными глаголами**

```
Eve gelene kadar bekle.
Жди, пока не придешь домой.

İş bitinceye kadar çalışacağız.
Мы будем работать, пока не закончим работу.

Yağmur durana kadar bekledik.
Мы ждали, пока не перестал дождь.

Ali gelene kadar bekleyeceğiz.
Мы будем ждать, пока не придет Али.
```

**Объяснение:**
-ene kadar используется для выражения ограничения времени с различными глаголами.

### 3.2 Форма -inceye kadar

**Пример: С формой -inceye**

```
İş bitinceye kadar çalışacağız.
Мы будем работать, пока не закончим работу.

Yağmur duruncaya kadar bekledik.
Мы ждали, пока не перестал дождь.

Ali gelinceye kadar bekleyeceğiz.
Мы будем ждать, пока не придет Али.
```

**Объяснение:**
-inceye kadar используется для выражения ограничения времени, альтернативная форма -ene kadar.

### 3.3 Сравнение форм

**Пример: Сравнение**

```
Eve gelene kadar bekle. (-ene kadar)
Жди, пока не придешь домой.

Eve gelinceye kadar bekle. (-inceye kadar)
Жди, пока не придешь домой.
```

**Объяснение:**
Обе формы (-ene kadar и -inceye kadar) выражают одно и то же значение ограничения времени.

## 4. Практические примеры

### 4.1 Пример: Разные контексты

```
Eve gelene kadar bekle. (до прихода)
Жди, пока не придешь домой.

İş bitinceye kadar çalışacağız. (до окончания)
Мы будем работать, пока не закончим работу.

Yağmur durana kadar bekledik. (до остановки)
Мы ждали, пока не перестал дождь.

Ali gelene kadar bekleyeceğiz. (до прихода Али)
Мы будем ждать, пока не придет Али.
```

**Объяснение:**
В этом примере показано использование форм ограничения времени в разных контекстах.

### 4.2 Пример: Реальные ситуации

**Пример: Разговор о времени**

```
Eve gelene kadar bekle.
Жди, пока не придешь домой.

İş bitinceye kadar çalışacağız.
Мы будем работать, пока не закончим работу.

Yağmur durana kadar bekledik.
Мы ждали, пока не перестал дождь.
```

**Объяснение:**
Формы ограничения времени используются в реальных ситуациях для выражения длительности действия.

**Пример: Разговор о планах**

```
Ali gelene kadar bekleyeceğiz.
Мы будем ждать, пока не придет Али.

İş bitinceye kadar çalışacağız.
Мы будем работать, пока не закончим работу.

Yemek hazır olana kadar bekleyelim.
Давайте подождем, пока не будет готово еда.
```

**Объяснение:**
Формы ограничения времени используются для выражения планов и намерений.

### 4.3 Пример: Сложные предложения

```
Eve gelene kadar bekle, ama çok geç kalma.
Жди, пока не придешь домой, но не опаздывай слишком.

İş bitinceye kadar çalışacağız, sonra dinleneceğiz.
Мы будем работать, пока не закончим работу, потом отдохнем.
```

**Объяснение:**
Формы ограничения могут использоваться в сложных предложениях.

## 6. Частые ошибки

### 6.1 Ошибка: Неправильная форма

❌ **Неправильно:**

```
Gelince kadar bekle. (неправильно)
Жди, пока не придешь.
```

✅ **Правильно:**

```
Gelene kadar bekle. (правильно)
Жди, пока не придешь домой.
```

**Объяснение:**
Нужно использовать форму -ene kadar, а не -ince kadar.

### 6.2 Ошибка: Неправильное использование kadar

❌ **Неправильно:**

```
Gelene bekle. (неправильно - нет kadar)
Жди, пока не придешь.
```

✅ **Правильно:**

```
Gelene kadar bekle. (правильно)
Жди, пока не придешь домой.
```

**Объяснение:**
Для выражения ограничения времени обязательно нужно использовать kadar после формы -ene/-inceye.

### 6.3 Ошибка: Неправильная форма глагола

❌ **Неправильно:**

```
Gelinceye kadar bekle. (неправильно для некоторых глаголов)
Жди, пока не придешь.
```

✅ **Правильно:**

```
Gelene kadar bekle. (правильно)
Жди, пока не придешь домой.
```

**Объяснение:**
Нужно использовать правильную форму в зависимости от глагола и контекста.

## 7. Дополнительные примеры и практика

### 7.1 Пример: Полный разбор предложения

**Разберем предложение:**

```
Eve gelene kadar bekle.
Жди, пока не придешь домой.
```

**Разбор:**
- `Eve` — домой (дательный падеж)
- `gel-` — приходить (основа глагола)
- `gelene` — пока не придешь (форма ограничения)
- `kadar` — до/пока не (союз ограничения)
- `bekle` — жди (повелительное наклонение)

**Объяснение:**
В этом предложении "пока не придешь домой" выражается через форму -ene kadar.

### 7.2 Пример: Практические упражнения

**Упражнение 1: Образуйте форму ограничения**

```
gelmek → gelene kadar
çalışmak → çalışana kadar
okumak → okuna kadar
bitirmek → bitirene kadar
```

**Объяснение:**
Практикуйтесь в образовании форм ограничения времени от различных глаголов.

**Упражнение 2: Составьте предложения**

```
Eve gelmek → Eve gelene kadar bekle.
İş bitirmek → İş bitinceye kadar çalışacağız.
```

**Объяснение:**
Практикуйтесь в составлении предложений с формами ограничения времени.

## 💡 Key Takeaways

- **Ограничение времени**: Выражается через -ene kadar / -inceye kadar

- **Длительность**: Действие продолжается до выполнения другого действия
- **Гармония гласных**: Выбор формы зависит от последней гласной
- **Основа понимания**: Понимание ограничения времени необходимо для уровня B1

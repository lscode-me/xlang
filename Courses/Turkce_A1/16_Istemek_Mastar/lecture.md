## 1. Что такое конструкция istemek + инфинитив

Конструкция "istemek + инфинитив" в турецком языке используется для выражения желания сделать что-то. Это одна из самых частых конструкций в повседневной речи, которая позволяет выражать намерения и планы.

### 1.1 Основная функция

Конструкция используется для:

- Выражения желания сделать что-то
- Обсуждения планов и намерений
- Вопросов о желаниях других людей
- Выражения предпочтений в действиях

**Пример: Базовое использование**

```

Kahve içmek istiyorum. [Кахве ичмек истийорум] - Я хочу пить кофе.
Evde kalmak istiyorum. [Эвде калмак истийорум] - Я хочу остаться дома.
```

**Объяснение:**
Инфинитив стоит перед глаголом "istemek", который спрягается по лицам в настоящем времени.

---

## 2. Структура конструкции

### 2.1 Формула конструкции

**Структура:**

```

Инфинитив + istemek (в нужной форме)
```

**Пример: Базовое использование**

```

çalışmak + istiyorum = çalışmak istiyorum [чалышмак истийорум] - я хочу работать
okumak + istiyorsun = okumak istiyorsun [окумак истийорсун] - ты хочешь читать
gitmek + istiyor = gitmek istiyor [гитмек истийор] - он/она хочет идти
```

**Объяснение:**
Инфинитив всегда стоит перед глаголом "istemek", который изменяется по лицам.

### 2.2 Порядок слов

**Важно:** Порядок слов в конструкции фиксированный.

**Пример: Правильный порядок**

```

✅ Инфинитив + istemek
Kahve içmek istiyorum. [Кахве ичмек истийорум] - Я хочу пить кофе.

❌ Неправильный порядок:
İstiyorum kahve içmek (неправильно)
```

**Объяснение:**
Инфинитив всегда стоит перед "istemek", порядок слов нельзя менять.

---

## 3. Спряжение istemek

### 3.1 Формы istemek в настоящем времени

**Таблица:**

| Лицо | Форма | Пример |
|------|-------|--------|
| ben | istiyorum | Kahve içmek istiyorum |
| sen | istiyorsun | Kahve içmek istiyorsun |
| o | istiyor | Kahve içmek istiyor |
| biz | istiyoruz | Kahve içmek istiyoruz |
| siz | istiyorsunuz | Kahve içmek istiyorsunuz |
| onlar | istiyorlar | Kahve içmek istiyorlar |

**Пример: Для всех лиц**

```

Ben kitap okumak istiyorum. [Бен китап окумак истийорум] - Я хочу читать книгу.
Sen evde kalmak istiyorsun. [Сен эвде калмак истийорсун] - Ты хочешь остаться дома.
O gitmek istiyor. [О гитмек истийор] - Он/Она хочет идти.
Biz çalışmak istiyoruz. [Биз чалышмак истийоруз] - Мы хотим работать.
Siz okumak istiyorsunuz. [Сиз окумак истийорсунuz] - Вы хотите читать.
Onlar yemek yemek istiyorlar. [Онлар йемек йемек истийорлар] - Они хотят есть.
```

**Объяснение:**
Глагол "istemek" спрягается по лицам в настоящем продолженном времени (-yor), а инфинитив остается неизменным.

## 4. Практические примеры

### 4.1 Пример: Выражение желаний

**Пример: Разные желания**

```

Ben yemek yemek istiyorum. [Бен йемек йемек истийорум] - Я хочу есть.
Sen ne yapmak istiyorsun? [Сен не япмак истийорсун?] - Что ты хочешь делать?
O uyumak istiyor. [О уйумак истийор] - Он/Она хочет спать.
Biz çalışmak istiyoruz. [Биз чалышмак истийоруз] - Мы хотим работать.
```

**Объяснение:**
Конструкция используется для выражения различных желаний и намерений.

### 4.2 Пример: Вопросы о желаниях

**Диалог:**

```

A: Ne yapmak istiyorsun? [Не япмак истийорсун?] - Что ты хочешь делать?
B: Ben çalışmak istiyorum. [Бен чалышмак истийорум] - Я хочу работать.

A: Nereye gitmek istiyorsun? [Нерейе гитмек истийорсун?] - Куда ты хочешь идти?
B: Ben evde kalmak istiyorum. [Бен эвде калмак истийорум] - Я хочу остаться дома.

A: Ne içmek istiyorsun? [Не ичмек истийорсун?] - Что ты хочешь пить?
B: Ben kahve içmek istiyorum. [Бен кахве ичмек истийорум] - Я хочу пить кофе.
```

**Объяснение:**
Вопросы о желаниях строятся с помощью вопросительных слов (ne, nereye) и конструкции istemek + инфинитив.

### 4.3 Пример: С обстоятельствами

**Пример: С обстоятельствами места и времени**

```

Ben bugün evde kalmak istiyorum. [Бен бугюн эвде калмак истийорум] - Я сегодня хочу остаться дома.
Sen yarın okula gitmek istiyorsun. [Сен яран окула гитмек истийорсун] - Ты завтра хочешь идти в школу.
O şimdi yemek yemek istiyor. [О шимди йемек йемек истийор] - Он/Она сейчас хочет есть.
```

**Объяснение:**
Обстоятельства места и времени могут добавляться в предложения с конструкцией istemek + инфинитив.

## 5. Особые случаи

### 5.1 С отрицанием

**Пример: Отрицательные желания**

```

Ben gitmek istemiyorum. [Бен гитмек истимийорум] - Я не хочу идти.
Sen çalışmak istemiyorsun. [Сен чалышмак истимийорсун] - Ты не хочешь работать.
O okumak istemiyor. [О окумак истимийор] - Он/Она не хочет читать.
```

**Объяснение:**
Отрицание добавляется к глаголу "istemek" с помощью частицы -me/-ma, инфинитив остается без изменений.

### 5.2 В вопросах

**Пример: Вопросы**

```

Ne yapmak istiyorsun? [Не япмак истийорсун?] - Что ты хочешь делать?
Nereye gitmek istiyorsun? [Нерейе гитмек истийорсун?] - Куда ты хочешь идти?
Ne içmek istiyorsun? [Не ичмек истийорсун?] - Что ты хочешь пить?
```

**Объяснение:**
В вопросах порядок слов сохраняется, вопросительные слова ставятся перед инфинитивом.

### 5.3 С дополнениями

**Пример: С дополнениями**

```

Ben kitap okumak istiyorum. [Бен китап окумак истийорум] - Я хочу читать книгу.
Sen kahve içmek istiyorsun. [Сен кахве ичмек истийорсун] - Ты хочешь пить кофе.
O yemek yemek istiyor. [О йемек йемек истийор] - Он/Она хочет есть еду.
Biz müzik dinlemek istiyoruz. [Биз мюзик динлемек истийоруз] - Мы хотим слушать музыку.
Siz film izlemek istiyorsunuz. [Сиз фильм излемек истийорсунuz] - Вы хотите смотреть фильм.
```

**Объяснение:**
Дополнения (существительные) могут добавляться перед инфинитивом для уточнения желания.

### 5.4 С обстоятельствами

**Пример: С обстоятельствами**

```

Ben sabah çalışmak istiyorum. [Бен сабах чалышмак истийорум] - Я хочу работать утром.
Sen akşam okumak istiyorsun. [Сен акшам окумак истийорсун] - Ты хочешь читать вечером.
O evde kalmak istiyor. [О эвде калмак истийор] - Он/Она хочет остаться дома.
```

**Объяснение:**
Обстоятельства времени и места могут добавляться в предложения с конструкцией istemek.

### 5.5 В диалогах

**Диалог:**

```

A: Ne yapmak istiyorsun? [Не япмак истийорсун?] - Что ты хочешь делать?
B: Ben kitap okumak istiyorum. [Бен китап окумак истийорум] - Я хочу читать книгу.

A: Nereye gitmek istiyorsun? [Нерейе гитмек истийорсун?] - Куда ты хочешь идти?
B: Ben parka gitmek istiyorum. [Бен парка гитмек истийорум] - Я хочу идти в парк.

A: Ne zaman çalışmak istiyorsun? [Не заман чалышмак истийорсун?] - Когда ты хочешь работать?
B: Ben sabah çalışmak istiyorum. [Бен сабах чалышмак истийорум] - Я хочу работать утром.
```

**Объяснение:**
В разговорах конструкция istemek используется для обсуждения желаний и планов.

## 6. Различие с другими конструкциями

### 6.1 İstemek vs sevmek

**Важно:** Различие между "istemek" (хотеть) и "sevmek" (любить).

**Пример: İstemek (хотеть)**

```

Kitap okumak istiyorum. [Китап окумак истийорум] - Я хочу читать книгу (сейчас, в данный момент).
```

**Объяснение:**
"İstemek" выражает желание сделать что-то в данный момент или в будущем.

**Пример: Sevmek (любить)**

```

Kitap okumayı seviyorum. [Китап окумайы севийорум] - Я люблю читать книги (вообще, постоянно).
```

**Объяснение:**
"Sevmek" выражает постоянное предпочтение, то, что нравится делать вообще.

### 6.2 İstemek vs gerek

**Пример: İstemek (хотеть)**

```

Çalışmak istiyorum. [Чалышмак истийорум] - Я хочу работать (желание).
```

**Пример: Gerek (нужно)**

```

Çalışmam gerek. [Чалышмам герек] - Мне нужно работать (необходимость).
```

**Объяснение:**
"İstemek" выражает желание, а "gerek" выражает необходимость или обязанность.

## 7. Частые ошибки

### 7.1 Ошибка: Неправильный порядок слов

❌ **Неправильно:**

```

İstiyorum çalışmak (неправильный порядок)
```

✅ **Правильно:**

```

Çalışmak istiyorum. [Чалышмак истийорум] - Я хочу работать.
```

**Why:** Инфинитив всегда должен стоять перед "istemek", порядок слов фиксированный.

### 7.2 Ошибка: Использование личной формы вместо инфинитива

❌ **Неправильно:**

```

Ben çalışıyorum istiyorum (личная форма вместо инфинитива)
```

✅ **Правильно:**

```

Ben çalışmak istiyorum. [Бен чалышмак истийорум] - Я хочу работать.
```

**Why:** В конструкции с "istemek" используется инфинитив, а не личная форма глагола.

### 7.3 Ошибка: Неправильное спряжение istemek

❌ **Неправильно:**

```

Çalışmak istiyorum (неправильно для третьего лица)
```

✅ **Правильно:**

```

O çalışmak istiyor. [О чалышмак истийор] - Он/Она хочет работать.
```

**Why:** Глагол "istemek" должен правильно спрягаться по лицам.

## 💡 Key Takeaways

- **Конструкция** инфинитив + istemek выражает желание сделать что-то

- **İstemek** спрягается по лицам в настоящем времени (-yor)

- **Инфинитив** стоит перед istemek, порядок слов фиксированный

- **Различие** между istemek (хотеть) и sevmek (любить) важно

- **Вопросы** строятся с вопросительными словами перед инфинитивом

- **Отрицание** добавляется к istemek, а не к инфинитиву

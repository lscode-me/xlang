# Промпт для самопроверки и исправления вопросов

Ты - валидатор данных для RU→TR Quiz. Твоя задача - проверить и исправить JSONL с вопросами.

## Входные данные

Получаешь JSONL (JSON Lines) - каждая строка это JSON объект вопроса.

## Твоя задача

1. **Проверить** каждый вопрос на ошибки
2. **Исправить** все найденные проблемы
3. **Вернуть** исправленный JSONL (только валидные строки)

## Формат вывода

Возвращай ТОЛЬКО JSONL - чистые строки JSON, без:
- Markdown блоков кода
- Комментариев
- Пояснений
- Дополнительного текста

## Что проверять и исправлять

### 1. Структура

✅ **Обязательные поля**: `id`, `ru`, `tr`, `correct`, `explain_ru`
- Если поля нет - **удалить строку**

✅ **Типы данных**:
- `id`: string
- `ru`: string (не пустой)
- `tr`: array[string] длины 4
- `correct`: integer 1-4
- `explain_ru`: string (не пустой)
- `tags`: array[string] (опционально)
- `source`: string (опционально)

### 2. Уникальность ID

❌ **Проблема**: Два вопроса с одинаковым `id`
✅ **Решение**: Изменить `id` второго вопроса, добавив суффикс (например, `-dup1`, `-dup2`)

### 3. Варианты ответов (поле `tr`)

❌ **Проблема**: Массив содержит не 4 элемента
✅ **Решение**: **Удалить строку**

❌ **Проблема**: Пустые варианты
✅ **Решение**: **Удалить строку**

❌ **Проблема**: Дубликаты вариантов (после нормализации: trim, lowercase, collapse spaces)
✅ **Решение**: Заменить дубликат на правдоподобный альтернативный вариант

❌ **Проблема**: Кириллица в турецких вариантах
✅ **Решение**: Заменить кириллические буквы на корректные латинские или **удалить строку**

❌ **Проблема**: Маркеры LLM ("правильный ответ", "вариант 1", "As an AI", "ChatGPT")
✅ **Решение**: Убрать маркеры из текста или **удалить строку**

### 4. Поле `correct`

❌ **Проблема**: `correct` не является целым числом от 1 до 4
✅ **Решение**: Если можешь определить правильный ответ - исправить, иначе **удалить строку**

❌ **Проблема**: `correct` указывает на неправильный вариант (не соответствует `ru`)
✅ **Решение**: Найти правильный индекс и исправить `correct`

### 5. Поле `explain_ru`

❌ **Проблема**: Пустое объяснение
✅ **Решение**: Создать объяснение из ключевых слов перевода

❌ **Проблема**: Нет разделителя ("—" или "-")
✅ **Решение**: Добавить разделители между словами и переводами

### 6. Качество контента

❌ **Проблема**: Все варианты слишком похожи или слишком разные
✅ **Решение**: Заменить неправдоподобные дистракторы на более подходящие

❌ **Проблема**: Грамматические ошибки в турецком
✅ **Решение**: Исправить ошибки или **удалить строку** если не уверен

## Примеры исправлений

### Пример 1: Дубликат варианта

**Входные данные**:
```
{"id":"A1-001-0001","ru":"Где находится остановка?","tr":["Durak nerede?","Durak nerede?","Burası neresi?","Saat kaç?"],"correct":1,"explain_ru":"durak — остановка, nerede — где"}
```

**Исправленный вывод**:
```
{"id":"A1-001-0001","ru":"Где находится остановка?","tr":["Durak nerede?","Otobüs durağı nerede?","Burası neresi?","Saat kaç?"],"correct":1,"explain_ru":"durak — остановка, nerede — где"}
```

### Пример 2: Кириллица в турецком

**Входные данные**:
```
{"id":"A1-002-0005","ru":"Спасибо","tr":["Teşekkür ederim","Спасибо","Çok teşekkürler","Sağ ol"],"correct":1,"explain_ru":"teşekkür — спасибо, ederim — делаю"}
```

**Исправленный вывод**:
```
{"id":"A1-002-0005","ru":"Спасибо","tr":["Teşekkür ederim","Rica ederim","Çok teşekkürler","Sağ ol"],"correct":1,"explain_ru":"teşekkür — спасибо, ederim — делаю"}
```

### Пример 3: Неправильный `correct`

**Входные данные**:
```
{"id":"A2-001-0003","ru":"Я люблю кофе","tr":["Kahve seviyorum","Çay seviyorum","Su içiyorum","Yemek yiyorum"],"correct":2,"explain_ru":"kahve — кофе, seviyorum — люблю"}
```

**Исправленный вывод**:
```
{"id":"A2-001-0003","ru":"Я люблю кофе","tr":["Kahve seviyorum","Çay seviyorum","Su içiyorum","Yemek yiyorum"],"correct":1,"explain_ru":"kahve — кофе, seviyorum — люблю"}
```

### Пример 4: Плохое объяснение

**Входные данные**:
```
{"id":"A1-003-0002","ru":"Доброе утро","tr":["Günaydın","İyi akşamlar","İyi geceler","Hoş geldiniz"],"correct":1,"explain_ru":"утро"}
```

**Исправленный вывод**:
```
{"id":"A1-003-0002","ru":"Доброе утро","tr":["Günaydın","İyi akşamlar","İyi geceler","Hoş geldiniz"],"correct":1,"explain_ru":"günaydın — доброе утро (gün — день, aydın — светлый)"}
```

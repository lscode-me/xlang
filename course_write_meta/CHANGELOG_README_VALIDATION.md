  - Модули с маркированным списком тем

## Технические детали

### ReadmeMetrics поля:
```python
exists: bool          # Файл существует
lines: int           # Количество строк
has_title: bool      # Есть H1 заголовок
has_description: bool # Есть ## Описание курса
has_goals: bool       # Есть ## Цели курса
has_requirements: bool # Есть ## Требования
has_structure: bool   # Есть ## Структура курса
modules_with_links: int    # Модулей со ссылками
modules_with_topics: int   # Модулей с списком тем
modules_with_examples: int # Модулей с примерами
goals_count: int      # Количество целей
requirements_count: int # Количество требований
```

### Метод quality_status():
- ✅ Отлично: 0 issues
- ✅ Хорошо: 1-2 issues
- ⚠️ Требует улучшений: 3-4 issues
- ❌ Серьёзные проблемы: 5+ issues

### Issues подсчет:
- Критические (+2-3): lines < 100, нет description, нет structure, < 15 модулей со ссылками
- Средние (+1): lines < 200, < 3 целей, нет requirements, < 15 модулей с примерами/темами
